Kaplan-Meier 곡선

같은 분류로 생존곡선을 그립니다. 코드는 실습 7 나 절의 군별 곡선과 같습니다.

Cox 모형

코드는 실습 11 나 절의 단변수 Cox 모형과 같습니다. 뒤에서 위험비와 신뢰구간을 여러 번 적어야 하므로, 한 줄로 뽑아 주는 함수 hr_ci를 함께 만들어 둡니다.

출력의 time fit was run 줄은 모형을 적합한 시각이어서 실행할 때마다 다릅니다.

코드 한 줄씩

  1. cph.fit(d, duration_col="fu_days", event_col="died", formula="ever")추적 일수와 사망 여부를 알려 주고, 모형에 넣을 변수를 formula로 지정합니다. formula를 쓰면 표에 있는 다른 열(id, rx_day)은 모형에 들어가지 않습니다.
  2. def hr_ci(model, name):적합한 모형과 변수 이름을 받아 "위험비 (하한-상한)" 글자를 돌려주는 함수입니다.
  3. r = model.summary.loc[name]결과표 summary에서 그 변수의 행을 꺼냅니다. r["exp(coef)"]가 위험비, r["exp(coef) lower 95%"]와 r["exp(coef) upper 95%"]가 95% 신뢰구간의 두 끝입니다.
  4. return f"{r['exp(coef)']:.2f} ({lo:.2f}-{hi:.2f})"세 숫자를 소수 둘째 자리로 맞춰 한 문자열로 만듭니다. CoxPHFitter와 CoxTimeVaryingFitter 모두 summary의 열 이름이 같아서 두 모형에 함께 쓸 수 있습니다.

출력 읽기

  1. 1사건 1,234건. 사망 수가 셀 3과 같은지 먼저 봅니다.
  2. 2coef −1.004. 로그 위험비입니다.
  3. 3exp(coef) 0.366. 위험비입니다.
  4. 495% 신뢰구간의 하한 0.323. 출력 칸을 오른쪽으로 밀면 보입니다.
  5. 5상한 0.416.
  6. 6P < 0.0005. 통계적으로는 매우 뚜렷합니다. P값은 설계가 옳은지를 알려 주지 않습니다.
  7. 7HR 0.37 (0.32–0.42). 16장 표 16-2의 ①과 같은 값입니다. 약물 X는 효과가 없으므로 이 숫자는 전부 편향입니다.

이런 오류가 나면 · NaNs were detected

formula를 빼면 lifelines는 시간과 사건 열을 뺀 나머지 열을 모두 공변량으로 넣으려 합니다. 이 자료에서는 결측이 있는 rx_day가 들어가 아래 오류가 납니다. formula로 변수를 지정하거나 d[["fu_days", "died", "ever"]]처럼 필요한 열만 골라 넣습니다. 일부러 오류를 내는 셀이어서 노트북 파일에는 넣지 않았습니다. 노트북에서 셀 7 다음이 셀 9인 것은 그 때문입니다.

흔한 오해 · 이 위험비를 읽을 때

HR 0.37이므로 약물 X를 쓰면 사망 위험이 63% 줄어든다. 0.37은 편향으로 만들어진 값입니다. 편향이 없더라도 위험비는 위험률의 비이고 1년 사망 위험의 비가 아닙니다. 같은 분류에서 1년 사망 위험의 비(상대위험도)는 셀 5의 0.42로 위험비와 다릅니다(16장 가 절 흔한 오해).

사용군이 죽을 수 없었던 시간

다.랜드마크 분석

라.시간의존 Cox 모형

두 번째 해법은 사람을 두 군으로 나누지 않고 시간을 두 상태로 나누는 것입니다(16장 다 절). 약을 시작한 환자의 추적 시간을 첫 처방일에서 잘라 앞부분은 비노출, 뒷부분은 노출로 셉니다. 이렇게 시간에 따라 값이 바뀌는 노출이 시간의존 노출(time-varying exposure)입니다. 그러려면 한 사람 한 줄인 자료를 한 사람이 여러 줄인 긴 형식(long format)으로 바꿔야 합니다. 실습 11 다 절에서는 모든 환자를 같은 시점(3년)에서 나눴습니다. 여기서는 환자마다 다른 시점(자기의 첫 처방일)에서 나누고, 나뉜 두 줄의 노출 값이 다릅니다.

긴 형식으로 바꾸기

환자는 두 종류입니다. 약을 시작한 사람은 처방 전과 처방 후의 두 줄이 되고, 시작하지 않은 사람은 한 줄 그대로입니다. 세 가지 줄을 따로 만든 뒤 이어 붙입니다.

표 이름누구의 어느 구간startstopdrugxdied
before시작한 사람의 처방 전0rx_day00
after시작한 사람의 처방 후rx_dayfu_days1원래의 died
never시작하지 않은 사람의 전 기간0fu_days0원래의 died

코드 한 줄씩

  1. u = d[d["ever"] == 1], nu = d[d["ever"] == 0]셀 9와 같습니다. 약을 시작한 2,734명과 시작하지 않은 3,266명입니다.
  2. before = pd.DataFrame({"id": u["id"], "start": 0.0, "stop": u["rx_day"], "drugx": 0, "died": 0})열 이름과 값을 짝지어 새 표를 만듭니다. u["id"]와 u["rx_day"]는 2,734개 값이 든 열이고, 0.0과 0처럼 숫자 하나를 적으면 모든 줄에 같은 값이 채워집니다. 뜻은 "퇴원일(0)부터 첫 처방일까지, 비노출, 이 구간 끝에 사망 없음"입니다. 첫 처방을 받은 날에는 살아 있었으므로 died는 반드시 0입니다.
  3. after = pd.DataFrame({…, "start": u["rx_day"], "stop": u["fu_days"], "drugx": 1, "died": u["died"]})같은 2,734명의 둘째 줄입니다. 첫 처방일에서 시작해 추적 종료일에 끝나고 노출 상태입니다. 원래의 사망 여부는 이 줄에만 적습니다.
  4. never = pd.DataFrame({…, "start": 0.0, "stop": nu["fu_days"], "drugx": 0, "died": nu["died"]})약을 시작하지 않은 3,266명은 처음부터 끝까지 비노출인 한 줄입니다.

  6. long.sort_values(["id", "start"]).reset_index(drop=True)환자 번호, 구간 시작 순으로 정렬해 한 환자의 줄이 시간 순서대로 붙어 있게 합니다. 세 표가 원래의 행 번호를 달고 와서 번호가 겹치므로 reset_index(drop=True)로 0부터 새로 매깁니다.

출력 읽기

  1. 16,000명이 8,734줄. 약을 시작한 2,734명이 두 줄씩 되었습니다. 16장 다 절의 8,734줄과 같습니다.
  2. 20번 환자. 약을 시작하지 않고 177.8일째에 사망했습니다. 한 줄이고 drugx 0, died 1입니다.
  3. 32번 환자의 첫 줄. 0일부터 249.9일까지 비노출이고 died 0입니다. 나 절의 분석은 이 249.9일을 사용군의 시간으로 셌습니다.
  4. 42번 환자의 둘째 줄. 249.9일부터 365일까지 노출이고, 1년까지 생존했으므로 died 0입니다.

표 16-4의 환자 세 명

16장 표 16-4에 실린 환자 A, B, C는 이 자료의 298번, 64번, 3번입니다. 방금 만든 자료에서 꺼내 표와 같은지 확인합니다.

코드 한 줄씩

  1. ex = {298: "A", 64: "B", 3: "C"}환자 번호와 표 16-4의 이름을 짝지은 사전입니다.
  2. long[long["id"].isin(ex)]id가 사전의 번호(298, 64, 3) 가운데 하나인 줄만 고릅니다.
  3. t["patient"] = t["id"].map(ex)번호를 이름으로 바꾼 열을 만듭니다(실습 2 가 절의 map).
  4. t[["start", "stop"]] = t[["start", "stop"]].round().astype(int)표 16-4처럼 일수를 정수로 반올림해 보여 줍니다. 분석에는 반올림하지 않은 long을 씁니다.

출력 읽기

  1. 1환자 A의 첫 줄. 126일째 첫 처방 전까지 비노출입니다.
  2. 2환자 A의 둘째 줄. 노출 상태로 301일째에 사망했습니다. 사망은 이 줄에만 1로 적혀 있습니다.
  3. 3환자 B. 약을 시작하지 않고 44일째에 사망해 한 줄입니다.
  4. 4환자 C. 49일째에 시작해 365일까지 생존했습니다. 다섯 줄 모두 표 16-4와 같습니다.

긴 형식 자료 점검

긴 형식 자료의 오류는 모형이 알려 주지 않습니다. 틀린 자료도 오류 없이 적합되어 그럴듯한 위험비를 냅니다. 16장 다 절 '내 연구에 쓸 때'의 확인 항목을 코드로 옮깁니다. 구간이 겹치거나 비지 않는지, 사망이 마지막 줄에만 있는지, 인년의 합이 원래 자료와 같은지입니다.

코드 한 줄씩

  1. g = long.groupby("id")환자별로 묶은 것을 변수에 담아 여러 번 씁니다.
  2. prev_stop = g["stop"].shift()shift()는 값을 한 줄 아래로 밉니다. 환자별로 묶은 뒤에 쓰면 같은 환자 안에서만 밉니다. 환자의 첫 줄은 앞 줄이 없어 NaN, 둘째 줄에는 그 환자 첫 줄의 stop이 들어갑니다.
  3. second = long[prev_stop.notna()]앞 줄이 있는 줄, 곧 둘째 줄만 고릅니다.
  4. (second["start"] == prev_stop.dropna()).all()둘째 줄의 start가 앞 줄의 stop과 같은지 줄마다 비교하고, .all()로 전부 True인지 확인합니다. 다른 줄이 있으면 구간이 겹치거나 빈 것입니다.
  5. (long["stop"] <= long["start"]).sum()길이가 0이거나 음수인 구간의 수입니다. 퇴원 당일 처방처럼 start와 stop이 같은 줄이 있으면 미리 정리해야 합니다.
  6. last = g.tail(1)환자마다 마지막 한 줄을 뽑습니다.

출력 읽기

  1. 1둘째 줄 2,734줄. 약을 시작한 사람의 수와 같습니다.
  2. 2True. 모든 둘째 줄이 첫 줄이 끝난 시점에서 시작합니다.
  3. 3길이가 0 이하인 구간 0줄.
  4. 4사망 1,234건이 모두 마지막 줄에 있고 원자료와 같습니다.
  5. 5인년 합계 5,312. 원자료의 전체 추적 시간과 같습니다. 줄을 나눠도 시간의 총량은 변하지 않아야 합니다.

주의 · 사망을 두 줄에 모두 적는 실수

가장 흔한 실수는 before의 died에도 원래의 사망 여부(u["died"])를 넣는 것입니다. 그러면 사용자의 사망 321건이 두 번 세어져 사건이 1,555건이 되고, 이 자료에서 위험비가 0.81(0.71–0.92)로 나옵니다. 오류 메시지는 없습니다. 셀 16처럼 사망 수를 원자료와 맞춰 보면 바로 드러납니다.

노출 상태별 사망, 인년, 사망률

긴 형식 자료에서는 줄마다 구간의 길이가 그 줄의 인년이고, drugx가 그 인년의 노출 상태입니다. 노출 상태별로 더하면 논문의 결과표가 됩니다.

코드 한 줄씩

  1. long["py"] = (long["stop"] - long["start"]) / 365줄마다 구간의 길이를 연으로 바꾼 열입니다.
  2. long.groupby("drugx").agg(deaths=("died", "sum"), py=("py", "sum"))노출 상태별로 사망 수와 인년을 더합니다. 새 이름=("열", "함수") 형식은 실습 4 라 절에서 쓴 것과 같습니다.
  3. t3.round({"py": 0, "rate": 1})열마다 반올림 자릿수를 다르게 줍니다. 인년은 정수로, 사망률은 소수 첫째 자리로 보여 줍니다.

출력 읽기

  3. 3비노출 3,841인년. 비사용자의 2,699인년에 사용자의 처방 전 1,142인년을 더한 값입니다(셀 9). 나 절에서 사용군에 잘못 들어갔던 시간이 제자리로 왔습니다.
  4. 4비노출 사망률 100인년당 23.8.

lifelines 함수로 같은 자료 만들기

lifelines에는 긴 형식을 만들어 주는 함수가 있습니다. 직접 만든 자료와 결과가 같은지 확인해 둡니다. 과제 3에서 이 함수의 delay 인자를 씁니다.

코드 한 줄씩

  1. base = to_long_format(d[["id", "fu_days", "died"]], duration_col="fu_days")한 사람 한 줄 자료에 start = 0, stop = 추적 일수 열을 만들어 긴 형식의 출발점으로 삼습니다. 필요한 세 열만 골라 넣었습니다.
  2. rx = d.loc[d["ever"] == 1, ["id", "rx_day"]].assign(drugx=1)약을 시작한 사람의 번호와 첫 처방일만 뽑고, 값이 모두 1인 drugx 열을 붙입니다. "이 사람은 이 시점부터 drugx가 1"이라는 사건 목록입니다.

  • 긴 형식은 세 가지 줄을 만들어 이어 붙입니다. 시작한 사람의 처방 전(비노출, 사망 0), 처방 후(노출, 원래의 사망 여부), 시작하지 않은 사람의 전 기간(비노출)입니다. 6,000명이 8,734줄이 됩니다.
