a.보정할 변수 고르기

보정할 변수를 늘리면 상대위험도는 어떻게 움직이나?

결과가 예/아니오인 자료에서 상대위험도를 바로 구하려고, 포아송 분포의 glm()에 강건 분산(sandwich::vcovHC(type = "HC0"))을 붙인 수정 포아송 회귀를 씁니다. 예는 보건통계학 기초 15장 a 절의 코호트입니다. 약물 A 사용자 4,053명과 B 사용자 5,947명의 1년 안 입원을 비교하고, 허약(frail)은 실제 청구자료에는 없지만 이 가상 자료에는 심어 둔 교란변수입니다.

  1. 1보정 전 1.33(1.19–1.48). A가 입원을 33% 늘리는 것처럼 보입니다.
  2. 2측정한 7개 변수를 모두 넣으면 0.93(0.83–1.05). 15장 a 절 표의 숫자입니다. 강건 분산 대신 glm()의 기본 분산을 쓰면 포아송 분산을 가정해 구간이 넓게 나옵니다.
  3. 3허약까지 넣으면 0.80(0.71–0.90). 이 자료에 심어 둔 참값입니다. 실제 연구에서는 이 줄을 구할 수 없습니다.

보건통계학 기초 15장의 '직접 분석' 상자와 본문에 있던 내용입니다.

파이썬에서는 statsmodels의 GEE(..., family=Poisson(), cov_struct=Independence()) 또는 GLM(..., family=Poisson()).fit(cov_type="HC0")로 적합합니다.

GEE는 강건 분산이 기본값이고, GLM은 cov_type="HC0"를 적어야 강건 분산이 됩니다. 두 방법의 결과는 R의 vcovHC(type = "HC0")와 같습니다.

b.성향점수의 추정과 겹침

성향점수 모형은 어떻게 적합하고 무엇을 보나?

치료(drugA)를 결과변수로 둔 로지스틱 회귀를 glm(…, family = binomial)으로 적합하고, fitted()로 환자마다의 성향점수를 꺼냅니다. 두 군의 점수 범위와 C 통계량은 점수 열로 직접 구합니다. 보건통계학 기초 15장 b 절의 모형입니다.

  1. 1age 0.0265. 계수는 '누가 A를 처방받았나'의 처방 양상입니다. 심부전(hf)의 계수 0.757을 오즈비로 바꾸면 2.13이고, 약의 효과와는 관계가 없습니다. 유의하지 않은 변수(female, P = 0.075)도 미리 정한 변수이므로 그대로 둡니다.
  2. 2분석 인원 10,000명. glm()은 공변량이 비어 있는 행을 경고 없이 빼므로, nobs()가 코호트 인원과 같은지 먼저 봅니다. 결측이 있으면 fitted()는 그 환자를 빼고 짧은 벡터를 돌려주어, 그대로 열에 넣으면 오류가 납니다(predict(ps_fit, newdata = d, type = "response")는 그 자리에 NA를 둡니다).
  3. 3B군 0.130–0.896, A군 0.149–0.932. 범위가 거의 같아 겹침이 좋습니다. 분포 그림도 함께 봅니다.
  4. 4C 통계량 0.658. A군 점수의 순위 합으로 구한 Mann–Whitney 통계량을 비교한 쌍의 수로 나눈 값입니다. 성향점수 모형의 목적은 예측이 아니므로 C 통계량이 높을 필요는 없습니다.
  5. 5두 환자 0.881과 0.253. 15장 b 절에서 손으로 계산한 78세 여성과 58세 남성의 점수입니다.

보건통계학 기초 15장의 '직접 분석' 상자와 본문에 있던 내용입니다.

환자 한 명이 한 줄인 표 df가 있으면 앞의 성향점수 모형은 statsmodels에서 다음 두 줄입니다.

# 파이썬 (statsmodels)
fit = smf.logit("drugA ~ age + female + hf + ckd"
                " + prior_hosp + n_drug + tertiary", data=df).fit()
df["ps"] = fit.predict(df)

프로그램이 내놓는 것은 변수마다의 계수와, fit.predict(df)로 얻는 환자마다의 성향점수입니다. 두 군의 점수 분포 그림, 점수의 범위, C 통계량은 따로 주지 않으므로 점수 열로 직접 구합니다(보건통계학 기초 15장 b 절 '두 군의 점수는 겹치는가?'). 나이 같은 연속형 변수를 어떤 형태로 넣을지는 균형을 본 뒤 정하며, 고치는 법은 보건통계학 기초 15장 d 절 '성향점수 모형은 어떻게 고치나?'에 있습니다.

결측이 있거나 scikit-learn을 쓰면.

statsmodels 0.15.0과 scikit-learn 1.9.1로 이 코호트에서 확인한 동작입니다.

상황프로그램이 하는 일
공변량에 결측이 있음statsmodels의 모형식은 결측이 있는 행을 경고 없이 빼고 적합합니다. 10명의 나이를 결측으로 두면 No. Observations가 9,990이고, fit.predict(df)는 그 10명에게 점수 대신 NaN을 줍니다. 가중 분석(GEE)은 이 10명을 빼고 계산합니다. 그러나 실습 15의 match_1to1처럼 np.argmin으로 짝을 찾는 함수는 B 사용자 한 명의 점수만 NaN이어도 짝을 하나도 만들지 못합니다(이 코호트에서 0쌍, 경고 없음)
scikit-learn을 기본값으로 씀LogisticRegression()은 계수를 0 쪽으로 줄이는 규제(penalty)를 기본으로 겁니다(C = 1.0인 L2 규제). statsmodels 점수와의 차이는 이 코호트에서 최대 0.0015이지만, 300명을 뽑은 부분 표본에서는 최대 0.030입니다
scikit-learn에서 규제를 끔LogisticRegression(C=np.inf)로 끄면 statsmodels 점수와의 차이가 0.001 미만입니다. 점수는 predict_proba(X)[:, 1]입니다. 1.8 이전 버전은 penalty=None으로 끄고, 1.9.1에서 penalty를 쓰면 곧 없어질 인자라는 경고가 납니다

그래서 분석 인원 fit.nobs가 코호트 인원과 같은지 먼저 봅니다. 결측으로 빠지는 환자가 있으면 몇 명이 왜 빠지는지 확인하고 처리 방법을 정합니다(보건통계학 기초 9장의 접힌 상자 '결측값이 있으면 프로그램은 어떻게 하나?'). scikit-learn을 쓴다면 표본이 작을수록 규제가 점수를 더 많이 바꾸므로 규제를 끕니다. 다만 규제를 꺼도 반복 계산을 멈추는 기준이 달라 점수가 소수 넷째 자리에서 차이 나고, 이 작은 차이로도 매칭의 짝이 바뀔 수 있습니다(c 절의 파이썬 상자). C 통계량은 scikit-learn의 roc_auc_score(df["drugA"], df["ps"])로 구하고, 이 코호트에서 0.658입니다.

c.매칭과 가중

1:1 매칭은 어떻게 하나?

A 사용자를 정한 순서대로 하나씩 꺼내, 아직 짝이 없는 B 사용자 가운데 로짓 성향점수가 가장 가까운 사람을 고릅니다. 거리가 허용 한계(로짓 표준편차의 0.2배)를 넘으면 짝을 짓지 않습니다. 보건통계학 기초 15장 c 절의 설계입니다. A 사용자를 짝짓는 순서는 15장과 같은 무작위 순서를 파일로 읽어, 같은 짝이 나오게 했습니다.

  1. 1허용 한계 0.1232, 3,516쌍, 짝을 못 찾은 A 사용자 537명. A 사용자의 86.8%가 짝을 찾았습니다.
  2. 2짝을 못 찾은 A 사용자: 평균 성향점수 0.687, 나이 75.7세, 심부전 52.7%. 짝을 찾은 사람(0.418, 66.7세, 9.0%)보다 훨씬 아픈 사람들입니다. 매칭 결과는 이들을 뺀 A 사용자에 대한 효과입니다(15장 c 절 '예제 코호트에서는 누가 짝을 못 찾았나?').

MatchIt으로 하면 무엇이 같고 무엇이 다른가?

MatchIt 패키지의 matchit()에 같은 성향점수 모형과 method = "nearest", 로짓 거리(link = "linear.logit"), caliper = 0.2, 무작위 순서(m.order = "random")를 주면 같은 설계의 매칭이 됩니다. 짝 번호는 match.data()가 돌려주는 subclass 열에 있습니다.

  1. 13,521쌍. 순서를 정한 난수가 달라 위의 3,516쌍과 짝이 조금 다릅니다.
  2. 2RR 0.93(0.82–1.05). 위 매칭의 0.91과 끝자리가 다릅니다. 비복원 매칭은 짝짓는 순서에 따라 결과가 이만큼 흔들리므로, 순서를 정한 방법과 seed를 기록합니다. m.order의 기본값은 성향점수가 큰 사람부터 짝짓는 "largest"이고, caliper는 기본으로 거리 표준편차의 배수로 읽습니다(std.caliper = TRUE).

가중치는 어떻게 만들고 얼마나 커졌나?

역확률 가중치, 안정화 가중치, A 사용자 기준(ATT) 가중치, 겹침 가중치는 모두 성향점수로 만든 한 줄 식입니다. 가중치의 범위와 합, 유효 표본 크기(가중치 합의 제곱 ÷ 가중치 제곱의 합)를 함께 봅니다.

  1. 1역확률 가중치 1.07–9.58. 가장 큰 가중치는 점수가 낮은데 A를 받았거나 높은데 B를 받은 사람에게 갑니다.
  2. 2안정화 가중치 0.43–5.70. 군의 비율을 분자에 둬 평균이 1 근처이고 가중 후 인원이 원래 인원과 비슷합니다.
  3. 3가중치 합 A 10,040, B 9,975, 유효 표본 크기 A 3,597, B 5,471. 두 군 모두 코호트 전체(10,000명)의 모습으로 맞춰졌습니다. 유효 표본 크기가 실제 인원보다 작은 만큼 정보가 줄었습니다.

보건통계학 기초 15장의 '직접 분석' 상자와 본문에 있던 내용입니다.

매칭과 가중에 넣는 것은 b 절에서 구한 성향점수 열과 치료 열(약물 A = 1, B = 0)입니다. 결과 사건인 입원은 이 단계에서 쓰지 않습니다. 위에서 본 역확률 가중치와 ATT 가중치는 numpy로 한 줄씩 만듭니다.

# 파이썬 (numpy). ps는 성향점수 열
w_ate = np.where(df["drugA"] == 1, 1 / df["ps"], 1 / (1 - df["ps"]))   # 역확률 가중치
w_att = np.where(df["drugA"] == 1, 1, df["ps"] / (1 - df["ps"]))       # ATT 가중치

성향점수 매칭 함수는 statsmodels, scipy, lifelines에 없습니다. scikit-learn의 NearestNeighbors로 가장 가까운 상대를 찾을 수는 있지만, 한 번 쓴 B 사용자를 다시 쓰는 복원 매칭만 됩니다. 그래서 비복원 매칭과 허용 한계는 반복문으로 직접 짭니다(실습 15 c 절). 매칭의 비율, 허용 한계, 복원 여부, A 사용자를 짝짓는 순서, 가중치의 종류는 프로그램이 정해 주지 않으므로 분석 전에 정합니다. 이 선택이 결과를 얼마나 바꾸는지는 보건통계학 기초 15장 c 절 '예제 코호트에서는 누가 짝을 못 찾았나?'와 '예제 코호트의 가중치는 얼마나 커졌나?'의 접힌 상자들에 있습니다. 성향점수를 어느 프로그램으로 구했는지도 짝을 바꿉니다. scikit-learn에서 규제를 꺼도 점수가 소수 넷째 자리에서 달라, 이 코호트에서는 statsmodels 점수로 매칭했을 때의 상대위험도 0.91이 0.92가 됩니다(규제를 켜 둔 기본값이면 0.90, 실습 15 b 절).

치료군이 셋 이상이면 statsmodels의 MNLogit으로 확률을 구하고 가중치는 직접 계산합니다.

d.균형 진단과 효과 추정

두 군이 비슷해졌는지는 무엇으로 보나?

가중 평균과 가중 분산으로 표준화 평균차(SMD)를 구하는 함수를 몇 줄로 짜서, 매칭 전, 매칭 후, 가중 후를 한 표로 봅니다. 0/1 변수도 같은 식으로 구합니다. 보건통계학 기초 15장 d 절의 균형표입니다.

  1. 1매칭 전: 나이 0.35, 허약 0.40. 0.1을 넘는 변수가 여럿입니다.
  2. 2매칭 후: 측정한 7개 변수는 모두 0.02 이하, 허약은 0.34. 성향점수 모형에 넣지 않은 변수는 맞춰지지 않습니다. 실제 연구에서는 이 마지막 열을 볼 수 없습니다.

cobalt 패키지의 bal.tab()도 같은 표를 만듭니다. 가중 후 SMD의 분모를 가중 전 표준편차로 두는 것이 기본값이라, 이 함수와 셋째 자리가 다를 수 있으므로 어느 분모를 썼는지 적습니다.

효과와 신뢰구간은 어떻게 구하나?

결과 모형에는 치료 변수 하나만 넣고, 매칭 자료는 짝 번호로 묶은 강건 분산(vcovCL(…, cluster = ~ pair))을, 가중 자료는 환자 단위 강건 분산(vcovHC())을 씁니다. 15장 d 절 효과 추정 표의 숫자입니다.

  1. 1매칭 0.91(0.80–1.03). 짝을 무시해도 이 코호트에서는 구간이 거의 같습니다.
  2. 2역확률 가중 0.95(0.85–1.07). 그 아래 ATT 가중 0.97, 겹침 가중 0.94는 맞추는 대상이 다른 효과입니다.
  3. 3모형 기반 분산 0.88–1.04. 가중치를 인원처럼 세어 약 20,000명이 있는 것처럼 계산하므로 지나치게 좁습니다. R은 이 경우 경고를 내지 않습니다.
  4. 4위험차 −0.54%p(−1.86 ~ 0.78). 가중 자료에 정규분포(gaussian)의 glm()을 적합하고 같은 강건 분산을 붙였습니다.
  1. 1가중 Cox 모형 0.95(0.84–1.08). coxph()는 가중치가 0이나 1이 아니면 강건 분산을 기본으로 씁니다. 매칭 자료는 cluster = pair를 적어 짝 단위 강건 분산을 씁니다.
  2. 2짝을 층으로 둔 모형 0.90(0.78–1.03). 짝 안에서의 효과(조건부 효과)이고, 강건 분산 모형(0.90, 0.79–1.04)은 집단 전체의 평균 효과입니다.

부트스트랩 구간은 강건 분산과 무엇이 다른가?

자료를 복원추출로 다시 뽑아 성향점수 추정부터 가중 상대위험도까지 500번 되풀이하고, 로그 상대위험도의 2.5·97.5번째 백분위수를 지수로 되돌립니다.

  1. 1부트스트랩 표준오차 0.0585 대 강건 0.0598. 성향점수를 표본에서 추정한 데서 오는 정밀도 이득까지 담아 조금 작습니다. 구간 0.85–1.05는 15장의 0.85–1.06과 난수가 달라 끝자리가 다릅니다.

보건통계학 기초 15장의 '직접 분석' 상자와 본문에 있던 내용입니다.

SMD는 위의 세 단계를 몇 줄의 함수로 옮겨 직접 계산합니다(실습 15 d 절의 smd 함수). 가중 후에는 평균과 분산을 모두 가중해서 구합니다. 가중 평균은 np.average(x, weights=w)로 구합니다. 가중 분산은 각 값에서 가중 평균을 뺀 뒤 제곱하고, 그 값들을 같은 가중치로 다시 평균해 구합니다.

교란은 매칭이나 가중으로 이미 다뤘으므로 결과 모형에는 보통 치료 변수 하나만 넣습니다. 그래서 프로그램에 넣는 것도 간단합니다. 결과 열과 치료 열 하나를 넣고, 매칭 자료에는 짝 번호를, 가중 자료에는 가중치 열을 함께 넣습니다. 이 장의 상대위험도는 statsmodels의 포아송 GEE로, 위험비는 lifelines의 Cox 모형으로 구했습니다(포아송 GEE는 보건통계학 기초 12장 b 절의 접힌 상자 '결과가 예/아니오인데 상대위험도를 구하려면?'). 짝 번호와 가중치를 넣는 인자는 아래와 같습니다.

프로그램에서는 다음처럼 넣습니다. statsmodels 0.15와 lifelines 0.30에서 확인한 것이고, 버전에 따라 다를 수 있습니다.

  • 상대위험도. statsmodels의 GEE에 포아송 분포와 독립 작업상관을 주고, 가중치는 weights에, 환자 번호(매칭 자료는 짝 번호)는 groups에 넣습니다. GEE는 강건 분산이 기본값입니다. 같은 모형을 GLM으로 적합하면 기본값이 모형 기반 분산이라 cov_type="HC0"를 적어야 합니다. 이때 보통의 가중치를 freq_weights에 넣으면 HC0를 적어도 구간이 0.88–1.03으로 좁고, var_weights에 넣으면 0.85–1.07이 나옵니다.
  • 위험차. 같은 GEE에서 분포를 정규분포(Gaussian())로 바꾸면 위험차와 그 강건 신뢰구간이 나옵니다. statsmodels의 TreatmentEffect(…).ipw()는 성향점수 추정까지 반영한 위험차와 두 잠재결과의 평균(A 11.04%, B 11.58%)을 주고, effect_group=1이면 A 사용자 기준 효과를 줍니다. 상대위험도는 주지 않습니다.
  • 위험비. lifelines의 CoxPHFitter().fit(…, weights_col="w")는 robust=False가 기본값이라, 가중치가 정수가 아니면 경고를 내고 모형 기반 분산으로 계산합니다. robust=True를 적거나, 매칭 자료에서 cluster_col="pair"로 짝 번호를 주면 강건 분산이 됩니다. 가중 Kaplan-Meier 곡선은 KaplanMeierFitter().fit(T, E, weights=w)입니다.

위험차의 표준오차는 강건 분산으로 0.0067, 성향점수 추정까지 반영한 TreatmentEffect(…).ipw()로 0.0066이었습니다.

짝을 층으로 둔 Cox 모형은 statsmodels에서 smf.phreg("hosp_day ~ drugA", data=m, status="hosp_1y", strata="pair")로 적합합니다(실습 15 d 절).

e.남는 교란과 민감도 분석

음성 대조 결과에서는 무엇이 나와야 하나?

두 약 모두와 관계가 없어야 하는 결과(손상으로 인한 응급실 방문, injury_ed)를 같은 매칭·가중 자료에서 분석합니다. 1에서 멀면 측정하지 못한 교란이 남았다는 흔적입니다. 보건통계학 기초 15장 e 절의 점검입니다.

  1. 1보정 전 1.47(1.27–1.70).
  2. 2가중 후에도 1.26(1.08–1.47). 측정한 변수를 맞춘 뒤에도 A군이 손상 방문이 많습니다. 허약처럼 두 결과 모두에 영향을 주는 변수가 남았다는 신호입니다.

E-value는 어떻게 구하나?

상대위험도 RR(1보다 작으면 역수)로 RR + √(RR × (RR − 1))을 계산합니다. 신뢰구간은 1에 가까운 끝으로 같은 계산을 하고, 구간이 1을 포함하면 1입니다. 반올림하지 않은 추정값으로 계산합니다.

  1. 1보정 전 1.99, 신뢰한계 1.67.
  2. 2매칭 1.44, 신뢰한계 1.00. 반올림 전의 0.908로 계산해 1.44이고, 15장 본문의 1.43은 0.91로 계산한 값입니다. 구간이 1을 포함해 신뢰한계의 E-value는 1입니다.

보건통계학 기초 15장 '장 마무리'의 '프로그램에는 무엇을 입력하나?'에 있던 내용입니다.

여기까지 정했으면 프로그램에서는 아래 코드를 차례로 실행합니다. 이 장의 예제와 같은 열 이름으로 적었습니다. 매칭 함수는 statsmodels와 scikit-learn에 없고 균형 진단용 SMD는 몇 줄이면 되므로, 두 함수(match_1to1, smd)는 실습 15에서 직접 짠 것을 씁니다.

# 파이썬 (statsmodels, lifelines). 불러오기와 df는 실습 15와 같음
covs = ["age", "female", "hf", "ckd", "prior_hosp",
        "n_drug", "tertiary"]
# 1. 성향점수: 결과변수는 치료(drugA). 입원은 넣지 않음
ps_fit = smf.logit("drugA ~ " + " + ".join(covs), data=df).fit()
df["ps"] = ps_fit.predict(df)
# 2. 겹침: 두 군의 점수 범위 (분포 그림도 함께 봄)
df.groupby("drugA")["ps"].agg(["min", "max"])
# 3. 가중치. a는 A 사용자이면 True
a = df["drugA"] == 1
pA = a.mean()
df["sw"] = np.where(a, pA / df["ps"], (1 - pA) / (1 - df["ps"]))
df["w_att"] = np.where(a, 1, df["ps"] / (1 - df["ps"]))
#    매칭은 실습 15의 match_1to1()로 짝을 만든 표 m (짝 번호 pair)
# 4. 균형: 실습 15의 smd()로 매칭 전후, 가중 후의 SMD
# 5. 효과와 강건 분산: groups에 매칭은 짝 번호, 가중은 환자 번호
opt = dict(family=sm.families.Poisson(),
           cov_struct=sm.cov_struct.Independence())
fit_m = smf.gee("hosp_1y ~ drugA", groups="pair", data=m, **opt).fit()
fit_w = smf.gee("hosp_1y ~ drugA", groups="id", data=df,
                weights=df["sw"], **opt).fit()
cox_m = CoxPHFitter().fit(m, "hosp_day", "hosp_1y",
                          formula="drugA", cluster_col="pair")
# 6. 민감도: 가중치 열(w_att)이나 결과 열(injury_ed)만 바꿔 다시 실행
r = np.exp(fit_m.params["drugA"])
r = 1 / r if r < 1 else r
evalue = r + np.sqrt(r * (r - 1))     # E-value (점추정값)

실행하면 이 장의 숫자가 그대로 나옵니다. 상대위험도는 매칭 0.91(0.80–1.03), 역확률 가중 0.95(0.85–1.07)이고, 매칭 자료의 위험비는 0.90(0.79–1.04)입니다. E-value는 반올림 전의 RR 0.908로 계산되어 1.44입니다(보건통계학 기초 15장 본문의 1.43은 0.91로 계산한 값).

이때 프로그램의 기본값이 결과를 바꾸는 곳이 네 군데 있습니다. statsmodels 0.15, scikit-learn 1.9, lifelines 0.30에서 확인한 것이고, 버전에 따라 다를 수 있습니다.

  • 결측. smf.logit은 공변량이 비어 있는 행을 경고 없이 빼고 모형을 적합합니다. 그다음 predict를 실행하면 해당 환자의 점수가 빈 값(NaN)이 되고, 이 NaN이 남아 있으면 직접 짠 매칭 함수가 짝을 만들지 못합니다. 요약표의 No. Observations가 코호트 인원과 같은지 봅니다(b 절의 파이썬 상자).
  • 규제. scikit-learn의 LogisticRegression()은 기본값으로 계수를 줄이는 규제를 걸어 statsmodels와 점수가 조금 다릅니다. 규제를 끄는 법은 같은 접힌 상자에 있습니다.
  • 매칭 순서. 비복원 매칭은 A 사용자를 짝짓는 순서에 따라 짝과 결과가 조금 달라지므로, 순서를 정한 seed를 적어 둡니다(보건통계학 기초 15장 c 절의 접힌 상자 '복원 여부, 매칭 비율, 매칭 순서는 결과를 얼마나 바꾸나?').
  • 분산. statsmodels의 GEE는 강건 분산이 기본값이지만 GLM은 아니고, lifelines의 가중 Cox 모형은 robust=True나 cluster_col을 적어야 강건 분산이 됩니다(d 절의 파이썬 상자).

정답 코드와 풀이
