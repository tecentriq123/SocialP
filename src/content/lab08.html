비율의 95% 신뢰구간

비율의 구간을 만드는 방법은 여럿입니다. 교과서의 기본 공식(Wald 구간)은 표본이 작거나 비율이 0이나 1에 가까우면 실제 포함 확률이 95%보다 낮아지므로 Wilson 구간(또는 Jeffreys 구간)이 권장됩니다. 정확(Clopper–Pearson) 구간도 흔히 쓰이지만 실제 포함 확률이 95%보다 높은 보수적인 구간입니다. 전체 저체중아 비율(59/189)과 고혈압 병력 산모의 저체중아 비율(7/12)로 세 방법을 비교합니다.

코드 한 줄씩

  1. from statsmodels.stats.proportion import proportion_confint비율의 신뢰구간 함수를 불러옵니다.
  2. rows = []결과를 한 줄씩 모을 빈 목록입니다. 마지막에 표로 바꿉니다.
  3. for count, n in [(59, 189), (7, 12)]:(사건 수, 인원) 두 쌍을 차례로 꺼냅니다.
  4. for method in ["normal", "wilson", "beta"]:안쪽 반복문으로 세 방법을 돌립니다. "normal"은 Wald 구간 \(p \pm 1.96\sqrt{p(1-p)/n}\), "wilson"은 Wilson 점수 구간, "beta"는 이항분포에서 직접 구하는 Clopper–Pearson 정확 구간입니다.
  5. proportion_confint(count, n, method=method)(하한, 상한)을 돌려줍니다. 신뢰수준은 기본값 95%(alpha=0.05)입니다.
  6. rows.append([…])자료 이름, 방법, 점추정값, 하한, 상한을 한 줄로 목록에 덧붙입니다.
  7. pd.DataFrame(rows, columns=cols).round(3)목록을 6행 5열의 표로 바꾸고 소수 셋째 자리로 반올림합니다.

평균의 95% 신뢰구간

출생체중 평균의 구간을 공식대로 계산합니다. 표준편차를 표본에서 추정하므로 1.96 대신 자유도 n − 1인 t 분포의 임계값을 씁니다(8장 가 절).

코드 한 줄씩

  1. bwt = df["bwt"]출생체중(g) 열을 꺼냅니다. 189개 값의 Series입니다.
  2. mean, sd = bwt.mean(), bwt.std()평균과 표준편차를 한 줄에 구합니다. pandas의 std()는 기본으로 n − 1로 나눈 표본 표준편차입니다(numpy의 np.std는 기본이 n이라 다릅니다).
  3. se = sd / np.sqrt(n)평균의 표준오차 SD/√n입니다.
  4. stats.t.ppf(0.975, n - 1)자유도 188인 t 분포에서 아래쪽 확률이 0.975인 점, 즉 양쪽에 2.5%씩 남기는 임계값입니다. ppf는 누적확률을 넣으면 값을 돌려주는 함수(분위수 함수)입니다.
  5. mean - t_crit * se mean + t_crit * se추정값 ± 임계값 × SE입니다.

부트스트랩 신뢰구간

부트스트랩(bootstrap)은 가지고 있는 표본을 모집단 삼아, 189명 중에서 복원추출로 189명을 다시 뽑는 일을 수천 번 반복하고, 매번 계산한 추정값의 흩어짐으로 신뢰구간을 만드는 방법입니다. SE 공식이 없는 통계량(중앙값의 차이, 표준화 위험, 비용의 차이 등)에도 쓸 수 있어 약물경제학 연구에서 자주 봅니다(8장 라 절). 공식이 있는 상대위험도로 먼저 해 보고 로그 척도 구간과 비교합니다.

  2. y = df["low"].to_numpy() x = df["smoke"].to_numpy()반복 계산을 빠르게 하려고 두 열을 numpy 배열로 꺼냅니다.
  3. for _ in range(2000):2,000번 반복합니다. 반복 번호를 쓰지 않으므로 변수 이름을 밑줄 _로 두었습니다.
  4. i = rng.integers(0, len(y), size=len(y))0부터 188 사이의 정수 189개를 무작위로 뽑습니다(끝값 189는 포함하지 않음). 같은 번호가 여러 번 나올 수 있으므로 복원추출입니다. 어떤 산모는 두세 번, 어떤 산모는 한 번도 뽑히지 않습니다.

인종 전체의 P: 결합 검정

"인종이 저체중아와 관련 있는가"에는 가변수 하나하나의 P가 아니라, 두 가변수의 계수가 모두 0이라는 가설을 한꺼번에 검정해 답합니다. Wald 결합 검정과 우도비 검정 두 가지로 구합니다.

코드 한 줄씩

  1. m_cat.wald_test_terms()formula의 항(term)마다 그 항에 속한 계수들이 모두 0인지 Wald 검정을 합니다. 가변수 2개로 된 인종 항은 자유도 2로 한 번에 검정됩니다. SAS의 "Type 3 Analysis of Effects"와 같은 역할입니다. statsmodels 0.14에서는 이 함수가 향후 출력 형식이 바뀐다는 FutureWarning을 함께 낼 수 있고 숫자가 대괄호 안에 표시되기도 하지만 값은 같습니다.
  2. m_smoke = smf.logit("low ~ smoke", df)인종을 뺀 작은 모형입니다.
  3. lr = 2 * (m_cat.llf - m_smoke.llf) stats.chi2.sf(lr, 2)인종 가변수 2개를 넣은 효과의 우도비 검정입니다. 추가한 계수가 2개이므로 자유도 2입니다.

출력 읽기

  2. 2우도비 검정 χ² = 9.83, P = 0.0073. Wald 검정과 비슷한 결론입니다. 이 P는 기준범주를 무엇으로 바꾸든 같습니다. 논문 표의 범주형 변수 옆에 있는 "overall P"가 이 값입니다.

  6. 6변수 선택의 근거. 단변수 P 값으로 고르지 않았다는 것을 밝힙니다. 이 표의 나이는 단변수 분석에서 유의하지 않았지만(구간 0.89–1.01) 교란변수 후보라서 모형에 넣었습니다. 단변수 P < 0.2 같은 기준으로 고르면 중요한 교란변수를 빠뜨릴 수 있습니다(8장 아 절).

정리

  • 숫자로 코딩된 명목변수는 C(race)처럼 범주형으로 지정해야 가변수가 됩니다. 그대로 넣으면 오류 없이 "번호가 1 늘 때"라는 의미 없는 계수가 나옵니다.
  • 기준범주는 C(race, Treatment(reference=값))으로 정합니다. 기준을 바꾸면 가변수의 계수만 바뀌고 다른 변수의 계수와 로그우도는 그대로입니다.
  • 범주형 변수 전체의 P는 res.wald_test_terms()의 Wald 결합 검정이나 변수를 뺀 모형과의 우도비 검정으로 구합니다.
  • 단변수 표는 변수마다 모형을 따로 적합해 pd.concat으로, 다변수 표는 한 모형에서 만들고 행 순서를 맞춰 나란히 놓습니다. 사건 수 대비 계수 수(EPV)를 함께 확인합니다.
  • 원인 추정 모형에서 노출 외 공변량의 OR은 노출의 OR과 같은 의미가 아닙니다(Table 2 오류).
