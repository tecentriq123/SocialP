b.증분비용효과비와 지배

결정할 것은 "표준요법 B 대신 신약 A를 쓸 것인가"입니다. 그래서 A의 값어치는 B에 견주어 더 드는 돈(증분비용)과 더 얻는 건강(증분 QALY)으로 따지고, 그 비가 증분비용효과비(incremental cost-effectiveness ratio, ICER)입니다(20장 d 절). 이 절에서는 ICER를 구하고, 증분의 부호로 사분면을 판정하는 함수와, 대안이 여럿일 때 효율 경계를 만드는 함수를 짭니다.

신약 A 대 표준요법 B

코드 한 줄씩

  1. cost_A, qaly_A = alts.loc["A", "cost"], alts.loc["A", "qaly"].loc[행 이름, 열 이름]은 표에서 값 하나를 꺼냅니다. 쉼표 오른쪽의 두 값이 왼쪽의 두 이름에 차례로 들어갑니다.
  2. d_cost = cost_A - cost_B비교의 기준인 B를 뺍니다. 순서를 바꿔 B − A로 쓰면 증분비용과 증분 QALY의 부호가 둘 다 바뀝니다. 비는 같게 나오지만 사분면은 정반대가 되므로, 무엇에서 무엇을 뺐는지 항상 정해 두고 씁니다.
  3. icer = d_cost / d_qalyQALY 1을 더 얻는 데 더 드는 돈입니다. 반올림하기 전의 두 증분으로 나눕니다.
  4. round(cost_A / qaly_A)총비용을 총 QALY로 나눈 평균 비용효과비(average cost-effectiveness ratio)입니다. ICER와 견주려고 함께 출력합니다.
  5. ly_A, ly_B = 3.398772, 2.728843할인한 생존연수입니다(실습 23 셀 16의 ly_d 행). 같은 증분비용을 생존연수의 증분으로 나누면 생존연수당 비용입니다.

  4. 4신약 A의 평균 비 4,429. 이 예시에서 가정한 임계값 5,000만원/QALY보다 낮지만 ICER가 아닙니다.

평균 비는 비용도 건강도 0인 대안과 견준 값입니다. 그런데 B를 써도 환자는 이미 1.874 QALY를 얻고 7,689만원이 들므로 그런 대안은 없습니다(20장 d 절 2단계 '총비용을 QALY로 나눈 값은 왜 쓰지 않나?'). 판단에 쓰는 값은 ICER 5,621이고, 이것은 가정한 임계값 5,000을 넘습니다. 다만 ICER 하나로는 두 대안이 각각 얼마를 쓰고 얼마를 얻는지 알 수 없어서, 논문에는 대안별 총비용과 QALY를 함께 싣습니다. 국내 지침도 ICER와 함께 각 대안의 총비용과 총효과를 따로 제시하도록 요구합니다(지침 12쪽).

사분면 판정과 음수 ICER

ICER는 두 증분의 비여서 부호가 사라집니다. 증분비용과 증분 QALY의 부호를 따로 보고 비용효과평면(cost-effectiveness plane)의 어느 사분면에 놓이는지부터 정하는 함수를 만듭니다. 평면의 가로축이 증분 QALY, 세로축이 증분비용입니다.

코드 한 줄씩

  1. def quadrant(dc, dq):증분비용 dc와 증분 QALY dq를 받아 사분면의 이름을 문자열로 돌려주는 함수입니다.
  2. if dq > 0 and dc <= 0:더 효과적이면서 비용이 같거나 적으면 우월(dominant)입니다. and는 두 조건이 모두 참일 때만 참입니다. return을 만나면 함수가 그 자리에서 끝나므로 아래 조건은 보지 않습니다.
  3. if dq <= 0 and dc > 0:효과가 같거나 적으면서 더 비싸면 열등(dominated)입니다.
  4. if dq > 0:위의 두 조건에 걸리지 않고 더 효과적이면 남은 경우는 더 비싼 것뿐이므로 오른쪽 위입니다. 마지막 return은 나머지, 곧 왼쪽 아래입니다.
  5. cases = {"A vs B": (d_cost, d_qaly), …}이름과 (증분비용, 증분 QALY) 짝을 담은 딕셔너리입니다. 예 1–3은 20장 d 절이 든 가상의 숫자입니다.
  6. for name, (dc, dq) in cases.items():.items()가 (이름, 짝)을 하나씩 꺼내고, 괄호를 써서 짝을 다시 두 이름으로 풀어 받습니다.

출력 읽기

  2. 2예 1은 ICER −2,500, 우월. 500만원 덜 들고 0.2 QALY를 더 얻습니다.
  3. 3예 2도 ICER −2,500, 열등. 500만원 더 들고 0.2 QALY를 잃습니다. 정반대의 두 약이 같은 숫자가 됩니다.
  4. 4예 3은 ICER 10,000. 양수이지만 1,000만원을 아끼려고 0.1 QALY를 잃는 경우입니다. 이 값은 QALY 1을 포기할 때마다 아끼는 돈이어서 임계값보다 높아야 받아들일 만합니다(20장 d 절 '더 알아보기'의 '덜 효과적이고 더 싼 대안').

그래서 음수 ICER는 숫자로 읽지 않고, 논문에서는 숫자 대신 "dominant"나 "dominated"로 적습니다. ICER를 계산하는 코드에는 이 함수처럼 부호를 먼저 보는 줄을 함께 둡니다. 다만 엄밀하게는 증분 QALY가 정확히 0이면 ICER를 계산할 수 없습니다. 이 함수는 그런 경우를 효과가 같거나 적은 쪽으로 보아 더 비싸면 열등, 같거나 싸면 왼쪽 아래로 판정하므로, 증분이 정확히 0인 결과는 함수의 판정보다 두 증분을 직접 보고 읽습니다.

열등, 확장 열등, 효율 경계

대안이 셋 이상이면 신약을 대안마다 따로 짝지어 ICER를 구하지 않습니다. 비용순으로 놓고, 지배당한 대안과 확장 지배(extended dominance)당한 대안을 뺀 뒤, 남은 대안을 이은 효율 경계(efficiency frontier) 위에서 이웃끼리 견줍니다(20장 d 절 3단계). 20장 '더 알아보기'의 코드와 같은 순서를 함수로 묶었습니다. 함수로 만들어 두면 과제 2에서 대안을 하나 더한 표에 그대로 다시 쓸 수 있습니다.

코드 한 줄씩

  1. def icer_between(df, lo, hi):표 df에서 대안 lo에서 hi로 옮길 때의 ICER입니다. 셀 3의 계산을 행 이름 두 개로 일반화했습니다. 식이 길어 괄호로 감싸 두 줄에 나눠 적었습니다.
  2. def frontier(df):네 대안의 표를 받아, 판정(status), 견준 대안(vs), ICER(icer) 세 열을 붙인 새 표를 돌려줍니다.
  3. df = df.sort_values("cost").copy()비용이 낮은 순서로 줄을 세우고 사본을 만듭니다. .copy()가 없으면 아래에서 열을 더할 때 원래의 alts까지 바뀔 수 있습니다.
  4. df["status"], df["vs"], df["icer"] = "경계", "", np.nan세 열을 한꺼번에 만들고 기본값을 넣습니다. 모든 대안을 일단 경계에 있다고 두고, 빠지는 대안만 고쳐 적습니다. np.nan은 "값 없음"입니다.
  5. if any(df.loc[j, "qaly"] >= df.loc[i, "qaly"] for j in keep):이미 경계에 남긴 대안(keep, 모두 지금 대안보다 싸거나 같음) 가운데 QALY가 같거나 큰 것이 하나라도 있으면 참입니다. 더 싸면서 효과도 같거나 큰 대안이 있다는 뜻이므로 열등으로 적고 continue로 다음 대안으로 넘어갑니다.
  6. while len(keep) >= 3:, a, b, c = keep[-3:]경계에 남은 마지막 세 대안을 꺼냅니다. 경계 위에서는 효과가 큰 쪽으로 갈수록 ICER가 커져야 합니다.
  7. if icer_between(df, a, b) <= icer_between(df, b, c): break앞 단계(a → b)의 ICER가 뒤 단계(b → c)보다 작거나 같으면 순서가 맞으므로 멈춥니다. 앞 단계가 더 크면 가운데 b가 확장 열등이어서 표에 적고 keep.pop(-2)로 뒤에서 둘째, 곧 b를 뺍니다. 빼고 나면 새 세 대안을 다시 확인하려고 while을 되풀이합니다.
  8. for a, b in zip(keep[:-1], keep[1:]):경계에 남은 대안을 이웃끼리 짝짓습니다. 남은 것이 [B, A]이면 (B, A) 한 짝입니다. 짝마다 뒤 대안의 행에 견준 대안과 ICER를 적습니다.
  9. front.round({"icer": 0})icer 열만 정수로 반올림해 보여 줍니다. front에 든 값은 그대로입니다.

출력 읽기

B와 A를 섞은 전략과 병용요법 D

확장 지배가 무슨 뜻인지 숫자로 확인합니다. 환자의 일부에게 A를, 나머지에게 B를 쓰면 평균 비용과 평균 QALY는 B와 A를 잇는 선분 위에 놓입니다. D와 같은 QALY를 내는 비율을 구해 그때의 비용을 D와 견줍니다.

코드 한 줄씩

  1. f = (alts.loc["D", "qaly"] - qaly_B) / (qaly_A - qaly_B)B에서 A까지 늘어나는 QALY 0.511 가운데 D가 B보다 더 얻는 0.126이 차지하는 몫입니다. 환자의 이 비율에게 A를 쓰면 평균 QALY가 D와 같아집니다.
  2. mix_cost = cost_B + f * (cost_A - cost_B)섞은 전략의 평균 비용입니다. B의 비용에서 출발해 A로 바꾼 환자 몫만큼 증분비용을 더합니다. 다음 줄의 QALY도 같은 방식입니다.

이 판단은 환자 일부에게만 A를 쓰는 섞음이 가능하고, 섞은 비율만큼 비용과 효과가 비례해 바뀐다는 가정에 기댑니다(20장 d 절 '더 알아보기'의 '효율 경계를 만드는 순서와 파이썬 코드').

c.순편익과 비용효과평면

같은 판단을 비가 아닌 차로 나타낸 것이 순편익(net benefit)입니다. 늘어난 건강을 임계값으로 돈으로 바꾼 뒤 늘어난 비용을 빼면 순금전편익(net monetary benefit, NMB), 늘어난 비용을 임계값으로 나눠 건강으로 바꾼 뒤 늘어난 건강에서 빼면 순건강편익(net health benefit, NHB)입니다(20장 d 절 3단계 '비로 낼까, 차로 낼까?'). 임계값(cost-effectiveness threshold)은 QALY 1을 더 얻는 데 낼 수 있는 최대 금액입니다. 이 실습의 5,000만원/QALY는 이 예시에서 가정한 값이고, 우리나라에는 공식적으로 정한 명시적 임계값이 없습니다. 심평원 지침에도 임계값 수치는 없습니다.

코드 한 줄씩

  3. pd.Series(best).value_counts()목록에서 이름마다 몇 번 나왔는지 셉니다.
  4. grid[best.index("A")].index("A")는 목록에서 "A"가 처음 나온 자리 번호이고, 그 자리의 임계값을 꺼냅니다.

출력 읽기

  1. 1A 144번, B 57번. C와 D는 한 번도 나오지 않습니다. 열등이나 확장 열등인 대안은 어떤 임계값에서도 고를 이유가 없다는 뜻이고, 그래서 경계에서 빼도 결론이 달라지지 않습니다.
  2. 2A가 처음 가장 커지는 임계값 5,700. 100만원 간격이어서 5,600과 5,700 사이, 곧 5,620.6에서 바뀐다는 것을 이 격자로 확인했습니다.

비용효과평면 그리기

가로축에 증분 QALY, 세로축에 증분비용을 놓고 신약 A 대 B의 점과 임계값 선을 그립니다. 20장 그림 20-3 나에 셀 4의 두 예를 더한 그림입니다.

코드 한 줄씩

  1. x = np.array([-0.6, 0.8]), ax.plot(x, lam * x, …)원점을 지나고 기울기가 임계값 5,000인 직선입니다. 직선은 두 점만 있으면 그려지므로 가로축의 양 끝 두 값만 넣었습니다.
  2. ax.fill_between(x, lam * x, -3500, …)임계값 선에서 그림 아래 끝까지를 옅게 칠합니다. 이 영역(선의 오른쪽 아래)에 있으면 가정한 임계값에서 비용효과적입니다. alpha=0.08은 투명도입니다.
  3. ax.axhline(0, …), ax.axvline(0, …)가로선과 세로선을 0에 그어 사분면을 나눕니다. 원점이 비교대안 B입니다.
  4. ax.plot([d_qaly, d_qaly], [lam * d_qaly, d_cost], …)같은 가로 위치에서 임계값 선 위의 점(2,555)부터 신약 A의 점(2,872)까지 세로로 잇는 빨간 선분입니다. 그 길이 317이 순금전편익의 크기입니다.

신약 A의 파란 점은 오른쪽 위 사분면에서 임계값 선보다 조금 위에 있고, 빨간 선분만큼 떨어져 있습니다. 순금전편익이 음수라는 것은 점이 선의 위쪽, 칠하지 않은 쪽에 있다는 뜻입니다. 셀 4의 예 1(초록 삼각형)은 오른쪽 아래, 예 2(주황 삼각형)는 왼쪽 위에 놓여 ICER가 같은 −2,500이어도 평면에서는 정반대 자리입니다. 임계값을 6,000으로 올리면 선이 가팔라져 파란 점이 선 아래로 들어갑니다(셀 9의 +193.9).

정리

  • 순금전편익은 lam * d_qaly - d_cost, 순건강편익은 d_qaly - d_cost / lam입니다. 가정한 임계값 5,000만원에서 각각 −317.1만원, −0.063 QALY입니다.
  • 오른쪽 위 사분면에서는 "ICER < 임계값"과 "순금전편익 > 0"이 같은 판단이고, 순금전편익의 부호는 임계값이 ICER(5,620.6)를 지날 때 바뀝니다.
  • 대안이 여럿이면 대안마다 순금전편익을 구해 가장 큰 것을 골라도 효율 경계와 같은 답이 나옵니다. 열등과 확장 열등인 대안은 어떤 임계값에서도 뽑히지 않습니다.
  • 우리나라에는 공식 임계값이 없으므로 결과는 가정한 값이라는 것을 밝히고 여러 임계값에서 함께 보입니다. 임계값마다 비용효과적일 확률은 실습 24 d 절에서 구합니다.

앞의 셀을 모두 실행한 상태에서 이어서 풉니다. 세 과제는 하는 일이 다릅니다. 과제 1은 출력의 한 행을 말로 옮기고, 과제 2는 조건 하나를 바꿔 다시 돌린 결과를 비교하고, 과제 3은 그럴듯하지만 틀린 분석을 찾습니다. 먼저 스스로 코드를 짜 본 뒤 접힌 정답을 열어 보세요.

과제 1. 임계값 6,000만원의 순금전편익을 말로 옮기기

셀 9 표의 넷째 행(lam 6000, nmb 193.9, nhb 0.032, ce True)을 급여 평가 보고서에 쓰듯 한 문장으로 옮기고, 이 값이 뜻하지 않는 것을 두 가지 쓰세요. 힌트. 순금전편익을 늘어난 QALY의 값(임계값 × 증분 QALY)과 늘어난 비용으로 나눠 출력해 보면 문장으로 옮기기 쉽습니다.

정답 코드와 풀이
  1. 1늘어난 QALY의 값 3,066.2만원. 0.511 QALY에 QALY당 6,000만원을 곱했습니다.
  2. 2늘어난 비용 2,872.3만원.
  3. 3순금전편익 193.9만원. 두 값의 차입니다.
  4. 4순건강편익 0.032 QALY. 193.9 ÷ 6,000입니다.
  5. 5환자 100명이면 19,388만원. 약 1.94억 원입니다.
  6. 6100명이면 3.2 QALY.

한 문장으로 옮기면 "QALY당 6,000만원까지 낼 수 있다고 가정하면, 표준요법 B 대신 신약 A를 쓸 때 환자 1명당 늘어나는 0.511 QALY의 값(3,066만원)이 늘어나는 비용(2,872만원)보다 194만원 커서, 이 임계값에서는 신약 A가 비용효과적이다"입니다. 비교의 기준(B)과 임계값의 조건이 문장에 들어가야 합니다.

이 값이 뜻하지 않는 것은 두 가지입니다. 첫째, 194만원을 아낀다는 뜻이 아닙니다. 신약 A는 여전히 환자 1명당 2,872만원이 더 들고, 건강보험의 지출은 늘어납니다. 194만원은 늘어난 건강을 임계값으로 돈으로 바꾼 뒤에 남는 차이입니다. 지출이 얼마나 느는지는 재정영향분석이 따로 답합니다(25장 c 절). 둘째, 이 결론은 임계값에 묶여 있습니다. 6,000만원은 공식 기준이 아니라 가정한 값이고, 셀 9에서 보았듯 5,620.6만원 아래로 내리면 부호가 바뀝니다. 그래서 이 행 하나만 결론으로 쓰지 않고 여러 임계값의 결과를 함께 보입니다. 또 이 값은 기준 입력값으로 계산한 하나의 값이어서, 입력값의 불확실성을 넣었을 때 비용효과적일 확률은 따로 구합니다(24장 c 절).

과제 2. 신약 E를 더해 다시 고르기

표준요법 B보다 600만원 더 들고 0.20 QALY를 더 얻는 신약 E가 나왔다고 합시다(20장 d 절 스스로 확인하기 2번의 약). E를 네 대안의 표에 더해 셀 5의 frontier 함수로 효율 경계를 다시 만들고, 임계값 5,000만원과 8,000만원에서 어느 대안을 고르는지 답하세요. 그다음 셀 5의 결과와 견주어 무엇이 바뀌었는지, 그리고 B와 견준 ICER는 E(3,000)가 A(5,621)보다 낮은데 8,000만원에서 A를 고르는 이유를 설명하세요. 힌트. alts_E = alts.copy()로 표를 복사한 뒤 alts_E.loc["E"] = [비용, QALY]로 한 줄을 더합니다.

정답 코드와 풀이

alts_E.loc["E"] = […]는 없는 행 이름에 값을 넣어 새 행을 붙이는 줄입니다. 사본에 붙였으므로 alts는 그대로입니다. 표는 frontier 안에서 비용순으로 다시 정렬되어 E가 C와 D 사이에 들어갑니다. nb_["E"] - nb_["B"]는 대안마다 구한 순금전편익의 차, 곧 B와 견준 증분 순금전편익입니다.

  1. 1신약 E의 총비용 8,289.485만원. QALY는 2.073640입니다.
  2. 2병용요법 D가 이번에는 열등. E가 D보다 싸면서(8,289 < 9,400) QALY가 많아서(2.074 > 2.000) D를 지배합니다. 셀 5에서는 확장 열등이었습니다.
  3. 3E 대 B의 ICER 3,000. 600 ÷ 0.20입니다.
  4. 4A 대 E의 ICER 7,306. 2,272.3 ÷ 0.311입니다. 경계는 B, E, A이고 ICER가 3,000에서 7,306으로 커지므로 확장 열등인 대안은 없습니다.
  5. 55,000만원에서는 E. B 대비 증분 순금전편익이 E +400.0만원, A −317.1만원입니다.
  6. 68,000만원에서는 A. E +1,000.0만원, A +1,215.9만원입니다. 20장 스스로 확인하기 2번의 답과 같습니다.

고르는 순서는 경계를 따라갑니다. 가장 싼 B에서 출발해, 다음 대안으로 옮기는 ICER가 임계값보다 낮은 동안 옮겨 갑니다. 5,000만원에서는 E로 옮기는 값(3,000)은 낮고 A로 더 옮기는 값(7,306)은 높으므로 E에 머뭅니다. 8,000만원에서는 7,306도 낮으므로 A까지 갑니다.

바뀐 것은 두 가지입니다. 첫째, 신약 A의 숫자는 하나도 바뀌지 않았는데 보고할 ICER가 5,621(B 대비)에서 7,306(E 대비)으로 바뀌었습니다. 경계 위에서 A의 이웃이 B에서 E로 바뀌었기 때문입니다. ICER가 약의 성질이 아니라 비교대안에 달린 값이라는 것을 보여 줍니다. 둘째, D의 판정이 확장 열등에서 열등으로 바뀌었습니다. 대안이 더해지면 경계 전체를 다시 만들어야 하는 이유입니다.

B와 견준 ICER가 낮은 E가 8,000만원에서 지는 것은, B와 견준 ICER가 얻는 건강의 크기를 담지 않기 때문입니다. E는 0.20 QALY, A는 0.511 QALY를 더합니다. 둘 가운데 하나를 고를 때 물을 것은 "E 대신 A를 쓰면 0.311 QALY를 더 얻는 데 QALY당 7,306만원이 드는데 그만한 값을 하나"이고, 임계값 8,000만원에서는 그렇습니다(20장 d 절 4단계 'ICER가 낮은 약이 더 좋은 약인가?').

과제 3. 평균 비와 확장 열등 대안으로 낸 결론

동료가 같은 네 대안으로 이렇게 썼습니다.

"대안마다 총비용을 QALY로 나눈 비용효과비를 구했더니 신약 A는 4,429만원/QALY로 임계값 5,000만원보다 낮았다. 신약 A를 병용요법 D와 견준 ICER도 3,020만원/QALY로 임계값보다 낮다. 어느 쪽으로 보아도 신약 A는 비용효과적이므로 급여를 권고한다."

동료의 두 계산을 셀 하나로 재현하고, 이 분석에서 틀린 곳 두 가지를 찾아 왜 틀렸는지 설명하세요. 같은 비용효과비가 기존약 C에서는 얼마인지, 셀 5의 판정과 경계 위의 ICER는 무엇인지 함께 보세요.

정답 코드와 풀이

ratio[ratio < lam]은 조건이 참인 값만 남기고, .index로 그 대안의 이름을 꺼냅니다. lam은 셀 8의 5,000, front는 셀 5의 결과입니다.

  1. 1기존약 C의 비용효과비 4,765. B에 지배당하는 C도 5,000보다 낮습니다.
  2. 2네 대안 모두 임계값보다 낮음. 이 기준이면 열등인 C까지 "비용효과적"이 됩니다.
  3. 3동료의 A 대 D 3,020. 계산은 맞습니다.
  4. 4그러나 D는 확장 열등. 셀 5의 판정입니다.
  5. 5경계 위에서 A는 B와 견주어 5,621. 가정한 임계값 5,000보다 높습니다.
  6. 6임계값 5,000에서 순금전편익이 가장 큰 대안은 B.

첫째 잘못은 평균 비를 ICER처럼 쓴 것입니다. 총비용 ÷ QALY는 비용도 건강도 0인 대안과 견준 값인데, 결정할 것은 "B 대신 A를 쓸 것인가"이고 B를 써도 환자는 이미 1.874 QALY를 얻습니다. 이 값으로 판단하면 네 대안이 모두 5,000 아래여서, B보다 비싸고 효과도 적은 C까지 비용효과적이라는 말이 됩니다. 대안을 가르지 못하는 기준이라는 뜻입니다. 쓸 값은 B에 견준 증분의 비입니다(20장 d 절 2단계).

둘째 잘못은 비교대안입니다. D는 B와 A를 섞은 전략보다 같은 건강을 1,000만원 더 들여 얻는 확장 열등 대안이어서 비교대안이 될 수 없습니다. 비효율적인 대안과 비교하면 어떤 약도 좋아 보입니다. A 대 D의 3,020은 그래서 낮게 나온 값이고, 경계 위의 이웃인 B와 견준 값은 5,621입니다(20장 d 절 3단계 '비교대안이 여럿이면 어느 대안과 비교하나?').

바르게 쓰면 "신약 A는 표준요법 B보다 더 비싸고 더 효과적이었고(증분비용 2,872만원, 증분 QALY 0.511), ICER는 5,621만원/QALY로 이 예시에서 가정한 임계값 5,000만원/QALY를 넘었다. 기존약 C는 열등, 병용요법 D는 확장 열등이었다"입니다. 결론은 "현재 가격에서는 가정한 임계값 기준으로 비용효과적이지 않다"이고, 같은 임계값에서 순금전편익이 가장 큰 대안은 B입니다.
