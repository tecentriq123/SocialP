처방 기록을 환자 한 명 한 행으로 모으려면?

환자 번호로 묶은 뒤(group_by()), 묶음마다 요약할 값을 정합니다(summarise()). 어느 기간을 셀지, 중복을 어떻게 셀지 같은 결정은 보건통계학 기초 0장 a 절에 있습니다. 여기서는 그 결정을 코드로 옮깁니다. 예는 0장의 처방 표(환자 A 세 건, B 한 건, C 두 건)입니다.

코드 한 줄씩

  1. library(dplyr)자료를 묶고 요약하는 dplyr 패키지를 불러옵니다. warn.conflicts = FALSE는 같은 이름의 함수가 가려진다는 안내를 끄는 인자입니다.
  2. data.frame(patient = …, date = as.Date(…), days = …)처방 한 건이 한 행인 표를 만듭니다. 날짜는 as.Date()로 날짜형으로 바꿔야 min()이 가장 이른 날을 찾습니다. 글자 그대로 두면 글자 순서로 비교합니다.
  3. rx |> group_by(patient)|>는 왼쪽의 결과를 오른쪽 함수의 첫 인자로 넘깁니다. 같은 환자의 행을 한 묶음으로 만듭니다.
  4. summarise(first_date = min(date), n_rx = n(), total_days = sum(days))묶음마다 첫 처방일, 행의 개수(처방 건수), 공급일수의 합을 구해 한 행으로 줄입니다.
  1. 1환자 한 명이 한 행. 결과는 3행입니다. 환자 A는 처방 3건, 총 공급일수 90일입니다. 처방 단위 표(6행)를 그대로 검정에 넣으면 A가 세 번 세어지므로, 검정에는 이렇게 모은 표를 씁니다.

평균, 분산, 표준편차는 무엇으로 나누나?

R의 var()와 sd()는 n − 1로 나눕니다. 왜 n − 1로 나누는지는 보건통계학 기초 0장 c 절에 있습니다. 예는 A 병동 5명의 재원일수(8, 12, 9, 11, 10일)입니다.

  1. 1n − 1로 나눈 값. 분산 2.5, 표준편차 1.58일로 0장의 손 계산과 같습니다. SAS, SPSS, Excel의 STDEV.S도 같은 값을 줍니다.
  2. 2n으로 나눈 값. 1.41일입니다. R에는 n으로 나누는 함수가 따로 없어 식으로 썼습니다. 파이썬 numpy의 np.std()는 이쪽이 기본값이라, 같은 자료로 계산한 표준편차가 1.58과 1.41로 갈리면 이것부터 확인합니다(아래 접힌 상자).

값이 빈 환자가 있으면?

  1. 1NA를 그대로 돌려줌. 빈 값이 있다는 것을 알리는 R의 기본 동작입니다.
  2. 24명으로 계산. na.rm = TRUE를 넣으면 남은 4명으로 평균 10.25일, 표준편차 1.71일을 냅니다. 몇 명이 남았는지는 sum(!is.na(x))로 세어 Table 1에 함께 적습니다. summary()도 NA의 개수를 따로 보여 줍니다.

b.분포에서 확률과 경계값 구하기

정규분포에서 확률과 경계값을 구하려면?

확률은 pnorm(), 경계값은 그 반대인 qnorm()으로 구합니다. 앞 글자 p는 '그 값까지의 확률', q는 '그 확률이 되는 값(분위수)'입니다. 보건통계학 기초 0장 d 절의 세 숫자, 곧 z가 −1.5보다 작을 확률 6.7%, 2.0보다 클 확률 2.3%, 위쪽 2.5%를 자르는 1.96을 구합니다.

코드 한 줄씩

  1. pnorm(-1.5)표준정규분포에서 −1.5보다 작을 확률입니다. 평균과 SD를 주면(pnorm(140, mean = 125, sd = 15)) 표준화하지 않고 바로 구합니다.
  2. pnorm(2.0, lower.tail = FALSE)lower.tail = FALSE는 '그 값보다 클 확률'을 달라는 뜻입니다. 1 - pnorm(2.0)과 같지만, 아주 작은 꼬리 확률에서도 정확합니다.
  3. qnorm(0.975)아래쪽 넓이가 0.975가 되는 값, 곧 위쪽 2.5%를 자르는 경계입니다.
  1. 16.7%. 아래쪽 꼬리의 넓이입니다.
  2. 22.3%. 위쪽 꼬리의 넓이입니다.
  3. 31.96. 정규분포는 좌우 대칭이라 아래쪽 2.5%는 −1.96에서 잘리고, 가운데 95%가 ±1.96 안에 들어갑니다.

표준오차와 t 경계값은?

표준오차는 SD ÷ √n을 그대로 계산하고, t 분포의 경계값은 qt(0.975, 자유도)로 구합니다. 보건통계학 기초 0장 e 절의 혈압 시험(신약군 SD 7.0, 위약군 SD 7.2, 군마다 30명)입니다.

  1. 1세 표준오차. 신약군 평균의 SE 1.28, 위약군 1.31, 두 평균 차이의 SE 1.83 mmHg입니다.
  2. 2자유도별 경계값. 자유도 5에서 2.57, 29에서 2.05, 58에서 2.00, 1000에서 1.96입니다. 자유도가 커질수록 정규분포의 1.96에 가까워집니다. qt()는 자유도를 여러 개 한꺼번에 받습니다.

논문의 통계량과 자유도로 p를 검산하려면?

분포마다 이름이 정해져 있어, 앞에 p를 붙이면 확률, q를 붙이면 경계값입니다. t 분포는 pt()·qt(), χ² 분포는 pchisq(), F 분포는 pf()입니다. 논문에 t(58) = 2.35처럼 통계량과 자유도만 적혀 있어도 p를 다시 구할 수 있습니다. 보건통계학 기초의 다른 장에서 '직접 계산하면'이라고 할 때 쓰는 한 줄이 모두 이 형식입니다.

  1. 1임계값. 자유도 58인 t 분포에서 양쪽 꼬리에 2.5%씩 남기는 경계 2.00입니다. 보건통계학 기초 0장의 신뢰구간 4.3 ± 2.00 × 1.83의 2.00입니다.
  2. 2양측 p. 한쪽 꼬리의 넓이에 2를 곱해 0.022입니다. t가 음수이면 부호를 떼고 넣습니다(2 * pt(-abs(t), df)로 써도 같습니다).
  3. 3z = 1.96의 양측 p. 0.050입니다. 1.96이 95% 신뢰구간과 양측 α 0.05에 함께 쓰이는 이유입니다.
  4. 4누적확률 Φ. Φ(0.25) = 0.60이 보건통계학 기초 1장 b 절의 검정력 60%입니다.
  5. 5χ²(1) = 5.31. p = 0.021입니다. χ² 검정은 오른쪽 꼬리만 보므로 2를 곱하지 않습니다.
  6. 6F(2, 87) = 4.12. p = 0.0195, 논문 표기로 P = .020입니다. F도 오른쪽 꼬리만 봅니다.

보건통계학 기초 2장 a 절의 복약상담 시험이라면 2 * pt(2.49, 70, lower.tail = FALSE)가 0.015를, qt(0.975, 70)이 1.994를 줍니다.

보건통계학 기초 0–2장의 '직접 분석' 상자에 있던 셀입니다. scipy에서는 분포마다 객체가 있고(stats.norm, stats.t, stats.chi2, stats.f), 그 뒤에 붙이는 이름으로 계산이 정해집니다.

cdf는 "그 값보다 작을 확률", sf는 "그 값보다 클 확률"입니다. ppf는 cdf를 거꾸로 한 것으로, "그 값보다 작을 확률이 이만큼이 되는 값"입니다. 마지막 줄의 1.96은 그 값보다 작을 확률이 0.975, 곧 위쪽 꼬리 2.5%를 자르는 경계입니다. 정규분포는 좌우 대칭이라 아래쪽 2.5%는 −1.96에서 잘리므로, 가운데 95%의 범위가 ±1.96입니다. 고등학교 표준정규분포표를 읽는 것과 같은 계산입니다.

논문의 평균, SD, 인원만으로 신뢰구간과 P를 구하려면?

R의 t.test()는 원자료가 있어야 하므로, 요약값으로 계산하는 짧은 함수를 하나 만들어 씁니다. 식은 보건통계학 기초 2장 a 절의 접힌 상자 'Student와 Welch는 표준오차와 자유도를 어떻게 구하나?'와 같습니다. 먼저 0장의 혈압 시험(12.4 ± 7.0, 30명 대 8.1 ± 7.2, 30명)을 Student 방법으로 다시 구합니다.

코드 한 줄씩

  1. function(m1, s1, n1, m2, s2, n2, var.equal = FALSE)두 군의 평균, SD, 인원을 받는 함수입니다. var.equal의 기본값을 t.test()와 같이 FALSE(Welch)로 두었습니다.
  2. sp2 <- ((n1 - 1) * s1^2 + (n2 - 1) * s2^2) / (n1 + n2 - 2)Student 방법의 합동분산입니다. 자유도는 n₁ + n₂ − 2입니다.
  3. df <- (v1 + v2)^2 / (v1^2 / (n1 - 1) + v2^2 / (n2 - 1))Welch 방법의 자유도(Welch–Satterthwaite 식)입니다. 소수로 나옵니다.
  4. p = 2 * pt(-abs(t), df)b 절의 양측 p입니다. 신뢰구간은 차이 ± qt(0.975, df) × SE입니다.
  1. 10장의 숫자 그대로. 차이 4.3, SE 1.83, t = 2.35, 자유도 58, p = 0.022, 95% 신뢰구간 0.63–7.97 mmHg입니다. 원자료가 있다면 t.test()에 두 군의 값을 넣고 var.equal = TRUE를 더하면 같은 값을 줍니다(이 과목 2장 c 절).

Welch와 Student는 언제 다른 답을 내나?

두 군의 인원이 같으면 거의 같고, 인원과 SD가 함께 다르면 갈립니다. 그래서 어느 쪽을 쓸지 미리 정해 인자로 적습니다. R의 t.test()는 Welch가 기본값이고, Student는 var.equal = TRUE를 넣어야 합니다. 두 방법을 고르는 기준은 보건통계학 기초 2장 a 절에 있습니다.

  1. 1복약상담 시험(36명씩). Welch t = −2.49, 자유도 69.05, p = 0.015로 2장 a 절의 결과와 같습니다. 인원이 같고 SD가 비슷해 Student(자유도 70)와도 거의 같습니다.
  2. 2예비연구, Student. 중재군 40명(SD 0.60), 대조군 15명(SD 1.20)이면 SE 0.243, 자유도 53, p = 0.045입니다.
  3. 3예비연구, Welch. 같은 자료에서 SE 0.324, 자유도 16.7, p = 0.14입니다. 인원이 적은 군의 SD가 커서 Student 방법이 표준오차를 작게 잡았습니다. 2장 a 절 '두 방법이 다른 답을 내면 어떻게 하나?'의 표가 이 출력입니다.

보건통계학 기초 0장과 2장의 '직접 분석' 상자에 있던 셀과 출력 읽기입니다. scipy에는 요약값으로 계산하는 함수 ttest_ind_from_stats가 있어 위의 함수를 따로 만들지 않아도 됩니다.

논문의 평균, SD, 인원과 표로 결과를 검산하려면?

위의 t_from_stats()와 chisq.test()로 논문이 밝힌 방법 그대로 다시 계산해 보고, 기본값으로 바꾸면 무엇이 달라지는지 함께 봅니다. 예는 보건통계학 기초 분석 고르기 연습 d 절의 가상 논문(복약상담군과 일반 관리군 150명씩)입니다. 논문은 평균 PDC를 Welch t 검정으로, PDC ≥ 80% 비율을 연속성 보정 없이 카이제곱 검정으로 비교했다고 밝혔습니다.

  1. 1Welch t 검정. 차이 5.8%p, t = 2.90, 자유도 281.7, P = 0.004, 95% CI 1.9–9.7로 논문과 맞습니다. 두 군 인원이 같아 Student로 바꿔도 t는 같고 자유도(298)와 구간만 조금 다릅니다.
  2. 2연속성 보정 없는 χ². 4.81, P = 0.028로 논문의 P = 0.03과 맞습니다. 표에는 백분율이 아니라 인원을 넣습니다.
  3. 3R 기본값(Yates 보정). 4.29, P = 0.038입니다. 논문이 'without continuity correction'이라고 밝혔으므로 맞는 값은 0.028입니다.

보건통계학 기초 분석 고르기 연습 d 절의 '직접 분석' 상자에 있던 내용입니다.

직접 실행가상 논문의 숫자 검산
from scipy import stats
import numpy as np

# ⟨5⟩ 평균 PDC: 두 군의 평균, SD, 인원만으로 Welch t 검정
res = stats.ttest_ind_from_stats(84.9, 15.1, 150, 79.1, 19.3, 150, equal_var=False)
print(res)

# equal_var를 빼면 scipy 기본값인 Student t 검정
res_s = stats.ttest_ind_from_stats(84.9, 15.1, 150, 79.1, 19.3, 150)
print(round(res.pvalue, 5), round(res_s.pvalue, 5))

# 평균 차이의 95% CI = 차이 ± 임계값 × 차이의 SE
v1, v2 = 15.1**2 / 150, 19.3**2 / 150        # 각 군 평균의 분산(SE의 제곱)
se = np.sqrt(v1 + v2)                          # 차이의 SE
df = (v1 + v2)**2 / (v1**2 / 149 + v2**2 / 149)  # Welch 자유도
tc = stats.t.ppf(0.975, df)                    # 양측 5% 임계값
print(round(se, 3), round(df, 1), round(tc, 3))
print(round(5.8 - tc * se, 1), round(5.8 + tc * se, 1))

# PDC ≥ 80% 비율: 2×2 표의 카이제곱 검정(연속성 보정 없이)
table = [[108, 42], [90, 60]]
chi2, p, dof, expected = stats.chi2_contingency(table, correction=False)
print(round(chi2, 2), round(p, 3))

# correction을 빼면 scipy 기본값인 Yates 연속성 보정
chi2_y, p_y, dof_y, expected_y = stats.chi2_contingency(table)
print(round(chi2_y, 2), round(p_y, 3))

같은 2 × 2 표인데 χ²가 다르게 나오면?

R의 chisq.test()와 prop.test()는 2 × 2 표에서 연속성 보정(Yates 보정)이 기본값이라, 보정하지 않은 Pearson χ²는 correct = FALSE로 요청합니다. 보정이 무엇이고 언제 Fisher 검정으로 바꾸는지는 보건통계학 기초 1장 e 절과 5장 a 절에 있습니다. 예는 1장의 2 × 2 표(치료군 50명 중 12명, 대조군 50명 중 18명에게 사건)입니다.

  1. 1기본값은 연속성 보정. 칸마다 |관측 − 기대|에서 0.5를 뺀 뒤 제곱하므로 χ²가 1.19로 작아집니다(p = 0.28).
  2. 2보정하지 않은 Pearson χ². χ² = 1.71, p = 0.19입니다.
  3. 3두 비율의 z 검정. prop.test()는 χ²로 보고하므로 제곱근에 부호를 붙여 z = −1.31을 만들었습니다. z² = 1.714는 둘째 줄의 χ²와 같고 p도 0.19로 같습니다. 같은 검정을 z와 χ²로 다르게 나타낸 것입니다.

SPSS는 보정하지 않은 값(Pearson Chi-Square)과 보정한 값(Continuity Correction)을 두 줄로 함께 출력합니다. 같은 표로 계산한 p가 논문마다 0.19와 0.28처럼 다르면 연속성 보정 여부부터 확인합니다.

회귀 출력의 z와 SAS의 Wald χ²는 같은 검정인가?

같은 검정입니다. 계수 ÷ 표준오차가 z이고, 그 제곱이 자유도 1인 Wald χ²입니다. R의 glm()과 파이썬 statsmodels는 z를, SAS의 PROC LOGISTIC은 Wald χ²를 보여 줍니다. 30일 재입원에 대한 로지스틱 회귀에서 흡연의 계수 0.6420, 표준오차 0.2110을 받아 세 값을 다시 구합니다. 로지스틱 회귀 자체는 보건통계학 기초 9장과 이 과목 2장 e 절에서 다룹니다.

  1. 1z와 Wald χ². z = 0.642 ÷ 0.211 = 3.04, z² = 9.26입니다. SAS 출력의 Wald Chi-Square 9.2572와 끝자리가 조금 다른 것은 반올림된 계수와 표준오차로 계산했기 때문입니다.
  2. 2p는 같습니다. z의 양측 p와 χ²(1)의 p가 모두 0.0023입니다. 이것이 z² = χ²₁의 뜻입니다.
  3. 3오즈비와 95% 신뢰구간. 계수와 신뢰구간 양 끝에 지수함수를 취해 OR 1.90 (1.26–2.87)을 얻습니다. 논문에는 계수 대신 이 값을 보고합니다.

e.다중비교 보정과 부트스트랩

여러 p를 한꺼번에 보정하려면?

p.adjust()에 p값을 모두 넣고 방법을 method로 적습니다. 기본값은 Holm입니다. 무엇을 한 묶음으로 넣을지, 어느 방법을 고를지는 보건통계학 기초 1장 c 절에서 분석 전에 정합니다. 예는 1장 c 절 표의 다섯 p값입니다.

  1. 1Holm. 0.020, 0.048, 0.063, 0.076, 0.26으로 1장 c 절 표의 Holm 값과 같습니다.
  2. 2Benjamini–Hochberg(BH). 위음성을 줄이는 대신 유의하다고 한 것 가운데 틀린 비율(FDR)을 조절합니다.
  3. 3Bonferroni. p에 검정 수 5를 곱하고 1에서 자릅니다.

p.adjust()는 넣어 준 p값의 개수를 검정 수로 씁니다. 유의하게 나온 p만 골라 넣으면 검정 수가 줄어 보정이 약해지므로, 미리 정한 묶음을 통째로 넣습니다. 파이썬 statsmodels는 기본값이 Holm이 아니므로 아래 접힌 상자를 봅니다.

부트스트랩 신뢰구간은 어떻게 구하나?

표본에서 같은 인원을 복원추출로 다시 뽑아 평균을 구하는 일을 수천 번 되풀이하고, 모인 평균들로 구간을 만듭니다. 언제 쓰고 무엇을 보고하는지는 보건통계학 기초 1장 f 절에 있습니다. 예는 1장 h 절의 60명 재원일수(오른쪽으로 치우친 자료)입니다. 같은 자료로 t 분포를 써서 구한 평균의 95% 신뢰구간은 6.28–8.85일입니다.

다중비교 보정

statsmodels의 multipletests에 p값 여러 개를 넣으면 보정한 p값을 돌려줍니다. 보정 방법은 method로 지정합니다. 지정하지 않으면 기본값 'hs'(Holm–Šidák)를 써서, 위 표의 다섯 p값이 0.0198, 0.0471, 0.0617, 0.0746, 0.26으로 나옵니다. 표의 Holm 값(0.020, 0.048, 0.063, 0.076)과 조금 다릅니다.

from statsmodels.stats.multitest import multipletests
p = [0.004, 0.012, 0.021, 0.038, 0.260]
multipletests(p, method="holm")[1]        # 0.020 0.048 0.063 0.076 0.26
multipletests(p, method="fdr_bh")[1]      # 0.020 0.030 0.035 0.0475 0.26
multipletests(p, method="bonferroni")[1]  # 0.020 0.060 0.105 0.190 1.0

Holm–Šidák는 Holm과 같은 순서로 보정하되, p에 남은 검정 수를 곱하는 대신 1 − (1 − p)남은 검정 수로 계산해 값이 조금 작게 나옵니다. 기본값이 Holm이 아니므로, Methods에 쓴 방법과 프로그램의 method가 같은지 확인합니다. R의 p.adjust()는 Holm이 기본값입니다.

부트스트랩

scipy의 stats.bootstrap으로 구합니다. 두 군의 평균 차이라면 두 군의 자료를 함께 넣고 평균 차이를 계산하는 함수를 지정합니다. 그러면 군별 인원이 매번 그대로 유지되도록 군마다 따로 다시 뽑습니다(paired=False가 기본). 두 군을 합쳐 다시 뽑으면 군별 인원이 매번 달라지기 때문입니다.

# a, b는 두 군의 1인당 약제비 배열
import numpy as np
from scipy import stats
res = stats.bootstrap((a, b), lambda x, y: np.mean(x) - np.mean(y),
                      n_resamples=2000, method="percentile", rng=2026)
print(res.confidence_interval)    # 평균 차이의 95% CI

지정하지 않으면 BCa 방법으로 9,999번 되풀이합니다. BCa는 치우침을 보정하는 방법이라, 가운데 95% 범위를 그대로 쓰는 백분위수 방법(method="percentile")과 구간이 조금 다를 수 있습니다. 실행할 때마다 결과가 조금씩 달라지므로 난수 시드(rng)를 정해 기록합니다. Methods에는 방법, 되풀이 횟수, 군 안에서 따로 뽑았는지를 씁니다.

정규성 검정을 할 때 무엇을 조심하나?

무엇을 검정하는지는 분석하는 사람이 골라 넣고, Kolmogorov-Smirnov 검정은 비교할 분포를 잘못 넣기 쉽습니다. 정규성 검정으로 t 검정과 Mann-Whitney 검정을 바꿔 쓰지 않는 이유는 보건통계학 기초 1장 h 절에 있습니다.

  1. 1Shapiro-Wilk 검정. 재원일수의 p가 0.0000001 수준이라 정규분포에서 뚜렷하게 벗어납니다. R의 shapiro.test()는 5,000명까지만 받습니다. 청구자료처럼 큰 자료에서는 사소한 차이에도 기각되므로 그림과 요약통계로 판단합니다.
  2. 2표준정규분포와 비교해 버린 경우. ks.test(x, "pnorm")은 평균 0, SD 1인 정규분포와 비교합니다. 수축기혈압은 종 모양이지만 평균이 131.8이라 p가 0으로 나옵니다.
  3. 3같은 자료로 표준화한 경우. p = 0.043입니다. 곡선을 자료에 맞춘 뒤 비교하므로 차이가 작아 보여 p가 실제보다 크게 나옵니다. 같은 값이 있어 R은 근사 p를 계산했고, 경고는 이 때문입니다. 파이썬 scipy는 정확 분포로 0.038을 줍니다.
  4. 4Lilliefors 검정. 평균과 SD를 자료에서 추정했다는 점을 보정한 검정으로, p = 0.00006입니다. 3번의 0.043과 결론이 다릅니다.

보건통계학 기초 1장 h 절의 '직접 분석' 상자에 있던 내용입니다.

Q1 같은 분위수가 이웃한 두 관측값 사이의 어디에 놓이는지 정하는 규칙이 프로그램마다 다릅니다. numpy의 percentile과 pandas의 quantile은 선형 보간이 기본값입니다. SPSS의 기본값(가중평균)은 numpy에서 method='weibull'로 지정하면 같은 값이 나옵니다. 왜도는 프로그램마다 기본값이 다릅니다. scipy의 stats.skew는 표본 그대로의 값을 주고(bias=True), pandas의 .skew()와 SPSS는 표본 크기를 보정한 값을 줍니다. scipy에서 bias=False로 지정하면 같아집니다. 실습 1은 scipy의 stats.skew로 계산하므로 2.32 쪽 값이 나옵니다. 같은 자료에 pandas의 .skew()를 쓰면 표처럼 2.32가 2.38로 조금 커집니다.

파이썬에서는 scipy의 stats.probplot(x, plot=ax)나 statsmodels의 sm.qqplot(x, line='q')로 그립니다.

프로그램은 넣어 준 값만 검정합니다. 위에서 정한 대상(군별 값, 대응 차이, 잔차)을 골라 넣는 일은 분석하는 사람이 합니다. 그 밖에 결과를 바꾸는 점은 두 가지입니다.

  • Kolmogorov-Smirnov 검정을 하는 stats.kstest(x, 'norm')은 x를 평균 0, 표준편차 1인 표준정규분포와 비교합니다. 그래서 1장 h 절의 수축기혈압처럼 종 모양인 자료도 평균이 131.8이라 p가 0으로 나옵니다. 값을 표준화해 넣어도, 평균과 표준편차를 같은 자료에서 구했다면 p가 실제보다 크게 나옵니다. 곡선을 자료에 맞춘 뒤 비교하므로 자료와 곡선의 차이가 작아 보이기 때문입니다. 재원일수는 이렇게 계산하면 p = 0.038이지만, 이 점을 보정한 Lilliefors 검정(statsmodels의 lilliefors)으로는 p가 0.001 이하입니다.
  • stats.shapiro는 5,000명이 넘으면 p가 정확하지 않을 수 있다고 경고합니다. 청구자료처럼 큰 자료에서는 정규성 검정이 사소한 차이에도 기각되므로, 그림과 요약통계로 판단합니다.

shapiro()의 p에 따라 ttest_ind()와 mannwhitneyu()를 자동으로 바꾸는 코드는 쓰지 않습니다. 그 이유는 보건통계학 기초 1장 h 절의 접힌 상자 '정규성 검정 결과를 보고 t 검정과 Mann-Whitney 검정을 바꿔 써도 되나?'에 있습니다.

g.순위합 검정의 세부

같은 자료에서 Mann-Whitney 검정의 p가 왜 여러 개인가?

p를 정확 분포로 구하는지, 정규분포로 어림하는지, 어림할 때 연속성 보정을 하는지가 프로그램과 자료에 따라 다르기 때문입니다. R의 wilcox.test()는 두 군이 모두 50명 미만이면 정확 p를 계산합니다. 같은 값(동점)이 있을 때는 R 버전에 따라 다릅니다. R 4.5까지는 정확 p를 계산할 수 없다는 경고와 함께 동점 보정과 연속성 보정을 한 정규근사 p를 주고, R 4.6.0부터는 관측된 순위를 그대로 둔 조건부 정확 p를 줍니다. 그래서 아래 셀은 exact = FALSE로 방법을 직접 적었습니다. 예는 보건통계학 기초 1장 g 절의 7명씩 재원일수(A군에 3일이 두 명)입니다.

  1. 1정규근사. 동점 보정과 연속성 보정을 한 정규근사 p 0.030으로, 1장 g 절의 p = 0.03입니다. R 4.5까지는 이 자료에 인자 없이 wilcox.test(A, B)만 써도 이 값이 나옵니다.
  2. 2연속성 보정 없이. 0.025입니다.
  3. 3중간순위를 그대로 둔 정확 p. coin 패키지의 wilcox_test()로 동점의 평균 순위를 그대로 둔 채 모든 배치를 세면 0.024입니다. R 4.6.0 이상에서는 인자 없는 wilcox.test(A, B)가 이 값을 줍니다.

논문에는 p를 어느 방법으로 구했는지 씁니다. 동점 보정과 연속성 보정의 계산은 보건통계학 기초 2장 b 절에 있습니다.

검정과 Hodges–Lehmann 추정치를 한 번에 구하려면?

wilcox.test()에 두 군의 원래 값을 넣고 conf.int = TRUE를 더하면, 검정과 함께 Hodges–Lehmann 추정치와 그 신뢰구간을 줍니다. 예는 보건통계학 기초 2장 b 절의 오피오이드 사용량(프로토콜군 8명, 일반 관리군 7명, 동점 없음)입니다.

  1. 1W는 첫 번째 인자의 U. R이 W라고 적는 값은 첫 인자(프로토콜군)의 순위합 45에서 가장 작은 값 36을 뺀 U₁ = 9입니다. 다른 프로그램의 'Wilcoxon W'는 순위합 자체(45)인 경우도 있으므로, 어느 값인지는 반대 군 기준의 값과 더해 n₁n₂(56)가 되는지로 확인합니다. 동점이 없고 인원이 적어 정확 p 0.029를 계산했습니다.
  2. 2Hodges–Lehmann 신뢰구간. −40 ~ −3 MME입니다. 56개 쌍별 차이를 정렬한 11번째와 46번째 값입니다.
  3. 3Hodges–Lehmann 추정치. 56개 쌍별 차이(프로토콜 − 일반)의 중앙값 −18.5 MME입니다. R은 이 값을 'difference in location'이라고 적습니다.

인자 순서를 바꾸면 W가 47(U₂)이 되고 추정치와 신뢰구간의 부호가 바뀌지만 p는 같습니다. 우월 확률은 W를 쌍의 수로 나눠 9 ÷ 56 = 0.16으로 구합니다.

같은 점수가 많은 리커트 척도라면?

동점을 보정한 정규근사 p와, 관측된 중간순위를 그대로 둔 정확 p나 순열검정 p가 거의 같은지 봅니다. 예는 보건통계학 기초 2장 b 절의 만족도 점수(1–5점, 군마다 20명)입니다. rep(1:5, times = …)로 점수별 인원을 펼쳐 넣습니다.

  1. 1정규근사. 동점 보정에 연속성 보정까지 한 정규근사 p 0.019입니다. R 4.5까지는 인자 없이 쓰면 이 값이, R 4.6.0 이상에서는 군마다 50명 미만이라 중간순위를 그대로 둔 정확 p(약 0.019)가 나옵니다.
  2. 2연속성 보정 없이. 0.018로, 2장 b 절에서 손으로 구한 z = 2.36의 p와 같습니다.
  3. 3순열검정. 군 이름표를 10,000번 섞어 구한 p 0.0185입니다. 무작위로 섞으므로 시드에 따라 끝자리가 조금 다르고, 99% 신뢰구간이 함께 나옵니다.

두 군의 퍼진 정도가 크게 다르면?

한쪽 값이 더 클 확률이 0.5인지를 직접 검정하는 Brunner–Munzel 검정을 함께 봅니다. 언제 쓰는지는 보건통계학 기초 2장 b 절에 있습니다. 예는 오피오이드 자료입니다.

  1. 1통계량과 p. 통계량 2.95, 자유도 9.39, p = 0.016입니다. 통계량이 양수인 것은 둘째 인자(일반 관리군)의 값이 더 크게 나오는 경향이라는 뜻입니다. 군당 10명이 안 되는 작은 표본에서는 이 t 분포 근사가 정확하지 않을 수 있습니다.
  2. 2추정값의 방향. P(X < Y) + ½P(X = Y) = 0.84는 프로토콜군 환자가 일반 관리군 환자보다 적게 쓸 확률입니다. 우월 확률 0.16(프로토콜군이 더 많이 쓸 확률)과 방향이 반대라 1 − 0.16입니다.

보건통계학 기초 1장 g 절과 2장 b 절의 '직접 분석' 상자에 있던 내용입니다.

동점 보정은 scipy가 알아서 하므로 따로 지정할 인자가 없습니다. z와 함께 보고된 p는 프로그램에 따라 연속성 보정을 했을 수도 안 했을 수도 있으므로, z로 p를 다시 계산해 확인합니다. 보건통계학 기초 2장 b 절 '논문에서 읽기'의 Results 문장에 적힌 P = .028은 연속성 보정 없는 근사입니다(use_continuity=False를 더하면 같은 값). p가 0.05 근처라면 어느 방식인지에 따라 결론이 갈릴 수 있으므로 방식을 꼭 함께 적습니다.

방식을 지정하지 않으면(method="auto") scipy는 한 군이라도 8명 이하이고 동점이 없을 때 정확 p를, 그 밖에는 동점 보정과 연속성 보정을 한 정규근사 p를 계산합니다(1.17과 1.18에서 확인, 버전에 따라 다를 수 있음). 그래서 오피오이드 자료(8명과 7명, 동점 없음)는 기본값으로 정확 p 0.029가, 만족도 자료(동점 있음)는 근사 p 0.019가 나옵니다. 두 군이 모두 8명보다 많고 동점이 없는데 정확 p가 필요하면 method="exact"를 직접 지정합니다. 순열검정(PermutationMethod)은 관측된 중간순위(동점에 주는 평균 순위)를 그대로 둔 채 군 이름표만 섞어 p를 구합니다. 가능한 배치가 너무 많으면 기본 9,999번만 무작위로 섞으므로 실행할 때마다 값이 조금 다릅니다. 만족도 자료에서 난수 씨앗을 바꿔 200번 실행하면 대부분 0.016–0.023이었고, 가운데값은 약 0.019였습니다. stats.PermutationMethod(rng=np.random.default_rng(1))처럼 난수 씨앗을 정해 두면 같은 값이 다시 나옵니다. 만족도 자료에서 관측된 중간순위를 고정하고 모든 배치를 센 정확한 값은 0.019라, 동점 보정 근사와 거의 같습니다. 참고로 stats.ranksums()는 같은 검정을 연속성 보정 없는 정규근사로 계산해 z = −2.20, p = 0.028을 줍니다.

동점이 많으면 동점이 없다고 가정한 정확 분포를 그대로 쓸 수 없습니다. 그래서 scipy의 stats.mannwhitneyu()는 동점이 있으면 자동으로 동점 보정 정규근사를 씁니다(기본값인 연속성 보정까지 하면 p = 0.019). method="exact"를 지정하면 동점을 보정하지 않은 분포를 그대로 써서 p = 0.023이 나오므로 이런 자료에는 맞지 않습니다. 관측된 중간순위를 그대로 둔 정확 p에 가까운 값이 필요하면 method=stats.PermutationMethod()로 순열검정을 합니다(scipy 1.17–1.18 기준). 순열검정의 결과가 실행마다 조금 다른 이유는 바로 위 문단에 있습니다.

Brunner–Munzel 검정은 stats.brunnermunzel(protocol, usual)로 계산하며, 통계량 2.95로 R과 같습니다.

직접 실행오피오이드 자료로 Mann-Whitney 검정과 Hodges–Lehmann 추정치
import numpy as np
from scipy import stats

protocol = np.array([12, 15, 18, 20, 22, 26, 31, 68])  # 프로토콜군 8명
usual = np.array([24, 29, 36, 41, 45, 58, 115])        # 일반 관리군 7명

print(stats.mannwhitneyu(protocol, usual))

diffs = np.subtract.outer(protocol, usual).ravel()     # 56개 쌍별 차이
print(np.median(diffs))                                # Hodges–Lehmann 추정치
print(np.sort(diffs)[[10, 45]])                        # 95% CI 끝값

과제 3. 큰 군의 SD가 클 때

c 절 예비연구에서 두 군의 SD를 바꿔, 큰 군(40명)의 SD가 1.20, 작은 군(15명)의 SD가 0.60이라고 합시다. Student와 Welch의 p는 어떻게 되나요? c 절의 결과와 비교해 보세요.

정답 코드와 풀이

이번에는 Student가 0.13, Welch가 0.047로 c 절과 반대로 갈립니다. 큰 군의 분산이 합동분산을 끌어올려, Student 방법이 표준오차를 실제보다 크게 잡았기 때문입니다. 인원이 적은 군의 SD가 크면 Student 방법이 너무 자주 '유의'를 내고, 인원이 많은 군의 SD가 크면 너무 드물게 냅니다. 어느 쪽이든 Welch 방법은 두 경우 모두 맞는 표준오차를 쓰므로, 보건통계학 기초 2장 a 절은 Welch를 기본으로 정하기를 권합니다.
