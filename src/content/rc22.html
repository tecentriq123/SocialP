a.할인

할인 계수와 현재가치는 어떻게 구하나?

연 할인율 r에서 t년 뒤 금액의 할인 계수는 1 ÷ (1 + r)t이고, 금액에 이 계수를 곱하면 현재가치가 됩니다. R에서는 벡터에 한꺼번에 계산합니다. 보건통계학 기초 20장 c 절의 표 20-7입니다.

  1. 11, 5, 10, 20년 뒤의 할인 계수 0.957, 0.802, 0.644, 0.415. 표 20-7과 같습니다. 둘째 줄은 1,000만원에 곱한 현재가치입니다.
  2. 2해마다 500만원씩 3년이면 현재가치 1,374.5만원. 해마다 따로 할인해 더한 값입니다. 모형에서는 주기(공통 예시는 1개월)마다 같은 계산을 하고 더합니다. 기준 시점을 주기의 처음으로 잡을지 가운데로 잡을지는 보건통계학 기초 20장 c 절의 접힌 상자 '모형 안에서는 언제를 기준으로 할인하나?'에서 정합니다.

보건통계학 기초 20장의 '직접 분석' 상자와 본문에 있던 내용입니다.

표 20-7의 할인 계수와, 3년 동안 해마다 500만원씩 드는 비용의 현재가치를 계산합니다. 실습 환경(실습 0)의 주피터 노트북 셀에 붙여 넣어 실행하면 아래 출력이 나옵니다.

직접 실행할인 계수와 현재가치
import numpy as np

r = 0.045                                  # 연 할인율 4.5%
years = np.array([1, 5, 10, 20])           # 몇 년 뒤인가
factor = 1 / (1 + r) ** years              # 할인계수
print(np.round(factor, 3))
print(np.round(1000 * factor))             # 1,000만원의 현재가치

cost = np.array([500, 500, 500])           # 1, 2, 3년 뒤에 드는 비용(만원)
t = np.array([1, 2, 3])
pv = cost / (1 + r) ** t                   # 해마다 따로 할인
print(cost.sum(), np.round(pv, 1), round(pv.sum(), 1))

b.ICER, 사분면, 효율 경계

모형의 결과는 어떤 모양으로 넣나?

대안마다 할인한 총비용과 총 QALY 두 숫자를 반올림하지 않은 채 넣습니다. 표준요법 B와 신약 A는 모형의 기준 분석 결과이고, 기존약 C와 병용요법 D는 20장 d 절 표 20-12의 가상 대안입니다.

ICER는 어떻게 구하나?

증분비용을 증분 QALY로 나눕니다. 총비용 ÷ 총 QALY(평균 비)는 판단에 쓰지 않습니다.

  1. 1ICER 5,620.6만원/QALY. 증분비용 2,872.3만원 ÷ 증분 QALY 0.511입니다.
  2. 2평균 비 4,104(B), 4,765(C), 4,700(D), 4,429(A). A의 평균 비는 ICER보다 1,200만원 가까이 낮습니다. A를 고르면 B 대신 A를 쓰는 것이므로, 판단에 필요한 것은 A가 B보다 더 드는 비용과 더 얻는 QALY입니다.
  3. 3늘어난 생존연수 1년당 4,287만원. 분모를 생존연수로 바꾼 값으로, QALY당 값보다 낮습니다(보건통계학 기초 20장 b 절 '왜 QALY당 비용이 더 높나?').

사분면은 왜 먼저 정하나?

증분비용과 증분 QALY의 부호로 비용효과평면의 사분면을 정한 뒤에만 ICER를 읽습니다. 나눗셈은 사분면을 구분하지 않습니다.

  1. 1우월(−500만원, +0.2 QALY)과 열등(+500만원, −0.2 QALY)이 똑같이 −2,500. 음수 ICER는 경고 없이 계산되므로, 숫자 대신 "dominant", "dominated"로 적습니다. 왼쪽 아래(덜 효과적이고 더 쌈)의 10,000은 '아낀 비용 ÷ 잃은 QALY'로 읽고, 임계값보다 커야 받아들입니다.
  2. 2증분 QALY가 0이면 Inf, 둘 다 0이면 NaN. R의 나눗셈은 경고도 오류도 내지 않습니다. 함수의 첫 줄처럼 증분 QALY가 0인 경우를 먼저 거릅니다.

효율 경계는 어떻게 만드나?

대안을 비용이 낮은 순서로(비용이 같으면 효과가 큰 순서로) 놓고, 더 싸면서 효과가 같거나 큰 대안이 있으면 열등으로 빼고, 경계에 남은 이웃 세 대안에서 앞 쌍의 ICER가 뒤 쌍보다 크면 가운데를 확장 열등으로 뺍니다. R에는 효율 경계를 만드는 기본 함수가 없어 직접 짭니다. 순서를 정하는 order(df$cost, -df$qaly)가 비용이 같은 대안의 순서를 정합니다.

  1. 1D 확장 열등: 13,537 > 3,020. B → D의 ICER가 D → A보다 커서 D가 빠집니다. C는 더 싼 B보다 효과가 작아 열등입니다.
  2. 2경계에 남은 A 대 B의 ICER 5,621. 효율 경계 위의 이웃끼리 비교한 값이 보고할 ICER입니다(보건통계학 기초 20장 d 절 '병용요법 D는 왜 빠지나?').

확장 열등은 왜 빼나?

환자의 24.7%에게 A를, 나머지에게 B를 쓰면 D와 같은 2.000 QALY를 D보다 1,000만원 적게 얻습니다.

  1. 1섞은 전략 8,399.7만원, D보다 1,000.3만원 적음. 같은 효과를 더 싸게 얻는 방법이 있으므로 D는 고를 이유가 없습니다.

보건통계학 기초 20장의 '직접 분석' 상자와 본문에 있던 내용입니다.

넣는 것은 모형이 대안마다 낸 할인한 총비용과 총 QALY이고, 반올림하지 않은 값을 그대로 넣습니다. 나오는 것은 증분비용, 증분 QALY, ICER이고, 임계값을 정하면 순금전편익과 순건강편익도 나옵니다. 공통 예시의 두 대안이라면 다음 몇 줄입니다.

# 파이썬. 입력값은 실습 20과 같음. 모형이 낸 할인한 총비용(만원)과 총 QALY
cost = {"B": 7689.485, "A": 10561.778}
qaly = {"B": 1.873640, "A": 2.384669}
lam = 5000                        # 가정한 임계값(만원/QALY)
d_c = cost["A"] - cost["B"]       # 증분비용 2,872.3
d_q = qaly["A"] - qaly["B"]       # 증분 QALY 0.5110
icer = d_c / d_q                  # 5,620.6만원/QALY
nmb = lam * d_q - d_c             # 순금전편익 −317.1만원
nhb = d_q - d_c / lam             # 순건강편익 −0.063 QALY

여기에 사분면 판정(증분의 부호), 효율 경계, 여러 임계값의 표를 직접 덧붙입니다. 네 대안으로 이 모두를 해 보는 노트북은 실습 20에 있습니다. 이런 계산을 직접 할 때 조심할 곳이 세 군데 있습니다. numpy, pandas, 파이썬 기본 나눗셈 가운데 무엇으로 계산하느냐에 따라 반응이 다르거나 경고 없이 계산이 넘어가는 곳입니다(numpy 2.5, pandas 3.0에서 확인).

  • 증분 QALY가 0일 때. numpy의 나눗셈은 RuntimeWarning을 내고 inf를 돌려주고, pandas의 열 나눗셈은 경고 없이 inf를 돌려주며, 파이썬 float의 나눗셈은 ZeroDivisionError로 멈춥니다. ICER를 구하기 전에 증분의 부호와 크기를 먼저 봅니다.
  • 음수 ICER. 우월(−500만원, +0.2 QALY)이든 열등(+500만원, −0.2 QALY)이든 −2,500이 경고 없이 계산됩니다(보건통계학 기초 20장 d 절 '비로 낼 때와 차로 낼 때는 무엇이 다른가?'). 사분면을 먼저 정하고, 음수 ICER 대신 "dominant"나 "dominated"로 적습니다.
  • 비용이 같은 대안. 효율 경계를 만들 때 비용만으로 정렬하면(np.argsort(cost)) 비용이 같은 두 대안 가운데 효과가 작은 쪽이 먼저 놓일 수 있습니다. 그러면 그 대안을 열등으로 걸러 내지 못하고 "ICER 0"을 냅니다. 비용 다음 효과의 내림차순으로 정렬합니다(아래 코드).

같은 순서를 파이썬으로 옮긴 코드와 실행 결과입니다. numpy와 pandas에는 효율 경계를 만드는 함수가 없어 직접 구현합니다.

직접 실행열등, 확장 열등, 효율 경계
import numpy as np

names = ["표준요법 B", "기존약 C", "병용요법 D", "신약 A"]
cost = np.array([7689.5, 8100.0, 9400.0, 10561.8])   # 총비용(만원)
qaly = np.array([1.87364, 1.70000, 2.00000, 2.38467]) # 총 QALY

keep = []                                    # 효율 경계에 남는 대안의 번호
for i in np.lexsort((-qaly, cost)):          # 비용이 낮은 것부터, 같으면 효과가 큰 것부터
    if any(qaly[j] >= qaly[i] for j in keep):
        print(names[i], "-> 열등")           # 비용이 같거나 더 싸면서 효과가 같거나 큰 대안이 있음
        continue
    keep.append(i)
    while len(keep) >= 3:                    # 이어진 세 대안의 ICER 순서를 확인
        a, b, c = keep[-3:]
        icer_ab = (cost[b] - cost[a]) / (qaly[b] - qaly[a])
        icer_bc = (cost[c] - cost[b]) / (qaly[c] - qaly[b])
        if icer_ab <= icer_bc:
            break
        print(names[b], "-> 확장 열등", round(icer_ab), ">", round(icer_bc))
        keep.pop(-2)                         # 가운데 대안을 뺌

for a, b in zip(keep[:-1], keep[1:]):
    icer = (cost[b] - cost[a]) / (qaly[b] - qaly[a])
    print(names[b], "대", names[a], "ICER", round(icer), "만원/QALY")
출력
기존약 C -> 열등
병용요법 D -> 확장 열등 13537 > 3020
신약 A 대 표준요법 B ICER 5621 만원/QALY
  • np.lexsort((-qaly, cost)): 마지막에 적은 cost를 첫 기준으로 삼아 비용이 낮은 순서대로 대안의 번호를 주고, 비용이 같으면 -qaly가 작은 순서, 곧 효과가 큰 순서로 놓습니다. 여기서는 0(B), 1(C), 2(D), 3(A)입니다. 비용만으로 정렬하는 np.argsort(cost)는 비용이 같은 두 대안의 순서를 효과와 관계없이 정합니다. 이 때문에 효과가 작은 대안이 앞에 놓이면, 그 대안을 열등으로 걸러 내지 못하고 "ICER 0"을 출력합니다.
  • any(qaly[j] >= qaly[i] for j in keep): 이미 남겨 둔 대안(모두 지금 대안보다 싸거나 비용이 같음) 가운데 효과가 같거나 큰 것이 하나라도 있으면 참입니다. C에서 참이 되어 "열등"이 출력됩니다.
  • while 블록은 경계에 남은 마지막 세 대안(a, b, c)에서 앞 쌍의 ICER가 뒤 쌍의 ICER보다 크면 가운데(b)를 뺍니다. A를 넣는 순간 B–D–A에서 13537 > 3020이어서 D가 빠집니다.
  • 마지막 반복문은 경계에 남은 대안을 이웃끼리 짝지어 ICER를 출력합니다. 반올림 차이를 없애려고 입력값을 소수 다섯째 자리까지 넣었습니다.

R과 다른 점은 0으로 나눌 때의 반응입니다. R은 경고 없이 Inf나 NaN을 돌려주므로, 어느 언어든 증분 QALY가 0인 경우를 먼저 거릅니다.

c.순편익

임계값에서 순편익은 어떻게 구하나?

임계값 λ에서 순금전편익은 λ × 증분 QALY − 증분비용, 순건강편익은 증분 QALY − 증분비용 ÷ λ입니다. 둘 다 0보다 크면 비용효과적입니다.

  1. 1λ = 5,000에서 순금전편익 −317.1만원, 순건강편익 −0.063 QALY. 환자 100명에게 쓰면 다른 곳에서 얻을 수 있었던 6.3 QALY를 잃는다는 뜻입니다(보건통계학 기초 20장 a 절 '환자 100명에게 쓰면 무엇을 얻고 무엇을 포기하나?').
  2. 2λ = 6,000부터 양수. 부호가 바뀌는 임계값이 ICER 5,620.6입니다.

대안이 넷이면 무엇을 고르나?

대안마다 λ × 총 QALY − 총비용을 구해 가장 큰 대안을 고릅니다. 효율 경계와 같은 답이 나옵니다.

  1. 1λ = 5,000에서는 B, 6,000에서는 A.
  2. 2A가 처음 가장 커지는 임계값 5,700(100 간격). 실제 경계는 ICER 5,620.6이고, 격자의 간격만큼 뒤에서 잡힙니다.

늘어난 0.511 QALY는 6,000만원/QALY로 3,066.2만원어치이고, 더 드는 비용은 2,872.3만원이므로 순금전편익은 193.9만원입니다. "QALY 하나에 6,000만원까지 낼 수 있다면, 신약 A로 얻는 건강은 더 드는 비용보다 환자 1인당 193.9만원(0.032 QALY)만큼 가치가 큽니다."

과제 2. 신약 E를 더해 다시 고르기

표준요법 B보다 600만원 더 들고 0.20 QALY를 더 주는 신약 E가 나왔습니다(보건통계학 기초 20장 d 절 '스스로 확인하기'). 다섯 대안의 효율 경계를 다시 만드세요.

정답 코드와 풀이

E가 경계에 들어오고(B 대비 ICER 3,000), D는 이제 더 싼 E보다 효과가 작아 열등이 됩니다. A의 비교 상대는 B가 아니라 경계에서 바로 앞에 있는 E가 되어 ICER가 7,306으로 올라갑니다. 대안이 늘면 같은 신약의 ICER도 달라지므로, 보고하는 ICER가 어느 대안과의 비교인지 밝힙니다.
