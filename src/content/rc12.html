b.부호순위 검정과 부호 검정

부호순위 검정은 어떻게 하나?

wilcox.test()에 paired = TRUE를 넣습니다. 변화가 0인 쌍과 같은 크기의 변화가 있으면 P를 구하는 방식이 여러 개라, 방식을 인자로 직접 적습니다. 예는 보건통계학 기초 3장 b 절의 약물 정리 전후 복용 약물 수 14명입니다.

  1. 1방향별 인원. 줄어든 사람 10명, 그대로 2명, 늘어난 사람 2명입니다. 이 표를 결과와 함께 보고합니다.
  2. 2정규근사, 연속성 보정 없이. 0인 쌍을 빼고 0.011입니다.
  3. 3정규근사, 연속성 보정. 0.012입니다. R 4.5까지는 이 자료에 인자 없이 써도 이 값이 나옵니다.

R 4.6.0부터는 쌍이 50개 미만이면 0과 동점이 있어도 정확 p를 기본으로 구하는데, 이때 0을 순위에 넣는 Pratt 방식을 써서 이 자료에서 V = 11, p = 0.0117이 나옵니다. 그래서 0을 어떻게 다뤘는지와 P를 구한 방식을 함께 밝힙니다.

정확 p, 부호 검정, t 검정은 어떻게 다른가?

0을 뺀 정확 p는 coin 패키지로, 부호 검정은 binom.test()로 구합니다. 세 검정이 쓰는 정보의 차이는 보건통계학 기초 3장 b 절에 있습니다.

  1. 1부호순위 검정의 정확 p. 0인 2쌍을 빼고 12쌍의 부호 조합 4,096가지를 모두 세어 0.0098입니다.
  2. 2부호 검정. 0이 아닌 12명 가운데 늘어난 2명으로 이항분포를 써서 0.039입니다.
  3. 3대응표본 t 검정. 0인 쌍까지 14쌍을 모두 써서 0.006입니다.

Hodges–Lehmann 추정치는 어떻게 구하나?

0을 뺀 차이로 두 개씩 평균(Walsh 평균)을 모두 만들고 그 중앙값을 구합니다. wilcox.test(…, conf.int = TRUE)도 이 값과 신뢰구간을 주지만, 0과 동점이 있으면 R 버전에 따라 계산 방식이 달라집니다.

  1. 1−2개. 차이의 중앙값과 같습니다. 0을 빼지 않고 14개로 계산하면 −1.5가 되므로, 어느 쪽인지 밝힙니다.

보건통계학 기초 3장 b 절의 '직접 분석' 상자에 있던 내용입니다.

a 절과 같은 두 열(환자당 한 줄, 기저와 3개월 약물 수)을 넣고 함수만 stats.wilcoxon(after, before)로 바꿉니다. 결과로는 늘어난 쪽과 줄어든 쪽의 순위합 가운데 작은 값과 P만 나오므로, 방향별 인원과 환자 내 변화의 중앙값은 직접 계산합니다. 0인 쌍의 처리와 P 계산 방식은 아래 두 문단에 있습니다.

scipy 1.17–1.18의 stats.wilcoxon()은 기본값(method="auto")에서 0과 동점이 없고 쌍이 50개 이하이면 정확 검정을 씁니다. 0이나 동점이 있으면 0을 포함한 쌍이 13개 이하일 때만 순열 분포로 정확 p를 구하고, 그보다 많으면 연속성 보정 없는 정규근사를 씁니다. 이 자료는 0을 포함해 14쌍이라 정규근사(0.011)가 나왔고, 정확 p는 method=stats.PermutationMethod(n_resamples=np.inf)로 따로 요청합니다. 논문에 흔한 R의 부호순위 검정 함수(wilcox.test())는 R 4.5까지 0이나 동점이 있으면 연속성 보정을 한 정규근사(0.012)가 기본이었고, R 4.6.0부터는 쌍이 50개 미만이면 0이나 동점이 있어도 조건부 정확 p를 구하는데, 0이 있으면 0을 포함해 순위를 매기는 Pratt 방식이라 이 자료에서는 V = 11, p = 0.0117입니다(정규근사는 지금도 0을 뺍니다). 이처럼 기본값은 버전에 따라 달라지므로 논문의 p와 비교할 때는 방식부터 확인합니다.

변화가 0인 환자는 늘었는지 줄었는지 알려 주지 않습니다. 그래서 Wilcoxon의 원래 방식은 0인 쌍을 빼고 남은 쌍으로 순위를 매기며, scipy의 기본값과 R 4.5까지의 기본값이 이 방식입니다(scipy의 zero_method="wilcox"). R 4.6.0부터는 기본값인 정확 계산(쌍 50개 미만)이 Pratt 방식으로 바뀌었으므로 R 버전을 함께 확인합니다. 0을 포함해 순위를 매긴 뒤 0의 순위만 버리는 Pratt 방식(zero_method="pratt")도 있습니다. Pratt 방식에서는 0인 환자가 가장 작은 순위들을 차지하므로 나머지 환자의 순위가 그만큼 커집니다. 이 자료를 Pratt 방식의 정규근사로 분석하면 p = 0.0112로, 원래 방식의 정규근사 0.011과 거의 같습니다. 0이 많을수록 두 방식의 차이가 커질 수 있으므로 어느 방식을 썼는지 Methods에 밝힙니다.

  5. 5PR(>F) = 0.0196. F(2, 87) 분포에서 4.117보다 큰 쪽의 넓이, 즉 p-value입니다. 논문에는 P = 0.020처럼 씁니다.

원자료가 없어도 출력의 sum_sq와 df만 있으면 나머지 칸과 p-value를 다시 계산할 수 있습니다. stats.f.sf(F, 분자 자유도, 분모 자유도)가 F보다 오른쪽 넓이(p-value)를, stats.f.ppf(0.95, …)가 5% 임계값을 줍니다.

print(f"5% 임계값 = {stats.f.ppf(0.95, df_b, df_w):.2f}")
print(f"eta^2 = {ss_b / (ss_b + ss_w):.3f}")

직접 실행요약값으로 Tukey 문턱과 p-value 다시 계산
import numpy as np
from scipy import stats

ms_w, n, k, df_w = 139.469651, 30, 3, 87   # 군내 평균제곱, 군당 인원, 군 수, 자유도
se_one = np.sqrt(ms_w / n)                  # 평균 하나의 SE (2.16)
se_diff = np.sqrt(2 * ms_w / n)             # 두 평균 차이의 SE (3.05)

q_crit = stats.studentized_range.ppf(0.95, k, df_w)
t_crit = stats.t.ppf(0.975, df_w)
print(f"q = {q_crit:.3f}, q/√2 = {q_crit / np.sqrt(2):.3f}, t = {t_crit:.3f}")
print(f"Tukey 문턱 = {q_crit * se_one:.2f}, 보정 없는 문턱 = {t_crit * se_diff:.2f}")

for name, diff in [("1회 - 일반", 5.800), ("집중 - 일반", 8.573), ("집중 - 1회", 2.773)]:
    p = stats.studentized_range.sf(diff / se_one, k, df_w)
    print(f"{name}: Tukey p = {p:.3f}")

e.순위로 비교하기와 추세

Kruskal-Wallis 검정은 어떻게 하나?

kruskal.test(결과 ~ 군)에 원래 값을 넣습니다. 군당 인원이 적으면 카이제곱 근사 대신 coin 패키지로 순열검정 p를 구합니다. 예는 보건통계학 기초 4장 d 절의 군당 5명 예비 자료입니다.

  1. 1카이제곱 근사. H = 5.78, P = 0.056입니다.
  2. 2순열검정. 군 이름표를 10만 번 섞어 구한 P 0.049로, 756,756가지 배정을 모두 센 정확 p와 같습니다. 무작위로 섞으므로 시드를 정합니다.

어느 쌍이 다른지는 어떻게 찾나?

rstatix 패키지의 dunn_test()로 Dunn 검정을 하고 보정 방법을 적습니다. 예는 4장의 PDC 90명입니다.

  1. 1Kruskal-Wallis. H = 7.45, P = 0.024입니다. 동점 보정은 R이 자동으로 합니다.
  2. 2동점이 많은 점수. 0–10점 지식 점수는 보정한 H가 8.99입니다(보정 전 8.75).
  3. 3Dunn 검정. 집중 상담 − 일반은 z = 2.71, 보정 전 P = 0.007, Holm 보정 0.020입니다. 쌍마다 Mann-Whitney 검정을 따로 하는 것과 달리 90명 전체의 순위를 씁니다.

세 군에 순서가 있으면?

DescTools 패키지의 JonckheereTerpstraTest()가 순위 기반 추세를, 군을 1, 2, 3 점수로 넣은 lm()이 한 단계당 평균 변화를 줍니다. 순서는 factor 수준의 순서입니다. 어느 방법을 'P for trend'로 쓸지는 보건통계학 기초 4장 e 절에서 정합니다.

  2. 2한 단계당 변화의 95% 신뢰구간. 1.3 ~ 7.3%p입니다.
  3. 3한 단계당 4.29%p. P = 0.006입니다. 점수 간격이 같다는 가정이 들어갑니다.

두 검정의 P까지 똑같이 나오는 것은, 엄밀히 말해 Mann-Whitney 검정을 연속성 보정 없이 정규근사로 계산할 때뿐입니다. scipy의 stats.mannwhitneyu()는 기본값에서 표본이 작고 같은 값이 없으면 정확 계산을, 그 밖에는 연속성 보정을 한 정규근사를 쓰므로 P가 조금 다릅니다. 예를 들어 보건통계학 기초 4장 d 절 '순위로 H를 어떻게 구하나?'의 군당 5명 작은 예제에서 일반 복약지도군과 1회 상담군만 넣으면 Kruskal-Wallis 검정의 P는 0.25이고 mannwhitneyu() 기본값의 P는 0.31입니다.

군당 인원이 5명 이하처럼 작으면 카이제곱 근사 대신 정확검정(exact test)이나 순열검정(permutation test)을 쓰는 것이 좋습니다. 정확검정은 위의 756,756가지처럼 가능한 배정을 모두 따져 근사 없이 p-value를 구하고, 순열검정은 군 이름표를 바꿔 붙인 여러 경우에서 통계량의 분포를 직접 만들어 p-value를 구합니다(모든 경우를 따지면 정확검정과 같습니다). 파이썬 scipy의 stats.kruskal()은 카이제곱 근사 p-value만 주므로(scipy 1.17–1.18 기준), 정확 p-value가 필요하면 stats.permutation_test()로 모든 배정을 따지는 순열검정을 합니다. 이 예제는 756,756가지를 모두 계산하므로 몇 초가 걸립니다. 인원이 많아 경우의 수가 너무 많으면 n_resamples=9999처럼 무작위로 뽑은 배정으로 p-value를 어림합니다.

직접 실행작은 예제의 정확 p-value
import numpy as np
from scipy import stats

usual = [58, 63, 67, 69, 73]
brief = [62, 68, 71, 77, 82]
intensive = [70, 74, 79, 81, 86]

def h_stat(*groups, axis=-1):              # 배정마다 H를 계산하는 함수
    return stats.kruskal(*groups, axis=axis).statistic

res = stats.permutation_test((usual, brief, intensive), h_stat,
                             permutation_type="independent",  # 환자를 군 사이에서 바꿔 배정
                             n_resamples=np.inf,               # 가능한 배정을 모두 따짐
                             alternative="greater")            # H가 관측값 이상인 비율
print(f"H = {res.statistic:.2f}, 정확 p = {res.pvalue:.3f}")
print(f"카이제곱 근사 p = {stats.kruskal(usual, brief, intensive).pvalue:.3f}")

H = 5.78, 정확 p = 0.049

표의 합계도 확인합니다. 입원 여부가 비어 있는 환자는 pd.crosstab이 경고 없이 표에서 빼므로, 합계가 1,000명보다 적으면 몇 명이 왜 빠졌는지 확인하고 분석한 인원을 보고합니다.

scipy의 chi2_contingency()는 자유도가 1인 표, 곧 2×2 표에서 기본으로 연속성 보정(continuity correction, Yates' correction)을 합니다(correction=True). 칸마다 |O − E|에서 0.5를 뺀 뒤 제곱하는 조정이고, 약물 A·B 표에서는 어긋남 12명을 11.5명으로 계산하므로 χ² = 4.32, p = 0.038이 됩니다(식은 보건통계학 기초 5장 a 절 '수식으로 보기').

내 분석에서는 correction=False를 넣고 Methods에 "without continuity correction"이라고 씁니다. 논문의 P를 표의 숫자로 검산했는데 0.030과 0.038처럼 다르면 이 보정 여부를 먼저 의심합니다. 기대빈도가 클수록 0.5의 비중이 작아져 두 값의 차이는 줄어듭니다.

scipy의 chi2_contingency()는 기대빈도가 작아도 경고 없이 χ²와 P를 돌려줍니다. 그래서 결과의 expected_freq로 기대빈도를 직접 확인합니다.

res = stats.chi2_contingency([[48, 352], [102, 498]], correction=False)
res.expected_freq          # [[60, 340], [90, 510]], 가장 작은 칸이 60명

두 비율의 z 검정은 statsmodels의 proportions_ztest()가 z = −2.17을 주고, chi2_contingency(..., correction=False)의 χ² = 4.71과 p-value 0.030이 같습니다. 짝지은 전후 표의 McNemar 검정은 statsmodels의 mcnemar()에 짝지은 표를 넣습니다.

직접 실행약물 A·B 표의 RD, RR, OR과 95% CI
import numpy as np
from scipy import stats

# 위험차(RD): 두 비율의 분산을 더해 SE를 구한다
p1, n1, p2, n2 = 48/400, 400, 102/600, 600
rd = p1 - p2
se = np.sqrt(p1*(1 - p1)/n1 + p2*(1 - p2)/n2)
print("RD", round(rd, 3), round(rd - 1.96*se, 3), round(rd + 1.96*se, 3))

# 상대위험도(RR): (A군 사건 수, A군 인원, B군 사건 수, B군 인원) 순서
rr = stats.contingency.relative_risk(48, 400, 102, 600)
ci = rr.confidence_interval()

g.Fisher의 정확한 검정

기대빈도가 작은 표는 어떻게 검정하나?

fisher.test()에 표를 넣습니다. 출력의 오즈비는 표에서 바로 계산한 값이 아니라 조건부 최대우도 추정값이고, 신뢰구간은 정확 구간입니다. 예는 보건통계학 기초 5장 b 절의 간독성 표(약물 X 1/15, 약물 Y 6/14)입니다.

  1. 1양측 P. 관측된 표보다 확률이 같거나 작은 표를 모두 더한 0.035입니다.
  2. 2정확 95% 신뢰구간. 0.002 ~ 1.08로 1을 포함합니다. P는 0.05보다 작은데 구간은 1을 넘는 이유는 5장 b 절에 있습니다.
  3. 3조건부 최대우도 추정값. 0.103입니다.
  4. 4단측 P. X군의 간독성이 더 적다는 방향으로 0.031입니다.
  5. 5표본 오즈비. (1 × 8) ÷ (14 × 6) = 0.095로, 1번 줄의 추정값과 다릅니다.

보수성을 줄이는 방법은 어떻게 계산하나?

mid-p는 관측된 표의 확률을 절반만 더하고, 'N − 1' 카이제곱 검정은 Pearson χ²에 (N − 1)/N을 곱합니다. 어느 방법이든 분석 계획에 미리 정했을 때만 씁니다.

import numpy as np
from scipy import stats

# 환자 1,000명을 한 줄씩 만든다: 점수 x(1, 2, 3)와 입원 여부 y(1, 0)
x = np.repeat([1, 2, 3, 1, 2, 3], [30, 36, 40, 170, 264, 460])
y = np.repeat([1, 1, 1, 0, 0, 0], [30, 36, 40, 170, 264, 460])

# 신호 ÷ 잡음: 두 결과군의 평균 점수 차이 ÷ 그 표준오차
d = x[y == 1].mean() - x[y == 0].mean()
se = x.std(ddof=1) * np.sqrt(1/106 + 1/894)
z = d / se
print(round(d, 4), round(se, 4), round(z, 3), round(z**2, 3))

# 상관계수로 쓴 같은 값: M2 = (N - 1) * r^2
r = np.corrcoef(x, y)[0, 1]
M2 = (len(x) - 1) * r**2
print(round(r, 5), round(M2, 3), round(stats.chi2.sf(M2, df=1), 4))
