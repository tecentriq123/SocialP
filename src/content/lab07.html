사건 변수 만들기

시간 단위와 사건 수

time은 일 단위입니다. 종양학 논문은 보통 개월로 보고하므로 개월 단위 열을 새로 만듭니다. 1개월은 365.25일 ÷ 12 = 30.4375일로 계산합니다. 모든 환자의 시간을 같은 수로 나누는 것이라 사건의 순서는 그대로이고, Kaplan-Meier 곡선과 로그순위 검정 결과는 단위만 바뀔 뿐 똑같습니다. 이어서 7장 가 절에서 본 요약값들을 계산합니다.

코드 한 줄씩

  2. n, d = len(lung), lung["event"].sum()쉼표로 두 값을 한 번에 저장합니다. len(lung)은 행 수(228), lung["event"].sum()은 1의 개수, 즉 사망자 수입니다.

  5. round(d / py * 100, 1)100인년당 사망 수(조사망률)입니다.

중앙 추적기간

논문은 "median follow-up"으로 추적이 충분했는지 보고합니다. 7장 가 절에서 본 세 가지 계산을 모두 해 보고 차이를 확인합니다. 역 Kaplan-Meier 방법은 사건 부호를 뒤집어(중도절단 = '사건', 사망 = '중도절단') Kaplan-Meier 곡선을 구하고 그 중앙값을 읽습니다.

코드 한 줄씩

  2. lung["months"].median()228명 전체 time의 중앙값입니다(단순 계산 1).
  3. alive = lung["event"] == 0중도절단 환자면 True인 Series입니다. 이렇게 True/False로 된 조건을 '불리언 마스크'라고 부릅니다.
  4. lung.loc[alive, "months"].loc[행 조건, 열 이름]으로 True인 행(63명)의 months 열만 골라냅니다(단순 계산 2).
  5. KaplanMeierFitter().fit(lung["months"], 1 - lung["event"])1 - event는 0과 1을 뒤집은 Series입니다. 중도절단(0)이 1이 되어 '사건'으로, 사망(1)이 0이 되어 '중도절단'으로 들어갑니다. 이것이 역 Kaplan-Meier 곡선입니다.
  6. fu.median_survival_time_역 곡선이 처음 0.5 이하가 되는 시점, 즉 중앙 추적기간입니다.
  7. qth_survival_times([0.75, 0.25], fu.survival_function_)곡선(survival_function_)이 처음 0.75 이하, 0.25 이하가 되는 시점을 구합니다. 사분위범위(IQR)의 두 끝입니다.

Greenwood 공식과 신뢰구간 방법 확인

lifelines의 신뢰구간은 어떤 방법일까요? 7장 나 절의 Greenwood 분산과 log-log 변환으로 12개월 신뢰구간을 직접 계산해 비교합니다. 프로그램마다 기본 변환이 다르므로(R의 survfit은 log 변환이 기본값) Methods에 적을 내용을 이렇게 확인해 두면 좋습니다.

코드 한 줄씩

  1. et = kmf.event_table.loc[:12]사건 표에서 12개월 이하인 행만 남깁니다.
  2. d, n = et["observed"], et["at_risk"]시점별 사망 수 dj와 위험집합 크기 nj입니다(각각 Series).
  3. gw = (d / (n * (n - d))).sum()Greenwood 공식의 합 \( \sum d_j / [n_j(n_j - d_j)] \)입니다. 사망이 없는 행은 d = 0이라 0을 더합니다.
  4. s * np.sqrt(gw)S(12)의 표준오차 = S × √합 입니다.
  5. sigma = np.sqrt(gw) / abs(np.log(s))log(−log S) 척도의 표준오차입니다(7장의 σ).
  6. s ** np.exp(1.96 * sigma)7장 식 \( \hat S^{\exp(\pm 1.96\sigma)} \)의 하한입니다. **는 거듭제곱입니다. 지수의 부호를 바꾼 다음 줄이 상한입니다.

출력 읽기

  2. 20.339–0.478이 lifelines의 결과와 똑같습니다. lifelines의 KaplanMeierFitter는 Greenwood 분산에 log(−log) 변환을 적용한 신뢰구간을 기본으로 씁니다(소스 코드에는 'exponential Greenwood'라고 적혀 있음). 7장의 예제와 같은 방법이며, Methods에는 "95% CIs were calculated using Greenwood's formula with a log(−log) transformation"처럼 씁니다. 같은 자료를 R 기본값(log 변환)으로 분석하면 끝자리가 조금 다를 수 있습니다.

제한평균생존시간

RMST는 τ까지의 곡선 아래 넓이로, "처음 τ 기간 가운데 평균적으로 살아 있던 기간"입니다(7장 나 절). 두 군 모두 위험집합이 남아 있는 24개월을 τ로 씁니다(남성 7명, 여성 6명). 실제 연구에서는 τ를 자료를 보기 전에 정합니다.

lifelines의 restricted_mean_survival_time(model, t=τ)는 RMST 자체는 정확히 계산하지만 신뢰구간은 주지 않습니다. return_variance=True를 넣으면 두 번째 값이 나오는데, 소스 코드를 보면 이것은 환자 개개인의 제한 생존시간 min(T, τ)가 얼마나 퍼져 있는지(분산)이고 RMST 추정값의 표준오차의 제곱이 아닙니다. 그대로 신뢰구간에 쓰면 구간이 지나치게 넓어집니다. 또 0.30.3 버전의 difference_of_restricted_mean_survival_time_test는 이름만 있고 아무 값도 돌려주지 않습니다. 그래서 7장 예제의 RMST 신뢰구간(23.5개월, 16.2–30.8)과 같은 Greenwood형 분산을 계산하는 작은 함수를 직접 만듭니다.

\[ \widehat{\mathrm{Var}}\big[\text{RMST}(\tau)\big] = \sum_{t_j \le \tau} A_j^2 \, \frac{d_j}{n_j(n_j - d_j)}, \qquad A_j = \int_{t_j}^{\tau} \hat S(u)\,du \]

\(A_j\)는 사망 시점 \(t_j\)부터 τ까지의 곡선 아래 넓이입니다. 이른 시점의 계단일수록 그 뒤의 넓이 전체에 영향을 주므로 가중치가 큽니다.

코드 한 줄씩

  1. from lifelines.utils import restricted_mean_survival_time as rmst긴 함수 이름을 rmst라는 별명으로 불러옵니다. rmst(k, t=24)는 추정기 k의 곡선 아래 넓이를 0부터 24까지 구합니다.
  2. def rmst_se(k, tau):함수 정의입니다. 추정기 k와 τ를 받아 RMST와 표준오차 두 값을 돌려줍니다. 들여쓴 줄들이 함수 본문입니다.
  3. et = et[et["observed"] > 0]τ 이하의 사건 표에서 사망이 있었던 시점만 남깁니다.
  4. area = np.array([rmst(k, t=tau) - rmst(k, t=t) for t in et.index])사망 시점마다 (0–τ 넓이) − (0–tj 넓이) = tj부터 τ까지의 넓이 Aj를 구합니다. 대괄호 안의 for는 리스트를 한 줄로 만드는 문법(리스트 컴프리헨션)입니다.
  5. var = (area**2 * d / (n * (n - d))).sum()위 식의 분산입니다. 마지막 환자까지 사망한 시점(n = d)이 τ 안에 있으면 0으로 나누게 되므로, 그런 경우에는 τ를 더 짧게 잡습니다.
  6. (r_m, se_m), (r_f, se_f) = [rmst_se(k, 24) for k in km_sex.values()]남성, 여성 추정기 각각에 함수를 적용해 (RMST, SE) 쌍 두 개를 얻고 네 변수에 나눠 담습니다.
  7. diff, se = r_f - r_m, np.sqrt(se_m**2 + se_f**2)차이(여성 − 남성)와 그 표준오차입니다. 두 군이 독립이므로 분산을 더합니다.
  8. diff - 1.96*se, diff + 1.96*se95% 신뢰구간의 두 끝입니다.

정리

  • KaplanMeierFitter().fit(시간, 사건, label=…) 한 번으로 survival_function_(곡선), event_table(위험집합·사망·중도절단), median_survival_time_, confidence_interval_을 얻습니다.
  • 중앙생존기간의 신뢰구간은 median_survival_times(kmf.confidence_interval_), 시점별 생존율은 survival_function_at_times(t)와 신뢰구간 표의 t 이전 마지막 행으로 읽습니다.
  • lifelines의 신뢰구간은 Greenwood 분산 + log(−log) 변환입니다(7장과 같은 방법, R 기본값과는 다름).

가중 로그순위 검정

로그순위 검정은 모든 사망 시점에 같은 무게를 둡니다. weightings 인자로 7장 다 절의 가중 검정을 할 수 있습니다. 여기서는 여러 검정의 결과가 어떻게 다른지 보기 위해 모두 계산하지만, 실제 연구에서는 주 분석의 검정을 자료를 보기 전에 하나로 정해야 합니다.

코드 한 줄씩

  1. tests = {"log-rank": {}, "Gehan-Breslow": {"weightings": "wilcoxon"}, …}검정 이름을 이름표로, logrank_test에 추가로 넘길 인자들을 값(딕셔너리)으로 담습니다. lifelines의 이름과 7장의 이름은 "wilcoxon" = Gehan-Breslow(가중치 nj), "tarone-ware" = Tarone-Ware(√nj), "peto" = Peto-Peto(Peto-Peto의 수정 생존 추정값), "fleming-harrington" = Fleming-Harrington으로 대응합니다.
  2. {"weightings": "fleming-harrington", "p": 0, "q": 1}Fleming-Harrington 가중치 S(t−)p[1 − S(t−)]q의 두 모수입니다. 7장의 (ρ, γ)가 lifelines에서는 (p, q)이고, (0, 1)은 후반에 무게를 둡니다. p와 q를 빼면 오류가 납니다.
  3. logrank_test(…, **kw)**kw는 딕셔너리를 풀어서 weightings="wilcoxon"처럼 이름 붙은 인자로 넘긴다는 뜻입니다. 빈 딕셔너리({})이면 아무것도 넘기지 않아 보통의 로그순위 검정이 됩니다.
  4. f"{name:<24} chi2 = {r.test_statistic:6.2f}":<24는 24칸에 왼쪽 정렬, :6.2f는 6칸에 소수 둘째 자리입니다. 결과가 열을 맞춰 출력됩니다.

정리

  • 두 군은 logrank_test(시간A, 시간B, 사건A, 사건B), 세 군 이상은 multivariate_logrank_test(시간, 군, 사건)으로 검정합니다. 정확한 P는 .p_value에서 읽습니다.
  • lifelines는 O와 E를 출력하지 않습니다. 방향은 곡선과 직접 계산한 O − E로 확인하고, 크기는 중앙생존기간·생존율·RMST 차이·위험비로 제시합니다.

  • weightings("wilcoxon", "tarone-ware", "peto", "fleming-harrington" + p, q)로 가중 검정을 할 수 있습니다. 검정은 미리 하나로 정하고, 여러 검정의 결과를 골라 보고하지 않습니다.
