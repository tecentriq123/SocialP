모형의 입력값은 모두 불확실성을 지니고 있으므로, 경제성 평가는 기준 분석의 ICER 하나로 끝나지 않습니다. 이 장에서는 세 가지를 R로 만듭니다. 입력값을 하나씩 바꿔 보는 일원 민감도 분석(one-way sensitivity analysis), 모든 입력값을 분포에서 함께 뽑아 모형을 수천 번 돌리는 확률적 민감도 분석(probabilistic sensitivity analysis, PSA), 그리고 임계값마다 신약이 비용효과적으로 나온 반복의 비율을 이은 비용효과 수용곡선(cost-effectiveness acceptability curve, CEAC)입니다. 모형은 22장의 분할생존모형이고 분포는 보건통계학 기초 24장과 같습니다. 결정론적인 결과는 파이썬 실습 24와 그대로 맞고, 확률적인 결과는 난수가 달라 몬테카를로 오차 안에서 비슷합니다.

입력값마다 분포는 어떻게 정하나?

위험비와 곡선의 모수는 로그정규, 효용은 베타, 비용과 QALY 손실은 감마 분포를 쓰고, 분포의 모수를 정합니다. 베타와 감마는 평균과 표준오차로 모수를 구하는 적률법(method of moments)을 쓰고, 로그정규는 기준값과 로그 척도의 표준오차를 씁니다. 값의 범위에 맞는 분포를 고르는 것입니다. 효용은 0–1, 비용은 0 이상, 위험비는 로그 척도에서 대칭입니다(보건통계학 기초 24장 b 절).

코드 한 줄씩

  1. spec <- data.frame(key, dist, u)입력값마다 분포와 불확실성의 크기입니다. u는 로그정규면 로그 척도의 표준오차, 베타면 표준오차, 감마면 표준오차 ÷ 평균입니다.
  2. beta_ab(), gamma_ks()평균과 표준오차를 분포의 모수로 바꿉니다. 감마는 모양(shape)과 척도(scale)로 돌려줍니다.
  1. 115개. 약값 둘과 할인율을 뺀 입력값에 분포를 줍니다.
  2. 2베타(147.94, 41.73). 평균 0.78, 표준오차 0.03인 베타분포입니다. 실습 24와 같습니다.
  3. 3감마(모양 25, 척도 10). 평균 250만원, 표준오차 50만원입니다. R의 rgamma()와 qgamma()는 모양 다음 자리의 인자가 척도가 아니라 율(rate = 1/척도)이므로, 척도는 꼭 scale =로 이름을 붙여 넘깁니다.

보건통계학 기초 24장의 '직접 분석' 상자와 '장 마무리'에 있던 내용입니다. 글 속의 a–c 절은 24장의 절입니다.

  • numpy의 rng.gamma(shape, scale)는 둘째 인자가 척도입니다. 위의 감마분포는 rng.gamma(25, 10)입니다.
  • scipy의 stats.gamma.ppf(q, a, loc, scale)에 이름 없이 셋째로 넣은 값은 척도가 아니라 위치(loc)로 들어갑니다. stats.gamma.ppf(0.5, 25, 10)은 중앙값 246.7이 아니라 34.7을 내므로, 척도는 scale=10처럼 이름을 붙여 넣습니다.
  • numpy의 rng.lognormal(mean, sigma)에서 mean은 로그 척도의 평균입니다. 위험비 0.75라면 ln 0.75 = −0.288을 넣어야 하고, 0.75를 넣으면 중앙값이 2.12인 분포에서 뽑힙니다. scipy의 stats.lognorm(s, loc, scale)은 s에 로그 척도의 표준오차(0.131), scale에 위험비(0.75)를 넣습니다.
  • 적률법이 안 되는 베타분포. 표준오차의 제곱이 평균 × (1 − 평균) 이상이면 적률법 식의 n(b 절 접힌 상자 '평균과 표준오차를 분포의 모수로 어떻게 바꾸나?')이 0 이하가 되어 rng.beta가 ValueError를 냅니다(예를 들어 평균 0.9, 표준오차 0.3). 효용의 평균에 비해 이렇게 큰 표준오차는 드물므로, 표준편차를 표준오차 자리에 넣지 않았는지 먼저 봅니다.

보건통계학 기초 24장의 '직접 분석' 상자와 '장 마무리'에 있던 내용입니다. 글 속의 a–c 절은 24장의 절입니다.

a 절의 표 24-2와 임계 가격을 내는 코드입니다. 공통 예시의 모형을 함수 하나로 만들고, 입력값을 하나씩 바꿔 넣습니다. 앞부분의 model()은 보건통계학 기초 23장 c 절의 분할생존모형과 같은 계산입니다. 이 셀을 먼저 실행한 뒤 c 절과 d 절 파이썬 상자의 코드를 이어서 실행합니다.

직접 실행일원 민감도 분석과 임계 가격 (표 24-2)
import numpy as np
from scipy import stats
from scipy.optimize import brentq

t = np.arange(0, 241)                                   # 0, 1, ..., 240개월
base = dict(hr_pfs=0.65, hr_os=0.75,                    # 기준 분석 입력값(23장 c 절의 표)
            pfs_lam=np.log(2) / 10 ** 0.95, pfs_gam=0.95, os_lam=np.log(2) / 28 ** 1.15, os_gam=1.15,
            u_pf=0.78, u_pd=0.62, du_ae_A=0.012, du_ae_B=0.008,
            c_pf=40.0, c_pd=250.0, c_death=800.0, c_ae_A=120.0, c_ae_B=80.0,
            c_drug_A=190.0, c_drug_B=120.0)

def model(v):                                           # 입력값 한 세트 → (증분비용, 증분QALY)
    res = {}
    for arm, hr_pfs, hr_os in (("A", v["hr_pfs"], v["hr_os"]), ("B", 1.0, 1.0)):
        os_ = np.exp(-v["os_lam"] * hr_os * t ** v["os_gam"])
        pfs = np.minimum(np.exp(-v["pfs_lam"] * hr_pfs * t ** v["pfs_gam"]), os_)
        pf = (pfs[:-1] + pfs[1:]) / 2                   # 무진행 비율(반주기 보정)
        pd_ = ((os_ - pfs)[:-1] + (os_ - pfs)[1:]) / 2  # 진행 비율
        died = os_[:-1] - os_[1:]
        disc = 1 / 1.045 ** ((t[:-1] + 0.5) / 12)
        cost = ((pf * (v["c_drug_" + arm] + v["c_pf"]) + pd_ * v["c_pd"] + died * v["c_death"]) * disc).sum() + v["c_ae_" + arm]
        qaly = ((pf * v["u_pf"] + pd_ * v["u_pd"]) / 12 * disc).sum() - v["du_ae_" + arm]
        res[arm] = (cost, qaly)
    return res["A"][0] - res["B"][0], res["A"][1] - res["B"][1]

dc, dq = model(base)
print("기준 분석: 증분비용", round(dc), "증분QALY", round(dq, 3), "ICER", round(dc / dq))

z = np.array([-1.96, 1.96])
ranges = {"hr_os": np.exp(np.log(0.75) + z * 0.131),    # 위험비: 로그 척도에서 ±1.96 × 표준오차
          "hr_pfs": np.exp(np.log(0.65) + z * 0.113),
          "c_drug_A": np.array([152.0, 190.0]),         # 표시 가격에서 20% 인하한 값까지
          "u_pf": stats.beta.ppf([0.025, 0.975], 147.94, 41.727)}   # 베타분포의 95% 구간(b 절)
for name, (low, high) in ranges.items():                # 일원 민감도 분석: 하나씩만 바꾼다
    icers = []
    for value in (low, high):
        c, q = model({**base, name: value})
        icers.append(round(c / q))
    print(name, "범위", round(low, 3), "-", round(high, 3), " ICER", icers)

def gap(price):                                         # 그 가격에서의 ICER - 5,000
    c, q = model({**base, "c_drug_A": price})
    return c / q - 5000
print("ICER가 5,000이 되는 월 약값:", round(brentq(gap, 100, 190), 2))

  • brentq(gap, 100, 190)는 gap(price)가 0이 되는 가격을 100과 190 사이에서 찾습니다. 두 끝에서 함수값의 부호가 달라야 합니다. 결과 175.39가 a 절의 임계 가격 175.4만원입니다.

약값이 아닌 입력값의 임계값.

약값이 아닌 입력값은 결과가 입력값의 1차식이 아니어서 나눗셈 한 번으로 풀 수 없습니다. 이때는 'ICER − 5,000'을 그 입력값의 함수로 만들고, 이 값이 0이 되는 곳을 근 찾기 함수 scipy.optimize.brentq로 찾습니다. 위의 0.55, 0.36, 0.88이 이렇게 구한 값입니다. brentq에는 답이 들어 있을 구간의 양 끝을 주는데, 양 끝에서 함수값의 부호가 같으면 답을 찾지 못하고 ValueError를 냅니다. 찾은 값은 그 입력값의 95% 구간과 비교해 근거가 가리키는 범위 안인지 확인합니다. 위 코드는 이 계산을 약값으로 합니다. 그 코드의 gap() 안의 c_drug_A를 hr_pfs로, brentq의 구간을 0.3과 0.81로 바꾸면 0.55가 나옵니다.

  • 근 찾기의 구간. brentq(f, a, b)는 두 끝에서 f의 부호가 같으면 ValueError를 냅니다. 전체생존 위험비로 ICER가 5,000만원이 되는 값을 95% 구간(0.58–0.97) 안에서 찾으면 이 오류가 납니다. 찾는 값(0.36)이 구간 밖에 있다는 뜻이고, 구간 안에 답이 없다는 것이 곧 분석의 결과입니다(a 절 '결론이 바뀌는 약값은 얼마인가?').

c.확률적 민감도 분석

입력값 한 세트는 어떻게 뽑나?

곡선과 위험비는 무진행생존과 전체생존의 모수를 짝지어 상관(이 예에서는 ρ = 0.5)을 주고 함께 뽑습니다. 20년 안에 무진행생존이 전체생존보다 높아지는 조합이 나오면 그 반복은 버리고 다시 뽑습니다. 나머지 입력값은 각자의 분포에서 뽑습니다. 같은 환자들에게서 추정한 두 곡선의 불확실성은 서로 얽혀 있기 때문입니다(보건통계학 기초 23장 c 절의 접힌 상자 '확률적 민감도 분석에서는 두 곡선이 왜 더 자주 엇갈리나?').

  4. attr(q, "tries") <- tries몇 번 만에 채택했는지를 결과에 붙여 둡니다. 함수가 값 하나만 돌려줄 때 덧붙인 정보를 함께 넘기는 방법입니다.

환자 자료가 있으면 곡선의 두 모수는 어떻게 함께 뽑나?

와이블 모형을 적합한 뒤 로그 척도의 계수(coef())와 공분산 행렬(vcov())을 MASS 패키지의 mvrnorm()에 넣어 두 모수를 함께 뽑습니다. 위 셀은 중앙값과 모양 모수의 표준오차와 상관을 가정해 뽑았습니다. 환자 자료나 발표된 곡선에서 재구성한 자료가 있으면 적합 결과의 공분산 행렬을 그대로 씁니다(보건통계학 기초 24장 '장 마무리'의 접힌 상자 '발표된 생존곡선만 있으면 곡선 모수는 어떻게 뽑나?'). 여기서는 16장의 표준요법군 300명을 재구성한 자료로 봅니다.

  1. 1모양 1.145, 척도 39.059개월. flexsurv의 와이블은 S(t) = exp(−(t ÷ scale)shape)입니다. coef()는 두 값의 로그를 돌려줍니다.
  2. 2로그 척도 표준오차 0.077과 0.083, 상관 −0.48. flexsurv는 로그 척도에서 적합하므로 vcov()를 그대로 씁니다.
  3. 3뽑은 곡선의 24개월 생존율 95% 구간 0.508–0.615. 난수를 쓰는 값이지만 이 자료에서는 파이썬(lifelines, numpy)과 셋째 자리까지 같았습니다.
  4. 4Kaplan-Meier 추정값 0.557(0.499–0.611). 뽑은 곡선의 구간과 비슷하므로 자료와 맞는 곡선을 뽑았습니다. survfit()의 기본 구간(conf.type = "log")은 0.503–0.616이어서, 24장에 적은 파이썬 lifelines의 값과 맞추려고 log-log 구간을 썼습니다.
  5. 5이 과목의 꼴(λ, γ)로 적으면 상관 −0.96. 상관의 크기는 모수를 어떤 꼴로 적느냐에 따라 다르므로, 실제로 뽑는 꼴의 공분산 행렬을 씁니다.

보건통계학 기초 24장의 '직접 분석' 상자와 '장 마무리'에 있던 접힌 상자 '발표된 생존곡선만 있으면 곡선 모수는 어떻게 뽑나?'입니다. lifelines의 variance_matrix_는 모수 그 자체의 공분산 행렬이어서 델타법으로 로그 척도로 옮기고, Kaplan-Meier 신뢰구간은 log-log 방식이 기본입니다. 글 속의 a–c 절은 24장의 절입니다.

23장의 가상 시험 자료(표준요법 B군 300명, 실습 23의 rcc_trial.csv)를 재구성한 자료라고 보고, lifelines의 와이블 모형으로 해 봅니다. lifelines 0.30.3으로 실행한 출력입니다.

직접 실행곡선 모수를 함께 뽑기
import numpy as np
import pandas as pd
from lifelines import WeibullFitter

d = pd.read_csv("rcc_trial.csv")                     # 실습 23의 자료(재구성한 자료 대신)
wf = WeibullFitter().fit(d["months"], d["event"])
m = wf.params_.to_numpy()                            # [lambda_, rho_]
V = wf.variance_matrix_.to_numpy()                   # 같은 척도의 공분산 행렬
J = np.diag(1 / m)                                   # 델타법으로 로그 척도로 옮긴다
V_log = J @ V @ J
se = np.sqrt(np.diag(V_log))
print("lambda_, rho_:", m.round(3))
print("로그 척도 표준오차:", se.round(3), " 상관:", round(V_log[0, 1] / (se[0] * se[1]), 2))

rng = np.random.default_rng(1)
draws = np.exp(rng.multivariate_normal(np.log(m), V_log, size=20000))
s24 = np.exp(-(24 / draws[:, 0]) ** draws[:, 1])     # 뽑은 곡선마다 24개월 생존율
print("24개월 생존율 95% 구간:", np.percentile(s24, [2.5, 97.5]).round(3))
lam = draws[:, 0] ** (-draws[:, 1])                  # 이 책의 꼴 S(t) = exp(-lam * t^gam)의 lam

  • params_의 lambda_(39.06개월)는 시간의 척도이고 rho_(1.145)는 모양 모수입니다. lifelines의 곡선은 S(t) = exp(−(t ÷ lambda_)rho_)이므로, 이 책의 꼴 S(t) = exp(−λ tγ)로 옮기면 λ = lambda_−rho_ = 0.0150, γ = rho_입니다.
  • variance_matrix_는 lambda_와 rho_ 그 자체의 공분산 행렬입니다. 두 모수는 0보다 커야 하므로 로그 척도에서 뽑습니다(표 24-4의 위험비와 같은 이유). J @ V @ J는 행렬을 로그 척도로 옮기는 줄입니다. 각 모수의 표준오차를 그 모수의 값으로 나누는 델타법 계산입니다.
  • 상관의 크기는 모수를 어떤 꼴로 적느냐에 따라 다릅니다. 이 꼴에서는 −0.48이지만 이 책의 λ와 γ로 적으면 −0.96입니다(b 절 접힌 상자 '와이블 곡선의 두 모수는 왜 함께 뽑아야 하나?'). 그래서 실제로 뽑는 꼴로 옮긴 공분산 행렬을 씁니다.

  • 공분산 행렬은 한 곡선 안의 두 모수 사이의 상관만 줍니다. 무진행생존과 전체생존처럼 따로 적합한 두 곡선 사이의 상관은 이 행렬에 없습니다. 환자를 부트스트랩으로 다시 뽑아 두 곡선을 함께 다시 적합하거나, 공통 예시처럼 상관을 가정하고 근거를 밝힙니다.

직접 실행확률적 민감도 분석 5,000회 (표 24-5)
pairs = {("pfs_med", "os_med"): (10, 28, 0.07, 0.08),         # 함께 뽑는 짝: 기준값 둘, 로그 척도의 표준오차 둘
         ("pfs_gam", "os_gam"): (0.95, 1.15, 0.05, 0.06),    # med = 중앙 생존기간(개월), gam = 모양 모수
         ("hr_pfs", "hr_os"): (0.65, 0.75, 0.113, 0.131)}
rho = 0.5                                               # 짝 안의 두 값 사이의 상관계수
spec = dict(u_pf=("beta", 0.03), u_pd=("beta", 0.05),   # 따로 뽑는 입력값: (분포, 불확실성의 크기)
            du_ae_A=("gamma", 0.25), du_ae_B=("gamma", 0.25),
            c_pf=("gamma", 0.20), c_pd=("gamma", 0.20), c_death=("gamma", 0.20),
            c_ae_A=("gamma", 0.25), c_ae_B=("gamma", 0.25))
count = {"tries": 0}                                    # 곡선과 위험비를 뽑은 횟수를 센다

def crossed(v):                                         # 어느 군에서든 무진행생존 곡선이 전체생존 곡선을 넘으면 True
    for hr_pfs, hr_os in ((v["hr_pfs"], v["hr_os"]), (1.0, 1.0)):
        pfs = np.exp(-v["pfs_lam"] * hr_pfs * t ** v["pfs_gam"])
        os_ = np.exp(-v["os_lam"] * hr_os * t ** v["os_gam"])
        if (pfs > os_).any():
            return True
    return False

def draw(rng):                                          # 입력값 한 세트를 분포에서 뽑는다
    v = dict(base)                                      # 약값은 base의 값 그대로(고정)
    while True:                                         # 곡선이 엇갈리면 다시 뽑는다
        count["tries"] += 1
        for (k1, k2), (m1, m2, s1, s2) in pairs.items():
            z1, z2 = rng.normal(size=2)                 # 서로 독립인 표준정규 난수 두 개
            z2 = rho * z1 + np.sqrt(1 - rho ** 2) * z2  # z2를 z1과 상관 0.5인 값으로 바꾼다
            v[k1], v[k2] = m1 * np.exp(s1 * z1), m2 * np.exp(s2 * z2)
        v["pfs_lam"] = np.log(2) / v["pfs_med"] ** v["pfs_gam"]   # 중앙값과 모양 모수에서 척도 모수
        v["os_lam"] = np.log(2) / v["os_med"] ** v["os_gam"]
        if not crossed(v):
            break
    for name, (dist, u) in spec.items():
        m = base[name]
        if dist == "beta":                              # u = 표준오차
            n = m * (1 - m) / u ** 2 - 1
            v[name] = rng.beta(m * n, (1 - m) * n)
        else:                                           # gamma: u = 표준오차 / 평균
            se = m * u
            shape = (m / se) ** 2
            v[name] = rng.gamma(shape, m / shape)
    return v

rng = np.random.default_rng(20261002)                   # 난수 seed를 고정해 결과를 재현

d.수용곡선과 EVPI

임계값마다의 확률과 EVPI는 어떻게 구하나?

임계값 k마다 순금전편익(k × 증분 QALY − 증분비용)이 양수인 반복의 비율을 구하면 수용곡선이 됩니다. 또 반복마다 '더 나은 대안을 미리 알고 골랐을 때의 순편익'에서 '지금 고른 대안의 순편익'을 뺀 차이를 평균하면 완전정보의 기대가치(expected value of perfect information, EVPI)입니다. 두 값의 뜻은 보건통계학 기초 24장 c 절에 있습니다.

코드 한 줄씩

  1. mean(lam * dq - dc > 0)참·거짓의 평균은 참의 비율입니다.
  2. mean(pmax(nb, 0)) - max(mean(nb), 0)앞은 반복마다 더 나은 쪽(신약이면 nb, 표준요법이면 0)을 골랐을 때의 평균, 뒤는 평균만 보고 한 쪽을 골랐을 때입니다. pmax()는 칸마다, max()는 전체에서 큰 값입니다.
  1. 15,000에서 확률 0.163, EVPI 36.4만원. 1인당 값입니다. 대상 환자 수를 곱하면 추가 연구의 가치를 가늠하는 상한이 됩니다. 실습 24는 35.9만원이었습니다.
  2. 25,500에서 확률 0.437, EVPI 141.9만원. 평균끼리 나눈 ICER(5,569, 셀 10)에 가까운 임계값이라 결정이 가장 불확실해 EVPI가 큽니다.
  3. 312,000에서 0.980. 임계값을 아주 높여도 1이 되지 않습니다. ICER가 아주 큰 반복이 남아 있고, 끝까지 가도 신약의 효과가 더 낮게 나온 반복(27번)은 비용효과적이 될 수 없기 때문입니다.

수용곡선은 어떻게 그리나?

0부터 12,000만원까지 100만원 간격의 임계값마다 확률을 구해 선으로 잇습니다.

  1. 15,620. 확률이 처음으로 50% 이상이 되는 임계값으로, 순금전편익의 중앙값이 0이 되는 곳입니다. 그래서 평균 순금전편익이 0이 되어 결정이 바뀌는 곳(평균끼리 나눈 ICER 5,569, 셀 10)과는 다릅니다. 기준 분석의 ICER(5,621)와 거의 같지만 두 값이 같아야 할 이유는 없습니다(보건통계학 기초 24장 c 절의 '수용곡선은 어떻게 잘못 읽히나?'). 실습 24는 5,650이었습니다.

수용곡선은 'ICER가 임계값보다 작은 반복의 비율'이 아닙니다. ICER는 증분 QALY가 음수인 반복에서 뜻이 뒤집히므로, 확률은 언제나 순금전편익의 부호로 셉니다(보건통계학 기초 24장 c 절). 논문에는 수용곡선과 함께 몇 번 반복했는지, 난수 seed, 분포 표, 그리고 곡선이 엇갈린 반복을 어떻게 처리했는지를 적습니다.

정리

  • 입력값마다 범위에 맞는 분포(위험비 로그정규, 효용 베타, 비용 감마)를 정하고 적률법으로 모수를 구합니다. rgamma()와 qgamma()에는 scale =을 이름으로 넘깁니다.
  • 일원 민감도 분석은 입력값을 하나씩 양 끝으로 바꿔 ICER의 폭을 보고, 임계값을 넘는 입력값을 찾습니다. 이 예시에서는 무진행생존 위험비와 두 약값입니다.
  • 확률적 분석은 상관이 있는 곡선을 함께 뽑고 엇갈린 반복을 다시 뽑아 5,000번 돌립니다. 이 예시의 비용효과적일 확률은 0.163(몬테카를로 표준오차 0.005)입니다.
  • 수용곡선과 EVPI는 순금전편익의 부호와 크기로 계산합니다. R과 파이썬은 난수가 달라 결과가 몬테카를로 오차만큼 다릅니다.

보건통계학 기초 24장의 '직접 분석' 상자와 '장 마무리'에 있던 내용입니다. 글 속의 a–c 절은 24장의 절입니다.

c 절의 확률을 구할 때 프로그램에 넣는 것은 b 절이 낸 두 배열(모의실험 5,000번의 증분비용과 증분 QALY)과 임계값 하나입니다. numpy·scipy·statsmodels에는 수용곡선을 그려 주는 함수가 없습니다. 확률은 np.mean(lam * dq - dc > 0) 한 줄로 직접 계산하고, 임계값을 바꿔 가며 이 줄을 되풀이합니다.

c 절의 표 24-7과 EVPI를 내는 코드입니다. c 절 파이썬 상자에서 만든 dc, dq(5,000번의 증분비용과 증분 QALY)를 쓰므로 그 상자에 이어서 실행합니다.

직접 실행임계값별 확률과 EVPI
lams = np.array([3000, 4000, 5000, 6000, 7000, 8000, 10000])
for lam in lams:
    inmb = lam * dq - dc                                # 모의실험마다의 증분 순금전편익
    p_ce = np.mean(inmb > 0)                            # 양수인 비율 = 비용효과적일 확률
    evpi = np.maximum(inmb, 0).mean() - max(inmb.mean(), 0)
    print(lam, " 확률", round(p_ce, 3), " 평균 순편익", round(inmb.mean()), " EVPI", round(evpi, 1))

  • lam * dq - dc는 길이 5,000인 배열입니다. 모의실험마다의 증분 순금전편익이 한 줄로 계산됩니다.
  • np.mean(inmb > 0)은 참(1)과 거짓(0)의 평균이므로 양수인 비율입니다. 임계값마다 이 값을 구해 이으면 수용곡선입니다.
  • np.maximum(inmb, 0).mean()은 참값을 알고 고를 때의 기대 이득, max(inmb.mean(), 0)은 지금의 정보로 고를 때의 기대 이득입니다. 둘의 차이가 EVPI입니다.
  • 출력의 확률과 평균 순편익은 표 24-7과 같고, EVPI는 '확률만 보면 무엇을 놓치나?'의 접힌 상자 'EVPI는 어떻게 계산하나?'의 값과 같습니다. 수용곡선을 그리려면 lams를 np.arange(0, 12001, 100)처럼 촘촘하게 잡습니다.

과제 1. 임계 약값에서의 확률

22장 과제 1에서 구한 임계 약값(월 175.39만원)으로 확률적 분석을 다시 돌리세요. 기준 분석의 ICER가 임계값과 같을 때 비용효과적일 확률은 얼마인가요?

정답 코드와 풀이

기준 분석의 ICER는 5,000만원이고, 비용효과적일 확률은 0.498로 거의 50%입니다. 평균 순금전편익도 18만원으로 0에 가깝습니다. 이 예시에서는 확률적 분석의 결과가 기준 분석을 가운데에 두고 퍼져 있어서 반반에 가깝게 나왔고, 언제나 그렇지는 않습니다. 약가 협상에서 '임계 가격'은 결정이 가장 불확실한 지점이라는 뜻이기도 합니다.

과제 2. 모의실험 횟수와 몬테카를로 오차

처음 500번, 1,000번, 5,000번만 써서 비용효과적일 확률과 그 95% 범위를 구하세요. 또 seed를 1, 2, 3으로 바꿔 5,000번씩 돌려 보세요.

정답 코드와 풀이

500번의 표준오차는 0.016으로, 확률이 0.12–0.19 사이 어디라고밖에 말할 수 없습니다. 5,000번이면 0.005로 줄어듭니다. seed를 바꾼 세 번의 결과(0.165, 0.159, 0.163)도 이 범위 안에 있습니다. 몬테카를로 표준오차는 횟수의 제곱근에 반비례하므로, 오차를 절반으로 줄이려면 횟수를 네 배로 늘려야 합니다. 보고하는 자릿수는 이 오차에 맞춥니다.

과제 3. 곡선을 상관 없이 뽑으면

rho = 0으로 무진행생존과 전체생존의 모수를 따로 뽑아 다시 돌리세요. 다시 뽑은 비율과 비용효과적일 확률은 어떻게 바뀌나요?

정답 코드와 풀이

버리고 다시 뽑은 비율이 2.5%에서 8.7%로 세 배 넘게 늘어납니다. 따로 뽑으면 무진행생존은 좋게, 전체생존은 나쁘게 뽑히는 조합이 잦아 두 곡선이 자주 엇갈립니다. 비용효과적일 확률은 0.160으로 이 예시에서는 크게 다르지 않지만, 엇갈림을 그대로 두거나 상관을 무시하면 결과의 불확실성이 실제와 다르게 그려질 수 있습니다(실습 24 c 절). 상관의 크기를 어떻게 정했는지도 보고서에 적습니다.
