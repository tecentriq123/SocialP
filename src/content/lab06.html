다중공선성과 VIF

분산팽창계수(VIF)는 설명변수 하나를 나머지 설명변수로 회귀했을 때의 결정계수 Rj²로 VIF = 1/(1 − Rj²)를 계산합니다(6장 라 절). statsmodels의 variance_inflation_factor는 변수 하나씩 계산하므로 반복문으로 모든 변수에 적용합니다.

코드 한 줄씩

  1. from statsmodels.stats.outliers_influence import (variance_inflation_factor)VIF 함수를 불러옵니다. 이름이 길어 괄호로 감싸고 줄을 바꿨습니다.
  2. def vif_table(m):적합된 모형 m을 받아 VIF 표를 돌려주는 함수를 정의합니다. 한 번 정의해 두면 뒤에서 다른 모형에도 쓸 수 있습니다. 함수 안의 줄은 들여쓰기(공백 4칸)로 구분합니다.
  3. X, names = m.model.exog, m.model.exog_namesexog는 모형이 실제로 계산에 쓴 설계행렬(design matrix)입니다. 442행 × 6열(절편 열 1, sex 가변수 1, bmi, age, bp, s5)의 숫자 배열이고, exog_names는 그 열 이름입니다. C(sex)가 만든 가변수 열도 여기 들어 있습니다.
  4. v = [variance_inflation_factor(X, i) for i in range(X.shape[1])]리스트 컴프리헨션입니다. X.shape[1]은 열 수(6)이고, i = 0, 1, …, 5 각각에 대해 i번째 열의 VIF를 계산해 리스트로 모읍니다.
  5. s = pd.Series(v, index=names, name="VIF") return s.drop("Intercept").round(2)VIF 값에 설계행렬의 열 이름을 붙여 Series로 만들고, 의미가 없는 절편 행을 뺀 뒤 반올림해 돌려줍니다(return).

논문용 결과표 만들기

관찰연구의 회귀분석 결과는 보통 보정하지 않은 계수(변수 하나씩 넣은 단순회귀)와 보정한 계수(다중회귀)를 나란히 보여 줍니다(6장 라 절 Table 3). 숫자를 손으로 옮기면 오타가 생기기 쉬우므로 표를 코드로 만듭니다.

코드 한 줄씩

  1. def tidy(m):적합된 모형 하나를 받아 "β (95% CI)"와 P 두 열의 표를 돌려주는 함수입니다.
  2. f2 = "{:.2f}".format숫자를 소수 둘째 자리 문자열로 바꾸는 함수를 f2라는 이름으로 둡니다. f2(10.2331)은 "10.23"입니다.
  3. m.params.map(f2) + " (" + ci[0].map(f2) + " to " + ci[1].map(f2) + ")"map은 Series의 값 하나하나에 함수를 적용합니다. 계수, 하한, 상한을 문자열로 바꿔 이어 붙이면 계수마다 "10.23 (8.91 to 11.56)" 같은 문자열이 만들어집니다. 음수가 있는 구간은 "to"로 이어야 헷갈리지 않습니다.
  4. m.pvalues.map(lambda x: "<0.001" if x < 0.001 else f"{x:.3f}")p가 0.001보다 작으면 "<0.001", 아니면 소수 셋째 자리로 표시합니다.
  5. crude = pd.concat([tidy(smf.ols(f"target ~ {t}", data=df).fit()).drop("Intercept") for t in terms])terms의 변수마다 단순회귀를 적합해 tidy 표를 만들고, 절편 행을 뺀 뒤 위아래로 이어 붙입니다. 이것이 "Unadjusted" 열입니다.
  6. crude.join(tidy(model_adj), lsuffix=" crude", rsuffix=" adjusted")행 이름(계수 이름)이 같은 것끼리 옆으로 붙입니다. 두 표의 열 이름이 같으므로 왼쪽에 " crude", 오른쪽에 " adjusted"를 붙여 구분합니다. 이 표를 table.to_csv("table2.csv")로 저장하면 엑셀에서 열어 논문 표로 다듬을 수 있습니다. Colab에서는 왼쪽 파일(폴더 모양) 패널에 파일이 생기고, 오른쪽 클릭으로 내려받습니다.

정리

  • 다중회귀는 공식에 설명변수를 +로 이어 적합하고, 범주형 변수는 C()로 감싸 가변수로 넣습니다. 기준범주는 C(x, Treatment(reference=…))로 바꿉니다.
  • BMI 계수는 보정 후 10.23에서 6.45로 줄었습니다. 보정 변수가 교란변수인지 매개변수인지는 자료가 아니라 연구 질문과 인과 구조로 판단합니다.
  • VIF는 variance_inflation_factor(model.model.exog, i)로 구합니다. summary()의 조건수 경고는 척도 차이 때문일 수 있으므로 VIF로 확인합니다. 겹치는 혈청 측정값(s1–s4)을 함께 넣자 VIF가 59까지 올라가고 표준오차가 커졌습니다.
  • ln(결과변수) 모형의 계수는 (eβ − 1) × 100% 차이로, 신뢰구간은 양 끝을 각각 변환해 보고합니다. 변환이 필요한지는 잔차로 판단합니다. 이 자료에서는 원래 척도가 더 적절했습니다.
  • 결과표는 코드로 만들어 옮겨 적는 오류를 줄이고, 단위·기준범주·보정 변수·모형 정보를 표 안과 각주에 적습니다.
