같은 계산을 함수로 만들어 모든 시험에 한 번에 적용합니다. 0인 칸이 있는 시험은 그 시험의 네 칸에만 0.5를 더하는 본문의 방식을 함수 안에 넣어 둡니다. 이 처리를 연속성 수정(continuity correction)이라고 합니다. 허혈 사건에는 0인 칸이 없어 이 부분이 작동하지 않고, 뒤의 주요 출혈(셀 13)에서 쓰입니다.

코드 한 줄씩

  1. def log_or(e1, n1, e0, n0):약물 X군의 사건 수와 인원, 위약군의 사건 수와 인원 네 열을 받아 로그 오즈비 열과 분산 열을 돌려주는 함수입니다. 함수 정의는 실습 5 가 절에서 다뤘습니다.
  2. a, c = e1.astype(float), e0.astype(float)정수 열을 실수로 바꿉니다. 뒤에서 0.5를 더할 수 있게 하기 위해서입니다.
  3. zero = (a == 0) | (b == 0) | (c == 0) | (d == 0)네 칸 가운데 하나라도 0이면 True인 열입니다. |는 '또는'입니다.
  4. [x + 0.5 * zero for x in (a, b, c, d)]계산에서 True는 1, False는 0이므로 0.5 * zero는 0인 칸이 있는 시험에서만 0.5입니다. 네 칸에 차례로 더해 다시 a, b, c, d에 담습니다.
  5. return np.log(a * d / (b * c)), 1/a + 1/b + 1/c + 1/d값 두 개를 돌려줍니다. 바깥에서 es["yi"], es["vi"] = log_or(…)로 두 열에 나눠 받습니다.
  6. es = tr[["trial"]].copy()시험 이름 열 하나만 있는 새 표입니다. 대괄호를 두 겹으로 써야 표(DataFrame)로 남습니다. 여기에 효과크기 열을 붙여 갑니다.

연구 간 분산과 무작위효과 모형

무작위효과 모형(random-effects model)은 모든 시험의 분산에 연구 간 분산 τ²를 더해 가중치를 다시 구합니다. τ²는 DerSimonian–Laird 방법으로 추정합니다. Q와 τ²를 읽는 법은 다 절에서 다룹니다.

코드 한 줄씩

  1. Q = np.sum(w * (es["yi"] - fe)**2)각 시험이 고정효과 통합값에서 떨어진 거리의 제곱에 가중치를 곱해 더한 값입니다.
  2. C = np.sum(w) - np.sum(w**2) / np.sum(w)τ² 추정식의 분모입니다.
  3. tau2 = max(0, (Q - (k - 1)) / C)Q가 자유도(k − 1)를 넘는 만큼을 C로 나눕니다. max(0, …)는 두 값 가운데 큰 쪽을 고르므로 음수가 나오면 0이 됩니다.
  4. ws = 1 / (es["vi"] + tau2)무작위효과 가중치입니다. 이후의 가중평균과 표준오차는 고정효과와 같은 식입니다.
  5. p_re = 2 * stats.norm.sf(abs(re / se_re))z = 추정값 ÷ 표준오차의 양측 P입니다(실습 4 다 절의 norm.sf).
  6. es["w_fe"] = 100 * w / np.sum(w)가중치가 전체에서 차지하는 비율(%)을 표에 붙입니다.

I²는 시험이 적을수록 불확실합니다. 그 정도를 신뢰구간으로 봅니다. I²를 바로 다루지 않고 H = √(Q ÷ 자유도)의 신뢰구간을 로그 척도에서 구한 뒤 I² = (H² − 1) ÷ H²로 바꾸는 방법입니다(19장 다 절 '더 알아보기'의 '연구가 적을 때 I²를 얼마나 믿을 수 있나' 상자). statsmodels에는 이 함수가 없어 직접 짭니다.

코드 한 줄씩

  1. def i2_ci(Q, k):Q와 연구 수 k를 받아 I²의 95% 신뢰구간 하한과 상한을 목록으로 돌려주는 함수입니다.
  2. H = np.sqrt(Q / (k - 1))우연만 있으면 Q가 자유도 근처여서 H는 1 근처입니다. 예제의 열 시험은 √(13.28 ÷ 9) = 1.21입니다.
  3. if Q > k: … else: …ln H의 표준오차를 구하는 식이 Q가 연구 수보다 큰지에 따라 다릅니다(Higgins와 Thompson의 식). 열 시험 전체(Q 13.28, k 10)는 위의 식을, Q가 연구 수보다 작은 STEMI 하위군(Q 5.16, k 6)은 아래 식을 씁니다.
  4. H_lo, H_hi = np.exp(np.log(H) - Z * se_lnH), …로그 척도에서 ± 1.96 × 표준오차를 구하고 지수로 되돌립니다.
  5. [max(0, (h**2 - 1) / h**2) for h in (H_lo, H_hi)]두 끝을 I²로 바꿉니다. H가 1보다 작으면 음수가 나오므로 0으로 둡니다.
  6. "… {:.0%}-{:.0%}".format(m["I2"], *i2_ci(…))*로 함수가 돌려준 두 값을 풀어 중괄호 자리에 차례로 넣습니다. :.0%는 정수 퍼센트입니다.

출력 읽기

메타회귀

메타회귀는 시험의 효과를 결과변수로, 시험 수준의 특성을 설명변수로 놓은 가중회귀입니다. 10개 시험의 STEMI 환자 비율을 넣어 봅니다. 순서는 두 단계입니다. 설명변수로 설명되지 않고 남은 연구 간 분산을 먼저 구하고, 그 값을 더한 가중치로 다시 적합합니다. 이 계산을 한 번에 해 주는 함수는 statsmodels에 없습니다.

코드 한 줄씩

  1. es["stemi10"] = (tr["stemi_pct"] - 50) / 1050%를 0으로 옮기고 10%p를 한 단위로 삼습니다. 기울기가 "10%p 높을 때"의 값이 됩니다.
  2. smf.wls("yi ~ stemi10", data=es, weights=w).fit()가중최소제곱(weighted least squares) 회귀입니다. 공식은 실습 6 다 절의 smf.ols와 같고, weights에 준 값이 큰 줄일수록 직선에 더 큰 영향을 줍니다. 첫 적합은 역분산 가중치만 쓴 고정효과 회귀입니다.
  3. QE = np.sum(w * m0.resid**2)resid는 관측값 − 직선의 예측값입니다. Q와 같은 모양으로, 직선 주위의 흩어짐을 잽니다.

  6. A = np.linalg.inv(X.T @ W @ X)@는 행렬 곱, .T는 전치, np.linalg.inv는 역행렬입니다.
  7. C_reg = np.trace(W) - np.trace(A @ X.T @ W @ W @ X)np.trace는 대각선의 합입니다. 이 식은 나 절의 C를 회귀로 넓힌 것으로, 설명변수가 없으면 Σw − Σw² ÷ Σw와 같아집니다.

orci는 로그 척도의 값을 지수로 되돌리는 함수여서 상대위험도에도 그대로 쓸 수 있습니다. 위험차는 로그를 취하지 않았으므로 지수로 되돌리지 않고 100을 곱해 %p로 적었습니다.

  1. 1상대위험도 0.84 (0.75–0.94), 2 I² 33%. 19장 라 절 2단계 민감도 분석 표의 '효과 척도 바꾸기' 행입니다.
  2. 3위험차 −1.24%p (−2.02 ~ −0.46), 4 I² 34%.
  3. 5통합 위험차의 역수 81.
  4. 6위약군의 위험 3.5%부터 12.3%까지. 시험마다 기저 위험이 네 배 가까이 다릅니다.

상대위험도 0.84는 오즈비 0.83과 거의 같습니다. 위약군의 허혈 사건 위험이 시험마다 2.5–12.3%로 높지 않기 때문이고, 결과가 흔할수록 오즈비는 상대위험도보다 1에서 멀어집니다. 위험차는 척도가 다릅니다. 위약군의 위험이 2.5%(Trial C, 6개월)부터 12.3%(Trial F, 18개월)까지 다르므로, 상대적 효과가 같아도 위험차는 시험마다 달라집니다. 그래서 통합 위험차 −1.24%p와 그 역수 81은 추적 기간이 6–18개월로 다르고 기저 위험도 다른 시험들의 평균이어서, 어떤 환자를 몇 개월 치료했을 때의 값인지 말할 수 없습니다. 셀 27의 73은 기저 위험 8.4%, 12개월이라는 조건이 붙은 값입니다. 그래서 대개 상대적 효과를 먼저 합치고, 관심 있는 환자군의 기저 위험에 적용합니다(19장 마 절 '더 알아보기'의 '내 연구에 쓸 때').

과제 3. 이질성 검정으로 모형을 고른 동료의 분석

동료가 같은 자료를 이렇게 분석했습니다.

"Q 검정의 P가 0.15로 기준 0.10보다 커서 시험들 사이에 이질성이 없다고 보고 고정효과 모형을 썼다. 통합 오즈비는 0.84(95% CI 0.78–0.91)였다. 하위군도 같은 모형으로 합쳤더니 STEMI 0.78, NSTE-ACS 0.93이었고 하위군 간 차이의 P가 0.04여서, 약물 X는 STEMI 환자에서 더 효과적이라고 결론 내렸다."

동료의 분석을 셀 하나로 재현하고, 틀린 곳 두 가지를 찾아 왜 틀렸는지 설명하세요. 셀 17(Q 검정), 셀 19(I²의 신뢰구간), 셀 20–21(차이 검정)의 출력과 비교해 보세요.

정답 코드와 풀이

model = "fe" if p_q > 0.10 else "re"는 한 줄짜리 if로, 조건이 참이면 앞의 값("fe"), 거짓이면 뒤의 값("re")을 담습니다. "se_" + model은 문자열을 이어 열 이름 se_fe를 만듭니다. pool이 하위군마다 고정효과 결과도 함께 계산해 sg에 담아 두었으므로 열만 바꿔 읽으면 됩니다. np.sqrt((sg["se_" + model]**2).sum())은 두 하위군 표준오차의 제곱을 열 전체로 더해 제곱근을 취한 것으로, 셀 20의 차이의 표준오차를 짧게 쓴 것입니다(줄이 둘뿐이어서 가능합니다). 마지막 세 줄은 계획서대로 한 분석입니다. z와 p_w는 셀 20과 셀 21에서 만든 값입니다.

  1. 1고정효과 0.84 (0.78–0.91). 동료가 쓴 숫자와 같습니다.
  2. 2STEMI 0.78 (0.69–0.88), 3 NSTE-ACS 0.93 (0.83–1.04). 점추정값은 무작위효과 소계(0.78, 0.92)와 거의 같고, 구간이 좁아졌습니다.
  3. 4P for interaction 0.043. 동료의 0.04입니다.
  4. 5계획한 무작위효과로는 0.082, 6 시험 안의 차이를 합치면 0.08.

첫째 잘못은 모형을 Q 검정의 P로 고른 것입니다. 시험 10개의 Q 검정은 검정력이 낮아서 P = 0.15는 "이질성이 없다"는 뜻이 아닙니다. 셀 19에서 본 것처럼 I² 32%의 신뢰구간은 0–68%이고, 셀 17의 예측구간 0.63–1.08은 1을 넘습니다. 결과를 본 뒤 모형을 고르는 것이기도 합니다. 고정효과 모형은 시험 사이의 차이를 무시해 구간이 좁게 나옵니다(0.78–0.91 대 0.73–0.93). 모형은 계획서 단계에서 시험들이 같은 참값을 재는지로 정하고(이 예에서는 무작위효과), 다른 모형은 셀 26처럼 민감도 분석으로 함께 보고합니다(19장 나 절 3단계 3번).

둘째 잘못은 경계에 있는 P 하나로 "STEMI에서 더 효과적"이라고 결론 낸 것입니다. 소계의 점추정값은 두 모형에서 거의 같고, 달라진 것은 표준오차입니다. 고정효과 소계는 하위군 안의 시험 사이 차이를 무시해 표준오차가 작고, 그래서 차이 검정의 P도 작아졌습니다. 계획한 무작위효과 모형으로는 0.082, 시험 안의 차이를 먼저 합치면 0.08입니다. 모형에 따라 0.05의 양쪽을 오가는 결과는 그만큼 불안정합니다. 결론은 P for interaction이 뒷받침하는 만큼만 씁니다. "STEMI에서 효과가 더 클 가능성을 시사하지만, 진단에 따른 차이가 있다고 말하기는 어렵다(P for interaction = 0.08)"가 맞는 문장입니다. 그리고 하위군을 미리 정했는지, 몇 개를 보았는지, 다른 연구에서도 같은 방향인지를 함께 적습니다(19장 다 절 3단계 3번).
