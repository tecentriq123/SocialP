열 개 시험의 효과크기 표

같은 계산을 함수로 만들어 모든 시험에 한 번에 적용합니다. 0인 칸이 있는 시험은 그 시험의 네 칸에만 0.5를 더하는 본문의 방식을 함수 안에 넣어 둡니다. 이 처리를 연속성 수정(continuity correction)이라고 합니다. 허혈 사건에는 0인 칸이 없어 이 부분이 작동하지 않고, 뒤의 주요 출혈에서 쓰입니다.

코드 한 줄씩

  1. def log_or(e1, n1, e0, n0):약물 X군의 사건 수와 인원, 위약군의 사건 수와 인원 네 열을 받아 로그 오즈비 열과 분산 열을 돌려주는 함수입니다. 함수 정의는 실습 5 가 절에서 다뤘습니다.
  2. a, c = e1.astype(float), e0.astype(float)정수 열을 실수로 바꿉니다. 뒤에서 0.5를 더할 수 있게 하기 위해서입니다.
  3. zero = (a == 0) | (b == 0) | (c == 0) | (d == 0)네 칸 가운데 하나라도 0이면 True인 열입니다. |는 '또는'입니다.
  4. [x + 0.5 * zero for x in (a, b, c, d)]계산에서 True는 1, False는 0이므로 0.5 * zero는 0인 칸이 있는 시험에서만 0.5입니다. 네 칸에 차례로 더해 다시 a, b, c, d에 담습니다.
  5. return np.log(a * d / (b * c)), 1/a + 1/b + 1/c + 1/d값 두 개를 돌려줍니다. 바깥에서 es["yi"], es["vi"] = log_or(…)로 두 열에 나눠 받습니다.
  6. es = tr[["trial"]].copy()시험 이름 열 하나만 있는 새 표입니다. 대괄호를 두 겹으로 써야 표(DataFrame)로 남습니다. 여기에 효과크기 열을 붙여 갑니다.

연구 간 분산과 무작위효과 모형

무작위효과 모형(random-effects model)은 모든 시험의 분산에 연구 간 분산 τ²를 더해 가중치를 다시 구합니다. τ²는 DerSimonian–Laird 방법으로 추정합니다. Q와 τ²를 읽는 법은 다 절에서 다룹니다.

코드 한 줄씩

  1. Q = np.sum(w * (es["yi"] - fe)**2)각 시험이 고정효과 통합값에서 떨어진 거리의 제곱에 가중치를 곱해 더한 값입니다.
  2. C = np.sum(w) - np.sum(w**2) / np.sum(w)τ² 추정식의 분모입니다.
  3. tau2 = max(0, (Q - (k - 1)) / C)Q가 자유도(k − 1)를 넘는 만큼을 C로 나눕니다. max(0, …)는 두 값 가운데 큰 쪽을 고르므로 음수가 나오면 0이 됩니다.
  4. ws = 1 / (es["vi"] + tau2)무작위효과 가중치입니다. 이후의 가중평균과 표준오차는 고정효과와 같은 식입니다.
  5. p_re = 2 * stats.norm.sf(abs(re / se_re))z = 추정값 ÷ 표준오차의 양측 P입니다(실습 4 다 절의 norm.sf).
  6. es["w_fe"] = 100 * w / np.sum(w)가중치가 전체에서 차지하는 비율(%)을 표에 붙입니다.

통합 계산을 함수로 묶기

같은 계산을 하위군, 민감도 분석, 과제에서 여러 번 되풀이하므로 함수로 묶어 둡니다.

코드 한 줄씩

  1. def pool(y, v):효과(y)와 분산(v)을 받아 두 모형의 결과를 돌려줍니다. 안의 계산은 앞의 두 셀과 같습니다. 함수 안의 fe, Q 같은 이름은 함수 밖의 같은 이름과 별개여서, 앞 셀에서 만든 값은 바뀌지 않습니다.

정리

  • 깔때기 그림은 효과와 표준오차의 산점도이고, Egger 검정은 효과를 표준오차에 가중회귀시킨 기울기의 검정입니다. 유의하지 않은 결과는 편향이 없다는 증거가 아닙니다.
  • 한 시험씩 빼기는 반복문 안에서 통합 함수를 다시 부르면 됩니다. 결론이 한 시험에 달려 있는지 확인하는 분석이고, 시험을 고르는 도구가 아닙니다.
  • NNT와 NNH는 기저 위험에 통합 오즈비를 적용해 구합니다. 기저 위험의 출처와 기간을 함께 적습니다.

과제 2. 상대위험도와 위험차로 통합

효과 지표를 오즈비에서 상대위험도로 바꿔 무작위효과 모형으로 합쳐 보세요. 로그 상대위험도의 분산은 1/a − 1/n₁ + 1/c − 1/n₀입니다. 이어서 위험차를 시험마다 구해 합쳐 보세요. 위험차의 분산은 p₁(1 − p₁)/n₁ + p₀(1 − p₀)/n₀이고 로그를 취하지 않습니다.

정답 코드와 풀이

상대위험도는 1 0.84 (0.75–0.94)로 오즈비 0.83과 비슷합니다. 허혈 사건이 10% 안팎으로 드물기 때문이고, 결과가 흔할수록 오즈비는 상대위험도보다 1에서 멀어집니다. orci는 로그 척도의 값을 지수로 되돌리는 함수여서 상대위험도에도 그대로 쓸 수 있습니다. 위험차는 2 −1.24%p (−2.02 ~ −0.46)이고 I²는 3 34%입니다(19장 마 절 '내 연구에 쓸 때'). 기저 위험과 추적 기간이 다른 시험들에서는 위험차가 시험마다 달라지므로, 대개 상대적 효과를 먼저 합치고 라 절처럼 기저 위험에 적용합니다.

과제 3. 주요 출혈의 민감도 분석

주요 출혈의 통합 오즈비가 0건 처리 방법에 따라 달라지는지 확인해 보세요. Trial C를 뺀 결과와 수정 없이 계산하는 Mantel–Haenszel 결과를 구해 0.5를 더한 결과와 견주고, Trial C와 3상 시험 네 개의 가중치 비율을 구합니다.

정답 코드와 풀이
