귀무가설은 "흡연군과 비흡연군의 평균 출생체중이 같다"입니다. 2장 a 절에서 본 것처럼 독립표본 t 검정에는 합동분산을 쓰는 Student t 검정과 군별 분산을 따로 쓰는 Welch t 검정이 있고, 처음부터 Welch t 검정을 기본으로 쓰자는 권고가 많습니다(2장 a 절). 두 방법을 모두 실행해 결과를 비교합니다.

Student t 검정과 Welch t 검정

코드 한 줄씩

  1. smoker = df.loc[df["smoke"] == 1, "bwt"]df["smoke"] == 1은 189개의 True/False 값입니다(흡연이면 True). .loc[행 조건, 열]은 True인 행의 bwt만 꺼내므로 smoker는 74개 값의 Series가 됩니다.
  2. nonsmoker = df.loc[df["smoke"] == 0, "bwt"]같은 방식으로 비흡연군 115개 값입니다.
  3. stats.ttest_ind(smoker, nonsmoker, equal_var=True)독립표본 t 검정입니다. 차이는 첫 번째 인자 − 두 번째 인자(흡연 − 비흡연) 방향으로 계산됩니다. equal_var=True는 등분산을 가정하는 Student t 검정이며, scipy는 이것이 기본값이라 equal_var를 생략하면 Student t 검정이 됩니다.
  4. stats.ttest_ind(…, equal_var=False)등분산을 가정하지 않는 Welch t 검정입니다. Welch를 쓰려면 이 인자를 반드시 적어야 합니다.
  5. print(welch)결과 객체를 그대로 출력합니다. 긴 한 줄이라 출력 칸을 옆으로 밀어서 봐야 합니다.
  6. print(f"Student: t = {student.statistic:.3f}, " …)결과 객체에서 필요한 값만 꺼내 한 줄로 정리합니다. student.statistic은 t, .pvalue는 양측 p, .df는 자유도입니다. 따옴표 앞의 f는 문자열 안 {…} 자리에 값을 넣으라는 표시이고, :.3f는 소수 셋째 자리까지, :.0f는 정수로 보여 달라는 형식입니다. 괄호 안에서 문자열을 두 줄로 나눠 써도 하나로 이어집니다.

출력 읽기

  2. 2Student t 검정. t = −2.653, p = 0.0087, 자유도 187 = 74 + 115 − 2입니다.
  3. 3Welch t = −2.730. 음수인 것은 흡연군 평균이 더 작기 때문입니다(흡연 − 비흡연). 인자 순서를 바꾸면 부호만 바뀝니다.
  4. 4p = 0.0070. 두 군의 평균이 실제로 같다면 이 정도 이상 벌어진 차이가 우연히 나올 확률이 0.7%라는 뜻입니다.

평균 차이와 95% 신뢰구간

p-value만으로는 차이의 크기를 알 수 없으므로 평균 차이와 그 신뢰구간을 함께 구합니다. t 검정 결과 객체의 confidence_interval() 메서드를 씁니다(scipy 1.11 이상, 버전은 셀 1에서 확인).

코드 한 줄씩

  1. diff = smoker.mean() - nonsmoker.mean()평균 차이(흡연 − 비흡연)입니다.
  2. ci = welch.confidence_interval(confidence_level=0.95)Welch t 검정 결과(welch)에서 평균 차이의 95% 신뢰구간을 꺼냅니다. Welch의 표준오차와 자유도로 계산되며, 방향은 검정과 같습니다. 결과는 low(하한)와 high(상한)를 가진 객체입니다.
  3. print(f"평균 차이 = {diff:.1f} g")앞 셀과 같은 f-문자열입니다. :.1f는 소수 첫째 자리까지 보여 달라는 형식입니다.

출력 읽기

  1. 1평균 차이 −283.8 g. 흡연군 아기가 평균 약 284 g 가볍습니다. 요약표의 2,771.9 − 3,055.7과 같습니다.
  2. 295% CI −489.0 ~ −78.6 g. 구간 전체가 0보다 작으므로 p < 0.05와 같은 결론입니다. 동시에 구간이 넓다는 점도 읽어야 합니다. 실제 차이는 79 g처럼 작을 수도, 489 g처럼 클 수도 있습니다.

같은 값을 공식으로 계산하기

scipy가 무엇을 계산했는지 2장 a 절의 공식으로 확인합니다. 결과가 같으면 공식을 제대로 이해한 것입니다.

코드 한 줄씩

  1. n1, n2 = len(smoker), len(nonsmoker)두 군의 인원 74와 115를 한 줄에 저장합니다.
  2. v1, v2 = smoker.var(), nonsmoker.var()군별 분산입니다. pandas의 var()는 n − 1로 나눕니다. numpy의 np.var()는 기본값이 n으로 나누는 것이라 값이 조금 다르니 섞어 쓰지 않도록 주의합니다.
  3. se = np.sqrt(v1 / n1 + v2 / n2)차이의 표준오차 √(s₁²/n₁ + s₂²/n₂)입니다(2장 a 절). 두 평균의 불확실성이 분산의 합으로 더해집니다.
  4. df_w = (v1/n1 + v2/n2)**2 / (…)Welch–Satterthwaite 자유도 공식입니다. **2는 제곱입니다. 이름을 df로 하면 데이터프레임 df를 덮어쓰게 되므로 df_w로 했습니다.
  5. t_crit = stats.t.ppf(0.975, df_w)자유도 170.1인 t 분포에서 아래쪽 넓이가 0.975인 값, 즉 양측 5% 임계값(1.974)입니다.
  6. diff / se diff ± t_crit*set 통계량과 신뢰구간의 두 끝입니다.

출력 읽기

  1. 1SE = 103.95 g. t = −283.8 ÷ 103.95 = −2.730으로 Welch 결과와 같습니다.
  2. 2자유도 170.10. scipy 출력의 df와 같습니다.
  3. 3신뢰구간. −283.8 ± 1.974 × 103.95로, confidence_interval()과 같은 값입니다.

Cohen의 d

코드 한 줄씩

  1. sp = np.sqrt(((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2))합동표준편차입니다. 두 군의 분산을 자유도(n − 1)로 가중평균한 뒤 제곱근을 취합니다(2장 a 절).
  2. d = diff / sp평균 차이를 합동 SD로 나눈 표준화 평균차입니다.

출력 읽기

  1. 1합동 SD 717.8 g. 두 군의 SD(659.6, 752.7) 사이 값입니다.
  2. 2d = −0.40. 평균 차이가 개인 간 SD의 0.4배라는 뜻입니다. Cohen의 잠정 기준으로는 작은 효과(0.2)와 중간 효과(0.5) 사이이지만, 임상적 의미는 "평균 284 g"이라는 원래 단위로 판단합니다(2장 a 절 '더 알아보기'의 '표준화 효과크기 Cohen의 d'에 있는 참고 상자).

정리

  • stats.ttest_ind(a, b)는 a − b 방향으로 계산하며, 기본값이 Student t 검정입니다. Welch t 검정은 equal_var=False를 적어야 합니다.
  • 평균 차이의 95% 신뢰구간은 결과 객체의 confidence_interval()(scipy 1.11 이상)로 구하고, 공식 √(s₁²/n₁ + s₂²/n₂)로 검산할 수 있습니다.
  • Cohen의 d는 평균 차이 ÷ 합동 SD입니다. 해석은 원래 단위(g)로 합니다.
  • Levene 검정(scipy 기본은 중앙값 기준)의 결과로 Student와 Welch를 고르지 않고, Welch를 미리 정해 둡니다.

c.Mann-Whitney 검정

Mann-Whitney 검정은 두 군의 값을 한 줄로 세워 순위를 매기고, 한 군이 위쪽이나 아래쪽에 몰려 있는지 봅니다(2장 b 절). 이 자료는 분포가 대략 대칭이고 군당 인원도 많아 t 검정이 적절하지만, 같은 자료로 Mann-Whitney 검정을 해 보면 두 검정이 각각 무엇을 보고하는지 비교할 수 있습니다. 실제 연구에서는 표본이 작고 분포가 치우쳤거나 극단값이 있을 때, 결과가 순서형 척도일 때 이 검정을 씁니다.

Mann-Whitney 검정

코드 한 줄씩

  1. stats.mannwhitneyu(smoker, nonsmoker, alternative="two-sided")Mann-Whitney U 검정입니다. alternative의 기본값이 양측("two-sided")이지만 명시했습니다. "less", "greater"는 첫 번째 군의 값이 작은(큰) 쪽이라는 단측 대립가설입니다.
  2. method="auto" use_continuity=True코드에 적지 않았지만 자동으로 쓰이는 p-value 계산 방식의 기본값입니다. scipy 1.18 설명서에 따르면 "auto"는 한 군이 8명 이하이고 동점이 없으면 정확 분포("exact")를, 그 밖에는 동점 보정 정규근사("asymptotic")를 씁니다. 정규근사에는 연속성 보정이 기본으로 들어갑니다. 이 자료는 74명과 115명이고 동점도 있어 정규근사가 쓰였습니다. 이 기준은 scipy 버전에 따라 달랐던 적이 있습니다.
  3. n1n2 = n1 * n2두 군에서 한 명씩 뽑아 만들 수 있는 쌍의 수 74 × 115 = 8,510입니다.
  4. print("U(smoker) =", mw.statistic)결과 객체의 statistic을 꺼냅니다. print에 쉼표로 여러 값을 주면 사이에 한 칸씩 띄어 출력합니다.
  5. print("U(nonsmoker) =", n1n2 - mw.statistic)반대쪽 군의 U입니다. U₁ + U₂ = n₁n₂이므로 빼서 구합니다.

과제 3. Mann-Whitney 결과를 중앙값의 차이로 쓴 문장

동료가 c 절의 결과를 이렇게 썼습니다. "흡연군 아기의 출생체중은 2,772 ± 660 g, 비흡연군은 3,056 ± 753 g였고, Mann-Whitney 검정에서 흡연군의 중앙값이 비흡연군보다 324.5 g 유의하게 낮았다(P = 0.007)." 틀린 곳 두 가지를 찾아 왜 틀렸는지 설명하세요. 흡연군에서 위쪽 4분의 1의 값만 500 g씩 무겁게 바꾸면 중앙값의 차이와 Mann-Whitney 검정의 P가 각각 어떻게 되는지 확인해 보세요.

정답 코드와 풀이

smoker.quantile(0.75)는 흡연군의 3사분위수(3,245.75 g, 셀 12)입니다. smoker.where(조건, 바꿀 값)은 조건이 True인 자리의 값은 그대로 두고, False인 자리만 바꿀 값으로 채웁니다. 그래서 3사분위수보다 무거운 19명만 500 g 무거워집니다. 이 19명은 원래도 중앙값보다 위에 있었으므로 중앙값은 바뀌지 않습니다. 반복문은 원래 값과 바꾼 값으로 같은 Mann-Whitney 검정을 하고, 중앙값의 차이와 우월 확률(셀 15), P를 나란히 출력합니다.

  1. 1중앙값의 차이 −324.5 g. 2,775.5 − 3,100(셀 12)입니다.
  2. 2원래 자료의 우월 확률 0.383, P = 0.0068. 셀 13, 15와 같습니다.
  3. 3위쪽 4분의 1만 바꾼 자료의 우월 확률 0.431, P = 0.1110. 중앙값의 차이는 −324.5 g 그대로입니다.
  4. 4Hodges–Lehmann 추정치 −307.0 g. 셀 16의 값과 신뢰구간(−512 ~ −85 g)입니다.

첫째 잘못은 Mann-Whitney 검정의 P를 중앙값의 차이에 대한 검정으로 쓴 것입니다. 정답 셀에서 흡연군의 위쪽 4분의 1만 바꾸자 중앙값의 차이는 그대로인데 P는 0.007에서 0.111로 바뀌었습니다. 이 검정이 보는 것은 두 군에서 한 명씩 뽑았을 때 한쪽 값이 더 클 확률이 반반에서 벗어나는지이고(우월 확률 0.383 → 0.431), 중앙값 두 개가 아니기 때문입니다. 이 자료는 두 군의 퍼진 정도(IQR 폭 875.25 g 대 1,112.5 g)도 달라서, 분포가 통째로 옮겨 갔다고 보고 중앙값의 비교로 읽기도 어렵습니다(1장 g 절, 2장 b 절). 차이의 크기는 같은 쌍에서 나온 Hodges–Lehmann 추정치(−307 g)나 우월 확률(0.38)로 씁니다.

둘째 잘못은 평균 ± SD에 Mann-Whitney 검정의 P를 붙인 것입니다. 순위 검정과 짝이 맞는 요약은 중앙값(IQR)이고, 평균 ± SD를 쓰려면 t 검정의 평균 차이와 신뢰구간을 붙입니다(2장 b 절 '논문에 쓰기'). 고쳐 쓰면 "흡연군 아기의 출생체중 중앙값은 2,776 g(IQR 2,371–3,246), 비흡연군은 3,100 g(IQR 2,509–3,622)이었고, 흡연군 아기가 더 가벼운 쪽에 몰려 있었다(Mann-Whitney U = 3,260.5, P = 0.007, Hodges–Lehmann 추정치 −307 g, 95% CI −512 ~ −85)"입니다. c 절 논문 상자의 문장과 같은 내용입니다.
