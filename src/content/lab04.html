나.분산분석과 사후분석

귀무가설은 "세 군의 평균 출생체중이 모두 같다"이고, 대립가설은 "적어도 한 군의 평균이 다르다"입니다(4장 가 절). 먼저 전체 검정으로 분산분석을 하고, 어느 쌍이 다른지는 Tukey 사후분석으로 봅니다. scipy로 F와 p를 빠르게 구한 뒤, statsmodels로 4장 다 절의 분산분석표를 만듭니다.

일원배치 분산분석 (scipy)

  1. white = df.loc[df["race_f"] == "White", "bwt"]군마다 출생체중만 꺼내 세 개의 Series를 만듭니다(96, 26, 67개).
  2. stats.f_oneway(white, black, other)일원배치 분산분석입니다. 군마다 따로 된 값 묶음을 쉼표로 나열해 넣습니다. 군이 넷이면 네 개를 넣습니다.
  3. print(f"F = {res.statistic:.3f}, p = {res.pvalue:.4f}")결과 객체의 statistic이 F, pvalue가 p입니다. f_oneway는 자유도를 알려 주지 않으므로 직접 셉니다. 군간 k − 1 = 2, 군내 N − k = 189 − 3 = 186입니다.
  1. 1F = 4.913. 군 평균 사이의 흩어짐이 군 안의 흩어짐으로 기대되는 수준의 약 4.9배입니다. 귀무가설이 참이면 1 근처입니다(4장 다 절).
  2. 2p = 0.0083. 세 평균이 모두 같다면 이 정도 이상의 차이가 우연히 나올 확률이 0.8%입니다. "적어도 한 군은 다르다"는 뜻이고, 어느 군인지는 알려 주지 않습니다.

분산분석표 (statsmodels)

분산분석은 군을 가변수로 넣은 선형회귀와 같습니다(4장 다 절 '회귀분석과의 관계'). statsmodels는 회귀모형을 적합한 뒤 그 모형에서 분산분석표를 뽑는 방식으로 계산합니다.

  1. import statsmodels.api as sm import statsmodels.formula.api as smfstatsmodels의 기본 모듈(sm)과, 모형을 "결과 ~ 설명변수" 형태의 식(formula)으로 쓰게 해 주는 모듈(smf)입니다.
  2. smf.ols("bwt ~ race_f", data=df)"bwt를 race_f로 설명하는 선형회귀(OLS)"를 정의합니다. race_f가 범주형이므로 statsmodels가 자동으로 가변수를 만들고, 첫 범주(White)를 기준범주로 씁니다.
  3. .fit()모형을 자료에 적합해 계수를 추정합니다.
  4. sm.stats.anova_lm(model)적합한 모형에서 분산분석표를 만듭니다. 행 race_f는 군간 변동, Residual은 군내 변동(잔차)입니다.

지수 표기 읽기. 5.015725e+06은 5.015725 × 10⁶ = 5,015,725입니다. pandas는 값이 크면 이런 표기로 보여 줍니다. e+07은 × 10⁷, e+05는 × 10⁵입니다.

  1. 1df = 2. 군간 자유도 = 군 수 − 1.
  2. 2sum_sq = 5,015,725. 군간 제곱합 SSB입니다. 각 군 평균이 전체 평균에서 떨어진 거리의 제곱에 군 인원을 곱해 더한 값입니다(4장 다 절 '제곱합 나누기').
  3. 3mean_sq = 2,507,863. 군간 평균제곱 MSB = SSB ÷ 2입니다.
  4. 4F = 4.912513. MSB ÷ MSW = 2,507,863 ÷ 510,505입니다. scipy의 F와 같습니다.
  5. 5PR(>F) = 0.008336. F(2, 186) 분포에서 4.91보다 오른쪽의 넓이, 즉 p-value입니다.
  6. 6Residual의 df = 186. 분석된 인원 − 군 수 = 189 − 3입니다. 결측 없이 189명이 모두 분석되었다는 확인이기도 합니다. 잔차 행의 F와 PR(>F)는 해당 값이 없어서 NaN으로 표시됩니다.
  7. 7Residual의 mean_sq = 510,505. 군내 평균제곱 MSW로, 세 군의 분산을 합친 합동분산입니다. 제곱근 714.5 g이 세 군 공통의 SD 추정값이며 Tukey 계산에 쓰입니다. 전체 제곱합 행은 표에 없으므로 필요하면 두 행의 sum_sq를 더합니다.

효과크기 η²와 ω²

  1. table.loc["race_f", "sum_sq"]분산분석표에서 행 이름 race_f, 열 이름 sum_sq인 칸의 값을 꺼냅니다.
  2. eta2 = ss_b / (ss_b + ss_w)η² = SSB ÷ SST입니다(4장 다 절).
  3. omega2 = (ss_b - 2 * ms_w) / (ss_b + ss_w + ms_w)ω² = (SSB − (k − 1)MSW) ÷ (SST + MSW)입니다. 2는 k − 1입니다.
  4. f"{ss_b:,.0f}",는 세 자리마다 쉼표를 넣고, .0f는 소수점 없이 보여 달라는 형식입니다.
  1. 1SSB = 5,015,725, SSW = 94,953,931. 둘을 더한 99,969,656이 전체 제곱합입니다.
  2. 2η² = 0.050. 출생체중의 개인 간 차이 중 5.0%가 인종 분류로 설명되고, 95%는 같은 군 안의 개인차라는 뜻입니다. 군 차이가 유의해도(p = 0.008) 개인의 출생체중을 예측하는 데는 거의 도움이 되지 않습니다.
  3. 3ω² = 0.040. 표본 η²의 과대추정을 보정한 값으로 η²보다 조금 작습니다.
  4. 4합동 SD 714.5 g. √MSW입니다.

등분산 확인과 Welch 분산분석

군별 분산이 다를 때 쓰는 Welch 분산분석은 statsmodels의 anova_oneway 함수로 할 수 있습니다(statsmodels 0.12 이상). 분산이 비슷할 때도 손해가 거의 없어 기본으로 쓰자는 의견도 있습니다(4장 다 절).

  1. from statsmodels.stats.oneway import anova_oneway함수를 가져옵니다.
  2. stats.levene(white, black, other)세 군의 Levene 검정입니다. scipy 기본값은 중앙값 기준(Brown–Forsythe 변형)입니다.
  3. anova_oneway(df["bwt"], df["race_f"], use_var="unequal")첫 인자는 모든 사람의 결과값, 둘째 인자는 각 사람의 군입니다(f_oneway와 넣는 방식이 다릅니다). use_var="unequal"이 Welch 분산분석이고, "equal"로 바꾸면 일반 분산분석(F = 4.913)이 됩니다.
  4. welch.statistic welch.df_num welch.df_denom welch.pvalueF, 분자 자유도, 분모 자유도, p-value입니다. 결과 객체 전체를 print하면 정보가 너무 길어서 필요한 값만 꺼냈습니다.
  1. 1Levene p = 0.627. 분산이 다르다는 증거가 없고, SD 비도 1.14로 작습니다.
  2. 2Welch F = 5.060.
  3. 3분모 자유도 72.4. 186보다 작은 소수입니다. 군별 분산을 따로 추정하는 대가로 근사한 자유도이며, Welch 방법을 썼다는 표시입니다. 논문에는 F(2, 72.4)로 씁니다.
  4. 4p = 0.0088. 일반 분산분석(0.0083)과 거의 같습니다. 군 크기는 다르지만 분산이 비슷하기 때문입니다.

Tukey HSD 사후분석

  1. from statsmodels.stats.multicomp import pairwise_tukeyhsdTukey HSD 함수를 가져옵니다.
  2. pairwise_tukeyhsd(df["bwt"], df["race_f"], alpha=0.05)모든 쌍을 비교합니다. 첫 인자는 결과값, 둘째 인자는 군입니다. alpha=0.05는 가족단위 오류율(FWER)을 5%로 묶는다는 뜻입니다. 군 크기가 다르면 자동으로 Tukey-Kramer 방식으로 계산합니다.
  3. print(tukey)결과 요약표를 출력합니다.
  1. 1FWER=0.05. 세 비교 전체에서 1종 오류가 하나라도 생길 확률을 5%로 통제한다는 뜻입니다. 아래 신뢰구간은 세 구간이 동시에 참값을 포함할 확률이 95%인 동시 신뢰구간입니다(4장 나 절).
  2. 2meandiff = group2 평균 − group1 평균. statsmodels는 군 이름을 알파벳순(Black, Other, White)으로 정렬해 쌍을 만듭니다. 그래서 "Black White 383.0"은 White − Black = 383.0 g입니다. 우리가 정한 범주 순서와 다르므로 부호의 방향을 꼭 확인합니다.
  3. 3Other − Black = 85.6 g, p-adj = 0.862. 신뢰구간 −304.5 ~ 475.6이 0을 포함하고, reject가 False입니다. 유의한 차이가 없습니다.
  4. 4White − Black = 383.0 g, p-adj = 0.043. 신뢰구간 9.8 ~ 756.2 g은 0을 포함하지 않아 유의합니다(reject True). 다만 하한이 9.8 g으로 0에 매우 가까워 차이의 크기는 매우 불확실합니다. Black 군이 26명뿐이라 구간이 넓습니다.
  5. 5White − Other = 297.4 g, p-adj = 0.026. 신뢰구간 28.7 ~ 566.2 g. p-adj는 이미 보정된 값이므로 여기에 다시 3을 곱하지 않습니다. 4장 나 절의 위첨자 문자로 나타내면 Whitea, Blackb, Otherb입니다.

직접 바꿔 보기

  • scipy에도 Tukey HSD가 있습니다. print(stats.tukey_hsd(white, black, other))를 실행하면 같은 p-value(0.043, 0.026, 0.862)가 나옵니다. 군 이름 대신 넣은 순서대로 0, 1, 2 번호가 붙고, 모든 쌍이 양방향(0 − 1과 1 − 0)으로 나오므로 번호가 어느 군인지 기억해 두고 읽습니다.
  • print(model.params)로 회귀계수를 보세요. Intercept 3102.7은 기준범주 White의 평균이고, race_f[T.Black] −383.0과 race_f[T.Other] −297.4는 White와의 평균 차이입니다. 분산분석이 가변수 회귀와 같다는 것을 확인할 수 있습니다(8장 사 절). 단, 회귀계수의 p-value는 다중비교 보정을 하지 않은 값입니다.

다.Kruskal-Wallis 검정

Kruskal-Wallis 검정은 세 군을 합쳐 순위를 매기고, 군별 평균 순위가 전체 평균 순위에서 얼마나 떨어져 있는지(H)를 봅니다(4장 라 절). 이 자료는 분포가 대칭에 가까워 분산분석이 적절하지만, 같은 자료로 순위 기반 방법과 그 사후분석을 해 봅니다.

쌍별 Mann-Whitney 검정과 Holm 보정

어느 쌍이 다른지 보는 첫 번째 방법은 세 쌍 각각에 Mann-Whitney 검정(실습 2 다 절)을 하고 Holm 방법으로 보정하는 것입니다. 보정 방법 자체는 실습 1 라 절을 참고하세요.

  1. groups = {"White": white, …}군 이름으로 값 묶음을 찾을 수 있게 딕셔너리로 모아 둡니다. groups["Black"]은 black과 같습니다.
  2. pairs = [("White", "Black"), …]비교할 세 쌍의 목록입니다. 괄호로 묶은 두 이름이 한 쌍입니다.
  3. p_mw, sup = [], []결과를 모을 빈 목록 두 개를 만듭니다.
  4. for a, b in pairs:세 쌍을 차례로 꺼내 첫 이름을 a, 둘째 이름을 b에 넣고 아래 들여 쓴 세 줄을 반복합니다.
  5. r = stats.mannwhitneyu(groups[b], groups[a])b를 첫 번째 인자로 넣었으므로 statistic은 "b 군 값이 더 큰 쌍의 수"입니다.
  6. p_mw.append(r.pvalue) sup.append(r.statistic / (len(groups[a]) * len(groups[b])))p-value와 우월 확률 P(b > a) = U ÷ (nanb)를 목록 끝에 붙입니다.
  7. multipletests(p_mw, method="holm")[1]statsmodels의 다중비교 보정 함수입니다. 결과 네 가지(기각 여부, 보정된 p, 보정된 유의수준 두 가지) 중 두 번째(위치 1)인 보정된 p를 꺼냅니다.
  1. 1우월 확률 0.346, 0.394, 0.541. 순서대로 P(Black > White), P(Other > White), P(Other > Black)입니다. 예를 들어 Black 군과 White 군에서 아기를 한 명씩 뽑으면 Black 군 아기가 더 무거울 확률이 35%입니다. 0.5에서 멀수록 차이가 큽니다.
  2. 2보정 전 p: 0.0165, 0.0210, 0.5461.
  3. 3Holm 보정 p: 0.0495, 0.0495, 0.5461. 가장 작은 0.0165에 3을 곱해 0.0495, 두 번째 0.0210에 2를 곱하면 0.0419인데 앞 단계보다 작아질 수 없으므로 0.0495, 세 번째는 1을 곱해 0.5461입니다. White와 다른 두 군의 차이가 0.05 바로 아래에서 유의합니다.

Dunn 검정 직접 계산하기

4장이 Kruskal-Wallis 뒤의 사후분석으로 소개한 Dunn 검정은 scipy와 statsmodels에 함수가 없습니다(scikit-posthocs라는 별도 패키지의 posthoc_dunn에 있다고 알려져 있으나 이 페이지에서는 실행해 확인하지 않았습니다). 4장 라 절의 식이 간단하므로 직접 계산합니다.

  1. t = df["bwt"].value_counts()출생체중 값마다 몇 명이 그 값을 가졌는지 셉니다. 2 이상인 값이 동점 묶음입니다.
  2. tie = (t**3 - t).sum() / (12 * (N - 1))동점 보정 항 Σ(t³ − t) ÷ 12(N − 1)입니다. 동점이 없는 값은 t = 1이라 0을 더합니다.
  3. mean_rank = …["rank"].mean() n = df["race_f"].value_counts()앞에서 189명 전체로 매긴 순위의 군별 평균과 군별 인원입니다. mean_rank["White"], n["White"]처럼 군 이름으로 꺼낼 수 있습니다.
  4. se = np.sqrt((N * (N + 1) / 12 - tie) * (1 / n[a] + 1 / n[b]))두 군 평균 순위 차이의 표준오차입니다. N(N + 1)/12는 순위 1–N의 분산입니다(4장 라 절 Dunn 식).
  5. z = (mean_rank[a] - mean_rank[b]) / se평균 순위 차이 ÷ 표준오차입니다.
  6. 2 * stats.norm.sf(abs(z))norm.sf는 표준정규분포에서 그 값보다 오른쪽 넓이(1 − 누적확률)입니다. 2를 곱해 양측 p를 구합니다.
  1. 1보정 전 p: 0.0179, 0.0197, 0.5096. 쌍별 Mann-Whitney(0.0165, 0.0210, 0.5461)와 비슷하지만 같지 않습니다.
  2. 2Holm 보정 p: 0.0537, 0.0537, 0.5096. 이번에는 세 쌍 모두 0.05를 넘습니다.

두 방법은 무엇이 다른가

  • Dunn 검정은 Kruskal-Wallis 검정과 같은 순위, 즉 세 군 189명 전체에서 매긴 순위를 쓰고, 표준오차도 189명 순위 전체의 분산으로 계산합니다. 전체 검정과 사후분석이 같은 기준 위에 있습니다.
  • 쌍별 Mann-Whitney 검정은 비교하는 두 군만 떼어 순위를 다시 매깁니다. White–Black 비교에는 Other 군 67명이 전혀 쓰이지 않습니다. 두 군만의 질문("이 두 군 중 어느 쪽 값이 큰 경향이 있나")에 답하므로 해석은 직관적이지만, 전체 검정과 쓰는 정보가 다릅니다.

이 자료에서는 두 방법의 보정된 p가 0.0495와 0.0537로 0.05의 양쪽에 갈렸습니다. 결론이 0.05 근처에서 방법 선택에 따라 뒤집힌다면 어느 쪽이든 증거가 약하다고 읽는 것이 정확합니다(4장 라 절 참고 상자). 그리고 두 방법을 모두 해 본 뒤 유의하게 나온 쪽을 보고하면 그 자체가 다중비교가 됩니다. 사후분석 방법은 분석계획에 미리 정해 두고, 효과의 크기(위의 우월 확률 0.35, 0.39)를 함께 보고합니다.

논문에는 이렇게 씁니다 · 전체 검정은 유의하고 사후분석은 경계선일 때birthwt 자료의 실제 결과

정리

  • stats.kruskal(군1, 군2, 군3)은 동점 보정된 H와 카이제곱 근사 p를 줍니다. 자유도는 군 수 − 1입니다.
  • 쌍별 Mann-Whitney + Holm은 mannwhitneyu를 쌍마다 실행하고 multipletests(p, method="holm")로 보정합니다.
  • Dunn 검정은 전체 순위와 전체 순위 분산을 쓰고, 쌍별 Mann-Whitney는 두 군만으로 순위를 다시 매깁니다. 두 방법의 p는 다를 수 있으므로 방법을 미리 정합니다.
  • 전체 검정이 유의해도 사후분석에서 유의한 쌍이 없을 수 있습니다. 그대로 보고하고 효과크기를 함께 제시합니다.

라.Jonckheere-Terpstra 검정

군에 자연스러운 순서가 있고 연구가설이 "순서대로 커진다"일 때는 Jonckheere-Terpstra 검정이 Kruskal-Wallis 검정보다 강력합니다(4장 마 절). 인종 분류에는 순서가 없으므로, 여기서는 어머니 체중(lwt, 마지막 월경 시점, 파운드)을 삼분위로 나눈 세 군을 씁니다.

이 검정에서 가장 중요한 것은 순서와 방향을 자료를 보기 전에 정하는 것입니다. 이 실습의 가설은 "임신 전 어머니 체중이 무거울수록 출생체중이 크다"이고, 순서는 T1(가벼움) < T2 < T3(무거움), 방향은 증가입니다. 어머니 체중이 태아 성장과 관련 있다는 사전 지식에 근거한 가설이며, 코드 첫 줄에 주석으로 기록해 둡니다. 결과를 보고 순서를 바꾸거나 평균이 작은 군부터 늘어놓으면 경향이 없어도 쉽게 유의해집니다(4장 마 절 주의 상자).

scipy에는 이 검정의 함수가 없습니다. statsmodels는 0.15.0에서 jonckheere_terpstra 함수가 추가되었고 0.14 이하에는 없으므로, 쓰는 환경의 버전에 따라 이 함수를 쓸 수 없을 수 있습니다. 그래서 어느 환경에서나 돌아가는 짧은 함수를 직접 만들고, 그 결과를 statsmodels 0.15의 함수와 비교합니다. 원리는 4장 마 절 그대로입니다. 순서상 앞 군과 뒤 군의 모든 짝에서 뒤 군 값이 더 큰 짝의 수(Mann-Whitney U)를 세어 더한 것이 J입니다.

  5. J += (b > a).sum() + 0.5 * (b == a).sum()뒤 군 값이 더 큰 짝은 1개, 같은 짝은 0.5개로 세어 J에 더합니다. +=는 "기존 값에 더해서 다시 저장"입니다.
  6. return J계산한 J를 함수 밖으로 돌려줍니다.
  7. tert = [df.loc[df["lwt3"] == k, "bwt"] for k in order]order의 T1, T2, T3를 차례로 k에 넣으면서 그 군의 출생체중을 꺼내 목록으로 만듭니다(리스트 컴프리헨션). 결과는 Series 세 개의 목록이고, 목록의 순서가 곧 가설의 순서입니다.
  1. 1J = 7,356. 가능한 짝은 67 × 60 + 67 × 62 + 60 × 62 = 11,894개이고, 경향이 없다면 J는 그 절반인 5,947 근처여야 합니다. 관측값은 이보다 1,409 큽니다.

J는 Mann-Whitney U의 합

함수가 맞게 계산했는지 scipy의 Mann-Whitney U로 확인합니다.

  1. stats.mannwhitneyu(tert[1], tert[0]).statistic뒤 군(T2)을 첫 번째 인자로 넣었으므로 "T2 값이 T1 값보다 큰 짝의 수"입니다(실습 2 다 절). tert[0]이 T1, tert[1]이 T2, tert[2]가 T3입니다.
  1. 12,434.5 + 2,831.5 + 2,090.0 = 7,356. 함수의 J와 같습니다. 각 U를 짝의 수로 나누면 인접하거나 떨어진 두 군 사이의 우월 확률이 됩니다. P(T2 > T1) = 2,434.5 ÷ 4,020 = 0.61, P(T3 > T1) = 2,831.5 ÷ 4,154 = 0.68, P(T3 > T2) = 2,090 ÷ 3,720 = 0.56입니다.

정규근사로 p-value 구하기

귀무가설 아래 J의 평균과 분산을 구해 z로 표준화합니다. 동점이 없을 때의 분산은 4장 마 절의 식이고, 이 자료처럼 동점이 있으면 보정한 분산을 씁니다. 아래 함수의 분산 식(v1 + v2 + v3)은 동점이 없으면 4장 마 절의 식과 같아집니다.

  1. J = jt_J(groups)앞에서 만든 함수로 J를 구합니다.
  2. n = np.array([len(x) for x in groups]) N = n.sum()군별 인원 [67, 60, 62]와 전체 인원 189입니다.
  3. allv = np.concatenate(…) t = np.unique(allv, return_counts=True)[1]세 군의 값을 한 줄로 이어 붙인 뒤, 서로 다른 값마다 몇 번 나왔는지 셉니다. 이것이 동점 묶음의 크기 t입니다.
  4. EJ = (N**2 - (n**2).sum()) / 4귀무가설 아래 J의 평균 E(J) = (N² − Σni²)/4, 즉 가능한 짝 수의 절반입니다(4장 마 절).
  5. v1 v2 v3동점 보정 분산의 세 부분입니다. 동점이 없으면(모든 t = 1) v2와 v3는 0이 되고 v1은 4장 마 절의 [N²(2N + 3) − Σni²(2ni + 3)]/72와 같은 값이 됩니다.
  6. z = (J - EJ) / np.sqrt(v1 + v2 + v3)관측된 J가 기댓값에서 표준편차 몇 개만큼 떨어졌는지입니다.
  7. return J, EJ, z, 2 * stats.norm.sf(abs(z))네 값을 한 번에 돌려주고, 바깥에서 J, EJ, z, p = jt_test(tert)로 네 이름에 나눠 받습니다. p는 양측입니다.
  1. 1J = 7,356.
  2. 2E(J) = 5,947. (189² − (67² + 60² + 62²)) ÷ 4 = (35,721 − 11,933) ÷ 4입니다.
  3. 3z = 3.44.
  4. 4양측 p = 0.0006. 삼분위 순서대로 출생체중이 커지는 경향이 있다고 판단합니다. 증가 방향을 미리 정했다면 단측 p(0.0003)를 쓸 수도 있지만, 4장 마 절의 표처럼 양측을 보고하는 것이 일반적입니다.

순열검정으로 확인하기

정규근사가 맞는지 순열검정(permutation test)으로 확인합니다. 귀무가설이 참이면 어떤 아기가 어느 삼분위에 속하는지는 출생체중과 무관하므로, 군 이름표를 무작위로 섞어도 J의 분포는 같아야 합니다. 이름표를 1만 번 섞어 J를 계산하고, 관측값만큼 극단적인 경우의 비율을 구합니다.

  1. rng = np.random.default_rng(2026)난수 생성기를 만들고 시드(2026)를 고정합니다. 시드가 같으면 몇 번을 실행해도 같은 난수가 나와 결과를 재현할 수 있습니다.
  2. y = df["bwt"].to_numpy() lab = df["lwt3"].to_numpy()출생체중과 삼분위 이름표를 numpy 배열로 꺼냅니다.
  3. J_perm = np.empty(B)1만 개의 J를 저장할 빈 배열을 미리 만듭니다.
  4. s = rng.permutation(lab)이름표 189개의 순서를 무작위로 섞은 새 배열입니다. 각 군의 인원(67, 60, 62)은 그대로 유지됩니다.
  5. J_perm[r] = jt_J([y[s == k] for k in order])섞인 이름표로 군을 다시 나눠 J를 계산하고 r번째 칸에 저장합니다.
  6. np.abs(J_perm - EJ) >= abs(J - EJ)기댓값에서 떨어진 거리가 관측값 이상인지(양측)를 1만 개 각각에 대해 True/False로 구합니다.
  7. (extreme.sum() + 1) / (B + 1)관측 자료 자체도 가능한 배정의 하나로 세어 분자와 분모에 1을 더합니다. 이렇게 하면 p가 정확히 0으로 나오지 않습니다.
  1. 11만 번 중 4번. 이름표를 무작위로 섞었을 때 관측된 J(7,356)만큼 기댓값에서 멀어진 경우가 4번뿐이었습니다.
  2. 2순열 p = 0.0005. 정규근사의 0.0006과 거의 같습니다. 표본이 크면 정규근사가 잘 맞습니다. 시드를 바꾸면 이 값이 조금 달라지는데, 1만 번 섞은 추정값이라 생기는 오차입니다.

순서대로 커지지 않는 경우

같은 함수를 다른 순서형 군에도 적용해 봅니다. 임신 첫 3개월의 의사 방문 횟수(ftv)를 0회, 1회, 2회 이상으로 나누고, "방문이 많을수록 출생체중이 크다"를 미리 정한 가설로 삼았다고 합시다.

  2. jt_test(visits) stats.kruskal(*visits)같은 두 검정을 적용합니다.
  1. 11회 방문군의 중앙값 3,033 g이 가장 큽니다. 0회 2,921 g, 2회 이상 2,977 g으로, 가운데 군이 가장 높은 봉우리 모양입니다.
  2. 2Jonckheere-Terpstra p = 0.292. 0회 → 1회의 증가와 1회 → 2회 이상의 감소가 서로 상쇄되어 단조 경향을 찾지 못합니다. 4장 마 절의 검정력 그림에서 본 '가운데 군만 높은 경우'입니다.

정리

  • Jonckheere-Terpstra 통계량 J는 순서상 앞 군과 뒤 군의 모든 쌍에 대한 Mann-Whitney U의 합입니다. scipy에는 함수가 없고 statsmodels는 0.15부터 있으므로, 짧은 함수로 구현하고 답을 아는 예제(4장 마 절)로 검증합니다.
  • p-value는 E(J) = (N² − Σni²)/4와 동점 보정 분산으로 만든 z에서 구하며, 시드를 고정한 순열검정으로 확인할 수 있습니다.
  • 순서와 방향은 자료를 보기 전에 정하고 코드와 Methods에 기록합니다. 결과를 본 뒤 순서를 바꾸면 안 됩니다.
  • 가운데 군이 가장 높은 봉우리 모양의 차이는 Jonckheere-Terpstra 검정이 거의 잡아내지 못합니다.
