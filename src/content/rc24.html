a.EQ-5D 응답을 효용으로

자료는 어떻게 생겼나?

  1. 1응답 1,593건, 환자 320명.
  2. 2진행 뒤 응답 409건, 무진행 상태 응답 1,184건. b 절에서 상태별 효용을 구하는 응답입니다.

  4. 4살아 있던 방문 수의 합 1,593. 응답 수와 같으므로 살아 있는데 빠진 응답은 없습니다.

가치 세트는 어떻게 함수로 짜나?

영역 다섯 개와 수준 다섯 개의 감점을 5 × 5 행렬로 넣고, 응답 코드를 한 자리씩 잘라 행렬에서 감점을 꺼내 뺍니다. 한국 EQ-5D-5L 가치 세트는 11111이 아니면 붙는 상수 0.096, 영역과 수준마다의 감점, 수준 4나 5가 하나라도 있으면 붙는 0.078로 이루어집니다(보건통계학 기초 22장 b 절). KR5[cbind(1:5, lv)]는 1행의 lv[1]열, 2행의 lv[2]열처럼 영역마다 그 수준의 감점 하나씩, 모두 다섯 개를 꺼냅니다.

  1. 121222 → 0.762, 31342 → 0.518, 11211 → 0.883, 55555 → −0.066, 11111 → 1. 22장의 계산 예와 같습니다. 함수를 짜면 먼저 이 다섯 값으로 검산합니다.

함수 안에서 as.character()로 코드를 글자로 바꾸므로, 응답 코드 열을 숫자로 읽었더라도 이 함수는 같은 값을 냅니다. 영역의 수준이 1–5여서 코드가 0으로 시작하는 일이 없기 때문입니다. 다만 자리마다 영역을 뜻하는 코드이므로 처음부터 글자로 읽어 두는 편이 안전합니다.

모든 응답에 맞게 적용했나?

sapply()로 응답 1,593건에 함수를 적용하고, 자료에 들어 있던 utility 열과 비교합니다.

  1. 1서로 다른 응답 코드 227가지.
  2. 2utility 열과의 차이 0. 함수가 자료의 효용을 그대로 다시 만들었습니다. 효용이 1인 응답(11111)은 180건입니다.
  3. 30보다 작은 효용 두 건(−0.031, −0.022). 둘 다 진행 상태의 응답입니다. 가장 나쁜 상태 55555의 −0.066보다 작은 값이나 1보다 큰 값이 없으면 함수의 범위는 맞습니다.

공개된 구현과 같은 값인가?

eq5d 패키지는 여러 나라의 가치 세트를 담고 있어, eq5d(코드, country = "SouthKorea", version = "5L", type = "VT") 한 줄로 같은 계산을 합니다. 직접 짠 함수를 이 패키지와 대조하면 계수를 옮겨 적다 틀린 곳을 찾을 수 있습니다. 22장 표 22-3의 3L 비교(같은 응답, 한국과 영국의 가치 세트)도 이 패키지로 만듭니다.

  1. 1직접 짠 함수와의 차이 0. 1,593건 모두 같습니다.
  2. 211121: 한국 0.913, 영국 0.796. 같은 응답이라도 가치 세트에 따라 0.117 차이가 납니다.
  3. 333333: 한국 −0.171, 영국 −0.594. 나쁜 상태일수록 두 나라의 차이(0.423)가 커집니다.

패키지도 검산의 대상입니다. 가치 세트는 나라마다, 같은 나라에서도 판과 출판 연도마다 여럿이므로, country, version, type이 원 논문과 맞는지 확인하고 원 논문의 계산 예와도 맞춥니다. 22장에서 한국 5L과 영국 3L 계수는 이 패키지와 다른 공개 구현이 모든 건강상태에서 같은 값을 주는 것만 확인했다고 적은 이유입니다.

파이썬에서는 응답 코드 열을 pd.read_csv(…, dtype={"eq5d": str})로 글자로 읽고, 코드를 한 글자씩 숫자로 바꿔 감점을 뺍니다. 함수 전체는 실습 22 b 절의 셀 5에 있습니다.

KR5 = {"mobility": [0, 0.046, 0.058, 0.133, 0.251],   # 영역마다 수준 1-5의 감점
       "selfcare": [0, 0.032, 0.050, 0.078, 0.122],
       "activity": [0, 0.021, 0.051, 0.100, 0.175],
       "pain":     [0, 0.042, 0.053, 0.166, 0.207],
       "anxiety":  [0, 0.033, 0.046, 0.102, 0.137]}
def kr5l(code):
    lv = [int(x) for x in code]              # "21222" -> [2, 1, 2, 2, 2]
    if lv == [1, 1, 1, 1, 1]:
        return 1.0
    u = 1 - 0.096 - sum(KR5[d][l - 1] for d, l in zip(KR5, lv))
    if max(lv) >= 4:
        u = u - 0.078
    return round(u, 3)
df["u_calc"] = df["eq5d"].map(kr5l)        # 응답마다 적용

보건통계학 기초 22장의 '직접 분석' 상자와 본문에 있던 검산 목록입니다. R과 다른 점은 첫 항목입니다. pandas는 응답 코드 열을 정수로 읽으면 한 자리를 꺼내는 줄에서 멈추고, R의 함수는 as.character()로 바꿔 계속 계산합니다.

  1. 응답 코드를 글자로 읽었는지. pd.read_csv(…, dtype={"eq5d": str})처럼 응답 코드 열을 글자로 지정합니다. 지정하지 않으면 pandas 3.0.5는 이 열을 정수(int64)로 읽고, df["eq5d"].str[0]처럼 한 자리를 꺼내는 줄에서 AttributeError가 납니다.
  2. 계산 예와 맞는지. 위의 21222 → 0.762, 31342 → 0.518에 더해 11211 → 0.883, 55555 → −0.066, 11111 → 1이 나오는지 봅니다. 3L 함수라면 21232 → 0.559, 33333 → −0.171과 맞춥니다. 원 논문에 실린 계산 예가 있으면 그것과도 맞춥니다.
  3. 모든 응답에 맞게 적용했는지. df["eq5d"].map(함수)로 응답마다 적용한 뒤, 1보다 크거나 가장 나쁜 상태의 값보다 작은 효용이 없는지 봅니다.

b.상태별 효용과 신뢰구간

한 환자가 여러 번 답하면 신뢰구간은 어떻게 구하나?

상태를 설명변수로 넣고 절편을 뺀 선형회귀(utility ~ 0 + state)의 계수가 상태별 평균입니다. 표준오차는 sandwich 패키지의 vcovCL(fit, cluster = ~ id)로 같은 환자의 응답을 한 묶음으로 보고 구합니다. 보건통계학 기초 22장 b 절의 접힌 상자 '한 환자가 여러 번 답하면 상태별 평균과 신뢰구간은 어떻게 구하나?'의 계산입니다.

  1. 1진행 상태 0.621, 표준오차 0.0077 → 0.0133. lm()의 기본 표준오차는 응답 409건을 서로 독립으로 봅니다. 한 사람이 평균 2.35번 답했으므로 묶으면 1.7배가 됩니다.
  2. 2무진행 상태 0.780(0.765–0.794), 표준오차 0.0045 → 0.0074. 평균은 그대로이고 구간만 넓어집니다. 22장 본문의 값과 같습니다.

vcovCL()의 기본값은 HC1(자유도 보정)과 군집 수 보정을 함께 쓰고, coefci()는 t 분포로 구간을 냅니다. 파이썬 statsmodels의 군집 표준오차와 표준오차는 같고, statsmodels는 구간을 정규분포로 구합니다. 이 자료처럼 응답이 많으면 두 구간이 넷째 자리까지 같습니다.

혼합모형으로 구하거나 군별로 나누면?

환자를 무작위효과로 둔 혼합모형은 lme4 패키지의 lmer(utility ~ 0 + state + (1 | id))입니다. 두 군을 합쳐도 되는지는 상태마다 군의 차이를 넣은 회귀로 봅니다.

  1. 1혼합모형의 평균 0.623과 0.778. 여러 번 답한 환자의 무게를 줄인 평균이어서 단순 평균(0.621, 0.780)과 조금 다르지만, 모형에 넣는 반올림 값 0.62와 0.78은 그대로입니다.
  2. 2상태마다 B군 − A군: 진행 −0.022(P 0.434), 무진행 −0.008(P 0.586). 22장의 P 0.43과 0.59입니다.
  3. 3상호작용 항의 P 0.616. 두 상태에서 군의 차이가 서로 같은지를 묻는 값이어서, 두 군을 합쳐도 되는지에는 답하지 않습니다. 차이의 크기(0.008, 0.022)를 함께 봅니다.

EQ VAS를 100으로 나누면 효용과 같은가?

상태별로 효용과 VAS ÷ 100을 나란히 평균합니다.

  1. 1두 상태의 차이: 효용 0.158, VAS ÷ 100은 0.096. VAS ÷ 100은 진행의 손실을 작게 잡습니다. 가치 세트를 거치지 않은 점수여서 효용 자리에 넣지 않습니다(과제 2).

보건통계학 기초 22장의 '직접 분석' 상자와 본문에 있던 내용입니다.

statsmodels 0.15.0으로 이 시험의 응답 1,593건에서 확인한 결과입니다. 자료는 응답 한 건이 한 줄인 긴 형식(환자 번호 id, 군 arm, 응답한 때의 상태 state, 효용 utility)입니다.

  1. model = smf.ols("utility ~ 0 + state", data=df)
    절편을 빼면(0 +) 두 계수가 곧 상태별 평균(무진행 0.780, 진행 0.621)이 됩니다.
  2. model.fit()
    기본값은 응답 1,593건을 서로 독립으로 봅니다. 표준오차가 무진행 0.0045, 진행 0.0077로 작게 나옵니다.
  3. model.fit(cov_type="cluster", cov_kwds={"groups": df["id"]})
    같은 환자의 응답을 한 묶음으로 보는 군집 강건 표준오차입니다. 평균은 그대로이고 표준오차가 0.0074와 0.0133으로 1.6배와 1.7배가 됩니다. 이때 statsmodels는 신뢰구간을 t분포가 아니라 정규분포로 계산합니다.

환자를 무작위효과로 둔 혼합모형(smf.mixedlm("utility ~ 0 + state", data=df, groups=df["id"]), 보건통계학 기초 10장 d 절)으로도 구할 수 있습니다.

c.환자별 QALY

환자 한 명의 QALY는 어떻게 구하나?

측정 시점과 효용을 직선으로 이은 아래 넓이를 사다리꼴 공식으로 구하고 12로 나눕니다. 사망 시점에 효용 0인 점을 붙이는 일은 함수 path()가, 넓이는 한 줄짜리 함수 trap()이 합니다. 보건통계학 기초 22장 c 절의 표 22-4, 환자 다입니다. 0, 3, 6, 12개월에 응답하고 15개월에 사망했습니다.

  1. 115개월과 24개월에 효용 0. path()가 사망 시점과 추적 끝(24개월)에 0을 붙였습니다. 15–24개월의 넓이는 0이어서 24개월 점은 결과를 바꾸지 않지만, 모든 환자의 경로가 24개월에서 끝나게 해 둡니다.
  2. 2구간별 QALY 0.200, 0.189, 0.333, 0.073. 22장 접힌 상자 '환자 다의 사다리꼴 네 개를 숫자로 계산하면?'의 표와 같습니다.
  3. 3QALY 0.795. 직접 짠 trap()과 DescTools 패키지의 AUC(x, y)가 같은 값을 냅니다. AUC()는 시점이 첫 인자이고 넓이 계산의 기본값이 사다리꼴입니다.

빠진 방문이 있으면 넓이는 어떻게 되나?

24개월까지 살아서 여섯 번 답한 환자 가로, 중간이나 마지막 응답이 빠졌을 때 AUC()가 무엇을 내는지 봅니다.

  1. 112개월이 NA이면 1.703. 오류 없이 6개월과 18개월을 직선으로 이었습니다. 효용이 거의 일정한 환자여서 1.708과 0.005 차이지만, 빠진 사이에 상태가 바뀐 환자라면 차이가 커집니다.
  2. 224개월이 NA이면 결과도 NA. 첫 방문이나 마지막 방문이 비면 AUC()는 넓이를 내지 않습니다.
  3. 3그 행을 지우면 1.2825. 넓이가 18개월에서 끝나 살아 있던 18–24개월을 효용 0으로 센 것과 같습니다. 그래서 살아 있는 환자의 빠진 응답은 넓이를 구하기 전에 채웁니다(22장 c 절 '사망과 빠진 응답은 어떻게 다루나?').

환자 320명의 QALY와 두 군의 차이는?

환자마다 경로를 만들어 리스트 P에 담고, 넓이와 24개월 안의 생존연수, 치료 시작 시점의 효용을 pts에 붙입니다. 두 군의 차이는 기저 효용을 넣은 회귀로 보정합니다.

  1. 11번 환자: 17.3개월에 사망, QALY 0.799, 생존연수 1.442. QALY가 생존연수보다 작으므로 단위와 사망의 처리가 맞습니다.

보건통계학 기초 22장의 '직접 분석' 상자와 본문에 있던 접힌 상자 '사다리꼴 공식 코드를 한 줄씩 읽으면?'입니다. R의 DescTools::AUC(x, y)와 달리 trapezoid(y, x)는 효용이 첫 인자이고, 시점을 빼도 간격을 1로 보고 계산을 마칩니다.

환자 다의 QALY와, 세 환자의 QALY를 한꺼번에 구하는 코드입니다. 주피터 노트북(Colab 포함)의 셀에 붙여 넣어 실행합니다.

직접 실행사다리꼴 공식으로 QALY 구하기
import numpy as np
import pandas as pd
from scipy.integrate import trapezoid

# 환자 다: 측정 시점(개월)과 그때의 효용. 15개월에 사망했으므로 그 시점의 효용은 0
t = np.array([0, 3, 6, 12, 15])
u = np.array([0.841, 0.762, 0.751, 0.581, 0.0])

area = trapezoid(u, t)             # 곡선 아래 면적(단위: 효용 × 개월)
print("면적:", round(area, 3), "→ QALY:", round(area / 12, 3))

# 사다리꼴을 하나씩 계산해 같은 값인지 확인
width = np.diff(t)                 # 구간의 길이: 3, 3, 6, 3
height = (u[:-1] + u[1:]) / 2      # 구간 양 끝 효용의 평균
print("구간별 QALY:", np.round(width * height / 12, 3))

# 환자가 여러 명일 때: 긴 형식의 표(한 행 = 측정 한 번)에서 환자별로 계산
df = pd.DataFrame({
    "id":    ["가"] * 6 + ["나"] * 6 + ["다"] * 5,
    "month": [0, 3, 6, 12, 18, 24] * 2 + [0, 3, 6, 12, 15],
    "utility": [0.862, 0.841, 0.862, 0.862, 0.841, 0.862,
                0.862, 0.829, 0.762, 0.593, 0.560, 0.518,
                0.841, 0.762, 0.751, 0.581, 0.0],
})
qaly = df.groupby("id")[["month", "utility"]].apply(
    lambda g: trapezoid(g["utility"], g["month"]) / 12)
print(qaly.round(3))

  2. trapezoid(u, t)사다리꼴 공식으로 넓이를 구합니다. 첫 인자가 높이(효용), 둘째 인자가 가로축(시간)입니다. 순서를 바꾸면 다른 값이 나옵니다. 시간이 개월 단위이므로 12로 나눠 QALY로 바꿉니다. 출력 첫 줄의 0.795가 표 22-4의 값입니다.
  3. np.diff(t)이웃한 시점의 차이(3, 3, 6, 3)입니다. (u[:-1] + u[1:]) / 2는 각 구간 양 끝 효용의 평균입니다. 둘을 곱한 구간별 QALY가 보건통계학 기초 22장 c 절의 접힌 상자 '환자 다의 사다리꼴 네 개를 숫자로 계산하면?'의 표와 같은지 확인합니다.
  4. u = np.array([..., 0.0])사망 시점(15개월)을 효용 0인 측정값으로 직접 넣었습니다. 15–24개월은 넓이가 0이므로, 24개월에 효용 0인 점을 더 붙이지 않아도 결과가 같습니다.

  • 중간 방문이 빠진 계산. 환자 가의 12개월 응답이 빠지면 6개월과 18개월의 측정을 직선으로 이어 1.703이 됩니다. 이 환자는 효용이 거의 일정해 차이가 0.005뿐이지만, 빠진 방문 동안 상태가 바뀐 환자라면 차이가 커집니다.
  • 마지막 방문이 빠진 계산. 환자 가의 24개월 응답이 빠지면 넓이가 18개월에서 끝나, 1.708에서 0.426이 줄어듭니다. 살아 있던 18–24개월을 효용 0으로 센 것과 같습니다. 그래서 살아 있는 환자의 빠진 응답은 넓이를 구하기 전에 채웁니다(보건통계학 기초 22장 c 절 '사망과 빠진 응답은 어떻게 다루나?').

d.할인

시험 자료의 24개월 QALY는 어떻게 할인하나?

경로를 12개월에서 둘로 나눠 둘째 해의 QALY에만 1 ÷ 1.045를 곱하는 방법과, 0개월부터 QALY가 생긴 때마다 연속으로 할인하는 방법을 비교합니다. 12개월에 측정이 없으면 그 시점의 효용은 approx()로 직선 위에서 읽습니다. 연속 할인은 0.001개월 간격의 격자에서 효용에 할인 계수를 곱한 넓이입니다.

  2. 2보정 전 차이: 할인 전 0.117, 둘째 해만 할인 0.113, 연속 할인 0.110.

모형의 QALY는 어떻게 할인하나?

공통 예시의 분할생존모형(1개월 주기, 20년)을 함수 model() 하나로 만들고, 할인 계수를 매기는 시점을 인자 when으로 바꿀 수 있게 합니다. 기준 분석은 각 달의 한가운데((k + 0.5) / 12년)에 할인 계수를 매깁니다. 모형의 구조는 이 과목 분할생존모형 장에서 자세히 봅니다.

  2. 2ICER 5,620.6만원/QALY.

할인 시점과 단위를 바꾸면?

같은 모형을 할인 시점만 바꿔 다섯 번 돌립니다. wrong은 연수 자리에 개월 수를 넣은 경우입니다. 할인 계수를 직접 만드는 코드에서는 이 실수가 오류 없이 지나갑니다.

  1. 1연 단위로 할인하면(첫해 할인 없음) 증분 QALY 0.523, ICER 5,612. 달의 시작, 한가운데, 끝으로 바꾸면 ICER는 5,620–5,621로 거의 그대로입니다.
  2. 2개월 수를 연수 자리에 넣으면 QALY 0.969와 0.870, 증분 QALY 0.099, ICER 9,140. QALY 이득이 비용보다 늦게 생겨서 증분 QALY가 더 크게 줄고 ICER가 오릅니다.
  3. 312번째 달의 할인 계수 0.959(잘못 넣으면 0.603). 할인 계수를 만든 뒤 이 값 하나만 찍어 보아도 단위의 실수를 잡을 수 있습니다.

보건통계학 기초 22장의 '직접 분석' 상자와 본문에 있던 내용입니다.

파이썬에는 할인 함수가 없어 할인 계수 1 / (1 + r) ** years를 직접 만듭니다. years 자리에 연수 대신 개월 수를 넣어도 오류 없이 계산됩니다. 공통 예시에서 이렇게 잘못 할인하면 두 군의 QALY가 2.385와 1.874에서 0.969와 0.870으로 줄어듭니다. 그 결과 증분 QALY는 0.511에서 0.099로, 증분비용은 2,872만원에서 906만원으로 크게 줄어듭니다. 증분 QALY가 증분비용보다 큰 비율로 줄어드는 것은 QALY 이득이 비용보다 늦게 생기기 때문이고, 그래서 ICER는 9,140만원/QALY로 오릅니다.

사망 시점에 마지막 값과 0을 두 번 붙이면 됩니다(같은 시점의 두 점은 넓이가 0인 수직선). 환자 다는 0.795에서 0.868로 커지고, 평균 QALY는 A군 1.230, B군 1.118로 둘 다 커집니다. 차이는 0.112(보정 후 0.089)로 기준 규칙(0.117, 0.094)과 거의 같습니다. 사망이 B군에 조금 더 많아 B군이 더 많이 늘었기 때문입니다. 어느 규칙을 썼는지 Methods에 적고, 다른 규칙을 민감도 분석으로 보입니다.

과제 2. EQ VAS ÷ 100으로 계산한 동료의 QALY

동료가 효용 대신 EQ VAS를 100으로 나눈 값으로 환자별 QALY를 구했습니다. 같은 계산으로 두 군의 평균과 차이를 구하고, 모형의 상태별 효용을 VAS ÷ 100의 평균(0.73, 0.64)으로 바꿨을 때 증분 QALY와 ICER가 얼마나 달라지는지 보이세요.

정답 코드와 풀이

시험 자료의 QALY는 A군 1.153, B군 1.052로 둘 다 작아지고, 차이는 0.101(−0.004–0.207)입니다. 모형에서는 진행의 손실을 작게 잡아(b 절의 0.096 대 0.158) 증분 QALY가 0.511에서 0.481로 줄고, ICER가 5,621에서 5,974만원/QALY로 오릅니다. VAS는 가치 세트를 거친 선호 점수가 아니므로 효용 자리에 넣지 않습니다.
