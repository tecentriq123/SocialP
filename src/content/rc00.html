b.패키지는 어떻게 쓰나

설치와 불러오기는 무엇이 다른가?

install.packages()는 패키지를 컴퓨터에 내려받아 설치하고, library()는 설치한 패키지를 지금 세션에서 쓸 수 있게 불러옵니다. 설치는 한 번, 불러오기는 R을 새로 켤 때마다 합니다. 패키지는 특정 분석에 필요한 함수와 자료를 묶은 것으로, 생존분석의 survival, 모수적 생존모형의 flexsurv처럼 대부분 CRAN이라는 공식 저장소에서 받습니다.

코드 한 줄씩

  1. install.packages("survival")패키지 이름은 따옴표 안에 씁니다. 여러 개는 c("survival", "flexsurv")처럼 한 번에 설치합니다.
  2. library(survival)불러올 때는 따옴표 없이 씁니다.
  3. packageVersion("survival")설치된 판을 확인합니다. 패키지는 판마다 기본값이 바뀌기도 하므로 Methods에 판을 적습니다.
  1. 13.8.12. 이 과목의 출력을 만든 survival의 판입니다.

함수의 설명서는 ?survfit처럼 물음표 뒤에 함수 이름을 써서 엽니다. 인자의 기본값이 'Usage'에 나와 있어, 무엇을 정하지 않았을 때 R이 무엇을 대신 고르는지 확인할 수 있습니다. 패키지를 불러오지 않고 함수 하나만 쓸 때는 survival::survfit()처럼 패키지 이름과 ::를 앞에 붙입니다.

d.자료를 고르고 요약하기

조건으로 행을 고르고 군별로 요약하려면?

데이터프레임은 [행, 열]로 고르고, 행 자리에 조건을 쓰면 조건에 맞는 행만 남습니다. 군별 요약은 tapply()나 aggregate()로 합니다.

코드 한 줄씩

  1. cost[cost$arm == "A", c("pid", "age", "cost")]A군의 행과 세 열만 고릅니다. ==는 같은지 묻는 비교이고, = 하나는 비교가 아닙니다.
  2. cost$cost_m <- cost$cost / 100없는 열 이름에 값을 넣으면 새 열이 생깁니다. 만원을 백만원 단위로 바꿨습니다.
  3. tapply(cost$cost, cost$arm, mean)첫째 값을 둘째 값의 범주별로 나눠 셋째 함수를 적용합니다.
  4. aggregate(cost ~ arm, data = cost, FUN = median)같은 일을 '결과 ~ 묶을 변수'의 식으로 씁니다. 결과가 데이터프레임으로 나옵니다.
  1. 11203. A군 환자 수입니다.
  2. 22,272.8과 2,668.9. 군별 평균 비용으로 보건통계학 기초 21장 b 절의 2,273만원과 2,669만원입니다.

dplyr는 '고르기, 묶기, 요약하기'를 동사 이름의 함수로 이어 쓰게 해 주는 패키지입니다. 파이프 |>는 앞의 결과를 다음 함수의 첫째 인자로 넘깁니다.

e.결과를 읽고 남기기

모형의 출력은 어디서 보나?

모형을 맞춘 결과는 객체에 담기고, 이름만 쓰면 짧은 요약이, summary()를 쓰면 표준오차와 P까지 나옵니다. 아래는 보건통계학 기초 21장 c 절의 선형회귀와 같은 모형입니다.

  1. 1armA 512.573. 나이, 성별, 동반질환 점수, 4기 여부가 같을 때 신약 A군의 1년 비용이 B군보다 513만원 많다는 계수입니다(보건통계학 기초 21장 c 절). 기준범주를 B로 정했기 때문에 'armA'라는 이름이 붙었습니다.
  1. 1Std. Error 54.222. 계수의 표준오차입니다. 모든 환자에서 오차의 흩어짐이 같다고 가정한 값입니다.
  2. 2t 9.453, P < 2e-16. < 2e-16은 R이 보여 주는 가장 작은 값(약 2 × 10−16)보다도 작다는 뜻입니다. 논문에는 P < 0.001로 씁니다.
  3. 3R² 0.047. 이 변수들로는 비용의 흩어짐을 4.7%만 설명합니다. 군의 차이를 추정하는 것이 목적이라면 R²가 작아도 됩니다.

신뢰구간과 강건 표준오차는 어떻게 구하나?

confint()가 계수의 95% 신뢰구간을 줍니다. 비용처럼 환자마다 흩어짐이 다른 자료에서는 R의 기본 표준오차 대신 강건 표준오차를 씁니다. R의 lm()은 기본으로 흩어짐이 같다고 가정하고, 보건통계학 기초 21장은 파이썬에서 HC3 강건 표준오차를 따로 지정했습니다. R에서는 sandwich와 lmtest 패키지로 같은 값을 얻습니다.

코드 한 줄씩

  1. round(confint(fit), 1)모든 계수의 95% 신뢰구간을 소수 첫째 자리까지 봅니다.
  2. vcovHC(fit, type = "HC3")환자마다 흩어짐이 달라도 맞는 계수의 공분산을 계산합니다(sandwich 패키지).
  3. coeftest(fit, vcov = rob), coefci(fit, vcov = rob)그 공분산으로 다시 구한 검정과 신뢰구간입니다(lmtest 패키지). ["armA", ]는 그 행만 고릅니다.

  2. 2Loading required package: zoo. lmtest가 필요로 하는 패키지를 함께 불러왔다는 안내입니다.
  3. 3Std. Error 50.960. HC3 강건 표준오차로 보건통계학 기초 21장의 값과 같습니다.
  4. 4412.7–612.5. 강건 표준오차로 구한 신뢰구간으로 보건통계학 기초 21장 c 절의 값과 같습니다. 이 자료에서는 기본값과 차이가 작지만, 흩어짐이 군마다 크게 다르면 차이가 커집니다.

R은 실수를 어떻게 알려 주나?

R은 문제가 있으면 계산을 멈추는 오류(Error)를, 계산은 했지만 확인이 필요하면 경고(Warning)를 냅니다. 경고는 무시하기 쉬워서 더 조심합니다.

  1. 1NA와 경고. 열 이름은 대소문자를 가립니다. cost$Cost는 없는 열이라 오류 없이 빈 값(NULL)이 되고, 평균을 구하지 못해 NA와 경고만 남습니다. 결과가 NA이거나 경고가 나오면 열 이름부터 확인합니다.

만든 적 없는 객체를 부르면 오류가 납니다. 위의 셀부터 차례로 실행하지 않았거나 이름의 철자가 다를 때 자주 생깁니다.
