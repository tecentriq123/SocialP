가능한 모든 표의 확률

Fisher 검정의 p를 초기하분포로 직접 계산해 봅니다. 여백(전체 189명, 저체중아 59명, 고혈압 병력 산모 12명)을 고정하면 표는 왼쪽 위 칸 a(고혈압 병력 산모 중 저체중아 수) 하나로 정해지고, a는 0부터 12까지만 가능합니다. 12명을 189명 중에서 무작위로 뽑았을 때 그 안에 저체중아가 a명 들어갈 확률이 초기하분포입니다(5장 나 절의 카드 나누기 비유).

코드 한 줄씩

  1. total, lbw, ht_n = 189, 59, 12세 여백 값을 변수에 담습니다.
  2. a = np.arange(0, ht_n + 1)0, 1, …, 12의 정수 배열입니다. np.arange(시작, 끝)은 끝 값을 포함하지 않으므로 +1을 했습니다.
  3. stats.hypergeom.pmf(a, total, lbw, ht_n)초기하분포의 확률질량함수로 a가 각 값일 확률을 한꺼번에 구합니다. 인자 순서는 (구할 값, 전체 수, '성공' 항목 수, 뽑는 수)입니다. 결과 prob도 13개짜리 배열입니다.

참고 · 표가 2×2보다 크면

Fisher 검정은 r×c 표로 확장할 수 있습니다(Freeman–Halton 확장). scipy의 fisher_exact는 1.15 버전부터 r×c 표도 받지만, 그 전 버전에서는 2×2가 아닌 표를 넣으면 오류가 납니다. r×c 표에서는 오즈비가 하나로 정해지지 않으므로 statistic도 오즈비가 아닌 다른 값이 나옵니다. 기대빈도가 작은 r×c 표라면 범주를 의미 있게 합치는 방법도 고려하고, 어떤 방법을 썼는지 Methods에 밝힙니다.

정리

  • 검정을 고르기 전에 chi2_contingency(…).expected_freq로 기대빈도를 확인합니다. 2×2 표에서 한 칸이라도 5 미만이면 Fisher의 정확한 검정을 씁니다.
  • stats.fisher_exact(표)는 양측 p와 표본 오즈비를 돌려줍니다. R의 fisher.test()와 같은 조건부 최대우도 추정값과 정확 신뢰구간은 odds_ratio(표, kind="conditional")로 구합니다.
  • 양측 p는 초기하분포에서 관측된 표보다 확률이 같거나 작은 표의 확률을 모두 더한 값이며, stats.hypergeom.pmf로 직접 확인할 수 있습니다.
  • 기대빈도가 작은 표에서는 방법에 따라 p가 크게 달라지므로 검정 방법을 미리 정합니다. 작은 표본의 "유의하지 않음"은 대부분 정보 부족입니다.

M² = (N − 1)r² 직접 계산

선형 대 선형 결합 통계량은 사람마다 "음주 점수"와 "환자 여부(1/0)"를 붙인 뒤 두 값의 Pearson 상관계수 r로 계산합니다(5장 다 절). 집계 자료를 한 사람당 한 줄인 형태로 풀어 975명의 두 변수를 만듭니다.

코드 한 줄씩

  1. score = np.array([1, 2, 3, 4])네 음주 범주에 매긴 점수입니다. 간격이 같다는 가정을 담고 있습니다.
  2. case_n = cc["ncases"].to_numpy()음주군별 환자 수 [29, 75, 51, 45]를 numpy 배열로 꺼냅니다. 다음 줄은 대조군 수입니다.
  3. np.repeat(score, case_n)점수 1을 29번, 2를 75번, 3을 51번, 4를 45번 반복한 200개짜리 배열입니다. 환자 200명의 음주 점수가 됩니다.
  4. x = np.r_[…, …]np.r_는 배열을 이어 붙입니다. 환자 200명 뒤에 대조군 775명의 점수를 붙여 975개의 x를 만듭니다.
  5. y = np.r_[np.ones(…), np.zeros(…)]같은 순서로 환자는 1, 대조군은 0인 y를 만듭니다. x와 y의 같은 위치가 같은 사람입니다.
  6. x[y == 1].mean()y가 1인 사람(환자)의 평균 음주 점수입니다. 다음 값은 대조군의 평균 점수입니다.
  7. np.corrcoef(x, y)[0, 1]두 변수의 상관행렬(2×2)을 구하고 그중 x와 y의 상관계수 칸 [0, 1]을 꺼냅니다.
  8. M2 = (len(x) - 1) * r**2M² = (N − 1)r²입니다. **는 거듭제곱입니다.
  9. stats.chi2.sf(M2, 1)자유도 1인 카이제곱 분포에서 M² 이상이 나올 확률(생존함수, survival function)이 p-value입니다.

statsmodels로 같은 검정

매번 자료를 풀어 쓰지 않아도 statsmodels의 Table에 있는 test_ordinal_association으로 같은 값을 얻습니다. 이 메서드의 분산 계산에는 N − 1이 들어 있어 z²이 M²와 정확히 같습니다.

코드 한 줄씩

  1. Table(cc).test_ordinal_association(row_scores=score, col_scores=np.array([1, 0]))행(음주군)에 점수 1–4, 열(환자, 대조군)에 점수 1과 0을 줍니다. 열 점수를 적지 않으면 기본값 0, 1이 쓰여 환자가 0, 대조군이 1이 되므로 z의 부호만 반대로 나옵니다. 행 점수도 적지 않으면 0, 1, 2, 3이 쓰이는데, 간격이 같으면 결과는 1, 2, 3, 4와 똑같습니다.
  2. lbl.zscore lbl.pvalue결과 객체에서 z 값과 양측 p를 꺼냅니다.
  3. len(x) * r**2Cochran–Armitage 추세 검정의 통계량 N r²입니다.
  4. dev = pear.statistic - M2Pearson χ²에서 직선 추세 부분을 뺀 나머지, 즉 직선에서 벗어난 부분입니다. 자유도는 3 − 1 = 2입니다.

  5. 5보정하지 않았다는 사실을 각주에 밝힙니다. 실제 논문이라면 나이 등을 보정한 오즈비가 본 결과가 되고, 이 표는 그 앞 단계의 기술적 결과입니다. 층화와 보정은 실습 8에서 다룹니다.

정리

  • 집계 자료(한 행 = 한 조합, 환자 수·대조군 수)는 groupby(…).sum()으로 원하는 변수별로 합칩니다.
  • 순서가 있는 문자열 범주는 pd.Categorical(…, categories=[…], ordered=True)로 순서를 지정해야 합니다. 그대로 두면 사전 순서로 정렬되어 추세 검정이 틀립니다.
  • 선형 대 선형 결합 M² = (N − 1)r²는 자료를 한 사람당 한 줄로 풀어 직접 계산하거나 Table(표).test_ordinal_association(row_scores=…, col_scores=…)의 z²로 구합니다. Cochran–Armitage 통계량 N r²과 사실상 같습니다.
  • Pearson χ²(자유도 r − 1)와 M²(자유도 1)의 차이가 직선에서 벗어난 부분입니다.
  • 환자-대조군 자료의 환자 비율은 위험이 아닙니다. 효과는 오즈비로 보고하고, 합친 자료의 추세에는 교란이 섞일 수 있음을 밝힙니다.
