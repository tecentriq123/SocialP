a.입력값 표와 결과표

모형은 무엇을 돌려주게 짜나?

입력값은 이름이 붙은 리스트 하나(p)에 모으고, 모형 함수는 그 리스트와 분석기간, 할인 여부를 받아 군마다 총비용, QALY, 1차 약값, 상태에 머문 기간을 돌려주게 짭니다. 이 장의 모든 계산이 이 함수 하나를 분석기간이나 입력값만 바꿔 다시 부르는 것이어서, 필요한 값을 처음부터 돌려주게 해 둡니다.

  1. 1할인한 총비용 10,561.778만원과 7,689.485만원. 그 아래 QALY 2.385와 1.874까지, 보건통계학 기초 20장 d 절 표 20-11의 값입니다.
  2. 220년 동안 무진행 상태에 머문 평균 23.7개월과 15.1개월. 할인하지 않은 기간입니다. b 절에서 관찰 기간 안의 같은 값을 결과와 함께 적습니다.

입력값 표와 결과표는 어떻게 만드나?

입력값 표는 모형이 읽는 리스트 p에서 바로 꺼내고, 결과표는 모형이 낸 반올림하지 않은 값으로 만듭니다. ICER는 반올림 전 값으로 나눕니다. CHEERS 22번(모든 입력값의 값, 범위, 분포, 출처)을 채우는 표입니다. 표를 손으로 따로 만들면 모형의 입력값을 고친 뒤 표만 옛 값으로 남기 쉽습니다. 여기서는 일부만 보였고, 출처는 설명을 위한 예입니다.

  1. 1입력값과 출처가 한 표에. unlist(p[names(src)])가 출처를 적은 항목의 값을 모형이 실제로 읽는 리스트에서 꺼냅니다. 실제 표에는 범위와 분포 열을 더합니다.
  2. 2증분비용 2,872.294만원, 증분 QALY 0.5110288. 증분은 두 열을 뺀 값이어서 표 안에서 스스로 맞습니다.
  3. 3반올림 전 값으로 나누면 5,620.6, 표에 적힌 2,872 ÷ 0.511은 5,620.4. 정수로 적으면 5,621과 5,620입니다. 표 아래에 반올림 전 값으로 계산했다고 적어 두면 검산한 독자가 헷갈리지 않습니다.

반올림은 어느 쪽으로 하나?

R의 round()와 sprintf()는 정확히 반인 값을 짝수 쪽으로 보냅니다. 엑셀의 ROUND처럼 올리려면 함수를 따로 짭니다.

  1. 12.5 → 2, 3.5 → 4, 0.5 → 0. 짝수 쪽입니다.
  2. 256.25 → 56.2, 0.125 → 0.12. 이진수로 정확히 나타나는 값이어서 규칙대로 짝수 쪽으로 갑니다. 0.15처럼 이진수로 정확히 나타나지 않는 값은 저장된 값이 반보다 조금 크거나 작아서, 규칙이 아니라 그 값에 따라 정해집니다.
  3. 3올림 함수로는 3, 56.3, 0.13. 엑셀로 검산한 사람과 끝자리가 다르면 이 차이부터 확인합니다. 파이썬의 round도 R과 같이 짝수 쪽으로 보냅니다.

CHEERS 22번(모든 입력값의 값, 범위, 분포, 출처)은 모형 함수가 읽는 입력값 사전(dict)을 그대로 표로 옮기면 빠짐없이 채울 수 있습니다. 표를 손으로 따로 만들면 모형의 입력값을 고친 뒤 표만 옛 값으로 남기 쉽습니다. 결과표도 모형이 낸 반올림하지 않은 값에서 만들고, 반올림은 표에 옮길 때 한 번만 합니다.

  • 반올림 규칙. 파이썬의 round, numpy의 np.round, pandas의 .round(), f-문자열의 :.1f는 모두 정확히 반인 값을 짝수 쪽으로 보냅니다(2.5 → 2, 56.25 → 56.2, 0.125 → 0.12). 이 동작은 numpy 2.5와 pandas 3.0에서 확인했습니다. 엑셀의 ROUND 함수는 이런 값을 올리므로(3, 56.3, 0.13), 같은 표를 엑셀로 검산한 사람과 끝자리가 다를 수 있습니다. 표를 만들 때 쓴 반올림 방법을 정해 두고, 끝자리가 맞지 않으면 이 차이부터 확인합니다.
  • ICER는 반올림 전 값으로 나눕니다. 표에 적힌 2,872 ÷ 0.511은 5,620이고, 반올림 전 값으로 나누면 5,621입니다. 표 아래에 반올림 전 값으로 계산했다고 적어 두면 검산한 독자가 헷갈리지 않습니다.

b.관찰 기간의 결과

증분 QALY 가운데 관찰한 기간에서 나온 것은 얼마인가?

같은 모형을 분석기간 30개월(시험의 최대 추적 기간)로 한 번 더 돌리고, 20년 결과와 나눕니다. 관찰 기간만의 결과를 구하는 전용 함수는 없습니다. 모형 함수에 분석기간을 인자로 둔 이유입니다. 보건통계학 기초 25장 b 절 '관찰한 구간과 외삽한 구간은 어떻게 가르나?'의 계산입니다.

  1. 130개월에서 끊으면 증분비용 1,157만원, 증분 QALY 0.128, ICER 9,056만원/QALY. 20년 기준 분석은 2,872만원, 0.511, 5,621만원/QALY입니다.
  2. 2증분비용의 59.7%, 증분 QALY의 75.0%가 30개월 뒤에서 생깁니다. 이 비율이 외삽 시나리오를 얼마나 무겁게 읽을지 정합니다.
  3. 330개월 안에 무진행 16.6개월과 12.8개월, 진행 6.8개월과 8.9개월. 이 기간도 함께 적으면 독자가 시험 결과와 비교할 수 있습니다.

관찰 기간만의 결과도 외삽에 쓴 곡선으로 계산한 값입니다. 그 구간에서 곡선이 Kaplan-Meier 곡선에 잘 맞아야 '관찰한 부분'으로 읽을 수 있으므로, 적합을 확인한 결과를 함께 적습니다(보건통계학 기초 23장 d 절).

보건통계학 기초 25장의 '직접 분석' 상자와 '장 마무리'에 있던 내용입니다.

보건통계학 기초 23장 c 절의 분할생존모형을 분석기간을 바꿀 수 있는 함수로 만들고, 20년과 30개월로 두 번 돌립니다. 주피터 노트북의 셀에 그대로 붙여 넣어 실행합니다.

직접 실행분석기간 20년과 30개월의 증분 결과
import numpy as np

def model(horizon):                                   # 분석기간(개월)을 넣으면 (증분비용, 증분QALY)를 돌려준다
    t = np.arange(0, horizon + 1)
    res = {}
    for arm, hr_pfs, hr_os, c_drug, c_ae, dq_ae in (("A", 0.65, 0.75, 190, 120, 0.012), ("B", 1.0, 1.0, 120, 80, 0.008)):
        os_ = np.exp(-np.log(2) / 28 ** 1.15 * hr_os * t ** 1.15)                    # 전체생존 곡선
        pfs = np.minimum(np.exp(-np.log(2) / 10 ** 0.95 * hr_pfs * t ** 0.95), os_)  # 무진행생존 곡선
        pf = (pfs[:-1] + pfs[1:]) / 2                 # 무진행 비율(반주기 보정)
        pd_ = ((os_ - pfs)[:-1] + (os_ - pfs)[1:]) / 2
        died = os_[:-1] - os_[1:]
        disc = 1 / 1.045 ** ((t[:-1] + 0.5) / 12)     # 할인 계수
        cost = ((pf * (c_drug + 40) + pd_ * 250 + died * 800) * disc).sum() + c_ae
        qaly = ((pf * 0.78 + pd_ * 0.62) / 12 * disc).sum() - dq_ae
        res[arm] = (cost, qaly)
    return res["A"][0] - res["B"][0], res["A"][1] - res["B"][1]

dc_all, dq_all = model(240)                           # 기준 분석: 20년
dc_obs, dq_obs = model(30)                            # 시험이 관찰한 30개월에서 끊으면
print("20년  :", round(dc_all), round(dq_all, 3), round(dc_all / dq_all))
print("30개월:", round(dc_obs), round(dq_obs, 3), round(dc_obs / dq_obs))
print("30개월 뒤의 비율: QALY", round(1 - dq_obs / dq_all, 3), " 비용", round(1 - dc_obs / dc_all, 3))

  • model(horizon)은 23장 c 절의 분할생존모형(이 과목 22장 c 절의 파이썬 상자)과 같은 계산입니다. 달라진 것은 시점 배열 t의 끝을 horizon으로 받는다는 점뿐입니다.
  • 출력 첫 줄이 기준 분석(증분비용 2,872만원, 증분 QALY 0.511, ICER 5,621만원/QALY)입니다.
  • 둘째 줄은 30개월에서 끊은 결과입니다. 증분 QALY 0.128, ICER 9,056만원/QALY입니다.
  • 셋째 줄에서 증분 QALY의 75.0%, 증분비용의 59.7%가 30개월 뒤에 생깁니다.

c.재정영향

치료 연차별 1인당 비용은 어떻게 구하나?

할인하지 않은 모형을 분석기간 12, 24, …, 60개월로 돌려 누적 비용을 구하고, 한 해 앞의 누적 비용을 뺍니다. 재정영향은 해마다 실제로 나가는 돈이어서 할인하지 않습니다. 이상반응 치료비는 한 번만 드는 비용이어서 1년차에 모두 들어갑니다.

  1. 1표준요법 B 2,200.1, 1,821.0, 1,398.5, 1,021.5, 723.8만원. 처음 치료를 시작한 환자 1명당 평균이어서, 사망한 환자의 0원도 분모에 남습니다.
  2. 2차이 620.6, 405.8, 364.6, 345.4, 320.4만원. 보건통계학 기초 25장 c 절의 연차별 비용 표와 같습니다.

코호트를 쌓아 연도별 재정영향은 어떻게 더하나?

급여 y년차에는 1년차부터 y년차까지 신약 A로 시작한 코호트가 모두 치료 중입니다. 코호트마다 시작한 환자 수에 그 코호트의 치료 연차에 맞는 1인당 비용을 곱해 더합니다. 해마다 600명이 새로 치료를 시작하고, 그 가운데 신약 A의 점유율이 10%에서 50%까지 오른다고 가정한 예입니다.

  1. 1재정영향 3.7, 9.9, 18.2, 28.6, 41.0억 원, 5년 합 101.5억 원. 25장 표 25-8의 값입니다. 3년차는 60 × 364.6 + 120 × 405.8 + 180 × 620.6입니다.
  2. 2신약 A 약품비 총액 5년 252.4억 원. 같은 함수에 1차 약값만 넣고 비교군을 0으로 둔 값입니다. 재정영향의 2.5배로, 약품비 총액을 재정영향으로 읽으면 안 되는 이유입니다.

가정을 바꾸면 재정영향은 얼마나 달라지나?

함수 bia()의 환자 수와 점유율, 모형의 약값, 비용을 세는 범위만 바꿔 다시 부릅니다. ICER가 5,000만원/QALY가 되는 월 약값은 uniroot()로 찾습니다.

  1. 1ICER가 5,000이 되는 월 약값 175.4만원. 표시 가격 190만원보다 7.7% 낮습니다.
  2. 2그 가격에서도 3년차 14.5억 원, 5년 82.1억 원. ICER가 임계값과 같다는 것은 더 드는 돈이 그만한 값을 한다는 뜻이지, 더 드는 돈이 없다는 뜻이 아닙니다.
  3. 3약품비 순증가만 세면 3년차 24.0억 원, 5년 129.2억 원. 신약 A가 진행을 늦춰 줄여 주는 진행 상태와 임종기 비용이 빠져, 진료비 전체로 본 재정영향보다 큽니다.
  4. 4그 가격에서 치료 1년차의 1인당 비용 차이 485.8만원. 표시 가격에서는 620.6만원입니다.

점유율이 절반이면 재정영향도 절반(9.1억 원, 50.7억 원)이고, 새 환자가 900명이면 1.5배(27.3억 원, 152.2억 원)입니다. 환자 수와 점유율에 비례하므로 두 가정은 근거를 밝히고 여러 시나리오로 보입니다.

보건통계학 기초 25장의 '직접 분석' 상자와 '장 마무리'에 있던 내용입니다.

재정영향분석을 해 주는 전용 함수는 없어서, 연도별 지출은 numpy로 반복문 몇 줄을 짜서 더합니다. b 절 파이썬 상자의 분할생존모형에서 할인 계수를 뺀 함수로, 분석기간을 12, 24, …, 60개월로 바꿔 누적 비용을 구한 뒤 한 해씩 뺍니다. 그다음 해마다 치료를 시작한 코호트를 쌓아 더합니다. 주피터 노트북의 셀에 그대로 붙여 넣어 실행합니다.

직접 실행연차별 비용과 5년 재정영향
import numpy as np

def cum_cost(arm, horizon):                       # 분석기간(개월)까지 환자 1명의 누적 비용(만원). 할인하지 않음
    hr_pfs, hr_os, c_drug, c_ae = {"A": (0.65, 0.75, 190, 120), "B": (1.0, 1.0, 120, 80)}[arm]
    t = np.arange(0, horizon + 1)
    os_ = np.exp(-np.log(2) / 28 ** 1.15 * hr_os * t ** 1.15)                    # 전체생존 곡선
    pfs = np.minimum(np.exp(-np.log(2) / 10 ** 0.95 * hr_pfs * t ** 0.95), os_)  # 무진행생존 곡선
    pf = (pfs[:-1] + pfs[1:]) / 2                 # 무진행 비율(반주기 보정)
    pd_ = ((os_ - pfs)[:-1] + (os_ - pfs)[1:]) / 2
    died = os_[:-1] - os_[1:]
    return (pf * (c_drug + 40) + pd_ * 250 + died * 800).sum() + c_ae   # 할인 계수를 곱하지 않음

cost_A = np.diff([0] + [cum_cost("A", 12 * k) for k in range(1, 6)])   # 치료 시작 후 1-5년차의 1인당 비용(만원), 신약 A
cost_B = np.diff([0] + [cum_cost("B", 12 * k) for k in range(1, 6)])   # 표준요법 B
print(np.round(cost_A, 1))
print(np.round(cost_B, 1))

n_new = 600                                                    # 해마다 치료를 새로 시작하는 환자 수
share = np.array([0.10, 0.20, 0.30, 0.40, 0.50])               # 그해 시작하는 환자 가운데 신약 A의 비율
start_A = n_new * share                                        # 연도별로 신약 A를 시작한 환자 수

net = np.zeros(5)
for year in range(5):                                          # 급여 후 연차(0 = 첫해)
    for start in range(year + 1):                              # 그해까지 시작한 코호트를 모두 더한다
        k = year - start                                       # 그 코호트의 치료 연차(0 = 1년차)
        net[year] += start_A[start] * (cost_A[k] - cost_B[k])
print(start_A)
print(np.round(net / 10000, 1), round(net.sum() / 10000, 1))   # 억 원

  • cum_cost는 b 절 코드의 모형에서 할인 계수를 뺀 것입니다. 재정영향은 해마다 실제로 나가는 돈이어서 할인하지 않습니다. 이상반응 치료비(c_ae)는 한 번만 드는 비용이어서 1년차에 모두 들어갑니다.
  • np.diff는 이웃한 값의 차를 구합니다. 누적 비용 앞에 0을 붙였으므로 첫 값은 1년 누적 비용 그대로이고, 둘째 값부터는 k년 누적에서 k−1년 누적을 뺀 값입니다. 출력 첫 두 줄이 셀 5의 연차별 비용과 같습니다.
  • start_A는 해마다 신약 A로 시작하는 환자 수입니다. 출력 셋째 줄의 60, 120, …, 300명입니다.
  • 바깥 반복문은 급여 후 연차, 안쪽 반복문은 그해까지 치료를 시작한 코호트입니다. k는 그 코호트가 치료 몇 년차인지입니다.
  • cost_A[k] - cost_B[k]가 핵심입니다. 신약의 비용에서 대체된 표준요법의 비용을 뺀 값에 환자 수를 곱합니다.
  • 출력 마지막 줄이 표 25-8의 재정영향(억 원)과 5년 합 101.5입니다.

과제 1. 환급률에 따른 ICER

표시 가격(월 190만원)은 그대로 두고 제약사가 일정 비율을 돌려주는 환급형 계약에서, 환급률이 0%, 5%, 7.7%, 10%일 때 실제 가격으로 계산한 ICER를 구해 보건통계학 기초 25장 c 절의 표 25-7을 다시 만드세요.

정답 코드와 풀이

실제 가격으로 계산한 ICER는 5,621, 5,217, 5,000, 4,814만원/QALY입니다. 7.7%는 셀 7에서 찾은 가격(175.39만원)에 해당하는 환급률이어서, 반올림한 0.077을 그대로 넣으면 4,999가 나옵니다. 표시 가격으로 계산한 ICER는 환급률과 관계없이 5,621이고, 논문에는 이 값이 실립니다.

과제 2. 어디서 끊느냐에 따라 달라지는 관찰 기간만의 결과

시험의 중앙 추적 기간이 18개월이었다고 합시다. 분석기간 18개월에서 끊은 증분 결과와, 그 뒤에서 생긴 비율을 30개월에서 끊은 결과와 비교하세요.

정답 코드와 풀이

18개월에서 끊으면 증분 QALY 0.057, ICER 14,312만원/QALY이고, 증분 QALY의 88.9%가 그 뒤에서 생깁니다. 30개월에서는 75.0%였습니다. 같은 시험이라도 어디서 끊느냐에 따라 비율이 크게 달라지므로, 최대 추적 기간인지 중앙 추적 기간인지와 그 값을 함께 적습니다.
