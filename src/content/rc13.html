b.Spearman과 Kendall 상관계수

Spearman 상관계수와 P는 어떻게 구하나?

cor.test()에 method = "spearman"을 적습니다. 값은 그대로 넣고 순위는 R이 매깁니다. 동점이 없으면 R은 기본으로 순위 배열의 분포로 p를 구합니다(AS 89 알고리즘). 이 계산은 10명 미만이면 모든 배열을 따진 정확 p이고, 그보다 크면 근사입니다. exact = FALSE를 적으면 t 근사 p를 줍니다. 예는 보건통계학 기초 6장 b 절의 같은 8명입니다.

  2. 2t 근사 p 0.021. 같은 rs = 0.786으로 a 절의 t 식을 쓴 값입니다.

작은 표본에서는 두 p가 이만큼 다르므로 어느 방식인지 Methods에 밝힙니다. 동점이 있으면 R은 "Cannot compute exact p-value with ties" 경고를 내고 근사 p로 바꿉니다. 동점이 있는 작은 표본의 정확 p는 순열검정(coin 패키지의 spearman_test())으로 구합니다.

import numpy as np
from scipy import stats

n = 100
b0, b1, se_b1 = 97.2326, 0.5296, 0.1169   # 출력의 절편, 기울기, 기울기의 std err
s = 14.5008                                # 잔차 표준편차 (np.sqrt(fit.scale))

t_crit = stats.t.ppf(0.975, n - 2)         # 자유도 98인 t 분포의 97.5% 분위수
print(round(t_crit, 3))
print(round(b1 - t_crit * se_b1, 3), round(b1 + t_crit * se_b1, 3))   # 기울기의 95% CI
t = b1 / se_b1
print(round(t, 3), 2 * stats.t.sf(t, n - 2))                          # t와 양측 p

sxx = (s / se_b1) ** 2                     # SE(b1) = s ÷ √Σ(x − x̄)² 를 거꾸로 풀어 Σ(x − x̄)²를 구함
yhat = b0 + b1 * 70                        # 70세의 예측값
se_mean = s * np.sqrt(1/n + (70 - 56)**2 / sxx)       # 70세 '평균'의 표준오차 (평균 나이 56세)
se_pred = s * np.sqrt(1 + 1/n + (70 - 56)**2 / sxx)   # 70세 '한 사람' 예측의 표준오차
print(round(yhat, 1), round(se_mean, 2), round(se_pred, 2))
print(round(yhat - t_crit * se_mean, 1), round(yhat + t_crit * se_mean, 1))   # 평균의 95% 신뢰구간
print(round(yhat - t_crit * se_pred, 1), round(yhat + t_crit * se_pred, 1))   # 개인의 95% 예측구간

보건통계학 기초 6장 d 절의 '직접 분석' 상자에 있던 내용입니다.

곡선을 허용한 모형과 직선 모형을 F 검정으로 비교합니다. 곡선은 흔히 스플라인으로 넣습니다. 스플라인은 변수의 범위를 몇 구간으로 나눠 구간마다 곡선을 매끄럽게 이은 함수이고, 구간의 경계점을 매듭이라고 합니다. 논문에 흔한 제한 삼차 스플라인(restricted cubic spline)은 자료가 적은 양 끝 구간을 직선으로 제한해, 끝에서 곡선이 크게 휘지 않게 한 것입니다. statsmodels의 공식에서는 cr()이 이런 스플라인을 만듭니다. 그런데 cr()은 기본으로 가장 바깥 매듭을 자료의 최솟값과 최댓값에 두므로, 자료 범위 안에서는 양 끝 구간도 직선으로 제한되지 않습니다. 바깥 매듭을 5번째와 95번째 백분위수에 두려면 knots, lower_bound, upper_bound를 직접 지정합니다.

# 파이썬 (statsmodels) · 기저 SBP만 곡선으로 바꾼 모형과 직선 모형 비교
# sbp6 = 6개월 후 SBP, classes = 계열 수, base10·age10 = 기저 SBP·나이 ÷ 10, inst = 요양기관 종별
lin = smf.ols("sbp6 ~ classes + base10 + age10 + female + diabetes"
              " + bmi + adherent + C(inst)", data=d).fit()
spl = smf.ols('sbp6 ~ classes + cr(base10, df=3, constraints="center")'
              " + age10 + female + diabetes + bmi + adherent + C(inst)", data=d).fit()
print(spl.compare_f_test(lin))   # (F, P, 자유도)

df=3은 기저 SBP에 계수 3개(직선 하나와 곡선 둘)를 쓰라는 뜻이고, 이때 매듭은 4개입니다. 직선 모형보다 계수가 2개 많으므로 F 검정의 자유도는 2입니다. constraints="center"는 스플라인의 열이 절편과 겹치지 않게 하는 지정입니다. 빼면 경고 없이 곡선 항이 하나뿐인 다른 모형이 적합되어, 이 자료의 F 검정은 자유도 1, P = 0.25로 바뀝니다. 세 연속형 변수를 하나씩 곡선으로 바꿔 본 결과는 다음과 같습니다.

계열 수를 범주로 넣으려면 C(classes)로 적습니다. VIF는 statsmodels.stats.outliers_influence의 variance_inflation_factor로 변수마다 구합니다(실습 6 d 절). 로그 모형은 공식에 np.log(cost)를 그대로 적고, np.exp(fit.params) - 1과 np.exp(fit.conf_int()) - 1로 백분율 차이를 구합니다.

emmeans 패키지의 emmeans()는 기저값을 전체 평균에 두고 군별 평균을 예측합니다. 두 군의 기울기가 같은지는 군 × 기저값 교호작용을 넣은 모형과 비교합니다.

  1. 1일반 진료군 7.78.
  2. 2복약상담군 7.40. 두 값의 차이가 위의 −0.38입니다.
  3. 3기울기 차이 P = 0.86. 두 군의 기울기가 다르다는 근거가 없습니다. 이 점검은 분석계획에 미리 적어 둡니다.

공변량은 결과를 보기 전에 정하고, 무작위배정 뒤에 잰 변수는 넣지 않습니다(보건통계학 기초 6장 e 절 '무엇을 가정하고, 미리 무엇을 정하나?').

보건통계학 기초 6장 e 절의 접힌 상자에 있던 파이썬 코드입니다.

fit = smf.ols("hba1c_6m ~ arm + hba1c_0", data=d).fit()
# 군별 최소제곱 평균: 두 군 모두 기저값을 전체 평균에 두고 예측
lsm = fit.predict(pd.DataFrame({"arm": [0, 1], "hba1c_0": d["hba1c_0"].mean()}))
# 기울기 확인: 중심화한 기저값과의 교호작용 행 P
fit2 = smf.ols("hba1c_6m ~ arm * I(hba1c_0 - hba1c_0.mean())", data=d).fit()

arm 행의 계수 −0.3829가 보정한 차이이고, lsm은 7.78(일반 진료)과 7.40(복약상담)입니다.
