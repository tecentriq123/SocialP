나.발생률과 발생률비

먼저 모형 없이 군별 발생률과 그 정확 신뢰구간, 두 군의 발생률비를 구합니다(12장 가 절). 발생률은 사건 수 ÷ 총 인년이고, 정확 신뢰구간은 카이제곱 분포의 분위수로 계산합니다.

\[ \text{하한} = \frac{\chi^2_{0.025}(2D)}{2T}, \qquad \text{상한} = \frac{\chi^2_{0.975}(2D + 2)}{2T} \]

D는 사건 수, T는 총 인년입니다. 100을 곱하면 100인년당 값이 됩니다.

코드 한 줄씩

  1. from scipy import stats확률분포 함수가 들어 있는 scipy의 stats 모듈을 불러옵니다.
  2. pt.groupby("treat", observed=True).agg(…)배정군별로 환자 수("size", 행 수), 사건 수(n_inf의 합), 총 인년(py의 합)을 구합니다. 두 행짜리 표 rt가 되고 행 이름표는 placebo, rIFN-g입니다. observed=True는 범주형 열로 묶을 때 실제로 있는 범주만 쓰라는 옵션입니다.
  3. d, T = rt["events"], rt["py"]사건 수와 인년 열에 짧은 이름을 붙입니다. 각각 두 값(군별)을 가진 Series입니다.
  4. rt["rate"] = d / T * 100100인년당 발생률입니다. Series끼리의 계산은 같은 이름표(군)끼리 이뤄집니다.
  5. stats.chi2.ppf(0.025, 2 * d) / 2 / T * 100chi2.ppf(확률, 자유도)는 카이제곱 분포에서 누적확률이 그 값이 되는 점(분위수)입니다. 위 식의 하한을 두 군에 한꺼번에 계산합니다. 상한은 자유도 2D + 2, 확률 0.975로 같은 방식입니다.

출력 읽기

  1. 1위약군 100인년당 110.4건. 56건 ÷ 50.72인년 × 100입니다. 위약군 환자는 1년에 평균 1.1번 중증 감염으로 입원한 셈입니다.
  2. 2정확 95% CI 83.4–143.4. 점추정값 110.4에서 아래로 27.0, 위로 33.0으로 위쪽이 깁니다. 건수가 0 아래로는 갈 수 없는 포아송 분포의 모양이 반영된 비대칭입니다(12장 가 절).
  3. 3rIFN-g군 100인년당 38.5건(23.5–59.5). 사건이 20건뿐이라 구간이 상대적으로 더 넓습니다(상대 표준오차 1/√20 = 22%, 위약군은 1/√56 = 13%). 이 구간들은 포아송 가정 아래의 값이어서, 다 절에서 볼 과산포가 있으면 실제보다 좁을 수 있습니다.

두 발생률의 비를 구하고, 로그 척도에서 Wald 신뢰구간을 만듭니다. 로그 발생률비의 표준오차는 사건 수로만 정해집니다.

\[ SE(\ln \text{IRR}) = \sqrt{\frac{1}{D_1} + \frac{1}{D_0}} \]

코드 한 줄씩

  1. rt.loc["rIFN-g", "rate"] / rt.loc["placebo", "rate"].loc[행 이름, 열 이름]으로 표에서 값 하나를 꺼냅니다. rIFN-g군 발생률 ÷ 위약군 발생률 = 발생률비입니다.
  2. np.sqrt(1 / d["rIFN-g"] + 1 / d["placebo"])위 식의 표준오차입니다.
  3. np.exp(np.log(irr) - 1.96 * se)로그 척도에서 ±1.96 × SE를 한 뒤 지수함수로 되돌립니다(8장 다 절).
  4. print(f"IRR = {irr:.3f} …")f-문자열입니다. 중괄호 안의 변수를 :.3f(소수 셋째 자리) 형식으로 끼워 넣습니다.

출력 읽기

다.포아송 회귀와 과산포

여러 변수를 함께 보정한 발생률비는 포아송 회귀로 구합니다(12장 나 절). 환자마다 추적 기간이 다르므로 로그 인년을 오프셋(offset)으로 넣습니다.

\[ \ln(\mu_i) = \ln(\text{py}_i) + \beta_0 + \beta_1\,\text{rIFN-g}_i + \beta_2\,\text{age}_i + \cdots \]

μi는 환자 i의 기대 감염 건수입니다. ln(pyi)의 계수는 추정하지 않고 1로 고정되므로, 모형은 사실상 ln(μi ÷ pyi), 즉 로그 발생률을 설명합니다. 추적 기간이 2배인 환자는 발생률이 같아도 기대 건수가 2배라는 사실을 모형에 넣는 장치입니다.

보정 변수는 등록 시점의 나이, 유전 형태, 예방적 항생제 사용으로 정했습니다. 무작위배정 시험이므로 교란 보정이 아니라 예후 인자를 보정해 정밀도를 높이려는 목적이며, 실제 연구에서는 이런 변수를 계획서에 미리 정해 둡니다. 스테로이드 사용은 3명뿐이라 넣지 않았습니다.

코드 한 줄씩

  1. import statsmodels.api as sm, import statsmodels.formula.api as smf분포(sm.families)가 들어 있는 모음과 모형식으로 모형을 지정하는 함수 모음을 불러옵니다.
  2. pd.Categorical(pt["inherit"], categories=["X-linked", "autosomal"])유전 형태의 기준범주를 X-linked로 정합니다. 계수는 "autosomal 대 X-linked"로 나옵니다.
  3. form = "n_inf ~ treat + age + inherit + propylac"결과변수(감염 건수)와 설명변수를 적은 모형식입니다. 뒤 셀에서 다시 쓰려고 변수에 저장합니다. propylac은 0/1 숫자라 그대로 넣습니다.
  4. smf.glm(form, data=pt, family=sm.families.Poisson(), …)일반화 선형모형(8장 라 절)을 포아송 분포로 적합합니다. 연결함수는 기본값인 로그입니다.
  5. offset=np.log(pt["py"])환자별 로그 인년을 오프셋으로 넣습니다. py 자체가 아니라 로그를 넣어야 합니다. 모형식 안이 아니라 인자로 따로 주는 것이 statsmodels의 방식입니다.
  6. .fit(), print(pois.summary())최대우도로 적합하고 요약표를 출력합니다.

  4. 4강건 표준오차로 만든 신뢰구간. 점추정값 0.362와 구간 0.198–0.664를 반올림했습니다. 모형 기반 구간(0.22–0.61)을 보고했다면 정밀도를 과장했을 것입니다.

정리

  • 포아송 회귀는 smf.glm(form, data, family=sm.families.Poisson(), offset=np.log(인년))입니다. 오프셋은 로그 인년을 인자로 따로 줍니다.
  • 계수는 로그 발생률비이므로 np.exp로 발생률비와 신뢰구간을 구합니다.
  • deviance/df_resid, pearson_chi2/df_resid가 1보다 크면 과산포입니다. 건수별 관측·기대 빈도를 비교해 0과 꼬리를 확인합니다.
  • .fit(cov_type="HC0")의 강건 표준오차는 계수를 바꾸지 않고 신뢰구간만 넓힙니다.

라.음이항 회귀

음이항 회귀는 같은 공변량을 가진 환자라도 각자의 발생률이 다르다는 것을 분포로 모형화합니다. 분산을 Var = μ + αμ²로 두고 α를 계수와 함께 최대우도로 추정하는 NB2 모형이 표준입니다(12장 나 절 '음이항 모형의 α'). α = 0이면 포아송 모형으로 돌아갑니다. statsmodels에서는 smf.negativebinomial이 α까지 추정합니다.

코드 한 줄씩

  1. smf.negativebinomial(form, data=pt, offset=np.log(pt["py"]))모형식과 오프셋은 포아송 회귀와 같습니다. 기본값이 NB2 모형입니다. 결과를 nb2에 저장합니다.
  2. .fit()계수와 α를 함께 최대우도로 추정합니다. 반복 계산 과정의 메시지가 먼저 출력됩니다.

코드 한 줄씩

음이항 모형이 0건 환자 수를 얼마나 잘 맞추는지도 확인합니다. NB2 분포에서 0건일 확률은 (1 + αμ)−1/α입니다.

코드 한 줄씩

GLM의 음이항 family

statsmodels의 smf.glm에도 음이항 분포(sm.families.NegativeBinomial)가 있습니다. 다만 GLM은 α를 추정하지 않고 사용자가 준 값으로 고정합니다. 앞에서 추정한 α를 넣으면 계수가 같아지는지 확인합니다.

코드 한 줄씩

  1. sm.families.NegativeBinomial(alpha=a)α를 0.7153으로 고정한 음이항 분포입니다.
  2. pd.concat({...}, axis=1)두 결과의 계수(Series)를 열 방향으로 붙여 비교표를 만듭니다. GLM에는 alpha 행이 없어 NaN(값 없음)으로 표시됩니다.

계수는 소수 넷째 자리까지 거의 같습니다. 표준오차는 GLM이 α를 알려진 값으로 취급하는 등 계산 방식이 달라 셋째 자리에서 조금 다릅니다(치료군 0.309 대 0.306). α를 주지 않으면 어떻게 되는지 보겠습니다.

이런 오류가 나면

ValueWarning: Negative binomial dispersion parameter alpha not set. Using default value alpha=1.0.은 오류가 아니라 경고라서 분석은 그대로 진행됩니다. 그러나 α가 자료와 관계없이 1.0으로 고정되므로 표준오차와 신뢰구간이 틀릴 수 있습니다. 이 자료에서 α = 1로 적합하면 치료군 계수는 −1.009로 비슷하지만, α가 실제와 많이 다른 자료에서는 결과가 달라집니다. 음이항 회귀는 α를 추정하는 smf.negativebinomial을 쓰거나, GLM이라면 추정한 α를 직접 넣습니다. 이 경고는 statsmodels 버전에 따라 나오지 않을 수도 있으므로, 경고가 없다고 안심하지 말고 alpha=를 적었는지 확인하세요.

The negative binomial model fitted better than the Poisson model (2 dispersion parameter α = 0.72; likelihood ratio test P = .001; AIC, 256.6 vs 264.1). Interferon gamma reduced the rate of serious infection by 64% (3 adjusted rate ratio, 0.36; 95% CI, 0.20 to 0.66; P < .001); 4 Poisson regression with robust standard errors gave similar results (0.36; 95% CI, 0.20 to 0.66).

정리

  • smf.negativebinomial(form, data, offset=np.log(인년)).fit()은 계수와 과산포 모수 α를 함께 추정하는 NB2 모형입니다. α 줄의 P 대신 경계 보정한 우도비 검정과 AIC로 포아송과 비교합니다.
  • 과산포가 있으면 음이항 회귀와 강건 표준오차의 신뢰구간이 비슷하게 넓어지고, 모형 기반 포아송 구간만 좁습니다.
  • 0건 환자 수를 음이항 모형이 맞춘다면 영과잉 모형은 필요하지 않습니다.
  • GLM의 NegativeBinomial은 α를 추정하지 않으므로 alpha=를 직접 줍니다. 빠뜨리면 α = 1로 고정됩니다.
