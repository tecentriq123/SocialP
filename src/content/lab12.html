b.발생률과 발생률비

먼저 모형 없이 군별 발생률과 그 정확 신뢰구간, 두 군의 발생률비를 구합니다(12장 a 절 2단계). 발생률은 사건 수 ÷ 총 인년이고, 정확 신뢰구간은 아래처럼 카이제곱 분포의 분위수로 계산합니다(12장 a 절 '더 알아보기'의 '수식으로 보기').

\[ \text{하한} = \frac{\chi^2_{0.025}(2D)}{2T}, \qquad \text{상한} = \frac{\chi^2_{0.975}(2D + 2)}{2T} \]

D는 사건 수, T는 총 인년입니다. 100을 곱하면 100인년당 값이 됩니다.

코드 한 줄씩

  1. from scipy import stats확률분포 함수가 들어 있는 scipy의 stats 모듈을 불러옵니다.
  2. pt.groupby("treat", observed=True).agg(…)배정군별로 환자 수("size", 행 수), 사건 수(n_inf의 합), 총 인년(py의 합)을 구합니다. 두 행짜리 표 rt가 되고 행 이름표는 placebo, rIFN-g입니다. observed=True는 범주형 열로 묶을 때 실제로 있는 범주만 쓰라는 옵션입니다.
  3. d, T = rt["events"], rt["py"]사건 수와 인년 열에 짧은 이름을 붙입니다. 각각 두 값(군별)을 가진 Series입니다.
  4. rt["rate"] = d / T * 100100인년당 발생률입니다. Series끼리의 계산은 같은 이름표(군)끼리 이뤄집니다.
  5. stats.chi2.ppf(0.025, 2 * d) / 2 / T * 100chi2.ppf(확률, 자유도)는 카이제곱 분포에서 누적확률이 그 값이 되는 점(분위수)입니다. 위 식의 하한을 두 군에 한꺼번에 계산합니다. 상한은 자유도 2D + 2, 확률 0.975로 같은 방식입니다.

두 발생률의 비를 구하고, 로그 척도에서 Wald 신뢰구간을 만듭니다. 로그 발생률비의 표준오차는 사건 수로만 정해집니다(12장 a 절 2단계).

코드 한 줄씩

c.포아송 회귀와 과산포

여러 변수를 함께 보정한 발생률비는 포아송 회귀로 구합니다. 환자마다 추적 기간이 다르므로 로그 인년을 오프셋(offset)으로 넣습니다(12장 b 절 2단계의 '오프셋은 무엇을 하나?').

\[ \ln(\mu_i) = \ln(\text{py}_i) + \beta_0 + \beta_1\,\text{rIFN-g}_i + \beta_2\,\text{age}_i + \cdots \]

μi는 환자 i의 기대 감염 건수입니다. ln(pyi)의 계수는 추정하지 않고 1로 고정되므로, 나머지 계수는 로그 발생률 ln(μi ÷ pyi)을 설명합니다.

보정 변수는 등록 시점의 나이, 유전 형태, 예방적 항생제 사용으로 정했습니다. 무작위배정 시험이므로 교란을 보정하려는 것이 아니라 예후 인자를 보정해 정밀도를 높이려는 것이며, 실제 연구에서는 이런 변수를 계획서에 미리 정해 둡니다. 스테로이드 사용은 3명뿐이라 넣지 않았습니다.

준포아송

준포아송(quasi-Poisson)은 분산이 평균의 φ배라고 놓고, φ를 셀 11의 Pearson χ²/df로 추정합니다. statsmodels에서는 같은 포아송 모형을 fit(scale="X2")로 적합하면 됩니다.

코드 한 줄씩

  1. .fit(scale="X2")scale은 분산이 평균의 몇 배인지(φ)를 정하는 인자입니다. 기본값은 포아송의 1이고, "X2"를 주면 Pearson χ²(카이제곱을 X²로 적은 것)를 잔차 자유도로 나눈 값으로 정합니다. 계수를 구하는 계산은 그대로입니다.
  2. phi = pois.pearson_chi2 / pois.df_resid셀 11과 같은 계산으로 φ를 직접 구해 둡니다.
  3. np.allclose(pois_q.params, pois.params)두 모형의 계수가 계산 오차 범위에서 모두 같으면 True를 돌려줍니다.
  4. pois.bse[t] * np.sqrt(phi)모형 기반 표준오차에 √φ를 곱해, 준포아송의 표준오차와 같은지 봅니다.

  3. 3준포아송 SE 0.3085. 모형 기반 SE에 √φ를 곱한 값과 같습니다.

두 방법은 표준오차를 키우는 방식이 다릅니다. 준포아송은 모든 환자의 분산을 같은 배수로 키우고, 강건 표준오차는 배수를 정하지 않고 실제 잔차에서 바로 구합니다. 이 자료에서는 결과가 거의 같습니다. 오프셋의 단위를 바꾸거나 오프셋을 빼면 무엇이 달라지는지는 과제 2에서 직접 돌려 봅니다.

statsmodels의 smf.glm에도 음이항 분포(sm.families.NegativeBinomial)가 있습니다. 다만 GLM은 α를 추정하지 않고 사용자가 준 값으로 고정합니다. 앞에서 추정한 α를 넣으면 계수가 같아지는지 확인합니다.

  2. pd.concat({...}, axis=1)두 결과의 계수(Series)를 열 방향으로 붙여 비교표를 만듭니다. GLM에는 alpha 행이 없어 NaN(값 없음)으로 표시됩니다.

계수는 소수 넷째 자리까지 거의 같습니다. 표준오차는 GLM이 α를 알려진 값으로 취급하는 등 계산 방식이 달라 셋째 자리에서 조금 다릅니다(치료군 GLM 0.309, 셀 15의 0.306). α를 주지 않으면 어떻게 되는지 보겠습니다.

이런 오류가 나면

Using default value alpha=1.0.은 오류가 아니라 경고라서 분석은 그대로 진행됩니다. 그러나 α가 자료와 관계없이 1.0으로 고정되므로 표준오차와 신뢰구간이 틀릴 수 있습니다. 이 자료에서 α = 1로 적합하면 치료군 계수는 −1.009로 비슷하지만, α가 실제와 많이 다른 자료에서는 결과가 달라집니다. 음이항 회귀는 α를 추정하는 smf.negativebinomial을 쓰거나, GLM이라면 추정한 α를 직접 넣습니다. 이 경고는 statsmodels 버전에 따라 나오지 않을 수도 있으므로, 경고가 없다고 안심하지 말고 alpha=를 적었는지 확인하세요.

정리

  • smf.negativebinomial(form, data, offset=np.log(인년)).fit()은 계수와 과산포 모수 α를 함께 추정하는 NB2 모형입니다. α 줄의 P 대신 경계 보정한 우도비 검정과 AIC로 포아송과 비교합니다.
  • 과산포가 있으면 준포아송, 강건 표준오차, 음이항 회귀의 신뢰구간이 비슷하게 넓어지고, 모형 기반 포아송 구간만 좁습니다.
  • 0건 환자 수를 음이항 모형이 맞춘다면 영과잉 모형은 필요하지 않습니다.
  • 절대적인 크기는 모두 같은 군에 놓고 예측한 1인년당 기대 건수를 평균해(표준화) 그 차로 구합니다. 예측할 때 오프셋은 0(= ln 1인년)으로 줍니다.
  • GLM의 NegativeBinomial은 α를 추정하지 않으므로 alpha=를 직접 줍니다. 빠뜨리면 α = 1로 고정됩니다.

정답 코드와 풀이

오프셋을 빼려면 offset= 인자를 적지 않으면 됩니다. pd.DataFrame({…})은 세 모형의 계수(로그 척도)를 열로 나란히 놓습니다. coefs.loc[t]는 치료군 행이고, np.exp로 발생률비가 됩니다. 마지막 줄은 배정군별 평균 추적 일수입니다.
