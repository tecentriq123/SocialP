## 이번 확대에서 정한 것
1. **문장은 다시 쓰지 않는다.** 1–8장은 10월 11일 흐름 다듬기를 마친 글이다. 할 일은 구조와 위치(보이는 본문에 무엇을 남기고 무엇을 접거나 지울지)를 정하는 것이다. 옮기거나 줄이면서 끊긴 연결만 잇는다.
2. **실습으로는 옮기지 않는다.** 짝 실습은 다음 단계에서 따로 정비한다. 이번에는 본문에서 뺀 '어떻게'를 같은 장의 '더 알아보기'(또는 단계 안의 `<!--FOLD:제목-->`)로 옮긴다. 실습 링크는 그 내용이 실습에 **지금 실제로 있을 때만** 건다(`content/labNN.html`에서 확인).
3. **결과 한 행 먼저**는 1–8장에서 선택이다. 절의 첫 단계에 논문 결과 한 줄(예: "difference … (95% CI …), P = …")이 자연스러운 절에만 쓰고, 쓸 때는 비교 대상·결과·방향 세 가지를 짚는다.
4. **스스로 확인하기는 절마다 네 문제 이하.** 장 전체에서 세 역할(새 결과 해석, 잘못된 해석 찾기, 내 연구에 쓰기)이 한 번씩은 있게 한다. 덜어 낸 문제는 지운 것 목록에 적는다. 유명한 실수만 묻는 문제는 남기지 않는다(아래 예외 참고).
5. **지운 것 목록은 각자 작업 공간에.** `notes/deletions.md`는 여러 사람이 동시에 고치면 충돌하므로 건드리지 않는다. 같은 형식으로 `<작업 공간>/deletions_chNN.md`에 쓰면 주 작업자가 합친다.
6. **다른 파일은 고치지 않는다.** 단계·접힘 제목을 바꾸면 그 제목을 가리키는 다른 파일(`grep -rn "<옛 제목>" content/ realpapers/ gen/`)을 보고만 한다. 주 작업자가 한꺼번에 고친다. 같은 시간에 다른 장도 고쳐지고 있으므로, 다른 장의 내용에 기대어 문장을 쓰지 않는다.

## 유명한 실수의 집 (TWOLEVEL_BRIEF 9-1)
아래 실수는 표의 '집'에서만 짧게 다루고, 다른 장과 같은 장의 다른 단계에서는 되풀이하지 않는다(꼭 필요하면 반 문장과 링크).

| 실수 | 집 | 비고 |
|---|---|---|
| p값 = 귀무가설이 참일 확률, 유의하지 않음 = 효과가 같음, 95% 신뢰구간을 '참값이 들어 있을 확률 95%'로 읽기 | 0장 바 절 | 1장 나 절 '스스로 확인하기'의 "P = 0.32이므로 같다" 문제는 **남긴다**(여러 장과 실습이 '1장 나 절'로 가리킴) |
| p값이 작을수록 효과가 크다, 0.049와 0.051을 정반대로 읽기 | 1장 나 절 | |
| 여러 번 검정하면 우연히 유의한 결과가 나온다 | 1장 다 절 | |
| 오즈비를 '위험이 몇 배'로 읽기 | 5장 가 절(처음, 짧게: 사건이 드물 때만 비슷), 8장 나 절(이유와 크기) | 그 밖의 장에서는 되풀이하지 않음 |
| 상관이면 인과 | 6장 | |
| 위험비(HR)를 위험의 비로 읽기 | HR을 처음 가르치는 절 | 그 절을 찾아 한 곳에서 |
| 평균 ± SD와 평균 ± SE 혼동 | 0장 | |

집인 장에서도 설교하듯 길게 쓰지 않는다. 같은 오해가 그 장 안에서 오해 상자, 결과 읽기, 논문 상자 해설, 자주 하는 실수, 정리, 연습문제에 겹겹이 있으면 한 곳만 남긴다. 비운 자리에는 덜 알려졌지만 그 장에서 실제로 틀리기 쉬운 것을 둔다.
