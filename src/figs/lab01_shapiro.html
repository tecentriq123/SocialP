셀 14Shapiro-Wilk 검정
for col in ["mean radius", "area error"]:
    x = benign[col]
    w, p = stats.shapiro(x)       # 검정통계량 W와 p-value
    print(f"{col}: n = {len(x)}, skewness = {stats.skew(x):.2f}, "
          f"W = {w:.3f}, p = {p:.3g}")
출력
mean radius: n = 357, skewness = -0.08, W = 0.9971, p = 0.6682
area error: n = 357, skewness = 1.64, W = 0.8963, p = 6.76e-154
