# 과목 역할 나누기 (2026-11-18, 사이트 주인 결정)

이 문서는 보건통계학 기초(1과목)와 R 과목(3과목)의 역할을 다시 나누는 규칙이다. 이전 브리프와 STYLE.md의 규칙과 부딪히면 이 문서를 따른다.

## 1. 세 과목의 역할

| 과목 | 읽은 사람이 알게 되는 것 |
|---|---|
| 보건통계학 기초 (1과목) | 논문이 무슨 이야기를 하는지 읽고, 내 연구를 어떻게 설계하고, Methods·Results에 무엇을 써야 하는지 |
| R과 파이썬 과목 (3과목, 이름은 주인 확인 뒤 확정) | 코드를 어떻게 짜고, 자료를 어떻게 넣고, 출력의 어디를 어떻게 해석하는지 |
| 보건통계학 퀴즈 | 지금과 같음. 1과목에서 3과목으로 옮긴 내용에 걸린 링크는 3과목으로 바꿔 단다 |

3과목은 R이 본문이고 파이썬은 단계마다 접힌 상자로 둔다. SAS는 청구자료 관련 내용에만, 필요할 때 그때그때 더한다.

## 2. 나누는 선: '결정'은 1과목, '실행'은 3과목

| 1과목에 남길 것 | 3과목으로 보낼 것 | 1과목에서 줄일 것 |
|---|---|---|
| 무엇을 왜 정하나 (공변량, 추적 시작일, 시차, 1차 분석, 모형 고르기) | 코드, 함수와 옵션, 프로그램의 기본값과 프로그램마다 다른 점 | 프로그램이 바로 내주는 값을 손으로 구하는 과정 |
| 논문의 표·그림·문장을 읽는 법 | 출력 화면에서 어디를 읽나 | 판단에 쓰이지 않는 유도와 분포 이론 |
| 계획서와 Methods·Results에 쓸 내용 | 자료를 분석할 모양으로 만드는 작업 (청구자료에서 코호트 만들기 등) | |

'직접 분석할 때' 접힌 상자도 이 선으로 가른다. 설계 결정을 다루는 상자('추적 상한과 유도기간은 언제 두나?')는 1과목에 남기고, 프로그램 사용을 다루는 상자('Gray 검정은 파이썬에서 어떻게 구하나?')는 3과목으로 보낸다.

## 3. 계산과 원론의 기준 (주인의 예: 메타분석 이질성)

연구자는 추출한 자료를 R에 넣으면 Q, I², τ²를 바로 얻는다. 중요한 것은 그 값을 해석하는 법이지 직접 계산하는 법이 아니다.

1과목에 남길 것:
1. 값의 뜻을 보여 주는 간단한 식 하나와 말로 한 설명.
2. 값이 이렇게 나오면 이런 뜻, 저렇게 나오면 저런 뜻.
3. 그 값만으로는 확신할 수 없는 이유 (예: I²는 연구의 크기에 따라 달라진다).
4. 이런 경우에는 이 방법, 저런 경우에는 저 방법. 주인의 예: 고정효과 모형과 무작위효과 모형을 어떤 상황에서 어떻게 고르는지, 둘 다 써야 하는 때는 언제인지. 이런 판단은 여러 절과 접힌 상자에 흩어 두지 말고, 개념 설명 바로 뒤의 소제목 하나('…은 언제 무엇을 쓰나?')에 상황 → 고르는 것 → 이유의 표로 모은다. 하지 말아야 할 선택(예: 이질성 검정의 P로 모형 고르기)도 같은 자리에 둔다.

줄일 것: 손계산의 단계, 추정 방법의 계산 원리, 모의실험의 세부. 판단에 쓰이지 않으면 지우고, 궁금한 독자에게 꼭 필요하면 '심화' 접힌 상자 하나로 모은다.

t 검정, 카이제곱 검정처럼 검정을 고르고 이해하는 데 필요한 원리는 원론이어도 남긴다. 교재 원문의 요점(어떤 검정을 언제 쓰고 무엇을 비교하나)도 남긴다.

## 4. 파이썬 실습 옮기기

- 1과목 PART 5의 파이썬 실습 25개(lab00–lab24)는 모두 3과목으로 옮긴다. 3과목은 주제별 장으로 짜고, 각 장은 R 본문과 단계마다 파이썬 접힌 상자로 쓴다.
- 짝이 되는 R 장이 이미 있는 실습: lab00↔rc00, lab01·02·03·05·06·09↔rc01, lab07↔rc02, lab11↔rc03, lab23↔rc04·rc07, lab20·22↔rc07·rc08, lab24↔rc09.
- 짝이 되는 R 장이 없는 실습: lab04(분산분석), lab08(신뢰구간·효과크기·교란), lab10(반복측정), lab12(포아송·음이항), lab13(동등성·비열등성), lab14(청구자료 코호트), lab15(성향점수), lab16(불멸시간·시간의존 Cox), lab17(경쟁위험), lab18(중단시계열·이중차분), lab19(메타분석), lab21(비용 자료). 이 주제의 R 장을 쓸 때 실습을 함께 옮긴다. 그 전까지 실습은 지금 자리에 둔다. 파이썬만 접혀 있는 빈 장을 만들지 않는다.
- 옛 주소(stats.html#lab05 등)로 들어오면 새 위치로 이어지게 한다. 1과목 본문에서 실습으로 가는 링크(약 190개)는 3과목의 해당 장으로 바꾼다.

## 5. 다시 쓰는 방식: 목록에서 다시 쓰기

절마다 먼저 '그대로 가져갈 것' 목록을 만든다.
- 교재 원문의 요점
- 예제 자료와 숫자 (3과목·퀴즈와 맞아야 함. gen/ 스크립트로 다시 확인)
- 인용 문헌과 지금까지 바로잡은 사실 (notes/deletions.md)
- 다른 곳이 링크하는 소제목 id (글자를 바꿔도 id는 그대로. 따옴표로 옮겨 적은 글자는 도구로 맞춘다)

그다음 문장, 문단 순서, 소제목 나누기, 상자의 수와 위치는 새로 쓴다. 소제목 하나에 질문 하나, 첫 문장이 답. 소제목 없이 이어지는 구간은 2,000자 안팎을 넘기지 않는다. '잠깐 확인'은 절에 한두 개.

주인의 첫 피드백(19장 c 절 시범, 2026-11-18)에서 정한 것:
- **상위 주제와 하위 소제목을 맞춘다.** 번호 붙은 소제목(h3)이 묻는 것에 그 아래 소제목(h4)이 모두 답해야 한다. 어떤 결정의 세부 방법은 그 결정을 처음 소개한 자리 바로 아래에 둔다. 예: τ² 추정 방법과 평균의 신뢰구간 방법은 b 절 '무작위효과 모형에서는 무엇을 더 정하나?'(②, ③) 아래로, 하위군 분석과 메타회귀는 c 절 '이질성이 크면 어떻게 하나?'의 '차이의 원인은 어떻게 찾나?' 아래로 옮겼다.
- **메인표는 그 절에 다시 싣는다.** '표 고정' 단추가 있어도, 절 전체가 기대는 표(예: 열 시험의 결과)는 절 첫머리에 한 번 더 옮겨 싣고, 뒤에서는 그 표를 가리키는 표 링크(span.tref)와 소제목 단추(div.pin-bar.ref)를 둔다.
- **번호 소제목은 주제 이름으로 쓴다(19장 전체에 적용, 2026-11-18).** '2. 예제 메타분석에서 따라가기'처럼 여러 주제를 담는 일반 이름 대신, 절이 답하는 질문마다 번호 소제목을 하나씩 두고('2. 두 모형은 무엇을 가정하나?', '3. 시험 하나에서 무엇을 가져오나?' …) 그 아래에 그 질문의 세부만 둔다. 함정 목록 앞에 있던 방법 비교표는 그 방법을 다루는 번호 소제목 아래로 옮긴다. 순서는 1 막으려는 문제 → 주제 소제목들 → 흔한 함정 → 논문에서 읽기 → 논문에 쓰기 → (있으면) 내 연구에서 분석하기.
- **표 링크를 지우지 않는다.** 다시 쓸 때 원래 있던 표 링크(span.tref[data-t])를 목록에 넣고, 새 글에서도 같은 표를 가리키는 자리에 되살린다.

## 6. 순서

1. 시범 한 쌍: 1과목의 한 절을 이 규칙으로 다시 쓰고, 옮긴 실행 내용을 3과목의 짝 장에 넣는다(R 본문, 파이썬 접힌 상자).
2. 같은 기준으로 다시 재고 주인이 읽어 본 뒤 규칙을 고친다.
3. 부(파트) 단위로 넓힌다. 3과목의 받을 자리를 먼저 만들고 1과목에서 옮긴다.
4. 절마다 숫자 스크립트, 링크 점검, 퀴즈 점검을 다시 돌리고 notes/deletions.md에 남긴다.

## 7. PART 1 진행 결정 (주인 인터뷰, 2026-11-18)

- 19장에서 정한 방식(주제 이름의 번호 소제목, 메인표 다시 싣기, 표 링크 보존, 계산 줄의 숫자 이름)을 PART 1(0–7장, 분석 고르기 연습)에 적용한다.
- **코드**: R 장이 있는 주제(R 0장 R 시작하기, R 1장 Table 1·두 군 비교·비율·회귀, R 2장 Kaplan-Meier)는 그리로 옮긴다. R 장이 없는 주제(대응표본, 분산분석, 상관 등)는 R 장을 새로 써서 옮긴다(R 10장처럼 실제로 돌리고, 파이썬은 실습에서 접힌 상자로). 1과목에는 설계 결정을 다루는 '직접 분석' 상자만 남긴다.
- **계산**: 검정이 무엇을 비교하는지 보여 주는 계산(t, 카이제곱, 상관계수 등)은 펼쳐 두고 숫자에 이름을 붙인다. Welch 자유도 식, 동점 보정, 정확 분포 같은 세부는 '심화' 상자 하나로 줄인다.
- **'R에서' 칸**: 절 첫머리 한눈에 보기 표의 'R에서' 칸은 그대로 둔다.
- **올리는 단위**: 두세 장씩 묶어서 올린다(0–2장, 3–5장, 6–7장과 분석 고르기 연습).
- 0–2장 결과(2026-11-18): 코드는 새 R 11장 '요약통계, 분포, 검정의 기본'(rc11)으로. 1과목에 남기는 프로그램 이야기는 '프로그램마다 기본값이 다르다'는 한두 문장까지(예: R의 t.test는 Welch, scipy는 Student). 함수 이름과 인자, 출력 읽기는 3과목. 일반 소제목 '숫자로 따라가기', '헷갈리는 점', '가정과 대안', '결과 읽기'는 그 절이 답하는 질문으로 바꾼다.
- 3–5장 결과(2026-11-18): 코드는 새 R 3장 '짝지은 자료, 세 군 이상, 비율의 비교'(rc12)로. R 장 번호가 다시 밀림(생존 4–5장, 메타분석 6장 …). SPSS 출력 읽기도 3과목(R 3장 f·h 절)으로 옮기고, 1과목에는 'SPSS는 두 줄을 함께 낸다' 같은 논문 읽기 수준의 문장만 남긴다.
- 6–7장·분석 고르기 연습 결과(2026-11-18): 6장 코드는 새 R 4장 '상관과 회귀'(rc13)로, 7장 코드는 기존 R 5장(생존 자료와 Kaplan-Meier)에 e 절을 더해 옮김(생존 R 장을 새로 만들지 않음). 분석 고르기 연습의 검산 코드는 R 1장 c 절로. R 장은 0–13장이 됨(생존 5–6장, 메타분석 7장, 외삽 8장 …). 출력 읽기를 옮긴 자리의 핵심 숫자(예: 그림 7-6의 χ² 계산)는 1과목에 계산 줄로 남긴다.
- PART 2 첫 묶음 결과(2026-11-18): 8·9·12장 코드는 새 R 5장 '로지스틱 회귀와 포아송 회귀'(rc14)로. 8장의 효과 지표·GLM·우도·층화·가변수와 9장 로지스틱 회귀, 12장 발생률·포아송·음이항을 한 장 10절에 모음. R 장은 0–14장(생존 6–7장, 메타분석 8장, 외삽 9장 …). R과 파이썬의 실패 모습이 다른 곳(로그-이항, 분리, 0건 군)은 1과목에 두 프로그램의 결과를 나란히 한 문장으로 남김.
- PART 2 둘째 묶음 결과(2026-11-18): 10장 코드는 새 R 6장 '반복측정 자료: 혼합모형과 GEE'(rc15)로, 11장 코드는 R 8장(Cox) e 절 '보건통계학 기초 11장의 예'로. R 장은 0–15장(생존 7–8장, 메타분석 9장, 외삽 10장 …). 11장의 비례위험 검정 P는 R의 점수 검정 값으로 통일하고, lifelines의 근사 값과의 차이는 1과목 상자에 표로 남김.
