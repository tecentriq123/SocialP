# 학습 경로·탐색 문구 검토 (목차·홈·'처음 읽을 때' 상자 26개)

## 한눈에
- '읽는 순서'는 목차 페이지 **맨 아래**에 있고 내용도 낡았다("0–7장 순서대로, 8장부터는 찾아 읽어도"). PART 3·4의 들어가는 길이 없다. 목차 위로 올리고 첫 독해 경로 + 주제별 경로로 바꾼다.
- 상자의 '미리 알아 둘 것'이 실제 필요보다 많아 0→25 직선 과정처럼 보인다(20장 → 19마·13가, 14장 → 11·12장 등). 8개 장에서 줄일 수 있다.
- 목표 104개 중 독해 84 / 직접 분석 16 / 심화 4(빠른 분류). 표시가 없어 전부 필수로 읽힌다. '이 장을 마치면'을 두 줄로 나누고, 독해 밖 문제(약 40개)에만 꼬리표를 붙인다.
- 외부 의견의 기본 경로는 7장을 빼서 8장 나 절·종합 연습·23장과 맞지 않고, 17·18·19·12장이 어느 경로에도 없다.
- 홈 카드 설명이 "비열등성 검정까지"(13장)에서 끝난다.

### 1-2. 학습목표
- 독해 84 / 직접 분석 16 / 심화 4. 직접 분석: 2② 4③ 5① 8③ 9④ 10①③ 11④ 15① 16④ 17④ 19④ 21④ 23② 24②④. 심화: 2④ 3④ 6④ 20④.
- 논문 문구를 따옴표로 인용한 목표(약 절반)는 독해용임이 드러나지만, 나머지는 구분할 단서가 없다. 한 문장에 독해와 분석이 섞인 목표가 약 10개(8③ 10①③ 11④ 17④ 19④ 22③ 23①② 24②)라서 표시만 붙여서는 안 되고 문장을 나눠야 한다.
- 6장은 "같은 8명 자료의 r = 0.84와 기울기 0.547"처럼 예제 숫자로 써서 읽기 전에는 뜻을 알 수 없다. 7장 ①의 세척 기간·유예기간은 '나중에 읽을' 접힌 부분에서 설명된다(확인 필요: 논문 상자 풀이만으로 충분한지).

### 1-3. 문구와 분량
- 평균 864자(0장 418자 – 10장 1,194자). 본문 전에 낯선 소제목 10–17개를 읽게 된다.
- '먼저 읽을 부분'은 대부분 보이는 것 전부다. 9장은 보이는 소제목 15개 중 14개, 20·24·25장은 "표 20-1부터 20-11까지"처럼 전부를 적었다. 1장 상자의 "펼쳐져 있는 본문만 순서대로 읽으면 됩니다" 한 문장과 같은 정보다. → 공통 한 문장으로 줄이고, 예외(읽는 순서가 다른 4장, 요약만 읽어도 되는 절)만 남긴다.
- '나중에 읽을 부분'은 이미 접힌 것의 목록이다(평균 218자). "접힌 부분은 모두 나중에" + 직접 분석할 때 펼 것 1–2개로 줄인다.
- 형식 불일치: ①–④ 번호 없음(0·1·6·7장), 마침표 유무, 3장만 "~한다"체, 첫 문구 네 가지("접힌 '심화' 상자 전부" / "'심화' 표시가 붙은 소제목과 접힌 상자" / "접혀 있는 …" / "… 접힌 부분."). '내 연구에 쓸 때'가 1–4·13장 일부에서는 접힌 심화, 8·12–25장에서는 '먼저 읽을 부분'이다.

## 3. 넣을 자리와 문안
### (a) 목차 페이지
현재 소개 문단은 PART 4·5까지 반영되어 틀린 곳이 없다. 다만 장 목록을 되풀이하는 긴 한 문단이다. '읽는 순서'는 PART 5·부록까지 지난 페이지 끝에 있다. 지금 문구: "처음이라면 0장부터 7장까지 순서대로 읽되 … 8장부터는 논문에서 만난 기법을 찾아 읽어도 됩니다." → 4장까지 다 읽게 하고, 9·11·12장이 8장에, 15–17장이 14·11장에, 21–25장이 20장에 기대는 것을 알리지 않으며, PART 3·4와 실습 시점이 없다.

제안: 소개 문단 바로 아래(목차 위)로 옮긴다. 하단 3칸 중 '예시 자료'는 홈과 글자까지 같으므로 목차에서는 빼도 된다.

> **읽는 순서**  순서대로 다 읽을 필요는 없습니다. 먼저 아래 경로를 읽고, 그다음은 연구 주제에 맞는 장으로 갑니다.
> **처음 읽을 때** 0장 → 1장 가·나·다·사 → 2장 가 → 3장 가 → 5장 가 → 6장 가·다·라 → 7장 가·나 → 분석 고르기 연습 → 8장 가·나·다·바·아 → 9장
> **그다음** 청구자료 연구 14 → 11 → 15 → 16 · 반복측정 10 · 비열등성 13 · 정책 평가 18 · 메타분석 19 · 경제성 평가 20 → 25
> 접힌 부분과 '직접 분석'·'심화' 표시가 붙은 문제는 건너뛰어도 다음 장을 읽을 수 있습니다. 실습(PART 5)은 직접 분석할 때 짝이 되는 장과 함께 합니다.

소개 문단 대안: "논문을 읽는 데 필요한 통계(PART 1–2), 청구자료 연구의 설계와 편향(PART 3), 약물경제성 평가(PART 4), 파이썬 실습(PART 5)으로 이루어져 있습니다."

### (b) 다섯 줄 지도
종합 연습 가 절의 '여덟 가지 질문'이 이미 분석 선택용 지도다. 빠진 것은 연구설계와 효과지표이므로 새 절을 쓰지 말고 **목차 페이지 옆 카드 위쪽**에 다섯 줄을 두고, 0장 첫 문단과 종합 연습 가 절에서 한 문장으로 연결한다. 0장 본문에 넣지 않는 이유: 0장은 자료표와 SD·SE를 다루는 짧은 장이고, 지도에 나오는 코호트·위험비는 뒤에서 배우므로 본문이 아니라 길잡이 자리에 두어야 한다.

> **논문에서 먼저 찾을 다섯 가지** (예: SGLT2 억제제와 심부전 입원)
> 1. 연구질문 — SGLT2 억제제를 시작한 환자는 DPP-4 억제제를 시작한 환자보다 심부전 입원이 적은가
> 2. 연구설계 — 청구자료 코호트. 무작위배정이 아니므로 두 군이 처음부터 다르다 (8장 바, 14장)
> 3. 결과변수 — 심부전 입원까지의 시간. 추적 기간이 사람마다 다르다 (1장 가, 7장 가)
> 4. 효과지표 — 위험비와 95% 신뢰구간, 1,000인년당 발생률 (0장 바, 8장 나)
> 5. 분석 — 성향점수로 두 군을 맞춘 뒤 Cox 모형 (아래 표, 11·15장)

### (c) 옆 카드 '어떤 검정을 쓸까'
13–17번째 줄이 이미 검정이 아니라 설계·방법이다(성향점수, 중단시계열, 메타분석). 두 줄만 더한다: "비용 비교(치우친 금액) | 평균 차이와 부트스트랩, 감마 GLM | 21", "비용과 효과를 함께 | ICER, 결정분석 모형 | 20·23". 22·24·25장은 고르는 대상이 아니므로 넣지 않는다. 제목은 '어떤 분석을 쓸까'가 맞지만 종합 연습 가 절이 이 이름을 인용하므로(1곳) 함께 고친다. 선택: "같은 사람의 전후 이분형 | McNemar | 부록 A"(5장 목표 ④가 가리키는 곳).

## 4. 수준 표시 방식
권고: **표시 없음 = 독해, 예외에만 꼬리표.** (i)을 채택하고 (ii)는 예외에만, (iii)은 문제 블록마다가 아니라 사이트에서 한 번, (iv)는 접지 않는 새 꼬리표 하나.
1. 상자: '이 장을 마치면'에는 독해 목표만 두고, 새 줄 '직접 분석할 때'에 직접 분석·심화 목표를 옮긴다. 해당 목표가 없으면 줄을 만들지 않는다.
2. 문제: 유형 꼬리표(`qt`)는 그대로. 독해 밖 문제에만 `<span class="lv do">직접 분석</span>` 또는 기존 `<span class="lv deep">심화</span>`를 뒤에 붙이고 블록 안에서 맨 뒤로 보낸다. 330문제 전부에 둘째 꼬리표를 달면 번잡하고, '계산'에는 독해(2×2 표의 OR)와 심화(EVPI)가 섞여 있어 유형으로는 수준을 대신할 수 없다.
3. 안내 문장은 목차 '읽는 순서'와 홈 '읽는 방법'에 한 번. 블록마다 "앞의 n문제까지"를 쓰면 104곳을 문제 수가 바뀔 때마다 고쳐야 한다.
4. 본문은 새로 접지 않는다. '내 연구에 쓸 때'와 파이썬 출력 상자가 이미 직접 분석용이므로 상자에서 '먼저 읽을 부분'이 아니라 '직접 분석할 때' 줄에 적는다. `lv do`는 build.py의 접기 조건(`DEEP_TAG`)에 걸리지 않아 보이는 채로 남는다. CSS 한 줄(`.lv.do`)만 필요하다.

- 전: `이 장을 마치면` ① 결정수형 … ② 율과 확률을 구분해 … 전이확률 행렬로 코호트 추적을 만들어 비용과 QALY를 더할 수 있다 ③ … ④ …

## 확인하지 못한 것
- 목표·문제의 수준 분류는 문구만 보고 한 빠른 분류다.
