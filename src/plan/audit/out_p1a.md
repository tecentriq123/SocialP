# 0–3장 검토

## 한눈에
1. 1장 '처음 읽을 때'의 '먼저 읽을 부분'이 여덟 절의 보이는 글 전부(약 4만 2천 자, 0장의 2.8배)다. 절별 우선순위(최소 경로)를 상자에 적는다.
2. 2장 목표 ④(우월 확률·Hodges–Lehmann)와 3장 목표 ④(W+, 정확 p)는 독해 수준을 넘는다. 목표를 독해/선택으로 나누고, 손계산 문제(2장 나-1, 3장 나-1, 3장 가-1, 1장 나-3)에 수준 표시를 붙인다.
3. 3장 가 절 '흔한 오해 · 대응 자료를 다룰 때' 상자가 심화 접힘 안에 들어 있다(실제 빌드 확인). '먼저 읽을 부분' 안내와 어긋나므로 접힘 밖으로 꺼낸다.
4. "연구질문 → 연구설계 → 결과변수 → 효과지표 → 분석" 지도는 0장에 없다. 혈압 시험으로 채운 5줄을 0장 '처음 읽을 때' 상자 바로 아래에 둔다.
5. 0장 마 절이 Student·Welch·등분산을 정의(2장 가 절) 전에 쓴다. 1장 가 절은 '코호트 연구'와 접힌 식의 '합동표준편차 sp'를 설명 없이 쓴다.

계산 검증: 네 장의 예제 수치(t·p·CI, 검정력 60/44/88%, SMD, FWER, Mann-Whitney U·정확 p·HL −18.5(−40~−3), 대응 t, 부호순위 정확 p 0.0098·0.015, 평균으로의 회귀 8.3%·166.6·0.69, 치우친 비용의 포함률 89/92/95%)를 다시 계산했고 틀린 값은 없었다.

### 학습목표·확인 문제
- 목표 4개: 독해 4(②는 SE = SD ÷ √n 수준의 간단한 계산, ③ '1.96과 2.00의 출처'는 기초 개념).
- 문제 14개: 독해 13(간단한 계산 4 포함: 가-2, 다-1, 마-1, 바-1), 직접 분석 요소 1(라-1의 scipy 한 줄). 접힌 내용이 있어야 풀 수 있는 문제 없음.

### 처음 읽을 때 상자
'미리 알아 둘 것'은 최소한이다. '먼저 읽을 부분'(가–바 전체, 약 1만 5천 자)은 현실적이다. "코드 셀은 건너뛰어도 된다"와 라-1 문제(scipy 한 줄)가 어긋난다.

### 유지할 것
- 혈압 시험 하나로 SE → CI → p를 잇고 같은 숫자를 1장으로 넘기는 구성.
- 고등학교 표기와 논문 표기 대응표.
- 바 절 흔한 오해 3개와 "유의하지 않다 ≠ 차이가 없다"의 숫자 예(차이 2.0, CI −1.8~5.8).

### 학습목표·확인 문제
- 목표 4개: 독해 4(④는 후순위).
- 문제 25개: 독해 23, 직접 분석 1, 심화 1.
  - 심화: 나 절 3번(군당 60명 검정력). "접힌 '계산 과정 보기' 상자에 있는 세 줄 계산을 따라가세요" → 접힌 내용이 있어야 풀 수 있음. '심화(선택)' 표시.
  - 직접 분석: 라 절 3번(회귀 잔차 자유도 190에서 분석 인원 역산). 회귀는 6장이고 "접힌 '검정별 자유도' 표 참고". 괄호 설명으로 풀 수는 있음. '6장 뒤에' 표시.
  - 독해에 포함한 간단한 계산: 가-2(SMD), 다-1(FWER), 마-1·2·3, 바-1, 사-1(6명 순위합), 아-3(e^−0.105).
  - 다 절 2번의 HR은 정의 전(11장)이지만 풀 수 있음. "HR은 1보다 작으면 위험이 낮다는 뜻(11장)" 한 구절이면 충분.

### 처음 읽을 때 상자
