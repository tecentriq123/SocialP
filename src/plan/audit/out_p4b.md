# 23–25장 검토 (결정분석 모형 · 불확실성 분석 · 경제성 평가 논문 읽기)

## 한눈에
1. 23장 목표 ②, 24장 목표 ②·④가 구현 수준입니다. 두 장의 문제 21개 중 7개가 독해를 넘습니다(율–확률 변환, 전이행렬 산수, AIC·BIC 손계산, 임계 가격, 적률법, EVPI, 긴 손계산). 지우지 말고 '직접 분석' 꼬리표만 붙입니다. 코드를 요구하는 문제는 없습니다.
2. 잘림은 5,000벌 중 1,122벌(22.4%)로 재확인했습니다. 주석은 보이지만 결과표·그림·수용곡선 옆이 아닙니다. 새로 확인: 일원 민감도 분석의 γ 행에서도 잘림이 일어납니다.
3. 예제를 어떻게 고쳐도 비용효과적일 확률은 5,000만원에서 13–18%, 6,000만원에서 59–69%로 결론이 같습니다. 이번에는 주석을 결과 옆 네 곳에 달고 예제 수정은 따로 하기를 권합니다.
4. 베타분포: "0과 1 사이"는 표에 있으나 22장의 음수 효용과 이어지지 않습니다. 한 문장 추가.
5. 23장 '먼저 읽을 부분'이 보이는 글 거의 전부(약 3.8만 자)입니다. 독해 경로를 좁히고 모형 점검 내용을 다 절에 6줄 표로 모읍니다.

넣을 곳: 표 24-4 아래 '정규분포를 그대로 쓰지 않는 이유' 앞. "베타분포는 효용이 0과 1 사이에 있을 때의 선택입니다. 22장 가 절에서 본 것처럼 사망보다 나쁜 상태의 효용은 0보다 작을 수 있고, 그런 값이 나올 수 있으면 '1 − 효용'(완전한 건강에서 깎인 크기)에 감마분포나 로그정규분포를 줍니다." 정리의 "효용과 확률에는 베타"는 "0과 1 사이의 효용과 확률에는 베타"로.
근거: NICE DSU 기술지원문서 12(Ara, Wailoo, 2011) 4.1절이 "1 minus the HSUV"를 로그정규나 감마분포에서 뽑는 방법을 적습니다(요약 도구로 인용문 확인). Briggs, Claxton, Sculpher(2006)는 본문을 열지 못해 확인하지 못했고, ISPOR-SMDM 보고서(Briggs 2012)는 효용의 분포를 따로 다루지 않습니다. TSD 12를 새 문헌으로 추가해 인용합니다.
