# PART 5 B 실습(연구 유형별 실습) 작성 지침 (2026-10-04)

기본 규칙은 `LAB_BRIEF.md` 그대로다(먼저 그것을 처음부터 끝까지 읽는다: 실제 코드를 `gen/labkit.py`로 실제로 돌려 출력과 그림을 만들고, 손으로 출력을 적지 않는다. 셀, 코드 한 줄씩, 출력 읽기, 논문에는 이렇게 씁니다, 정리의 구성). `STYLE.md`, 짝이 되는 이론 장(`content/chNN.html`)과 그 숫자를 만든 `gen/nums_chNN.py`, 본보기로 `content/lab11.html`과 `gen/lab_lab11.py`를 읽는다. 이 파일은 B 실습에만 적용되는 추가·변경 사항이다.

## 독자와 목적
독자는 사회약학 연구실 신입 대학원생(약사, 파이썬 초보, Windows 11, Google Colab 사용). 실습 0–13(A 묶음)을 이미 했다고 가정한다. B 실습은 "논문에서 본 분석을 내 손으로 한 번 돌려 본다"가 목적이다. 이론 장을 다시 설명하지 않고(링크로 넘긴다), 자료를 만들고 분석을 돌리고 출력을 읽어 Methods·Results 문장으로 옮기는 과정을 보여 준다.

## 주인이 정한 것
1. **본문과 같은 예시.** 실습은 짝이 되는 장의 예제 자료(가상)를 그대로 쓴다. 실습 결과가 본문의 숫자와 같아야 한다.
2. **한국 청구자료 구조의 가상 자료.** 약물역학 실습의 원자료는 국내 청구자료를 닮은 표 구조(자격, 명세서·상병, 처방)로 주고, 변수 이름은 짧은 영문 소문자로 하되 가 절에서 표로 뜻을 설명한다. 실제 환자 자료가 아니라 이 사이트가 만든 가상 자료임을 가 절에서 한 번 분명히 적는다.
3. **새로운 것만 자세히.** '코드 한 줄씩'은 실습 0–13에서 설명한 적 없는 함수·문법에만 단다(먼저 `grep -l "함수이름" content/lab*.html`로 확인). 이미 나온 것은 "실습 11 나 절과 같습니다"처럼 링크 한 문장으로 넘긴다.
4. **노트북 파일.** 실습마다 `.ipynb`를 함께 준다(아래 '노트북').
5. **과제와 접힌 정답.** 마지막 절 '과제'에 과제 세 개(쉬운 것부터)를 두고 정답 코드와 풀이를 접어 둔다(아래 '과제').

## 자료
- 학생 코드는 사이트 주소에서 읽는다: `BASE = "https://socialp-ajou.tecentriq12.workers.dev/data/"`, `pd.read_csv(BASE + "파일이름.csv")`. `gen/labkit.py`가 이 주소를 `pub/data/파일이름.csv`로 바꿔 읽으므로(오프라인) 그 폴더에 파일을 만들어 둔다.
- 자료 파일은 `gen/data_labNN.py`가 만든다(결정적: 고정 seed, 다시 돌리면 같은 파일). 가능하면 `gen/nums_chNN.py`의 생성 코드를 불러 쓰거나 그 스크립트가 이미 저장한 `gen/_chNN_*.csv`를 가공한다. **`gen/nums_chNN.py`, `gen/lib_p4.py`와 이론 장은 고치지 않는다.**
- 파일 이름은 `labNN_` 접두어 없이 내용이 드러나게(프롬프트가 지정한 이름을 쓴다). CSV, UTF-8, 한 파일 3MB 이하, 열 이름은 영문 소문자와 밑줄. 날짜는 `YYYY-MM-DD` 문자열. 범주는 사람이 읽을 수 있는 값(예: `SGLT2i`, `DPP4i`)이나 0/1.
- 가 절에 자료 설명 표(파일, 행의 단위, 행 수, 열 이름과 뜻)를 둔다.

## 본문 숫자와 맞추기
- `gen/lab_labNN.py` 끝에 **대조 블록**을 둔다: 실습에서 얻은 핵심 숫자(표본 수, 효과 추정값과 신뢰구간 등 10개 안팎)를 `gen/_chNN_nums.json`이나 본문에 적힌 값과 `assert abs(a - b) < tol`로 맞춘다. 맞지 않으면 원인을 찾는다(대개 자료 내보내기나 모형 지정의 차이).
- 난수에 기대는 계산(부트스트랩, 매칭의 무작위 순서, 확률적 민감도 분석)은 같은 seed와 같은 순서로 맞추되, 끝자리까지 맞출 수 없으면 본문 값과 실습 값을 함께 적고 "난수 때문에 끝자리가 다를 수 있습니다"라고 쓴다(이 경우 대조 블록의 tol을 넓히고 보고서에 적는다).
- 본문과 다른 결과가 나오는데 본문 쪽이 틀린 것으로 보이면 고치지 말고 보고한다.

## 환경과 호환성
- 쓸 수 있는 패키지: pandas, numpy, scipy, statsmodels, lifelines, scikit-learn, matplotlib(이 환경에 PyPI가 없으므로 다른 패키지는 못 쓴다). Colab은 pandas 2.x, statsmodels 0.14일 수 있으니 양쪽에서 도는 코드를 쓴다(새 버전에만 있는 API 금지, 범주 순서는 명시).
- lifelines를 쓰는 실습은 첫 셀에서 `!pip install lifelines`(실습 7·11과 같은 방식, `shell_output`으로 보여 주기).
- 그림의 축 이름·제목은 영어. 본문에서 우리말로 설명.
- 한 실습은 셀 15–25개, 1–2시간 분량, `content/labNN.html` 40–75KB를 넘지 않게.

## 노트북
`gen/lab_labNN.py` 끝에서 `nb.save_ipynb("실습 NN. 제목", intro="…", skip=(오류 시연 셀 번호들), notes={셀 번호: "## 가. 절 제목\n\n짧은 안내"})`를 부른다(`pub/notebooks/labNN.ipynb`가 만들어진다). intro에는 무엇을 하는 노트북인지 두세 문장과 사이트의 실습 쪽 이름을 적는다. notes로 절이 시작되는 셀 앞에 절 제목을, 과제 정답 셀 앞에 과제 문장을 넣는다. 과제 정답 셀도 노트북에 포함한다(맨 뒤, "과제 정답" 제목 아래).
