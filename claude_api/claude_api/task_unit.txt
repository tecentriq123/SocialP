첨부한 글은 '{TITLE}'입니다. 이번 요청에서 고칠 범위는 '〔검토 단위 {UNIT} 시작〕'부터 '〔검토 단위 {UNIT} 끝〕'까지({UNIT_TITLE}부터)입니다. 장의 나머지 부분은 맥락으로만 읽고, 범위 밖의 문장은 고치지 마세요. 장 전체의 흐름과 버릇은 다른 요청에서 따로 받으므로 아래 두 제목만 써 주세요.

### 3. 문장 수정표
범위 안에서 독자가 실제로 멈추거나 다시 읽게 되는 문장은 개수 제한 없이 모두 적어 주세요. 범위의 앞부분과 끝부분을 같은 꼼꼼함으로 봐 주세요. 글의 순서대로 적습니다. 뜻도 읽기도 그대로인 단순한 어순·낱말 취향은 넣지 않습니다. 같은 버릇을 같은 방식으로 고치는 문장이 5개를 넘으면 대표 3개만 적고, 표 아래에 '같은 버릇 n곳 더: (버릇 이름)'이라고 한 줄 적어 주세요.
| 위치(절·소제목) | 원문 | 문제 | 수정안 | 의미 변경 |
원문은 글에 있는 그대로, 한 글자도 바꾸지 말고 옮겨 주세요(검색해서 찾을 수 있게). 표 칸 안에서는 줄을 바꾸지 마세요. 의미 변경이 없으면 '없음'이라고 씁니다. 원문이 괜찮다면 억지로 고치지 마세요.

### 4. 문단 다시 쓰기
범위 안에서 가장 안 읽히는 문단 1개를 골라 통째로 다시 써 주세요. 문장 단위로는 고쳐지지 않는 리듬과 흐름을 보여 주는 것이 목적입니다. 다시 쓸 만한 문단이 없으면 '없음'이라고만 씁니다.
- 위치
- 원문 첫 문장 (그대로 옮김)
- 다시 쓴 문단
- 무엇을 바꿨나 (2–3줄)
