### 4. 문단 다시 쓰기

- **위치**: b · 1. 언제 쓰나 · 무엇을 묻는 검정인가?

- **원문 첫 문장**: 귀무가설은 "두 군의 값이 같은 분포를 따른다"이고, P는 이 가설이 참이라고 가정해 계산합니다('숫자로 따라가기').

- **다시 쓴 문단**

  먼저 이 검정이 잡아내는 차이부터 봅니다. 두 군에서 한 명씩 뽑아 값을 비교할 때, 한쪽 값이 더 클 확률이 반반(0.5)에서 벗어나면 이 검정은 그 차이를 잡아냅니다. 값이 같은 쌍은 절반씩 셉니다. 그래서 결과는 "한 군의 값이 더 크게 나오는 경향"으로 읽습니다('결과 읽기'). 그런데 P를 계산할 때 참이라고 가정하는 귀무가설은 "두 군의 값이 같은 분포를 따른다"입니다('숫자로 따라가기'). 이 귀무가설과 '한쪽 값이 더 클 확률이 반반이다'는 똑같지 않습니다. 두 분포가 같으면 한쪽이 더 클 확률은 반드시 반반이지만, 확률이 반반이어도 두 분포는 다를 수 있기 때문입니다. 이 틈은 두 군의 퍼진 정도가 다를 때 드러나며, '결과 읽기'에서 다시 봅니다.

- **무엇을 바꿨나**

  원문은 추상적인 귀무가설로 시작해 '반면 → 그래서 → 다만'으로 오가다가, 읽는 법을 말한 뒤에야 두 가설이 다르다는 단서를 붙였습니다. 다시 쓴 문단은 '한 명씩 뽑아 비교하는 장면 → 읽는 법 → 귀무가설 → 둘의 틈' 순서로 한 방향으로만 나아갑니다. 괄호 안내는 네 번에서 세 번으로 줄였고, 짧은 문장("값이 같은 쌍은 절반씩 셉니다.")을 끼워 긴 문장 사이에 쉴 자리를 만들었습니다.
