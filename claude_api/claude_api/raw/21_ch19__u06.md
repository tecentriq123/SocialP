### 4. 문단 다시 쓰기

- 위치: d. 출판 편향과 민감도 분석 · 깔때기 그림과 비대칭 검정

- 원문 첫 문장: 눈으로 보는 판단은 주관적이어서, 비대칭을 회귀로 검정하는 **Egger 검정**을 함께 씁니다[292].

- 다시 쓴 문단:

  깔때기 그림의 모양을 눈으로 판단하는 것은 주관적이어서, 비대칭을 회귀로 검정하는 **Egger 검정**을 함께 씁니다[292]. 이 검정은 연구마다 점 하나를 찍습니다. 가로는 정밀도(1 ÷ 표준오차), 세로는 효과를 표준오차로 나눈 값입니다. 모든 연구가 같은 참값을 재고 편향이 없을 때 점이 어디에 놓이는지, 참값이 −0.2라고 하고 보겠습니다. 표준오차가 0.1인 연구는 가로 10, 세로 −0.2 ÷ 0.1 = −2 근처에 찍히고, 표준오차가 0.5인 연구는 가로 2, 세로 −0.4 근처에 찍힙니다. 어느 연구든 세로값이 참값 × 정밀도 근처에 놓이므로, 점들은 원점을 지나는 직선 주위에 모입니다. 그런데 정밀도가 0에 가까운 작은 연구들의 효과만 한쪽으로 부풀려져 있다면 어떻게 될까요? 회귀선의 왼쪽 끝이 그만큼 아래나 위로 옮겨져, 선이 원점을 지나지 않게 됩니다. 그래서 Egger 검정은 회귀선의 절편이 0인지 검정합니다. **즉, 절편이 0에서 멀수록 작은 연구의 결과가 큰 연구와 한쪽으로 다르다는 뜻입니다.**

- 무엇을 바꿨나: 가로축과 세로축을 먼저 한 문장으로 정해, 좌표 (10, −2)에 어느 쪽이 가로인지 붙였습니다. 기호 θ 대신 '참값'을 쓰고, 일반 규칙(θ ÷ 표준오차 = θ × 정밀도)을 숫자 예 뒤로 옮겨 숫자로 본 것을 정리하는 문장으로 만들었습니다. 작은 연구가 부풀려진 경우를 짧은 질문으로 끊어, '원점을 지나는 직선'에서 '절편 검정'으로 넘어가는 이유가 드러나게 했습니다.
