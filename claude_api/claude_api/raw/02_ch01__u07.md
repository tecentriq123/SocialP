### 4. 문단 다시 쓰기

- **위치**
  g · 4. 헷갈리는 점 · 흔한 오해 상자 '"Mann-Whitney 검정은 두 군의 중앙값을 비교한다"'

- **원문 첫 문장**
  정확히는 "한 군의 값이 다른 군의 값보다 큰 경향이 있는가", 즉 무작위로 한 명씩 뽑았을 때 A군 값이 B군 값보다 클 확률이 0.5인지를 검정합니다.

- **다시 쓴 문단**
  정확히 말하면 Mann-Whitney 검정이 묻는 것은 "한 군의 값이 다른 군의 값보다 큰 경향이 있는가"입니다. 두 군에서 무작위로 한 명씩 뽑았을 때 A군 값이 B군 값보다 클 확률이 0.5인지를 검정하는 것이지요. 그래서 이 검정을 중앙값 비교로 읽을 수 있는 것은 두 군의 분포 모양이 같을 때뿐입니다. 모양, 곧 퍼진 정도가 다르면 중앙값이 같아도 유의할 수 있습니다[21]. 퍼진 정도가 다를 때는 하나를 더 조심해야 합니다. 엄밀하게 말하면 Mann-Whitney 검정의 p는 '두 군의 분포가 완전히 같다'는 가정 아래에서 계산합니다. 그래서 퍼진 정도가 다르면 A군 값이 B군 값보다 클 확률이 0.5여도 1종 오류가 5%를 넘을 수 있습니다[20]. 끝으로, 비모수 검정에도 관측값의 독립성 같은 가정은 여전히 필요합니다.

- **무엇을 바꿨나**
  원문은 '독립성 가정' 문장이 중간에 끼어, 뒤의 '다만 엄밀하게 말하면'이 무엇과 대비되는지 알 수 없었습니다. 그래서 '무엇을 검정하나 → 중앙값으로 읽을 수 있는 조건 → 퍼진 정도가 다를 때의 두 가지 문제'로 이어지게 순서를 바꾸고, 독립성 가정은 맨 끝으로 보냈습니다. 첫 문장의 긴 인용과 풀이도 두 문장으로 나눠 숨을 돌릴 자리를 만들었습니다.
