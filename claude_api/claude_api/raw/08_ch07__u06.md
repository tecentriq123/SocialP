### 4. 문단 다시 쓰기

- **위치**: c. 로그순위법 · 5. 논문에서 읽기 (Table 2 해설 ⑤ '층화 분석')
- **원문 첫 문장**: 예후 위험군 안에서 비교하면 HR은 0.86으로 1에 가까워지고 P는 0.31이 됩니다.
- **다시 쓴 문단**:

  **층화 분석.** 같은 예후 위험군 안에서 비교하면 HR은 0.73에서 0.86으로 1에 가까워지고, P는 0.022에서 0.31이 됩니다. 이 변화는 보정하지 않은 차이의 상당 부분이 위험군 분포의 차이에서 왔을 가능성을 시사합니다. 그래서 저자가 보정 전 결과만 강조했다면 결론을 조심스럽게 읽어야 합니다. 두 값의 출처는 각주에 있습니다. 위험비는 층화 Cox 모형(각주 c)에서, P는 층화 로그순위 검정(각주 d)에서 나왔고, 이 자료에서는 층화 Cox 모형의 Wald P도 0.31로 같습니다. 층마다의 계산은 '가정과 대안'의 접힌 상자 '층화 로그순위법은 층마다 무엇을 더하나?'에 있습니다.

- **무엇을 바꿨나**: 원문은 결과 다음에 출처와 Wald P를 끼워 넣고 그 뒤에 해석을 두었습니다. 그래서 주어 없는 '시사합니다'가 Wald P에 붙어 읽혔습니다. 결과, 해석, 읽는 태도를 먼저 잇고 출처는 뒤로 모아 '무엇이 바뀌었나, 그래서 어떻게 읽나'의 흐름을 만들었습니다. 바뀌기 전 값(0.73, 0.022)은 같은 표에 있는 숫자로, 변화의 폭이 바로 보이도록 옆에 붙였습니다.
