  실제 당뇨병 시험은 이 계산과 조금 다르게, 기저 HbA1c를 함께 넣은 모형으로 분석합니다. 이유는 두 가지입니다. 첫째는 두 군의 기저값 차이입니다. 기저 HbA1c가 높은 환자일수록 24주 동안 많이 떨어지는 경향이 있고(여기에는 3장 a 절에서 본 평균으로의 회귀도 섞여 있습니다), 무작위배정을 해도 두 군의 기저 평균은 우연히 조금씩 다릅니다. 이 시험에서도 신약 X군이 8.12%, 대조약군이 8.09%였습니다. 기저 평균이 높은 군은 그만큼 더 떨어지므로, 변화량의 차이에는 약의 차이와 함께 기저값의 차이에서 온 몫이 섞입니다. 기저 HbA1c를 모형에 넣으면 기저값이 같은 환자끼리 비교한 차이를 구하게 되어 이 몫이 빠집니다. 둘째는 정밀도입니다. 변화량의 흩어짐 가운데 기저값으로 설명되는 부분도 함께 빠지므로 표준오차가 줄어듭니다. **그래서 실제 시험은 변화량을 기저 HbA1c로 보정한 공분산분석(analysis of covariance, ANCOVA)이나 반복측정 혼합모형으로 분석하고, 모형으로 보정한 군별 평균의 차이를 보고합니다.**

- **무엇을 바꿨나**:
  - 원문 첫 문장은 '조금 다르게'에서 멈춰서 무엇이 다른지 끝까지 알 수 없었습니다. 첫 문장에서 '기저값을 넣은 모형'이라고 먼저 밝혔습니다.
  - 원문은 치우침 제거와 표준오차 감소라는 서로 다른 두 이유를 짧은 문장의 사슬로 이어서 '또' 하나로만 갈랐습니다. 이를 '첫째/둘째'로 나눴습니다.
  - 원문에서는 두 번 나오는 '부분이 빠집니다'의 가리키는 대상이 달랐습니다. 첫째를 '몫'(뒤 '잠깐 확인'의 표현과 같음)으로 바꿔 구분했습니다. 평균으로의 회귀는 곁가지라서 괄호로 낮췄습니다.
