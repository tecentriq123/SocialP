### 4. 문단 다시 쓰기

- **위치**: c · 3. 가정과 그 영향 · 확률만 보면 무엇을 놓치나? (둘째 문단)
- **원문 첫 문장**: 왜 맞지 않는지 공통 예시로 봅니다.
- **다시 쓴 문단**:

  공통 예시로 이 생각이 왜 맞지 않는지 봅니다. 지금 신약 A를 급여할지 정해야 하고, 선택지는 신약 A와 표준요법 B 둘뿐인 단순한 상황이라고 가정합니다. 임계값을 확률적 분석의 ICER(5,586만원)보다 조금 높은 5,610만원으로 정하면, 순편익의 평균은 +13만원이어서 기대값으로는 신약 A가 낫습니다. 그런데 비용효과적일 확률은 48.3%로 절반에 못 미칩니다. 확률이 낮다는 이유로 신약 A를 거절해 B를 고르면, 환자 1인당 평균 13만원어치의 순편익을 포기하게 됩니다. 확신이 없다며 결정을 미뤄도 마찬가지입니다. 그동안 환자는 표준요법 B를 쓰므로 미루는 것도 B를 고른 것입니다. 순편익의 분포가 한쪽으로 더 치우친 분석에서는 확률과 평균이 더 크게 엇갈립니다. 이 절 끝 스스로 확인하기 3번의 신약은 확률이 40%인데 순편익의 평균이 +200만원입니다. 결정을 나중에 큰 비용 없이 되돌릴 수 있다면, 불확실성이 있다고 이 선택이 바뀌지는 않습니다. 불확실성은 그것을 줄이는 추가 연구가 얼마의 값어치가 있는지로 따로 셉니다. **즉, 확률이 낮다는 이유로 기대 순편익이 큰 대안을 버리면 평균적으로 손해이므로, 결정은 순편익의 평균으로 하고 불확실성은 추가 연구의 값어치로 따집니다.** 실제 심의에서 불확실성을 얼마나 받아들일지는 의사결정자가 정합니다(25장 c 절).

- **무엇을 바꿨나**: 원문은 숫자를 보이기도 전에 '미루는 것도 B를 고른 것'이라는 전제를 꺼냈습니다. 이 전제를 거절의 손실(13만원)을 보인 뒤로 옮겨, 숫자 → 손실 → 미뤄도 같다는 순서로 읽히게 했습니다. 뜻이 흐린 '이 차이가 커서'는 '확률과 평균이 더 크게 엇갈립니다'로 풀었습니다. 아직 보지 않은 연습 문제는 '이 절 끝'이라고 위치를 밝혔습니다. 주어가 중간에 바뀌던 '되돌릴 수 있다면…' 문장은 두 문장으로 나눠, 굵은 정리 문장 바로 앞에서 그 전제를 받치게 했습니다.
