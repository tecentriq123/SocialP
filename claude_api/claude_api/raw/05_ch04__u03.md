### 4. 문단 다시 쓰기

- **위치**: b. 일원배치 분산분석 · 스스로 확인하기 3 (답과 풀이)
- **원문 첫 문장 (그대로 옮김)**: Levene 검정의 P = 0.21은 "분산이 같다"의 증거가 아니라 "다르다고 할 증거가 부족하다"는 뜻이고, 12명처럼 작은 군이 있으면 검정력이 낮아 분산이 꽤 달라도 유의하지 않게 나옵니다.
- **다시 쓴 문단**:

  이 문장은 두 곳에서 어긋납니다. 첫째, Levene 검정의 P = 0.21은 "분산이 같다"는 증거가 아니라 "다르다고 할 증거가 부족하다"는 뜻입니다. 12명처럼 작은 군이 있으면 검정력이 낮아서, 분산이 꽤 달라도 유의하지 않게 나옵니다. 둘째, 군 크기가 12, 25, 50명으로 크게 다른 것이야말로 일반 분산분석이 분산 차이에 가장 취약한 상황입니다. 이 절의 모의실험에서도 작은 군의 분산이 크면 분산분석의 1종 오류가 20%까지 올라갔습니다. 그러니 군별 SD의 비와 군 크기를 함께 보고, 확신이 없으면 Welch 분산분석을 씁니다. 고쳐 쓰면 "Levene 검정에서 분산의 차이는 유의하지 않았으나(P = 0.21) 군 크기가 크게 달라 Welch 분산분석을 주 분석으로 썼다"입니다.

- **무엇을 바꿨나**: 원문은 문제 문장의 두 오류(P를 '같다'로 읽은 것, 군 크기 차이를 가볍게 본 것)를 한 줄로 몰아 써서, 첫 문장이 길고 '게다가' 문장은 주어가 빠져 있었습니다. 첫 문장에서 틀린 곳이 두 군데라고 먼저 알리고 '첫째·둘째'로 나눴습니다. 빠진 주어 '일반 분산분석'은 되살렸습니다. 결론 문장 앞의 '따라서'는 두 이유를 받는 '그러니'로 바꿔, 처방이 두 오류 모두에서 나온다는 것이 드러나게 했습니다.
