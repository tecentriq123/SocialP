### 4. 문단 다시 쓰기

- **위치**: b 절 · 더 알아보기(수식으로 보기)의 무작위효과 모형 부분(식 다음부터 접힌 내용 끝까지)
- **원문 첫 문장 (그대로 옮김)**: 무작위효과 모형. τ²는 c 절의 방법으로 추정하고, 이 장은 REML을 씁니다.
- **다시 쓴 문단**

무작위효과 모형은 표준오차²에 연구 간 분산 τ²를 더한 값의 역수를 가중치로 씁니다. 나머지 계산은 고정효과 모형과 같으므로, τ² = 0이면 두 모형이 같아집니다.

$$\hat{\theta}_{RE} = \frac{\sum w_i^{*} y_i}{\sum w_i^{*}}, \qquad w_i^{*} = \frac{1}{SE_i^2 + \tau^2}, \qquad SE(\hat{\theta}_{RE}) = \frac{1}{\sqrt{\sum w_i^{*}}}$$

τ²는 c 절 'τ²는 어떤 방법으로 구하나?'의 방법 가운데 REML로 구한 값을 씁니다. 예제로 계산하면 다음과 같습니다.

τ² = 0.0138, Σw\* = 225.2, Σw\*y = −44.46  
통합값 = −44.46 ÷ 225.2 = −0.197  
SE = 1 ÷ √225.2 = 0.067  
보통의 방법(Wald)으로 구한 95% CI = exp(−0.197 ± 1.96 × 0.067) = 0.72–0.94

이 장의 주 결과 0.82(0.72–0.94)는 같은 통합값에 HKSJ 방법으로 구간을 구한 것으로, 이 예에서는 반올림하면 보통의 방법과 구간이 같습니다. HKSJ 방법으로 구간과 P를 구하는 식은 c 절 '수식으로 보기'에 있습니다.

- **무엇을 바꿨나**: 식 뒤에 붙어 있던 이름표 '무작위효과 모형.'을, 식 앞에서 가중치가 무엇이 다른지 알려 주는 문장으로 바꿨습니다. 그래서 독자가 식을 읽기 전에 무엇을 볼지 압니다. 'τ² = 0이면 같아진다'는 '나머지 계산은 같다'와 이어 붙여 왜 같아지는지가 보이게 했습니다. 'c 절의 방법'은 소제목 이름으로 바꿔 칸 c와 헷갈리지 않게 했습니다. 끝에는 계산한 구간과 주 결과의 관계를 한 문장으로 밝혀, 독자가 본문으로 돌아가지 않고 접힌 상자를 닫을 수 있게 했습니다.
