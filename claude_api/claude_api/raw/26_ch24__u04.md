### 4. 문단 다시 쓰기

- **위치**: c. 비용효과 수용곡선과 순편익 · 5. 내 연구에서 분석하기 · 계산한 뒤에는 무엇을 판단하나?(점검표 바로 아래 문단)
- **원문 첫 문장**: 표의 '엇갈린 반복'과 '구조 시나리오' 두 줄에는 이유를 덧붙입니다.
- **다시 쓴 문단**:

  표의 두 줄은 왜 확인해야 하는지 짚어 둡니다. 먼저 '엇갈린 반복'입니다. 엇갈린 반복을 많이 버릴수록 남은 반복의 분포는 처음 정한 분포에서 멀어집니다. 그래서 반복 넷 가운데 하나를 버린 분석이라면 분포나 모형 구조부터 다시 봅니다. 이 절 끝 '스스로 확인하기' 2번에서 같은 표준요법 B와 비교하는 신약 C가 그런 예입니다. 다음은 '구조 시나리오'입니다. 이 확인은 모의실험 횟수를 늘린다고 대신되지 않습니다. 횟수가 줄이는 것은 몬테카를로 오차뿐이어서, 10만 번을 돌려 얻은 확률도 기준 구조 안의 확률이기 때문입니다(b 절 '모의실험 횟수는 어떻게 정하나?'). 공통 예시에서 같은 입력값 5,000세트를 효과 감소 구조로 돌리면 확률이 16.0%에서 5.1%로 바뀌었습니다(b 절 '모형 구조의 불확실성은 들어 있나?'). 그래서 주요 구조 시나리오에서는 확률적 분석을 다시 돌려 그 확률을 함께 제시합니다.

- **무엇을 바꿨나**: 첫 문장이 "왜 확인하는가"를 묻도록 고치고, 두 항목을 표의 줄 이름으로 시작해 표와 바로 맞물리게 했습니다. 신약 C를 끼워 넣은 긴 조건문은 판단과 예시로 나눴습니다. 주어가 빠졌던 "10만 번을 돌려도…" 문장에는 '얻은 확률'이라는 주어를 되살렸습니다. 마지막은 숫자(16.0%→5.1%)를 먼저 보이고 결론('그래서')으로 닫는 순서로 정리했습니다.
