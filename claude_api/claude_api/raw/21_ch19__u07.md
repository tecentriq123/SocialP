### 4. 문단 다시 쓰기

- **위치**
  e. 통합 결과의 활용 · 4. 논문에서 읽기 › 경제성 평가 논문에서 읽을 때, 확인할 것 2번

- **원문 첫 문장 (그대로 옮김)**
  통합 추정값의 신뢰구간이 모형의 불확실성 분석에 어떻게 들어갔는지 봅니다.

- **다시 쓴 문단**

  통합 추정값의 신뢰구간이 모형의 불확실성 분석에 어떻게 들어갔는지 봅니다. 예를 들어 확률적 민감도 분석(probabilistic sensitivity analysis)(24장)은 로그 오즈비를 평균 −0.197인 분포에서 여러 번 뽑아 모형을 다시 돌립니다. 이 분포가 얼마나 퍼지는지는 흔히 통합 결과의 95% CI에서 거꾸로 구합니다(b 절의 접힌 상자 '사건 수 없이 추정값과 신뢰구간만 있으면?'). 구간을 보통의 방법(Wald)으로 구했다면 로그 척도에서 로그 오즈비 ± 1.96 × 표준오차이므로, 구간의 폭을 2 × 1.96으로 나누면 표준오차가 나옵니다. 그런데 이 예의 구간 0.72–0.94는 HKSJ 방법으로 구했습니다. 그래서 같은 폭을 무엇으로 나누느냐에 따라 값이 둘로 갈립니다.

  (ln 0.942 − ln 0.715) ÷ (2 × 2.262) = 0.061  
  (ln 0.942 − ln 0.715) ÷ (2 × 1.96) = 0.070

  2.262는 자유도 9인 t 분포의 값이므로, 앞의 0.061이 HKSJ 방법의 표준오차입니다. 이 값을 쓴다면 자유도 9인 t 분포에서 뽑아야 보고된 구간과 같은 범위가 됩니다. 뒤의 0.070은 HKSJ 표준오차(0.061)도 모형의 표준오차(0.067)도 아닙니다. 정규분포에서 뽑을 때 95% 범위가 보고된 HKSJ 신뢰구간(0.72–0.94)과 같아지도록 거꾸로 맞춘 값입니다. 이처럼 같은 구간에서도 어떤 분포와 짝짓느냐에 따라 표준오차가 달라지므로, 논문에서는 어떤 분포와 표준오차를 썼는지 밝혔는지 봅니다.

- **무엇을 바꿨나**
  원문은 Wald 규칙을 일반론으로 말한 뒤 '이 예는 HKSJ이므로 2.262로 나눠야' 한다고 하고, 계산 뒤에 다시 0.070의 정체로 돌아갑니다. 그래서 독자는 두 숫자 중 어느 것이 옳은 값인지 앞뒤를 오가게 됩니다. '그런데 이 예는 HKSJ'라는 전환을 한 문장으로 세우고, 두 계산을 나란히 둔 뒤 각 값이 어떤 분포와 짝인지 차례로 설명했습니다. 긴 첫 문장(분포에서 뽑기 + 퍼짐의 출처)도 둘로 나눴습니다.
