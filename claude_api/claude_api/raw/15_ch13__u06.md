### 4. 문단 다시 쓰기

- **위치**: e. 4. 결과 읽기 · 80–125%는 무엇을 허용하나? (둘째 문단)
- **원문 첫 문장 (그대로 옮김)**: 이 기준은 "제네릭은 오리지널과 −20% ~ +25%까지 달라도 된다"는 뜻이 아닙니다.
- **다시 쓴 문단**:

  이 기준은 "제네릭은 오리지널과 −20% ~ +25%까지 달라도 된다"는 뜻이 아닙니다. 범위 안에 들어야 하는 것은 점추정값이 아니라 90% 신뢰구간 **전체**이므로, 점추정값은 이보다 훨씬 100%에 가까워야 통과합니다. 얼마나 가까워야 하는지는 '논문에서 읽기'의 Table 2에 나오는 AUC<sub>0–t</sub>로 계산해 볼 수 있습니다. 이 지표의 점추정값은 97.31%이고 90% 신뢰구간은 91.20–103.82%입니다. 로그 척도에서 대칭인 구간을 되돌린 것이라, 이 구간은 점추정값을 1.067로 나눈 값부터 1.067을 곱한 값까지입니다. 구간 폭이 이와 같다면, 하한이 80%보다 크려면 점추정값이 80 × 1.067 = 85.4%보다 커야 하고, 상한이 125%보다 작으려면 125 ÷ 1.067 = 117.2%보다 작아야 합니다. 즉 점추정값이 대략 85–117% 안에 있어야 통과합니다.

  한 가지 더 알아 둘 것은 이 기준이 대상자 집단의 평균에 대한 것이라는 점입니다. 환자 한 명 한 명의 혈중농도가 이 범위 안에 든다는 뜻은 아닙니다.

- **무엇을 바꿨나**: 아직 보지 않은 Table 2를 쓰는 이유를 먼저 밝히고, 점추정값과 구간을 따로 보여 준 뒤 계산으로 넘어가게 했습니다. 1.067이 어디서 나오는지는 Table 2 해설 ③의 '로그 척도에서 대칭인 구간을 되돌렸다'는 설명을 앞으로 옮겨 이어 붙였습니다. 내용이 다른 마지막 문장(집단 평균 대 개인)은 '또'로 덧붙이지 않고, 넘어간다는 것을 알리는 별도 문단으로 나눴습니다.
