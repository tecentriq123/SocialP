### 4. 문단 다시 쓰기

- **위치**: b.3 가정과 대안 · 차이의 분포가 대칭이어야 한다는 조건은 무엇인가? (둘째 문단)
- **원문 첫 문장**: 이 조건은 결과를 무엇으로 읽을지를 정합니다.
- **다시 쓴 문단**

  이 조건이 정하는 것은 결과를 무엇으로 읽느냐입니다. 차이의 분포가 대칭이라고 볼 수 있으면, 이 검정은 "환자 내 변화의 중앙값이 0인가"를 보는 검정으로 읽을 수 있습니다. 대칭이 아닐 때 왜 그렇게 읽으면 안 되는지는 한 가지 경우를 떠올려 보면 드러납니다. 환자 전체에서 값이 줄어들 확률과 늘어날 확률이 반반이라 변화의 중앙값은 0인데, 줄어드는 환자는 조금씩 줄고 늘어나는 환자는 크게 는다고 합시다. 그러면 큰 순위가 늘어난 쪽에 몰려, 중앙값이 0인데도 P가 작게 나올 수 있습니다. 대칭이 아닐 때 이 검정이 실제로 보는 것은 중앙값이 아니라 유사중앙값이라는 다른 값이고, 그 정의는 아래 접힌 상자에 있습니다.

- **무엇을 바꿨나**
  - 원문은 "읽으면 안 됩니다"라는 결론을 먼저 단정합니다. 이어지는 예도 '이때 … 이때'로 끊겨, 예가 그 결론의 근거라는 연결이 보이지 않았습니다.
  - 결론을 예로 넘어가는 다리 문장으로 바꾸고, 예의 두 조건(중앙값 0, 크기의 비대칭)을 한 문장에 모았습니다. 예가 보여 주려던 요점은 "중앙값이 0인데도"로 드러냈습니다.
  - 마지막 문장에서 '중앙값과 다른 유사중앙값'과 괄호 안내를 풀어 썼습니다. 새 개념의 이름을 문장 끝에서 받도록 리듬도 정리했습니다.
