| e. 내 연구에서 분석 정하고 쓰기 · 분석 전에 무엇을 정해 두나? | 먼저 결론을 무엇으로 내릴지 분석계획서에 적습니다. | 이 문장은 1차 결과 하나만 예고합니다. 그런데 바로 이어지는 표에는 양측 여부, 다중비교, 결측 처리까지 네 가지가 있습니다. 표를 다 읽은 독자는 첫 문장이 표의 일부만 말했다는 것을 알고 다시 올라가게 됩니다. | 먼저 아래 네 가지, 즉 무엇으로 결론을 내리고 어떤 기준으로 판단하며 결측을 어떻게 다룰지를 분석계획서에 적습니다. | 없음 |
| e. 내 연구에서 분석 정하고 쓰기 · 분석 전에 무엇을 정해 두나? (표, 2차 결과 행) | 하나라도 유의하면 효과가 있다고 말할 검정들은 한 묶음으로 세어 보정하거나, 탐색적 분석이라고 밝힘 | '하나라도 유의하면 효과가 있다고 말할'이 '검정들' 앞에 길게 쌓여 있습니다. 독자는 무엇이 하나라도 유의하다는 것인지 끝까지 읽고 나서야 알게 됩니다. | 검정 여러 개 가운데 하나라도 유의하면 효과가 있다고 말할 생각이면, 그 검정들을 한 묶음으로 세어 보정함. 보정하지 않으면 탐색적 분석이라고 밝힘 | 없음 |
| e. 내 연구에서 분석 정하고 쓰기 · 분석 전에 무엇을 정해 두나? (표, 결측 처리 행) | 빠진 환자를 어떻게 다룰지 미리 정함. 분석할 때 프로그램은 결측이 있으면 결과를 nan으로 내거나(scipy), 오류를 내거나(lifelines), 결측 행을 알리지 않고 빼므로(statsmodels 식), 실제 분석한 인원을 직접 세어 보고함 | 세 프로그램의 동작과 결론이 '-거나, -거나, -므로'로 한 문장에 이어져 있습니다. 또 '(statsmodels 식)'의 '식'이 formula 입력인지 '방식'인지 알기 어렵습니다. | 빠진 환자를 어떻게 다룰지 미리 정함. 결측이 있을 때 프로그램마다 하는 일이 다름: scipy는 결과를 nan으로 내고, lifelines는 오류를 내며, statsmodels의 식(formula) 입력은 결측 행을 알리지 않고 뺌. 그래서 실제 분석한 인원은 직접 세어 보고함 | 'formula' 병기 추가 ('식'을 formula 입력으로 읽은 해석. 저자 확인 필요) |
| e. 내 연구에서 분석 정하고 쓰기 · 분석 전에 무엇을 정해 두나? | 항목별 설명은 1장 b 절 '양측검정과 단측검정은 무엇이 다른가?', 1장 c 절의 접힌 상자 '내 연구에서 '여러 번'은 무엇을 세나?', 2장 a 절의 접힌 상자 '결측값이 있으면?'에 있습니다. | 참조 세 개가 어느 표 항목에 대응하는지 적혀 있지 않습니다. 독자가 표와 하나씩 맞춰 봐야 합니다. 또 작은따옴표 안에 작은따옴표가 들어가 제목의 경계가 흐려집니다. | 양측 여부는 1장 b 절 '양측검정과 단측검정은 무엇이 다른가?', 다중비교는 1장 c 절의 접힌 상자 '내 연구에서 "여러 번"은 무엇을 세나?', 결측 처리는 2장 a 절의 접힌 상자 '결측값이 있으면?'에서 자세히 다룹니다. | 제목 속 안쪽 따옴표를 큰따옴표로 바꿈 (사이트 제목 표기와 맞는지 확인 필요) |
| e. 내 연구에서 분석 정하고 쓰기 · 내 연구에 질문을 적용하면? | 중증 저혈당은 저혈당으로 입원하거나 응급실을 찾은 사건이고, 자료는 사망 정보가 연계된 국민건강보험공단(NHIS) 청구자료입니다. | 결과의 정의와 자료 출처라는 서로 다른 정보가 '-이고'로 묶여 있습니다. 그래서 뒷부분이 사건 정의의 일부처럼 읽힙니다. | 중증 저혈당은 저혈당으로 입원하거나 응급실을 찾은 사건입니다. 자료는 사망 정보가 연계된 국민건강보험공단(NHIS) 청구자료를 씁니다. | 없음 |
| e. 내 연구에서 분석 정하고 쓰기 · 내 연구에 질문을 적용하면? (표, ③ 행) | 추적이 사망, 자격 상실, 자료 기간 종료로 사람마다 다르게 끝나므로, 결과는 첫 중증 저혈당까지의 시간 | 질문이 '결과 유형'을 묻는데 답의 맨 끝에 와 있고, 유형 이름(시간-사건)도 없습니다. 독자가 a 절 표의 '시간-사건' 묶음과 직접 연결해야 합니다. | 시간-사건 결과(첫 중증 저혈당까지의 시간). 추적이 사망, 자격 상실, 자료 기간 종료로 사람마다 다르게 끝나 중도절단이 있음 | 없음 (유형 이름과 중도절단은 a 절 ③의 결론을 그대로 씀) |
| e. 내 연구에서 분석 정하고 쓰기 · 내 연구에 질문을 적용하면? | ⑥의 두 조건은 7장 b 절 '첫째, 관찰이 끊긴 이유가 예후와 관계없나?'와 7장 c 절의 접힌 상자 '사건이 몇 건뿐이면 이 P를 믿어도 되나?'에서 다룹니다. | 분석을 결론짓고 보정 계획까지 말한 뒤에 다시 표의 ⑥으로 돌아갑니다. 독자는 표를 다시 올려다보게 됩니다. | 이 문장을 표 바로 뒤, '그래서 PART 1 안의 분석은…' 앞으로 옮김: "표의 ⑥에 적은 두 조건은 7장 b 절 '첫째, 관찰이 끊긴 이유가 예후와 관계없나?'와 7장 c 절의 접힌 상자 '사건이 몇 건뿐이면 이 P를 믿어도 되나?'에서 다룹니다." | 없음 (순서 이동) |
| e. 내 연구에서 분석 정하고 쓰기 · 내 연구에 질문을 적용하면? | 세척 기간으로 신규 사용자를 정하는 법, 약을 끊거나 바꾼 환자의 추적 종료, 유예기간이 그 예입니다. | '세척 기간'과 '유예기간'이 풀이 없이 처음 나옵니다. 세척 기간은 바로 아래 Methods 예문에 구체적인 숫자로 나오지만, 독자는 둘을 연결하지 못합니다. | 세척 기간(첫 처방 전 두 약 모두 처방이 없어야 하는 기간, 아래 Methods 예문의 [365]일)으로 신규 사용자를 정하는 법, 약을 끊거나 바꾼 환자의 추적 종료, 유예기간이 그 예입니다. | 세척 기간에 풀이 추가 (내용은 예문 ①에서 가져옴). 유예기간은 그대로 7장 상자로 미룸 |
| e. 내 연구에서 분석 정하고 쓰기 · 프로그램에는 무엇을 넣나? | 추적 시간(index date 다음 날부터 사건이나 중도절단까지의 일수), 사건 여부(사건이면 1, 중도절단이면 0), 군입니다. | 같은 문단 끝의 참조 상자 제목에 'time과 status'가 나옵니다. 그런데 이 영어 열 이름이 여기서 소개되지 않아, 독자가 어느 열을 말하는지 다시 맞춰 봐야 합니다. | 추적 시간(time: index date 다음 날부터 사건이나 중도절단까지의 일수), 사건 여부(status: 사건이면 1, 중도절단이면 0), 군입니다. | 열 이름 영어 병기 추가 (7장 상자 제목과 연결) |
| e. 내 연구에서 분석 정하고 쓰기 · 프로그램에는 무엇을 넣나? | lifelines의 `KaplanMeierFitter`로 군별 곡선을 그리고, `logrank_test`로 두 곡선을 비교한 P를 구합니다. 위험비는 이 두 함수에서 나오지 않습니다(7장 b 절과 c 절의 '프로그램에는 무엇을 넣나?'). | 참조가 위험비 문장에 붙어 있어, 7장의 해당 소제목이 위험비를 다루는 곳처럼 읽힙니다. 실제로는 두 함수를 쓰는 법 전체를 가리킵니다. | lifelines의 `KaplanMeierFitter`로 군별 곡선을 그리고, `logrank_test`로 두 곡선을 비교한 P를 구합니다(7장 b 절과 c 절의 '프로그램에는 무엇을 넣나?'). 위험비는 이 두 함수에서 나오지 않습니다. | 없음 (참조 위치 이동) |

### 4. 문단 다시 쓰기

- **위치**
  e. 내 연구에서 분석 정하고 쓰기 · Methods와 Limitations는 어떻게 쓰나? (예문 아래 해설 ②)

- **원문 첫 문장 (그대로 옮김)**
  ② **결과의 정의와 추적 종료 사유(③).** 사건의 정의와 관찰이 끝나는 사유를 모두 적고 "whichever came first"로 묶습니다.

- **다시 쓴 문단**
  ② **결과의 정의와 추적 종료 사유(a 절 질문 ③).** 사건을 어떻게 정의했는지와 관찰이 끝나는 사유를 모두 적고, 사유들은 "whichever came first"로 한데 묶습니다. 여기에 두 가지를 덧붙입니다. 병원 밖 사망은 청구 명세서에 남지 않으므로 사망 정보를 어디서 얻었는지 쓰고, 약을 끊거나 바꾼 환자를 이 예문처럼 계속 추적했는지 끊거나 바꾼 날 중도절단했는지도 밝힙니다. 자료나 사건의 양상이 다르면 이 정의도 달라집니다. HIRA 청구자료에서는 자격 상실을 알 수 없으므로 추적 종료의 정의를 바꿉니다. 사망이 잦으면 사망을 중도절단으로 두는 대신 따로 다루는 방법이 있습니다(7장 b 절의 접힌 상자 '사망이 관심 사건을 막으면 1 − Kaplan-Meier는 얼마나 틀리나?').

- **무엇을 바꿨나**
  원문은 성격이 다른 다섯 문장이 같은 무게로 나열되어 있어, 어디까지가 예문 설명이고 어디부터가 다른 자료의 경우인지 독자가 직접 갈라야 했습니다. 이를 '반드시 적을 것 → 덧붙일 두 가지 → 자료가 다를 때'의 세 층으로 묶고, 층이 바뀌는 자리에 짧은 이음 문장 두 개를 넣었습니다. 함께 예문 표식 ②와 질문 ③이 섞이지 않도록 '질문'을 붙였고, 가리키는 날이 불분명한 '그날'을 '끊거나 바꾼 날'로 고쳤습니다.
