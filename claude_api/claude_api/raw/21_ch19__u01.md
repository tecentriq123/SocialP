  **Trial C, 2번 영역 '일부 우려'.** 이중 눈가림 위약 대조 시험이어서 참여자와 의료진이 배정을 몰랐으므로, 2번 영역에서 배정을 알아서 치료가 달라졌는지 묻는 질문들에는 문제가 없었습니다. 걸린 것은 분석 방법입니다. 논문은 연구약을 중간에 끊은 환자를 빼고 끝까지 먹은 환자만 분석한 계획서 순응 분석(per-protocol analysis)의 결과만 보고했습니다. 출혈로 약을 끊는 환자는 나이가 많거나 신장 기능이 나쁜 경우가 많고, 이런 환자는 허혈 사건의 위험도 높습니다. 출혈은 약물 X군에서 더 많이 생기므로, 끝까지 먹은 환자만 남기면 위험이 높은 환자가 약물 X군에서 더 많이 빠지고, 남은 두 군은 약효와 상관없이 원래의 위험부터 달라집니다(13장 a 절 '그러면 무엇을 확인하나?'). **약 중단처럼 배정 뒤에 생긴 일로 환자를 빼면, 빠지는 환자의 위험이 군마다 달라져 무작위배정으로 맞춰 놓은 두 군의 균형이 깨집니다.** 그래서 배정된 대로 분석했는지 묻는 질문의 답은 '아니오'입니다. 다만 뺀 환자가 군마다 2% 안팎으로 적어 이 분석이 결과를 크게 바꿨을 가능성은 낮다고 보았고, 판정은 '높음'이 아니라 '일부 우려'가 되었습니다.

- **무엇을 바꿨나**: 원문은 짧은 문장 열한 개가 '그래서'(세 번)와 '그런데', '그러면'으로 하나씩 이어져 판정의 흐름이 뚝뚝 끊겼습니다. 이를 '문제없던 점 → 걸린 점 → 왜 문제인가 → 답 → 그래도 일부 우려인 이유'의 다섯 마디로 묶고, 넘어가는 자리에 '걸린 것은 분석 방법입니다'를 두어 방향을 짚었습니다. '분석한 결과, 곧'처럼 '분석했더니'로 잘못 읽히는 자리는 없앴습니다. 내용과 굵은 글씨 문장은 그대로 두었고, '그래서'는 판정의 답을 이끄는 한 곳에만 남겼습니다.
