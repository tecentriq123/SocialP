- **위치**: e.분포와 검정통계량 · 2. 논문의 '±'와 오차막대는 무엇의 흩어짐인가? (접힌 상자 '같은 나이를 SE와 SD로 적은 요약과 본문' 바로 뒤, 도입 문장과 번호 목록 1–6)
- **원문 첫 문장**: 막대가 겹치는지로 유의성을 판단하면 안 되는 이유는 혈압 시험의 숫자로 확인할 수 있습니다.
- **다시 쓴 문단**

  막대가 겹치는지로 유의성을 판단하면 안 되는 이유는 혈압 시험의 숫자로 확인할 수 있습니다. 두 군 평균의 95% 신뢰구간은 신약군 9.8–15.0 mmHg, 위약군 5.4–10.8 mmHg라서, 두 막대는 9.8–10.8 mmHg에서 겹칩니다. 그런데 두 평균의 차이 4.3 mmHg는 p = 0.022로 유의했습니다(b 절). 겹침과 유의성이 어긋나는 것은 두 판단이 서로 다른 거리를 기준으로 삼기 때문입니다. 두 막대가 겹치지 않으려면 두 평균이 막대 반쪽 길이의 합, 곧 2.6 + 2.7 = 5.3 mmHg(15.0 − 12.4와 10.8 − 8.1)보다 멀어야 합니다. 차이가 유의하려면 차이의 95% 신뢰구간 반폭인 3.7 mmHg보다 멀기만 하면 됩니다(0장 f 절의 4.3 ± 3.7). 차이의 반폭이 두 막대 반쪽 길이의 합보다 짧은 것은, 차이의 표준오차가 두 표준오차를 그냥 더한 값보다 작기 때문입니다(0장 e 절 '왜 두 표준오차를 그냥 더하지 않나?'). 혈압 시험의 차이 4.3 mmHg는 3.7보다 크고 5.3보다 작으므로, 막대는 겹치는데도 차이는 유의합니다.

- **무엇을 바꿨나**: 원문은 하나의 논증을 여섯 토막으로 나눠, 결론("그래서 막대는 겹치는데도 차이는 유의합니다")을 5번에서 내린 뒤 그 근거(차이의 표준오차가 더 작음)를 6번에 따로 붙였습니다. 그래서 독자는 결론을 읽고 나서 다시 근거로 돌아가야 했습니다. 이 글에서는 목록을 이어진 문단으로 풀고 "두 판단이 다른 거리를 기준으로 삼는다"는 연결 문장을 넣었으며, 6번 근거를 두 거리를 비교하는 자리로 옮겨 결론이 맨 끝에 오게 했습니다. 2.6과 2.7이 어디서 나왔는지도 괄호로 보였습니다.
