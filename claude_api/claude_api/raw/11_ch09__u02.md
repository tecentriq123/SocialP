### 4. 문단 다시 쓰기

- **위치**: 다른 변수를 보정하면 · 프로그램이 하는 일과 내가 정할 일은 무엇인가? · 접힌 상자 '어떤 변수를 넣어야 하나?'(표 바로 아래 문단)
- **원문 첫 문장 (그대로 옮김)**: 위의 세 줄은 '원인인가', '약이 바꾼 값인가'만 따지면 판단됩니다.
- **다시 쓴 문단**

위의 세 줄은 '원인인가', '약이 바꾼 값인가'만 따지면 답이 나옵니다. 넷째 줄은 몇 단계를 더 따져야 합니다. 의원 A는 습관적으로 SGLT2 억제제를, 의원 B는 DPP-4 억제제를 주로 처방하고, 두 의원 환자의 상태는 비슷하다고 합시다. 이때 두 의원 사이의 약 차이는 환자 상태와 상관없는 차이이므로, 공정한 비교에 도움이 됩니다. 그런데 의원을 보정하면 같은 의원 환자끼리만 비교하게 되어 이 차이가 지워집니다. 같은 의원 안에서도 약이 갈렸다면 그 이유는 주로 환자 상태입니다. 그래서 남는 비교는 대부분 상태가 다른 환자끼리의 비교가 됩니다. 환자 상태 가운데 노쇠처럼 자료에 없는 것은 보정되지 않으므로, 남은 비교에서 이런 교란이 차지하는 비중이 커집니다. **그래서 약 선택만 바꾸는 변수를 넣으면 편향이 커질 수 있고, 비교에 쓸 약의 차이가 줄어 신뢰구간도 넓어집니다.** 처방 습관 같은 변수가 결과에도 영향을 준다면 판단이 달라지는데, 그 경우는 11장 '다른 변수를 보정하면'의 접힌 상자 '어떤 변수를 넣어야 하나?'에 있습니다.

- **무엇을 바꿨나**: 원문은 '습관에서 온 약 차이 → 의원 보정으로 지워짐 → 환자 상태 차이만 남음 → 자료에 없는 상태의 비중이 커짐'이라는 고리를 두세 문장에 몰아넣었습니다. 이 고리를 한 단계씩 문장으로 펼치고, '이때', '그런데', '그래서'로 각 단계가 왜 다음으로 이어지는지 짚었습니다. 명사 앞에 쌓인 '의원 안에서 약이 갈린 이유인 환자 상태의 차이'는 두 문장으로 풀었습니다. 무엇을 가리키는지 알 수 없던 '같은 이름 상자'는 상자 이름을 밝혀 적었습니다.
