### 2. 흐름 문제

**① 장 도입 · 이 장의 흐름 / a. 비용의 종류와 측정 · 모형의 비용 입력값은 어디서 오나?**
- 문제: "공통 예시 모형의 입력값으로 만든 자료여서 비용이 모형 입력값과 가깝다"는 설명이 도입과 a 절 둘째 문단에 거의 같은 말로 두 번 나옵니다. 도입에서는 아직 자료가 무엇인지 모르는 상태여서 이 문장이 독자에게 걸리지 않고 지나갑니다.
- 방향: 도입에는 "세 절이 같은 가상 청구자료를 이어 쓴다"만 남기고, 모형과의 관계는 a 절에서 한 번만 설명합니다.

**② a. 비용의 종류와 측정 · 관점에 따라 청구자료로 무엇을 셀 수 있나?**

- 방향: 안내 문단은 접힌 '이 절 한눈에 보기'로 옮기거나 한 줄로 줄입니다. 각주 a의 논문 언급은 '결과 읽기'에서 처음 꺼내고, 각주에는 "관점 이름보다 센 항목을 본다"만 남깁니다.

**③ a. 비용의 종류와 측정 · 명세서에서 환자 한 명의 1년 비용을 어떻게 만드나?**

- 방향: "작은 예로 따라가 봅니다"로 바로 시작하고, 표를 합친다는 설명은 프로그램 문단 하나로 모읍니다. 결과 표에 번호를 붙입니다.

**④ a. 비용의 종류와 측정 · 모형에 넣는 상태별 월 비용은 어떻게 구하나?** (이 장에서 가장 많이 되돌아가게 하는 곳)

- 문제 2: "약값 이외의 비용"만 묶는 이유는 '결과 읽기' ⑦에서야 나옵니다.
- 문제 3: 목록 4에서 0.0016개월에 188.2만원이 묶인 환자가 왜 생겼는지(진행 뒤의 입원)는 한 문단 뒤에 나옵니다.
- 문제 4: 소제목 안에서 두 주제가 번갈아 나옵니다. 순서가 '합계끼리 vs 비의 평균 → 묶는 규칙(33.5) → c 절 안내 → 접힌 상자(비의 평균 다시) → 이상반응 → 접힌 상자 → 잠깐 확인(비의 평균 다시)'입니다.
- 문제 5: 잠깐 확인의 답(67.5만원)이 바로 위 접힌 상자 첫 문장에 이미 나와 있습니다.

  1. 3,000명 자료로 넘어간다는 한 문장과 함께 38.0 계산을 보입니다. 약값은 따로 입력하므로 뺀다는 반 문장을 덧붙입니다.
  2. 합계끼리 나누는 이유(목록 1–4)를 설명하고, 188.2만원의 정체를 바로 붙입니다.
  3. 잠깐 확인을 둡니다.
  4. 점검용 접힌 상자를 둡니다.
  5. 묶는 규칙(33.5/260.0)을 설명합니다.
  6. 진행 날짜와 표준오차 안내를 둡니다.
  7. 이상반응·임종기 비용을 다룹니다.

**⑤ a. 비용의 종류와 측정 · 다른 해의 금액은 어떻게 맞추나?**
- 문제: 물가 보정 표 바로 뒤의 '즉' 요약이 관찰 창, 0원, 월 비용만 정리합니다. 방금 읽은 물가 보정과 할인은 빠져 있어서, 이 요약이 무엇을 마무리하는지 헷갈립니다.
- 방향: 요약에 물가 보정과 할인을 한 줄 넣습니다. 아니면 요약을 이 소제목 앞, 곧 월 비용 소제목 끝으로 옮깁니다.

**⑥ a. 비용의 종류와 측정 · 관점에 필요한 항목이 청구자료에 다 있나? / 청구 금액은 곧 비용인가?**
- 문제: "1년 비용 차이 396만원(b 절)"과 "1인당 1년 약제비 1,559만원"이 아직 보지 않은 b 절 숫자입니다. 1,559는 b 절 Table 2에만 나옵니다.
- 방향: a 절 첫머리의 2,273만원 문단에 A군 평균 2,669만원을 함께 적어 396이 계산되게 합니다. 약제비는 "b 절 표에서 볼 신약 A군 약제비 1,559만원"처럼 앞으로 나올 값이라고 밝힙니다.

**⑦ a. 비용의 종류와 측정 · 사용량과 단가는 어떻게 매겼나?**
- 문제: "자료원은 다음과 같습니다" 뒤에 표가 아니라 지침 문장 셋이 먼저 나옵니다. 마지막 문단에서는 107.8만원 이야기가 세 번째로 되풀이됩니다.
- 방향: 지침 문장은 표 뒤로 옮깁니다. 107.8 예는 "앞의 월 비용 예처럼" 정도의 반 문장으로 줄입니다.

**⑧ a. 비용의 종류와 측정 · 4. 결과 읽기 (접힌 실제 논문 뒤)**
- 문제: '급여 평가 보고서에서는 한 가지를 더 봅니다' 문단은 읽기가 아니라 제출할 때 쓰는 방법을 다룹니다. 접힌 상자를 건너뛴 독자에게는 앞 내용과 이어지지 않는 문단입니다.
- 방향: '5. 논문에 쓰기'의 보고 목록 뒤로 옮깁니다.

**⑨ 세 절 공통 · 정리 → 다음 절 예고 → 스스로 확인하기**
- 문제: 다음 절로 넘기는 문장이 연습문제 앞에 있습니다. 그래서 연습문제를 풀고 나면 아무 연결 없이 다음 절이 시작됩니다. c 절에서는 '이 장 한눈에'와 22장 예고가 c 절 연습문제·수식·지침 표보다 앞에 끼어 있습니다. 장을 닫은 뒤에 c 절 내용이 다시 이어지는 셈입니다.
- 방향: 예고 문장은 '더 알아보기' 뒤, 곧 다음 절 바로 앞으로 옮깁니다. '이 장 한눈에'와 22장 예고는 장의 맨 끝으로 보냅니다.

**⑩ b. 비용 분포와 평균 비용의 비교 · 왜 산술평균인가?**
- 문제: 표 21-3을 2단계에 보여 주고 해석은 3단계로 미룹니다. 로그 행(1.24 대 1.17)의 해석은 c 절까지 미뤄집니다. 게다가 1.24는 c 절에서 감마 GLM의 비용 비(산술평균의 비)로 다시 나옵니다. 같은 숫자가 뜻이 반대인 두 자리에 쓰이니, 독자가 같은 값으로 착각하기 쉽습니다.
- 방향: 표 21-3은 3단계 '치우친 비용을 중앙값이나…' 첫머리로 옮겨 해석과 붙입니다. c 절에서 1.24가 처음 나오는 곳에는 "b 절의 기하평균의 비 1.24와 우연히 같은 숫자지만 다른 값"이라는 구분을 한 줄 넣습니다.

**⑪ c. 비용의 회귀분석 · 1. 이 방법이 답하는 질문**
- 문제: 결과 표와 '세 가지만 먼저 봅니다' 목록이 먼저 나오고, 왜 보정하는지는 그 뒤에 나옵니다. 그 이유를 드는 예문("신약군의 병원비가 적은 것이 약 덕분인지…")은 예제와 방향이 반대입니다. 예제에서는 신약군이 더 많이 씁니다. 목록 2(할인하지 않음)는 이 자리에서 필요하지 않습니다.
- 방향: 표 바로 뒤에 보정이 필요한 이유를 둡니다. 예문은 예제 방향("보정 전 차이가 신약의 추가 비용을 작게 보일 수 있다")으로 고칩니다. 할인 이야기는 표의 각주로 옮깁니다.

**⑫ c. 비용의 회귀분석 · 두 군은 얼마나 다른가? / 감마 GLM으로 보정한 비와 금액 차이는?**
- 문제: "누구에 대해 평균하나"가 접힌 상자 안에 있는데, 본문 여러 곳이 이 개념을 전제합니다.
  - 501과 492가 다른 이유
  - 잠깐 확인(2,760 대 2,669)
  - 결과 읽기 ⑤
  - 내 연구 '금액을 평균할 집단'
  - Methods의 "every patient"

  상자를 펼치지 않으면 이 대목들이 이해되지 않습니다.
- 방향: 상자 안의 세 줄(536/519/547)과 집단을 고르는 기준 한 문장을 본문으로 꺼냅니다. 두 환자 예(527/667)와 "같은 비라도…" 굵은 문장 바로 뒤에 두면 자연스럽습니다. 코드와 15장 연결은 접힌 채로 둡니다.

**⑬ c. 비용의 회귀분석 · 다른 모형으로 하면 얼마가 나오나? ↔ 3. 로그 변환 회귀의 결과를 금액으로 되돌리면?**
- 문제: 표 21-7의 로그 변환 두 행(그대로, smearing)이 설명보다 먼저 나옵니다. 그래서 "뒤에서 봅니다"가 도입 문단, 표 각주, 세 번째 글머리에 세 번 반복됩니다. 반면 재변환 소제목은 가정이라기보다 계산 방법 설명이어서 3단계에 둘 이유가 약합니다.
- 방향: '로그 변환 회귀의 결과를 금액으로 되돌리면?'을 2단계로 옮겨 표 21-7 바로 앞에 둡니다. 그러면 표가 설명된 값만 담게 됩니다. b 절 연습문제 2의 답이 가리키는 위치도 함께 고칩니다.

**⑭ c. 비용의 회귀분석 · 0원이 많은 입원비는 어떻게 하나?**
- 문제: 이단계 모형 설명 안에 장 전체의 일반 원리("금액을 정하는 것은 평균 구조, 분포는 표준오차")가 들어 있습니다. 이 원리는 아직 나오지 않은 포아송 GLM 521만원(3단계 접힌 상자)과 '비가 모든 환자에게 같다는 가정'(3단계)을 근거로 삼습니다. 637 대 645 비교도 곁가지입니다. 나중에 '내 연구에서 분석하기'의 모형 고르는 순서 3번이 이 원리에 기대므로, 입원비 소제목에 묻혀 있으면 찾기 어렵습니다.
- 방향: 입원비 소제목은 이단계 모형과 세 모형의 금액 비교까지만 다룹니다. '분포를 바꿔도 금액이 비슷한 이유'는 3단계의 '비가 모든 환자에게…'와 점검 상자 뒤에 독립 소제목으로 옮깁니다. 그 자리에서는 포아송 521만원이 이미 나온 값이 됩니다.

**⑮ c. 비용의 회귀분석 · 5. 내 연구에서 분석하기 · 모형의 비용 입력값으로는 어떻게 넘기나?**
- 문제: 비율의 부트스트랩 표준오차라는 새 방법이 체크리스트 절 맨 뒤에 처음 나옵니다. 그런데 그 결과(표준오차 1.0)는 앞의 개요 표, 코드 출력, '계산한 뒤' 표에서 이미 쓰입니다. 표에는 "마지막 줄은 다음 소제목에서 풉니다"라는 안내까지 붙어 있습니다. a 절도 이 소제목을 앞으로 볼 곳으로 가리킵니다.
- 방향: 이 소제목을 c 절 '4. 결과 읽기' 앞에 독립 단계로 옮기거나, 5단계의 첫 소제목으로 올립니다. 체크리스트와 코드에는 이미 설명한 값만 남게 합니다.

**⑯ c. 비용의 회귀분석 · 5. 내 연구에서 분석하기 / 6. 논문에 쓰기**
- 문제: 같은 내용이 여러 겹으로 겹칩니다.
  - 개요 표와 '분석 전에 무엇을 정하나'의 산문이 같은 내용을 반복합니다.
  - '기본값이 결과를 조용히 바꾸는 곳 다섯 군데'는 세 접힌 상자의 숫자를 그대로 다시 씁니다.
  - '무엇을 보고하나'는 a·b·c 절 '논문에 쓰기'의 목록을 다시 모읍니다.
  - 6의 '보고할 것 다섯 가지'가 또 이어집니다.
  - 세 절 예문 전문이 다시 나옵니다.

  독자는 이 절에서 무엇이 새로운지 알 수 없습니다.
- 방향:
  - 개요 표와 산문 가운데 하나를 남깁니다.
  - '무엇을 보고하나'와 6의 목록을 하나로 합칩니다.
  - 이은 Methods 전문은 접힌 상자로 넣습니다. 내용은 a·b·c 절 예문에 그대로 남습니다.
  - 기본값 다섯 군데는 숫자 없이 한 줄씩 적고, 상세는 각 접힌 상자로 안내합니다.

### 5. 반복되는 버릇

1. **굵은 첫 문단과 굵은 '즉' 마무리가 같은 말을 되풀이합니다.** a 1, b 1, c 1, a 3에서 '즉' 문장이 굵은 첫 문단을 거의 그대로 다시 씁니다. b 3의 중도절단 부분에는 짧은 거리에 '즉'이 세 번(본문 두 번, KM 상자 한 번) 나옵니다.
   - 방향: 굵은 첫 문단은 번호 소제목에만 둡니다. '즉'은 계산에서 결론을 끌어낼 때만 남깁니다(a 2 월 비용의 '즉'은 좋은 예). 틀에 맞춰 넣은 것으로 보입니다.

2. **[규칙 때문] 다른 곳 안내를 소제목 제목 전체로 괄호에 넣습니다.** 예: "(a 절 '모형에 넣는 상태별 월 비용은 어떻게 구하나?')", "(접힌 상자 '모형이 자료에 맞는지는 어떻게 점검하나?')". 한 문장에 둘씩 들어가 문장이 길어지고, 안내만으로 된 문단까지 생깁니다(a 1 마지막 문단, a 2 '이 자료는 모의 자료라서…' 문단).
   - 방향: 같은 절 안은 "앞에서", "뒤의 점검 상자에서"처럼 짧게 씁니다. 다른 절은 처음 한 번만 제목을 적고, 그다음부터는 절 이름만 씁니다.

3. **"…은 아래 접힌 상자에 있습니다"가 거의 모든 소제목 끝에 붙습니다.** 그 앞에는 늘 "프로그램에 넣는 것은 … 나오는 것은 …" 문단이 옵니다.
   - 방향: 접힌 상자의 제목이 이미 안내 역할을 하므로 이 문장은 대부분 뺄 수 있습니다. 상자 안 내용이 본문 이해에 필요할 때만 이유를 한 마디 붙입니다.

4. **[규칙 때문] 지시어 대신 긴 개념 이름을 연달아 되풀이합니다.**
   - 예: '환자별 비의 평균'과 '합계끼리 나눈 값'이 a 2 잠깐 확인의 답과 접힌 상자에서 문장마다 반복됩니다. "끊긴 환자를 빼고 구한 평균은 끊기지 않았을 때의 평균보다"(b 3)도 같은 경우입니다.
   - 방향: 문단 안에서 처음 한 번만 전체 이름을 쓰고, 그다음은 "이 값", "앞의 방법"으로 받습니다.

5. **[규칙 때문] 숫자가 다시 나올 때마다 이름과 출처를 다시 붙입니다.** 예: "청구자료로 구한 1년 비용 차이 396만원(b 절)", "무진행 상태의 월 비용 38.0만원".
   - 방향: 한 소제목 안에서 두 번째부터는 숫자만 써도 충분합니다.

6. **[규칙 때문] 인과나 대비로 이어질 문장을 따로 끊습니다.**
   - 예: "…요구합니다(지침 5쪽). 기본 분석에 넣는 비용도 … 요구합니다"(a 1). "표본을 늘려도 감마 GLM은 6%쯤 큽니다. 선형회귀도 2%쯤 큽니다."(40만 명 상자).
   - 방향: '-고', '-어서', '-지만'으로 묶어 짧은 문장과 긴 문장이 섞이게 합니다.

7. **[규칙 때문] '~하도록 요구합니다'가 줄줄이 이어집니다.** a 3 등에서 지침 문장마다 같은 서술어로 끝납니다.
   - 방향: 권고 수준은 바꾸지 않고 문장 틀만 바꿉니다. 예: "지침의 요구는 세 가지입니다. 첫째 …".

8. **"논문에서는 ~를 봅니다/확인합니다"로 소제목을 닫습니다.** a 3, b 3, c 3의 거의 모든 소제목이 이렇게 끝납니다. 쓸모 있는 문장이지만 같은 틀이 반복되어 무게가 줄어듭니다.
   - 방향: 각 가정 소제목에서는 빼고, '결과 읽기' 해설에 모읍니다.

9. **비교표의 행과 열이 섞여 있습니다.** b 3 장단점 표와 c 3 네 모형 표에서는 '장점', '단점' 같은 행 이름이 첫 방법의 열에 들어가 있습니다. 그래서 어느 칸이 어느 방법인지 헷갈립니다.
   - 방향: 첫 열을 항목(뜻, 장점, 단점, 논문 표현)으로 두고, 방법을 열로 놓습니다.
