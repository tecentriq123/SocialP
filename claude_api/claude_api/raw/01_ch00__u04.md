### 4. 문단 다시 쓰기

- **위치**: d · 3. 헷갈리는 점 · 그러면 평균은 어떤가?
- **원문 첫 문장**: 여러 환자의 값을 평균 낸 *표본평균*은 다릅니다.
- **다시 쓴 문단**:
  여러 환자의 값을 평균 낸 *표본평균*은 사정이 다릅니다. 표본이 크면 원래 자료가 치우쳤더라도 표본평균은 정규분포에 가깝게 흩어집니다. 여기서 '흩어진다'는 것은 같은 크기의 표본을 되풀이해 뽑을 때마다 표본평균이 조금씩 다르게 나와, 그 값들이 하나의 분포를 이룬다는 뜻입니다. 왜 그런지 의료비로 따라가면 다음과 같습니다.
- **무엇을 바꿨나**: 원문은 '다릅니다'를 말한 뒤 준비 설명을 먼저 하고, 무엇이 다른지는 셋째 문장에서야 밝혔습니다. 다시 쓴 문단은 결론을 '다릅니다' 바로 뒤에 두고, '표본평균의 분포'라는 낯선 개념은 그 뒤에 풀었습니다. 마지막 문장에는 '왜 그런지'를 넣어 다음 목록이 이 주장의 이유라는 것을 미리 알렸고, 짧은 문장과 긴 문장이 번갈아 나오도록 리듬을 맞췄습니다.
