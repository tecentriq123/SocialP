### 4. 문단 다시 쓰기

- **위치**: c 절 · 스스로 확인하기 4 · 답과 풀이

- **원문 첫 문장**: 0.78 × 0.623 + 0.45 × 0.047 − 0.004 = 0.503입니다.

- **다시 쓴 문단**:

  증분 QALY는 0.78 × 0.623 + 0.45 × 0.047 − 0.004 = 0.503입니다. 기준 분석의 0.511보다 줄었고, ICER는 5,621만원에서 5,710만원/QALY로 조금 올라갑니다. 줄어든 것은 공통 예시의 신약 A가 진행 상태로 보내는 기간을 0.047년 늘리기 때문입니다(표 22-5). 진행 효용은 진행 기간의 차이에 곱해지므로, 이 차이가 양수인 약에서는 진행 효용이 낮아질수록 증분 QALY가 줄어듭니다. 그래서 움직이는 방향은 신약이 진행 상태로 보내는 기간을 줄이는지 늘리는지에 달려 있습니다. 신약 A처럼 생존도 함께 늘려 진행 기간이 오히려 길어지는 약은 진행 효용이 낮을수록 불리해집니다. 반대로 생존은 그대로 두고 진행만 늦추는 약은 진행 기간이 줄어들므로, 진행 효용이 낮을수록 증분 QALY가 커져 신약에 유리합니다. 방향을 짐작하지 말고, 문헌값으로 계산했다면 같은 시험 자료로 추정한 값(본문 예시에서는 0.62)으로 바꿔 ICER가 얼마나 달라지는지를 민감도 분석에서 확인해야 합니다.

- **무엇을 바꿨나**: 원문은 0.503을 구한 뒤 일반 원리로 갔다가 다시 신약 A의 0.503으로 돌아오는 원형 구조였습니다. 이를 "이 예의 답(0.503, ICER) → 왜 줄었나 → 일반 원리 → 두 종류의 약 → 권고" 순서로 펴서, 같은 숫자를 두 번 꺼내지 않게 했습니다. 문제 본문에 이미 있는 식의 되풀이는 지우고 "진행 기간의 차이에 곱해지므로"라는 한 구절로 이유만 남겼습니다. 마지막 문장은 0.45에서 0.62로 바꾼다는 방향이 드러나게 했습니다.
