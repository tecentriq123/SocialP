### 4. 문단 다시 쓰기

- **위치**: f.중심극한정리 · 2. 숫자로 따라가기 · 인원을 늘리면 평균의 분포는 어떻게 바뀌나?
- **원문 첫 문장**: n = 1이면 표본평균이 곧 환자 한 명의 값이므로 모집단 분포 그대로이고, n = 5에서도 오른쪽 꼬리가 뚜렷합니다.
- **다시 쓴 문단**:

  n = 1이면 표본평균이 곧 환자 한 명의 값이므로 모집단 분포가 그대로 나오고, n = 5에서도 오른쪽 꼬리가 뚜렷합니다. n = 30에서는 종 모양에 가까워집니다. 그래도 오른쪽 꼬리는 남아 있고, n = 100이 되어 시뮬레이션 그림의 주황색 정규곡선에 훨씬 가까워진 뒤에도 꼬리가 조금 남습니다. 치우친 정도를 숫자로 보면, 표본평균의 왜도가 n이 커질수록 0에 가까워집니다(다음 소제목의 표). 평균들이 흩어지는 폭인 표준오차도 함께 작아져, n = 30에서는 33.6 ÷ √30 = 6.1만원, n = 100에서는 3.36만원입니다.

- **무엇을 바꿨나**:
  - 원문은 '가까워지지만 … 남아 있습니다', '가까워지지만, … 남습니다'로 같은 꼴의 문장을 두 번 이었습니다. 이를 '종 모양에 가까워진다'는 짧은 문장과 '그래도 꼬리가 남는다'는 긴 문장으로 나눠 리듬을 살렸습니다.
  - 소제목을 건너가 있는 표를 '아래 표'라고 한 곳은 '다음 소제목의 표'로 바꿨습니다. 처음 나오는 '주황색 정규곡선'에는 '시뮬레이션 그림의'를 붙여 독자가 무엇을 찾아야 하는지 알게 했습니다. 텍스트판에 그 그림 자리가 있는지는 문장 수정표의 해당 행에 따로 적었습니다.
  - 때를 가리키는 '그동안'은 n과의 관계를 바로 보여 주는 '함께'로 바꿨습니다. '표준오차도 좁아져'는 주어에 맞게 '작아져'로 고쳤습니다.
