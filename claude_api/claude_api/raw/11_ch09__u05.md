### 4. 문단 다시 쓰기

- **위치**: 더 알아보기(수식으로 보기) · 우도, 이탈도, 우도비 검정의 마지막 문단
- **원문 첫 문장 (그대로 옮김)**: 자유도 1 카이제곱 분포의 95% 분위수가 3.84이므로, 프로파일 우도 신뢰구간은 로그 우도가 꼭대기보다 3.84 ÷ 2 = 1.92 낮아지는 두 지점입니다.
- **다시 쓴 문단**:

  같은 로그 우도에서 신뢰구간도 구합니다. 우도비 χ²는 이탈도의 차이, 곧 로그 우도 차이의 2배이고, 자유도 1 카이제곱 분포의 95% 분위수는 3.84입니다. 그래서 로그 우도가 꼭대기보다 3.84 ÷ 2 = 1.92 낮아지는 두 지점이 프로파일 우도 신뢰구간의 두 끝이 됩니다. 한편 Wald 검정은 z = β̂/SE를 표준정규분포와 비교합니다. 이 검정에 숫자를 넣은 계산은 '다른 변수를 보정하면'의 '보정 오즈비는 누구와 누구를 비교한 값인가?'와, '결과 읽기'의 접힌 상자 '프로그램 출력을 한 줄씩 읽으면?'의 해설 3에 있습니다.

- **무엇을 바꿨나**:
  - 원문은 AIC 계산 바로 뒤에서 예고 없이 신뢰구간으로 넘어갑니다. 그래서 첫 문장으로 넘어가는 이유를 밝히고, '÷ 2'의 근거를 위 식(D = −2 ln L)에서 이어 주었습니다.
  - '구간 = 두 지점'처럼 읽히던 표현을 '구간의 두 끝'으로 바로잡았습니다.
  - Wald 검정은 '한편'으로 다른 방법임을 알렸고, 본문보다 길던 괄호 안내는 독립된 문장으로 빼서 짧은 문장과 긴 문장이 번갈아 오게 했습니다.
