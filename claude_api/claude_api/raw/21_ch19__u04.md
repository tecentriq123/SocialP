### 4. 문단 다시 쓰기

- **위치**: c 절 · 이질성이 크면 무엇을 고르나? · 평균의 신뢰구간은 어떤 방법으로 구하나?(두 방법의 정의 다음, 계산 네 줄 바로 앞 문단)
- **원문 첫 문장**: 예제(REML)로 두 방법을 따라가 봅니다.
- **다시 쓴 문단**:

  예제(REML)로 두 방법을 따라가 봅니다. b 절에서 구한 무작위효과 통합값은 −0.197, 표준오차는 0.067입니다. 보통의 방법은 여기에 1.96을 곱하면 끝나지만, HKSJ는 먼저 q를 구해야 합니다. τ² = 0.0138을 넣은 가중치로 일반화 Q를 다시 재면 7.52로, 자유도 9보다 작습니다. 일반화 Q는 분모에 '표준오차² + τ²'가 들어 있어 τ²가 클수록 작아집니다. 이 예에서 일반화 Q가 9와 같아지는 τ²는 PM 방법의 값 0.0077입니다. REML의 0.0138은 그보다 크므로, 일반화 Q가 9 아래로 내려간 것입니다. 시험들이 REML의 τ²가 가정한 것보다 조금 덜 흩어져 있다는 뜻입니다.

- **무엇을 바꿨나**: 원문은 '일반화 Q', '자유도 9', 'PM의 τ² 0.0077'을 네 문장에 걸쳐 거듭 써서, 같은 비교를 두 번 읽는 느낌이 들었습니다. 일반화 Q를 왜 다시 재는지(q를 구하려고)를 한 마디로 먼저 짚어 숫자의 목적을 보였습니다. 이어 'τ²가 크면 Q가 작다 → 9에 맞는 값은 0.0077 → REML 값은 더 크다 → 그래서 9 아래'가 한 줄기로 이어지게 했습니다. 숫자와 결론, 단정의 강도는 그대로입니다.
