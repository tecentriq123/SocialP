### 4. 문단 다시 쓰기

- **위치**: c 절 · 2. 신세포암 예시로 따라가기 · 0원이 많은 입원비는 어떻게 하나? (1부·2부 표 바로 아래 문단)
- **원문 첫 문장 (그대로 옮김)**: 두 부분을 합칠 때는 환자마다 "입원비가 생길 확률 × 생겼을 때의 평균 비용"을 곱합니다.
- **다시 쓴 문단**:

  두 부분을 합치는 계산은 환자 한 명씩 합니다. 한 환자의 예측 입원비는 "입원비가 생길 확률 × 생겼을 때의 평균 비용"입니다. 표준요법 B를 쓰는 64세, 동반질환 점수 1점인 4기 남성 환자라면 0.639 × 1,155 = 738만원입니다. 모든 환자를 A로 놓고, 또 B로 놓고 이 곱을 환자마다 계산해 평균하면 A 645만원, B 716만원입니다. 곱한 뒤에 평균하는 이 순서가 중요합니다. 모두 A로 놓았을 때 확률의 평균(0.603)과 비용의 평균(1,056만원)을 먼저 구해 곱하면 약 637만원으로, 환자마다 곱한 645만원보다 작습니다. 동반질환이 많거나 4기인 환자는 입원할 확률도, 입원했을 때의 비용도 커서 두 값이 같은 환자에게서 함께 커지기 때문입니다.

- **무엇을 바꿨나**:
  - 첫 문장이 '환자 한 명씩 합친다'는 문단의 요점을 먼저 알리도록 바꿨습니다. 원문의 '환자마다 … 곱을 곱합니다'처럼 겹친 서술도 풀었습니다.
  - 원문에서는 '확률의 평균과 비용의 평균을 먼저 곱하면'이 예고 없이 나옵니다. 그래서 왜 이 계산을 하는지, 0.603과 1,056이 어느 군의 값인지 다시 읽어야 했습니다. '곱한 뒤에 평균하는 순서가 중요하다'는 이음 문장을 넣고, 두 값이 '모두 A일 때'의 값임을 밝혔습니다.
  - 원문의 '더 작습니다'가 무엇보다 작은지(645만원)를 문장 안에 적어, 독자가 앞 문장의 숫자로 돌아가지 않게 했습니다.
