- **위치**: d.이중차분법 · 3. 흔한 함정과 확인할 것 · 1번 항목
- **원문 첫 문장 (그대로 옮김)**: **시행 전 추세 검정의 P로 평행 추세를 '확인'했다고 쓰는 것.**
- **다시 쓴 문단**

**시행 전 추세 검정의 P로 평행 추세를 '확인'했다고 쓰는 것.** 이렇게 쓰면 안 되는 이유는 두 가지입니다. 첫째, 유의하지 않다는 것은 차이를 찾지 못했다는 뜻일 뿐이고(0장 f 절 'p값은 어떻게 잘못 읽히나?'), 자료가 적으면 꽤 큰 추세 차이도 유의하지 않게 나옵니다. 둘째, 검정이 보는 것은 시행 전 기간인데 가정은 시행 후에 대한 것입니다. 그래서 이 예의 P = 0.88도 평행하다는 증명이 아닙니다. 이 예의 결론을 믿을 근거는 P가 아니라, '평행 추세는 무엇이고 어떻게 점검하나?'에서 계산한 치우침의 범위(−1.1 ~ 1.0)가 효과 −7.40에 비해 작다는 데 있습니다.

논문을 읽을 때는 Methods와 Results에서 "confirmed" 같은 말 대신 사전 추세 차이의 신뢰구간과 사건연구 그림을 제시했는지, "가정과 모순되는 증거가 없다"까지만 말했는지 봅니다. Discussion에서는 평행 추세가 깨지는 네 경우를 검토했는지도 봅니다. 한 집단만 다른 변화를 겪었을 때, 두 집단의 환자 구성이 다르게 바뀌었을 때, 값이 높아서 뽑힌 지역을 골랐을 때(평균으로의 회귀는 고른 쪽에서만 일어남), 정책의 영향이 비교 집단으로 번졌을 때입니다.
