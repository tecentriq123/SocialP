### 4. 문단 다시 쓰기

- **위치**: b 절 7. 논문에 쓰기 · 스스로 확인하기 4 · 답과 풀이 첫 문단
- **원문 첫 문장**: 먼저 경향의 방향입니다.
- **다시 쓴 문단**:

  먼저 경향의 방향입니다. U = 5는 3번 문제에서 구한 프로토콜군 기준의 U₁이고, 일반 관리군 기준이면 15입니다. 이 값을 전체 쌍의 수 5 × 4 = 20으로 나눈 우월 확률 0.25는, 두 군에서 한 명씩 뽑으면 프로토콜군 환자가 더 많이 썼을 확률이 25%라는 뜻입니다. 0.5보다 작으니 프로토콜군 쪽이 덜 쓰는 방향이고, 본문 예제와 방향이 같습니다. 다음은 차이의 크기입니다. −11.5 MME는 20쌍의 사용량 차이(프로토콜 − 일반)의 중앙값으로, 두 중앙값의 차이 19 − 31.5 = −12.5와는 다른 값입니다. 그런데 95% 신뢰구간이 38 MME 덜 쓰는 쪽부터 10 MME 더 쓰는 쪽까지 걸쳐 있어서, 9명으로는 차이의 크기는 물론 방향도 정하기 어렵습니다. P를 보아도 0.29라 같은 결론입니다. 마지막으로 임상적 의미까지 따지면, 이 결과는 "프로토콜군이 덜 쓰는 방향이었지만, 이 작은 자료로는 우연에 의한 차이와 구분할 수 없고 차이의 크기도 거의 알 수 없다"로 읽습니다.

- **무엇을 바꿨나**: 문제는 '결과 읽기'의 네 단계를 따라 읽으라고 했습니다. 그런데 원문은 '먼저', '다음으로'까지만 표시하고 P와 임상적 의미는 '그래서' 한 문장에 섞어 버려, 독자가 네 단계가 어디서 끝나는지 놓쳤습니다. P와 임상적 의미에도 단계 표시를 붙였습니다. 또 '0.25이므로 …25%'처럼 같은 값을 원인과 결과로 이은 부분은 '0.25는 …라는 뜻'으로 바꾸고, '쌍의 수'는 '전체 쌍의 수'로 구분했습니다.
