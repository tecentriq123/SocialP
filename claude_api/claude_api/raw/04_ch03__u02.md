  **Table 2: 시점별 평균 ± SD와 평균 변화.** HbA1c 평균(괄호 안은 SD)은 기저 9.7 (1.5)%에서 수술 당일 7.9 (1.3)%로 내려갔고, 평균 변화는 −1.9%p (95% CI −2.2 to −1.5), P \< 0.001입니다. 환자별로 보면 77명 중 72명이 내려갔고 1명은 그대로, 4명은 올라갔습니다.
