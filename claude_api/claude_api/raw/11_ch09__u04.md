### 4. 문단 다시 쓰기

- **위치**: 10. 예측모형으로 쓸 때 · 스스로 확인하기 3 · 답과 풀이

- **원문 첫 문장**: 먼저 모든 대상자를 같은 기간 끝까지 관찰했는지, 그리고 자료가 짝지어져 있는지를 구분합니다.

- **다시 쓴 문단**:

  세 연구는 두 가지로 가릅니다. 모든 대상자를 같은 기간 끝까지 관찰했는지, 그리고 자료가 짝지어져 있는지입니다.

  (가)는 모두 7일 동안 끝까지 관찰했으므로 로지스틱 회귀가 맞습니다. 걸리는 것은 사건 수입니다. 추정할 계수는 병용 1, 나이 1, 성별 1, CCI 3, eGFR 스플라인 3, 심부전 1, 교호작용 1로 모두 11개입니다. 그래서 계수 하나당 사건 수(EPV)는 85 ÷ 11 = 7.7입니다. EPV 10은 대략의 경험칙이고, 교란 보정이 목적이면 5–9에서도 대체로 괜찮다는 연구가 있습니다. 그래도 여유 있는 수는 아닙니다. 그래서 CCI 범주나 스플라인 매듭 수를 사전 지식으로 줄이거나, 성향점수로 교란변수를 요약하는 방법을 고려하고, 신뢰구간이 지나치게 넓은 계수가 없는지 확인합니다. AKI가 7.1%로 드문 편이라 오즈비와 상대위험도의 차이는 크지 않습니다.

  (나)는 추적 기간이 사람마다 다르고 중도절단이 있습니다. 이런 자료에서는 '입원 여부'를 로지스틱 회귀에 넣으면 안 되고, 사건까지의 시간을 다루는 Cox 모형(11장)을 씁니다. 입원을 가로막는 사망은 경쟁위험으로 따로 다룹니다(17장).

  (다)는 짝지은 환자-대조군 자료이므로 조건부 로지스틱 회귀를 씁니다('가정과 대안'의 접힌 상자 '짝지어 뽑았거나 결과가 셋 이상이면 어떤 모형을 쓰나?'). 짝을 무시한 보통의 로지스틱 회귀나 짝마다 가변수를 넣은 모형은 오즈비가 치우칩니다. 환자-대조군 설계에서는 위험을 구할 수 없으므로 결과는 오즈비로만 보고합니다.

- **무엇을 바꿨나**:
  - 세 연구를 한 덩어리로 이어 붙여 (나), (다)의 시작이 묻혀 있었으므로, 판단 기준을 먼저 세우고 연구마다 단락을 나눴습니다.
  - (가)에서 '…있지만, 여유가 없으므로 … 고려하고, … 확인합니다'로 길게 이어진 문장을 근거, 판단, 대응의 세 문장으로 끊었습니다. '걸리는 것은 사건 수입니다'로 무엇을 따질지 먼저 알렸습니다.
  - 숫자, 조건, 단정의 강도('대체로', '고려하고')는 그대로 두었습니다. EPV 이름만 앞에서 정의한 뜻('계수 하나당 사건 수')으로 바꿨습니다.
