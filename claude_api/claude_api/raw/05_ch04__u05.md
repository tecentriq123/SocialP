### 4. 문단 다시 쓰기

- **위치**: c. 사후분석 · 스스로 확인하기 2 (답과 풀이)
- **원문 첫 문장**: Dunnett 방법은 각 처치군을 대조군과만 비교하므로 두 상담군끼리는 비교하지 않았습니다.
- **다시 쓴 문단**:

  Dunnett 방법은 각 처치군을 대조군과만 비교하므로, 두 상담군끼리는 처음부터 비교하지 않았습니다. 그렇다고 두 P를 나란히 놓고 판단할 수도 없습니다. 두 P는 각 상담군을 같은 대조군과 따로 견준 결과일 뿐이라, 한쪽은 유의하고 다른 쪽은 유의하지 않다는 사실이 두 효과가 서로 다르다는 증거가 되지 않습니다. 실제로 같은 자료에서 집중 상담 − 1회 상담을 직접 비교하면 차이는 2.77%p, Tukey P = 0.636입니다. 그래서 "집중 상담은 일반 복약지도보다 PDC가 8.6%p 높았고, 1회 상담과 일반 복약지도의 차이 5.8%p는 유의하지 않았다. 두 상담군끼리는 비교하지 않았다"로 고쳐 씁니다. 두 상담군의 비교가 궁금했다면 처음부터 그 쌍을 포함하는 방법(Tukey 등)을 계획해야 합니다.

- **무엇을 바꿨나**: 원문은 "비교하지 않았다 → 유의 여부 차이는 증거가 아니다 → 대조군을 공유하므로 판단할 수 없다"를 같은 무게의 세 문장으로 나란히 놓았습니다. 그래서 둘째와 셋째 문장이 같은 말을 두 번 하는 것처럼 읽혔습니다. 다시 쓴 문단에서는 "직접 비교하지 않았다"와 "두 P를 견주어도 안 된다"를 두 단계로 나누고, '그렇다고'와 '그래서'로 이어서 논리의 순서가 보이게 했습니다.
