### 4. 문단 다시 쓰기

- **위치**: c 절 · 스스로 확인하기 1번 · 답과 풀이(계산 줄 다음 문단)
- **원문 첫 문장 (그대로 옮김)**: 첫 번째는 높은 이질성입니다.
- **다시 쓴 문단**:

  첫 번째는 I² 83%로 이질성이 높습니다. 두 번째의 I² 5%는 낮아 보이지만, 연구가 5개뿐이어서 이 I²의 95% 신뢰구간은 0–80%에 이릅니다. 낮은 I²와 유의하지 않은 Q 검정은 이질성이 없다는 증거가 되지 못하므로, 두 번째 메타분석에 대해 "이질성이 없으므로 효과가 일관된다"고는 쓸 수 없습니다. 쓸 수 있는 문장은 "통계적 이질성의 증거는 관찰되지 않았다(I² = 5%), 다만 연구 수가 적어 이질성을 가려낼 검정력이 낮다" 정도입니다. 이와 함께 포레스트 플롯에서 연구들의 신뢰구간이 서로 겹치는지, 방향이 같은지를 눈으로도 확인합니다.

- **무엇을 바꿨나**:
  - 원문은 '첫 번째' 바로 뒤에 '그러나 … 이 I²'를 붙였습니다. 그래서 0–80%가 첫 번째(I² 83%)의 구간으로 읽혔습니다. 두 번째로 넘어간다는 표시를 넣어 숫자와 대상을 맞췄습니다.
  - 질문은 "쓸 수 있는가"였는데 원문은 판단을 일반론으로만 남겼습니다. 이 판단을 근거 문장과 한 문장으로 이어 답이 먼저 보이게 했습니다.
  - 마지막 두 문장은 '쓸 수 있는 문장'에서 '함께 확인할 것'으로 넘어가는 흐름이 보이도록 이었습니다. 새 숫자는 넣지 않았고, 83%는 바로 위 계산 줄의 값입니다.
