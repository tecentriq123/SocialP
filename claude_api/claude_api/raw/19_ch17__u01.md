### 4. 문단 다시 쓰기

- **위치**: a-3 흔한 함정과 확인할 것 · 접힌 상자 '성향점수로 보정한 누적발생함수는 어떻게 구하나?'의 둘째 문단

- **원문 첫 문장**: lifelines 0.30은 정수가 아닌 가중치를 받으면 분산 추정이 치우친다는 경고를 내고, 가중 누적발생함수를 계산합니다.

- **다시 쓴 문단**

  가중 누적발생함수 자체는 lifelines 0.30이 계산해 주지만, 출력의 신뢰구간은 그대로 쓰지 않습니다. 정수가 아닌 가중치를 받으면 lifelines는 분산 추정이 치우친다는 경고를 낸 뒤 계산을 이어 갑니다. 이때 나오는 신뢰구간은 가중치를 사람 수처럼 세어 구한 것입니다. 예를 들어 B군의 가중치를 모두 2로 두면 누적발생률은 24.5% 그대로인데 구간만 22.7–26.5%에서 23.2–25.9%로 좁아집니다. 그래서 신뢰구간과 두 군 차이의 구간은 부트스트랩으로 구합니다. 환자를 복원추출로 다시 뽑을 때마다 성향점수 모형부터 다시 적합해 가중 누적발생함수를 구하고, 이를 1,000번쯤 반복해 얻은 값의 2.5번째와 97.5번째 백분위수를 씁니다.

  이 반복을 코드로 짤 때는 두 가지를 지킵니다. 첫째, 다시 뽑는 표본은 `np.random.default_rng`로 만든 난수 생성기로 뽑습니다. 같은 날 사건이 있어 시간을 옮길 때 `AalenJohansenFitter(seed=1)`은 NumPy 전체의 난수 시드를 매번 같은 값으로 초기화합니다. 그래서 `np.random.choice`나 `DataFrame.sample`로 뽑으면 둘째 반복부터 똑같은 표본이 나옵니다. 둘째, 다시 뽑은 표본은 `reset_index(drop=True)`로 행 번호를 새로 매깁니다. 행 번호가 겹친 표를 그대로 넣으면 시간을 옮기는 단계에서 오류가 납니다.

- **무엇을 바꿨나**

  원문은 첫 문장이 경고 이야기로 시작해서, 이 문단의 요지(출력 구간을 쓰지 않고 부트스트랩으로 구한다)가 넷째 문장에서야 나왔습니다. 그래서 요지를 첫 문장으로 올렸습니다. 원문에서는 코드 지시 두 개(`default_rng`, `reset_index`)가 한 문장에 몰려 있고 그 이유는 맨 끝에 따로 떨어져 있었습니다. 이를 '첫째·둘째'로 지시와 이유를 짝지었고, '왜 부트스트랩인가'와 '코드에서 지킬 것'을 두 문단으로 나눠 숨 쉴 자리를 만들었습니다.
