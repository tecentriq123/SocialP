### 4. 문단 다시 쓰기

- **위치**: d · 2. 예제 코호트에서 따라가기 · 기존 사용자를 섞으면 무엇이 달라지나? (표 16-5 해설 다음 문단과 이어지는 번호 목록)
- **원문 첫 문장**: 약의 이득을 보는 연구에서는 같은 치우침이 반대 방향의 숫자로 나타납니다.
- **다시 쓴 문단**:

  같은 치우침이 약의 이득을 보는 연구에서는 비가 1에서 멀어지는 쪽으로 나타납니다. 그 까닭은 기존 사용자가 어떤 사람인지에서 출발하면 보입니다. 기존 사용자는 약을 시작한 직후의 이상반응과 치료 실패를 넘기고 약을 꾸준히 먹어 온 사람입니다. 그리고 약을 꾸준히 먹는 사람은 다른 건강 행동도 좋은 경우가 많아, 약과 무관하게 원래 사건 위험이 낮습니다(건강한 순응자 효과, 5장 c 절). 그래서 기존 사용자를 섞으면 위해 연구든 이득 연구든 약을 쓴 쪽의 발생률이 실제보다 낮게 나옵니다. 이 하나의 '낮아짐'이 비에서는 두 모습으로 드러납니다. 위해 연구에서는 1보다 큰 비가 1 쪽으로 줄고(표 16-5의 2.78 → 1.66), 이득 연구에서는 1보다 작은 비가 더 작아져 1에서 멀어집니다.

- **무엇을 바꿨나**:
  - 원문의 '반대 방향의 숫자'는 무엇이 반대인지 알 수 없었습니다. 이를 첫 문장에서 '1에서 멀어지는 쪽'으로 밝혀, 문단이 어디로 가는지 미리 알렸습니다.
  - 한 줄기 추론(어떤 사람이 남나 → 발생률이 낮아짐 → 비에서 두 모습)을 번호로 끊으면 단계 사이의 '왜'가 사라집니다. 그래서 산문으로 이어 쓰고, '그 까닭은', '이 하나의 낮아짐이'로 연결 고리를 드러냈습니다.
  - 원문은 첫 문장이 이득 연구만 말하다가 목록에서 위해·이득을 함께 다뤄 독자가 앞으로 돌아가게 했습니다. 다시 쓴 문단에서는 두 연구에 공통인 원인을 먼저 말하고 두 결과를 마지막 문장에서 나란히 놓았습니다. 숫자·조건·단정의 강도는 그대로입니다.
