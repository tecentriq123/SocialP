### 4. 문단 다시 쓰기

- **위치:** a. Pearson의 상관분석 · 6. 논문에 쓰기 · 접힌 상자 '상관계수가 주요 결과면 몇 명이 필요한가?'
- **원문 첫 문장:** "상관계수 0.3을 검출하려면 몇 명이 필요한가"도 Fisher z로 계산합니다.
- **다시 쓴 문단:**

  설문도구의 타당도 연구처럼 상관계수 자체가 주요 결과인 연구라면, 몇 명이 필요한지 계산한 내용이 Methods에 있어야 합니다. 이 계산도 신뢰구간처럼 Fisher z로 합니다. 상관계수 0.3을 양측 α = 0.05, 검정력 80%로 검출하려면 약 85명이 필요합니다(식은 '수식으로 보기'). 이보다 훨씬 적은 30명에서 r = 0.30을 얻었다면 p = 0.11이고, 95% CI는 −0.07에서 0.60까지입니다. 구간이 상관이 없는 경우부터 강한 상관까지 걸쳐 있어 어떤 결론도 내리기 어렵습니다.

- **무엇을 바꿨나:** 원문은 "~도 Fisher z로 계산합니다"로 시작합니다. 그래서 왜 이 계산을 하는지가 문단 맨 끝에야 나옵니다. 언제 필요한지를 첫 문장으로 올려, 이 문단에서 무엇을 할지 먼저 알 수 있게 했습니다. 85명과 30명 사이에 '이보다 훨씬 적은'을 넣어 예를 드는 이유를 이었습니다. 읽기 어려운 '−0.07–0.60'은 '−0.07에서 0.60까지'로 풀었습니다.
