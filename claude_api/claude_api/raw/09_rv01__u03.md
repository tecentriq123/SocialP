### 4. 문단 다시 쓰기

- **위치**: c. 틀린 해석 고쳐 쓰기 · 검정과 지표가 답하는 질문(8번 '답과 풀이'의 둘째 문단)
- **원문 첫 문장**: 오즈는 위험을 (1 − 위험)으로 나눈 값이라 위험이 클수록 위험보다 빠르게 커집니다.
- **다시 쓴 문단**:

  오즈비가 상대위험도보다 1에서 더 먼 까닭은, 두 군의 오즈를 위험과 나란히 놓아 보면 보입니다. 오즈는 위험을 (1 − 위험)으로 나눈 값이라, 위험이 클수록 위험보다 빠르게 커집니다. 부적절 약물 처방군은 위험이 0.36(36%)이고 오즈가 0.56이어서, 오즈가 위험의 1.56배로 커졌습니다. 비처방군은 위험이 0.20(20%)이고 오즈가 0.25여서, 위험의 1.25배로 덜 커졌습니다. 오즈비는 이 두 오즈의 비이므로, 상대위험도(0.36 ÷ 0.20 = 1.80)에 두 군이 커진 배수의 비(1.56 ÷ 1.25 = 1.25)를 곱한 2.25가 됩니다. 입원처럼 흔한 결과에서는 이렇게 오즈비가 상대위험도보다 1에서 더 멀어지므로, "2.25배"는 효과를 부풀립니다.

- **무엇을 바꿨나**:
  - 문단이 무엇을 보이려는지 알려 주는 첫 문장을 앞에 세웠습니다.
  - 한 문장에 몰려 있던 두 군의 '위험·오즈·배수'를 같은 틀의 두 문장으로 나눴습니다. 독자가 0.56과 1.56, 비처방군의 1.25와 배수의 비 1.25를 섞지 않고 따라갈 수 있습니다.
  - 지시어 '이 배수의 비'를 '두 군이 커진 배수의 비'로 풀었습니다. 숫자와 단정의 강도는 그대로 두었습니다.
