### 4. 문단 다시 쓰기

- **위치**: b 절 · 모형의 두 효용은 어디서 나왔나?(표 바로 아래 문단)
- **원문 첫 문장**: 두 가지를 정하고 계산했습니다.
- **다시 쓴 문단**:

  평균을 낼 때 두 가지를 정했습니다. 첫째, 두 군의 응답을 합쳐 평균을 냈습니다. "같은 건강상태에 있으면 어느 약을 쓰든 효용이 같다"고 가정한 것이어서, 모형에서 두 약의 차이는 각 상태에 머무는 시간과 이상반응의 QALY 손실로만 반영됩니다. 이상반응의 QALY 손실은 효용 감소(disutility)에 발생률과 지속 기간을 곱한 값입니다('결과 읽기'의 Table 2 해설 3). 둘째, 한 환자가 여러 번 답했으므로 신뢰구간은 환자 단위로 묶어 계산했습니다. 같은 환자의 응답끼리는 닮아서, 1,593건이 서로 독립인 정보 1,593개가 아니기 때문입니다(10장 d 절).

  공통 예시 모형은 이 평균을 반올림한 0.78과 0.62를 씁니다. 모형에 넣은 표준오차 0.03과 0.05는 이 예시 모형이 가정한 값으로, 이 신뢰구간에서 나온 표준오차보다 넓게 잡았습니다('결과 읽기'의 Table 2 해설 2).

- **무엇을 바꿨나**:
  - 첫 문장이 '무엇을 정했는지'를 알리도록 고쳤습니다.
  - 가정과 그 결과를 한 문장으로 이어 '이는 … 것입니다 / 이 가정 아래에서'의 끊김을 없앴습니다.
  - 바로 앞 소제목에서 가치 세트의 계수를 뜻하던 '감점'을 'QALY 손실'로 바꿔 두 개념이 섞이지 않게 했습니다.
  - 계산의 두 선택(첫째·둘째)과 모형에 넣은 값(반올림, 표준오차)은 성격이 달라 문단을 나눴습니다. 그래서 '둘째' 뒤에 모형 이야기가 이어 붙는 흐름이 사라졌습니다.
