# 22장 효용과 QALY: 구성과 흐름 검토

### 1. 총평

- **두 출처의 숫자가 섞입니다.** 이 장에는 24개월 가상 시험과 23장의 20년 공통 예시 모형, 두 출처의 숫자가 a 절부터 섞여 나옵니다. 그런데 둘을 가르는 문장은 c 절 첫머리에야 나오고, 그 전에 a·b 절이 c 절의 분해 계산(0.511, 0.670, 0.623)을 앞당겨 씁니다.
- **개념 설명 도중에 다른 것이 끼어듭니다.** 프로그램 함정, 지침의 쪽수와 권고 강도, 다른 절·상자 안내가 끼어들어 논증이 자주 끊깁니다. 같은 경고가 장 안에서 네다섯 번 되풀이됩니다.
- **같은 말을 두세 번 듣게 됩니다.** 소제목마다 굵은 요약으로 열고 굵은 '즉'으로 닫으며, 그 사이를 짧은 문장과 번호 목록으로 채웠습니다. 그래서 문장 사이의 연결을 독자가 직접 메워야 합니다.

### 2. 흐름 문제

**① 장 첫머리 · 이 장의 흐름 / a. 건강 관련 삶의 질과 효용 · 1. 이 개념이 답하는 질문 / b. 효용을 재는 방법 · 1. 이 개념이 답하는 질문**
- 문제: 머리말은 가상 시험만 예시로 소개합니다. 그런데 a.1에서 "공통 예시 모형에서 … 0.86년"이 설명 없이 나오고, b.1은 아직 보이지 않은 "공통 예시 모형의 입력값 표"를 가리킵니다. 0.786, 0.117은 시험의 값이고 0.78, 0.511, 5,621은 모형의 값인데, "급여 평가에 쓰는 것은 이 24개월 값이 아니라 23장 모형의 20년 값"이라는 구분은 c.1 끝에야 나옵니다.
- 고칠 방향: c.1의 그 문장을 '이 장의 흐름'으로 옮겨 두 출처를 처음부터 밝힙니다. a·b에서 모형 숫자가 처음 나올 때는 '23장 모형의 값'임을 붙입니다. b.1은 "모형에 넣을 효용은 두 개입니다" 정도로 쓰고, 표는 b.4의 Table 2를 가리킵니다.

**② a · 1. 이 개념이 답하는 질문 / a · 3. 선택지와 그 영향 (도입 문단)**
- 문제: a.1에서는 두 환자 장면과 QALY 정의 바로 뒤에 행정 안내가 붙어 장면이 끊깁니다. 지침의 용어 대응, "이 장에서 '지침'은 …", 기준 판의 위치가 그것입니다. a.3에서도 선택지 셋을 꺼낸 뒤 첫 소제목에 들어가기 전에 권고 네 단계 설명이 끼어듭니다.
- 고칠 방향: 두 안내를 a.3 도입 뒤의 짧은 일러두기 하나로 묶고, a.1 문단은 QALY 정의에서 끝냅니다. 권고 네 단계와 용어 대응은 장 끝의 지침 표에 이미 있으므로, 본문에서는 처음 쓰는 곳에서 한 번만 밝힙니다.

**③ a · 3 · '어떤 설문으로 재나?' (표 22-1 뒤 넷째 문단)와 접힌 상자 'EQ VAS ÷ 100을 효용 자리에 넣으면 QALY와 ICER는 얼마나 달라지나?'**
- 문제: 상태별 효용(b)과 증분 QALY의 분해(c '증분 QALY는 어디서 생기나?')를 모르는 시점에 "0.158 대 0.096"이 나오고, 이 때문에 "이득이 작게 계산된다"고 씁니다. 상자 1번은 c의 분해 논리를 0.670년, 0.623년과 함께 먼저 설명해서 c 본문과 겹칩니다. FKSI 대신 EQ VAS로 시연하는 사정을 밝히는 문장도 흐름을 끊습니다.
- 고칠 방향: a에는 세 가지 이유와 "어느 쪽으로 틀릴지 미리 알 수 없다"는 결론만 둡니다. 숫자 시연 문단과 상자는 c '증분 QALY는 어디서 생기나?' 뒤로 옮기고, 상자 1번의 분해 설명은 c 본문을 가리키는 것으로 줄입니다.

**④ a · 3 · '누구의 선호로 값을 매기나?' (마지막 문단)**
- 문제: "증분 QALY가 커지는지 작아지는지는 약이 생존을 늘리는지에 달려 있다"는 질문을 열어 두고, 답은 c의 접힌 상자에만 있습니다. 독자는 이 시점에 증분 QALY가 어떻게 구성되는지 모르므로 여기서 멈춥니다.
- 고칠 방향: 이 문단은 "누구의 선호인지에 따라 효용이 달라지므로 가치 세트의 출처를 본다"로 닫습니다. 방향 문제는 c의 상자 '진행 상태의 효용이 높게(또는 낮게) 매겨지면 …'에서 처음 꺼냅니다. 그 상자의 첫 줄이 이미 a 절을 되짚고 있습니다.

**⑤ a · 2 · '한 설문지에서 어떤 숫자들이 나오나?' / a · 4. 결과 읽기**
- 문제: '다섯 영역'이 a에서 여러 번 나오지만 영역 이름은 b.2에서야 나옵니다. a.4의 Table 1에는 영어 영역명과 '11111'이 설명 없이 실려 있습니다.
- 고칠 방향: b.2의 영역 이름 문장을 a.2의 첫 등장 자리로 옮깁니다. 11111은 b.2의 "모든 영역에 문제가 없는 상태" 구절을 해설 ④에 함께 옮깁니다.

**⑥ b · 2 · '모형의 두 효용은 어디서 나왔나?' (표 뒤 문단)**
- 문제: 두 군을 합친 가정과 환자 단위로 묶은 신뢰구간을 설명하는 중간에 두 문장이 끼어듭니다. 하나는 이상반응 감점의 정의이고, 다른 하나는 모형 표준오차 0.03·0.05가 가정값이라는 내용입니다. 둘 다 b.4의 Table 2 해설로 앞질러 보내서, 한 문단이 다섯 가지 일을 합니다. 또 Table 2 해설 ②의 시험 표준오차 0.0074는 접힌 상자에만 나온 숫자여서, 상자를 펼치지 않은 독자는 해설에서 처음 보게 됩니다.
- 고칠 방향: 이상반응과 표준오차 가정값 문장은 해설 ②③에 이미 있으니 이 문단에서 뺍니다. 그러면 문단에는 가정과 군집 두 가지만 남습니다. 0.0074는 상자에서 본문 '프로그램에서는 …' 문단으로 한 번 옮깁니다.

**⑦ b · 3 · '어떤 도구, 어느 판인가?'의 21222 표와 '잠깐 확인' / '어느 가치 세트인가?'**
- 문제: 판을 다루는 소제목에서 나라 비교(영국 0.620, 차이 0.103)까지 먼저 합니다. 그 뒤 나라를 다루는 소제목의 표 22-3이 21222 줄을 다시 보여 줍니다. 0.142 대 0.103을 묻는 '잠깐 확인'도 나라 소제목보다 앞에 있습니다.
- 고칠 방향: 판 소제목의 표에는 한국 5L과 한국 3L만 둡니다. 영국 열과 표 아래 2번 항목, 그리고 '잠깐 확인'은 표 22-3 뒤로 옮깁니다.

**⑧ b · 3 · '상태마다 효용을 어디서 가져오나?' (표 뒤 첫 문단)**
- 문제: "그 차이가 마치 약의 효과인 것처럼 계산에 들어갑니다"라는 경고 바로 뒤의 예가 0.511에서 0.503으로의 작은 변화입니다. 그래서 경고의 무게와 숫자가 어긋나고, 왜 작은지는 c에서야 알 수 있습니다. 독자는 "그러면 별문제 아닌가"에서 멈춥니다.
- 고칠 방향: 숫자 예는 c의 '스스로 확인하기' 4와 c의 상자 쪽으로 넘기고, 여기에는 경고와 심평원 제출 자료 검토 수치만 둡니다. 숫자 예를 남긴다면 c 상자의 '진행만 늦추는 약' 결과를 함께 가리켜, 크기가 약의 성격에 따라 달라진다는 점을 보입니다.

**⑨ b 절 마무리 연결 문단 → c · 1. 이 개념이 답하는 질문**
- 문제: b 끝은 "모형의 효용 0.78과 0.62"를 시간에 곱한다며 c로 넘어갑니다. 그런데 c.1은 시험 자료의 24개월 결과표로 시작하고, 모형은 c.2의 넷째 소제목에서야 나옵니다.
- 고칠 방향: 연결 문단에 "먼저 시험의 환자마다, 이어서 모형에서"라는 순서를 밝힙니다. ①과 함께 고치면 됩니다.

**⑩ c · 2 · '프로그램에는 무엇을 넣고 무엇이 나오나?'**
- 문제: 사다리꼴 공식과 '곡선 아래 넓이'는 다음 소제목에서 설명합니다. 그런데 그 전에 `trapezoid`의 입력, 시점 인자, 빠진 방문의 함정을 먼저 다룹니다. "양옆을 직선으로 잇는다"는 설명은 그림 22-3을 보기 전에는 그려지지 않고, 다음 소제목 끝의 상자를 가리키기까지 합니다.
- 고칠 방향: 이 소제목을 '환자 한 명의 QALY는 어떻게 구하나?' 뒤로 옮기거나, 상자 '사다리꼴 공식 코드를 한 줄씩 읽으면?'의 머리에 합칩니다.

**⑪ c · 2 · '모형에서는 QALY를 어떻게 구하나?' (셋째 문단)**
- 문제: 한 문단에 상태 비율 세기, 반주기 보정(23장의 개념), 할인 계수, 달의 한가운데라는 기준 시점이 몰려 있습니다. 그래서 표 22-5의 '기간'이 무엇인지 잡히기 전에 할인까지 넘어갑니다.
- 고칠 방향: 상태 기간을 세는 문단과 할인 문단으로 나눕니다. 기준 시점의 세부는 '언제 생긴 QALY를 얼마나 할인하나?'에 맡깁니다.

**⑫ c · 3 · '사망과 빠진 응답은 어떻게 다루나?'**
- 문제: 첫 문단과 상자 '생존자만의 평균으로 계산하면 왜 틀리나?'가 같은 숫자(1.496, 1.411, 0.084)와 같은 결론을 되풀이합니다. 또 빠진 응답 부분을 마무리하는 굵은 '즉' 문장이 앞의 목록에 없던 "채운 값에서 일정량을 빼 보는 민감도 분석"을 처음 꺼냅니다. 이 내용은 상자 4번에만 있어서, 독자는 요약을 읽다가 멈춥니다.
- 고칠 방향: 상자에는 시점별 평균값만 남기고 결론은 본문에 맡깁니다. 민감도 분석은 목록 3번 뒤에 본문 한 줄로 올리고, '즉' 문장은 앞 내용만 요약합니다.

**⑬ c · 3 · '언제 생긴 QALY를 얼마나 할인하나?'의 '시간 단위' 문단**
- 문제: 개념을 다루는 소제목 안에서 코드 실수 시연이 ICER 9,140만원까지 이어지고, c.5의 함정 목록에서 다시 나옵니다. "두 가지만 봅니다"의 둘째가 개념이 아니라 코드 실수여서, 첫째와 성격이 다릅니다.
- 고칠 방향: 이 시연은 직접 분석 상자로 내리거나 c.5의 함정 목록에 합칩니다. 본문에는 연 단위로 바꿔 넣어야 한다는 것과 12번째 달 계수가 약 0.957인지 점검하는 것만 둡니다.

**⑭ c · 5 · '문헌에서 효용을 가져오면 무엇을 확인하고 적나?' / '계산한 뒤에는 무엇을 확인하나?'**
- 문제: 순서가 응답 자료 경로(코드)에서 문헌 경로로 갔다가 다시 응답 자료 경로의 점검표로 돌아옵니다. 점검표 항목은 모두 응답 자료용이어서, 문헌 소제목을 읽고 온 독자는 어느 경로의 점검인지 되짚게 됩니다.
- 고칠 방향: '계산한 뒤에는 무엇을 확인하나?'를 '응답 자료가 있으면 프로그램에 무엇을 입력하나?' 바로 뒤로 옮기고, 문헌 경로를 그다음에 둡니다.

**⑮ c · 6. 논문에 쓰기 이후의 장 끝 순서 (a·b 절 끝도 같은 꼴)**
- 문제: 세 절을 이은 예문, c 정리, '이 장 한눈에', 23장 연결 문단으로 장을 닫은 뒤에 c의 '스스로 확인하기'와 수식이 다시 시작됩니다. 머리말은 '이 장 한눈에'가 장 끝에 있다고 안내합니다. a·b 절도 다음 절로 넘어가는 연결 문단이 '스스로 확인하기' 앞에 있어서, 독자는 연결을 읽은 뒤 이전 절의 문제로 되돌아갑니다.
- 고칠 방향: 절마다 '정리 → 스스로 확인하기 → 더 알아보기 → 다음 절 연결'의 순서로 둡니다. c 절 뒤에는 장 마무리(이은 예문, 이 장 한눈에, 23장 연결)를 따로 두고, 지침 인용 표는 맨 끝에 둡니다.

### 5. 반복되는 버릇

1. **굵은 첫 문장과 굵은 '즉' 마무리가 같은 말을 합니다.**
   - 예: a.1은 "효용은 … 몇 배 가치인지를 나타내는 숫자"로 열고 "효용은 … 시간에 곱할 수 있게 만든 숫자"로 닫습니다. c.1도 같은 꼴입니다. 반대로 c '사망과 빠진 응답은 어떻게 다루나?'에서는 '즉'이 새 내용을 들여옵니다.
   - 방향: 짧은 소제목에서는 둘 중 하나만 씁니다. 요약에는 새 내용을 넣지 않습니다.

2. **다른 절 안내 괄호가 깁니다. [규칙 때문]**
   - 예: "(b 절의 접힌 상자 '5L로 모은 응답을 3L 값으로 바꿔 써도 되나?')", "(15장 d 절의 접힌 상자 '같은 불균형도 인원에 따라 P가 얼마나 달라지나?')". 소제목 이름을 따옴표째 넣은 괄호가 한 문단에 두세 개씩 들어갑니다.
   - 방향: 논증에 필요한 곳에서만 '(b 절)' 정도로 줄입니다. 위치는 사이트 링크에 맡기고, 안내만 하는 괄호는 뺍니다.

3. **앞 내용을 소제목 이름으로 다시 부릅니다. [규칙 때문]**
   - 예: "'한 설문지에서 어떤 숫자들이 나오나?'의 0.786처럼", "'두 군은 어떻게 비교하나?'에서 구한 시험의 결과를". 같은 절 안의 가까운 내용인데 제목을 다시 읽게 합니다.
   - 방향: 같은 절 안에서는 '앞에서 본 0.786', '이 결과'처럼 지시어로 받습니다.

4. **한 번의 곱셈도 '이름 = 식 = 값' 줄로 떼어 씁니다. [규칙 때문]**
   - 예: a.2는 "2년을 지내면 그 두 배입니다" 직후에 "효용 0.78로 2년 = 2 × 0.78 = 1.56 QALY"를 다시 씁니다. 약 X·Y의 계산은 본문, 같은 문단의 줄, a의 수식 상자까지 세 번 나옵니다.
   - 방향: 한 단계 계산은 문장 안에 씁니다. 줄로 떼는 것은 여러 구간을 더하는 계산에만 씁니다.

5. **인과를 짧은 문장과 번호 목록으로 쪼갭니다. [규칙 때문]**
   - 예: "분석자가 고르는/정하는 것은 셋/넷입니다", "설문은 둘입니다. 하나는 … 다른 하나는 …", "이유는 다음 두 가지입니다" 같은 정형 도입이 반복됩니다. c '두 군은 어떻게 비교하나?'의 1–4, c '기저 효용을 보정하나?'의 1–2, 다중대체의 1–3은 한 줄짜리 인과 사슬인데 목록으로 나뉘었습니다.
   - 방향: '그래서', '이때' 같은 접속어로 두세 문장에 잇습니다. 목록은 서로 나란한 항목에만 씁니다.

6. **'지침은'이 주어인 문장이 연달아 나오고 쪽수가 반복됩니다. [규칙 때문]**
   - 예: b.3 '직접 측정인가, 간접 측정인가?'와 '어떤 도구, 어느 판인가?'에서 "지침은 … 선호합니다(지침 31–32쪽). … 지침은 … 할 수 있다고 합니다. … 요구합니다."가 이어집니다.
   - 방향: '요구·권장·선호' 동사는 그대로 둡니다. 주어는 문단 첫머리에 한 번만 쓰고, 쪽수는 장 끝 지침 표에 맡기거나 문단 끝에 한 번만 적습니다.

7. **"…은 아래 접힌 상자에 있습니다"가 열 곳 넘게 나옵니다.**
   - 예: 상자 제목(질문형)이 바로 아래에 보이는데 안내 문장이 그 질문을 되풀이합니다.
   - 방향: 본문이 상자 없이도 완결되는 곳에서는 안내 문장을 뺍니다.

8. **같은 경고를 여러 번 합니다.**
   - 예: 개념 경고 "판이 다르면 같은 코드도 다른 건강상태"가 b.2부터 c.5까지 일곱 번 나옵니다. 프로그램 경고도 겹칩니다. "전용 함수가 없다"는 머리말 상자, b.2, c.2, c.3, c.5에 나오고, `trapezoid`의 시점 인자, 군집 표준오차, `dtype` 경고도 두세 곳씩 나옵니다.
   - 방향: 개념 경고는 처음 나올 때와 정리에 한 번씩만 둡니다. 프로그램 경고는 c.5와 해당 직접 분석 상자에만 둡니다.

9. **환자 표지 '가·나·다'에 조사가 붙으면 다른 낱말로 읽힙니다.**
   - 예: "환자 가는", "환자 나는", "환자 나가 6개월째에 답한 코드"에서 독자가 멈춥니다.
   - 방향: 조사가 붙어도 낱말이 되지 않는 표지(예: 환자 1·2·3)로 일괄 바꿉니다. 그림 캡션과 코드의 `id`도 함께 바꿉니다.

### 6. 잘 읽히는 곳

- **a · 2 · '한 설문지에서 어떤 숫자들이 나오나?'의 표 뒤 문단("첫 줄은 … 둘째 줄은 … 셋째 줄만 …")**: 표의 실제 숫자 세 개를 한 줄씩 짚은 뒤에야 '가치 세트'라는 용어를 꺼냅니다. 짧은 문장과 긴 문장이 섞여 리듬이 있습니다.
- **b · 1 · 이 개념이 답하는 질문의 약국 비유 문단("약국에서 처방전의 약 이름과 수량을 …")**: 독자에게 익숙한 장면 하나로, 상태를 기술하는 일과 값을 매기는 일의 분리, 그리고 '조사는 한 번, 시험에서는 설문만'이라는 역할 구분을 두 문장에 담았습니다. 괄호 안내도 없습니다.
