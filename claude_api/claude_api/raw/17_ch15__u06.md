### 4. 문단 다시 쓰기

- **위치:** e. 남는 교란과 민감도 분석 · 더 알아보기 (수식으로 보기)의 둘째 식 아래 문단
- **원문 첫 문장:** 이분형 미측정 교란변수가 결과 위험을 두 군에서 똑같이 γ배 높이고 그 비율이 치료군에서 p₁, 비교군에서 p₀일 때의 편향입니다.
- **다시 쓴 문단:**
  교란변수의 세기와 두 군에서의 비율을 알 때, 관찰되는 상대위험도가 참값에서 얼마나 치우치는지 보여 주는 식입니다. 측정하지 않은 교란변수가 이분형이고, 두 군 모두에서 결과 위험을 똑같이 γ배 높인다고 합시다. 그 변수를 가진 환자가 치료군에 p₁, 비교군에 p₀의 비율로 있으면, 관찰되는 상대위험도는 참값에 오른쪽 분수를 곱한 값이 됩니다. 이 분수가 편향 배수입니다. 이 코호트의 허약을 넣어 계산한 예는 '숨은 교란이 얼마나 강해야 결론이 바뀌나?'의 접힌 상자 '허약이 만든 편향은 숫자로 얼마인가?'에 있습니다.
- **무엇을 바꿨나:**
  - 첫 문장에서 식이 무엇을 하는지부터 밝혔습니다. 바로 앞의 E-value 식(필요한 세기)과 달리 이 식은 세기와 비율이 주어졌을 때의 치우침을 계산한다는 점이 드러나, 두 식 사이의 넘어감이 자연스러워집니다.
  - 한 문장에 쌓여 있던 두 조건을 "~라고 합시다"로 풀어 차례로 놓았습니다. "그 비율"은 "그 변수를 가진 환자의 비율"로 바꿨습니다.
  - 식의 분수 부분을 본문과 같은 '편향 배수'라는 이름으로 짚어, 식과 설명이 바로 이어지게 했습니다.
