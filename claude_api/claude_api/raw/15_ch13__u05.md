### 4. 문단 다시 쓰기

- **위치**: d. 숫자로 따라가기 · 비열등성의 P는 어떻게 구하나? (첫째 문단)
- **원문 첫 문장**: b 절처럼 관측 차이가 한계 −10%p에서 표준오차 몇 개만큼 오른쪽에 있는지 잽니다.
- **다시 쓴 문단**:

  비열등성의 P도 b 절처럼, 관측 차이가 한계 −10%p에서 오른쪽으로 표준오차 몇 개만큼 떨어져 있는지로 구합니다. 달라지는 것은 그 표준오차에 넣는 두 비율입니다. P는 귀무가설이 맞다고 놓고 계산하는 확률이므로, Wald 구간처럼 관측 비율을 그대로 넣지 않고 귀무가설에 맞는 비율을 넣습니다. 차이 = 0을 검정할 때 두 군을 합친 비율로 표준오차를 구한 것(5장 a 절)과 같은 이치입니다. 이 검정의 귀무가설이 맞다면 두 제균율은 정확히 10%p 차이가 나야 하므로, 그 조건을 지키는 비율 가운데 관측 자료와 가장 잘 맞는 두 비율, 2제 77.95%와 4제 87.95%로 표준오차를 계산합니다. 이것이 **Farrington–Manning 검정**[196]이고, 논문의 단측 P는 흔히 이 검정으로 구합니다. 이 자료에서는 z = 2.33, 즉 관측 차이가 한계에서 표준오차 2.33개만큼 떨어져 있고, 단측 p = 0.0098입니다.

- **무엇을 바꿨나**: 원문은 주어 없는 '잽니다'로 시작해, 이 문단이 'P 구하는 법'을 다룬다는 것이 소제목에만 기대고 있었습니다. 그래서 첫 문장의 주어를 세웠습니다. '다른 점은 두 비율'에는 바로 위에서 Wald가 관측 비율을 넣었다는 사실을 이어 붙여 무엇과 대비되는지 보이게 했습니다. "귀무가설이 맞다면…/그래서…"와 "이 검정을…이라고 합니다/논문의 단측 P는…"처럼 짧게 끊겨 같은 박자로 이어지던 두 쌍은 각각 한 문장으로 묶어 리듬을 살렸습니다. 숫자, 조건, 인용 번호는 그대로이고 새 내용은 없습니다.
