### 4. 문단 다시 쓰기

- **위치**: d. Kruskal-Wallis test · 3. 가정과 대안 · 언제 다른 방법으로 넘어가나? (모의실험을 따라가는 셋째 문단)
- **원문 첫 문장**: H의 P는 세 군의 분포가 같을 때를 기준으로 계산합니다.
- **다시 쓴 문단**:

  문제는 H의 P가 세 군의 분포가 같다는 가정 아래 계산된다는 데 있습니다. 이 가정에서는 10명 군의 평균 순위가 표본마다 5.9만큼만 흔들린다고 보고 P를 매깁니다. 그런데 이 상황에서 실제 흔들림은 7.6이라, 우연히 흔히 나오는 크기의 H까지 드문 값으로 판정됩니다. 그 결과 모의실험에서 H의 평균은 분포가 같을 때의 2가 아니라 2.8이었고, 5%로 정한 기준에서 12%가 '유의'로 나왔습니다. 거꾸로 인원이 가장 적은 군이 가장 좁게 퍼져 있으면 그 군의 평균 순위가 덜 흔들립니다. 그러면 '유의'가 2.2%로 줄고, 실제 차이가 있을 때 놓치기 쉬워집니다.

- **무엇을 바꿨나**: 둘째 문장은 앞 문단의 '5.9'를 되풀이하는 것처럼 읽혔습니다. 그래서 'P가 가정하는 흔들림'이라는 역할이 드러나게 고쳤습니다. '실제 표준오차가 7.6이면 … 드물다고 판단'은 사이에 빠진 고리(5.9로 보고 P를 매긴다)를 채워, 조건에서 결과로 바로 이어지게 했습니다. 첫 문장은 '문제는 …'으로 열어 앞 문단의 관찰과 이어지게 하고, 마지막 긴 문장은 원인과 결과로 나눠 리듬을 고르게 했습니다.
