### 4. 문단 다시 쓰기

- **위치**: d. 이중차분법 · 스스로 확인하기 3 (답과 풀이)
- **원문 첫 문장 (그대로 옮김)**: (가)는 시행하지 않은 지역이 없으므로 중단시계열분석(b 절)이 기본입니다.
- **다시 쓴 문단**

  (가)는 정책을 시행하지 않은 지역이 없으므로 중단시계열분석(b 절)이 기본입니다. 시행 전 42개월, 시행 후 30개월이라 시점은 충분합니다. 약점은 같은 시기의 다른 변화를 정책의 효과와 구분하지 못한다는 것인데, 이 기간에는 코로나19 유행기의 의료 이용 변화가 겹칩니다. 그래서 변경 대상이 아닌 약이나 집단에서 비교 계열을 찾아 c 절의 분석을 더합니다. 다만 대체 관계에 있는 약은 비교 계열로 쓰지 않습니다.
