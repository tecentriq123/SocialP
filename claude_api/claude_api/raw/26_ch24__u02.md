### 4. 문단 다시 쓰기

- **위치**: b · 3. 가정과 그 영향 · 함께 움직이는 입력값을 따로 뽑으면? (소제목의 첫 문단)
- **원문 첫 문장**: 공통 예시에서 상관을 0으로 두면 버리는 반복이 2.7%에서 9.1%로 늘고, 버려지는 반복이 "진행은 늦고 사망은 빠른" 쪽에 몰려 있어 남은 반복의 분포가 처음 정한 분포에서 멀어집니다.
- **다시 쓴 문단**:

  상관을 주지 않고 따로 뽑으면 무엇이 달라지는지 공통 예시로 봅니다. 상관을 0으로 두면 곡선이 엇갈려 버리는 반복이 2.7%에서 9.1%로 늘어납니다. 버려지는 반복은 "진행은 늦고 사망은 빠른" 쪽에 몰려 있으므로, 이만큼 버리면 남은 반복의 분포가 처음 정한 분포에서 멀어집니다. 엇갈린 반복을 버리지도 않으면 5,000번 가운데 427번에서 무진행생존 곡선이 전체생존 곡선을 넘습니다. 그래도 코드의 장치(23장 c 절 '무진행생존 곡선이 전체생존 곡선을 넘으면?')가 넘어간 부분을 조용히 잘라 내므로 결과는 오류 없이 나옵니다. 이렇게 상관도 다시 뽑기도 없이 구한 비용효과적일 확률은 17.0%로, 상관을 주어 함께 뽑고 엇갈린 반복을 버린 이 장의 확률 16.0%와 1%포인트 다릅니다. 이 차이는 5,000회의 몬테카를로 표준오차 0.5%포인트('모의실험 횟수는 어떻게 정하나?')의 두 배쯤이어서 일부는 난수 때문일 수 있습니다. 그래서 이 예시에서는 뽑는 방법에 따른 차이가 작다고 읽습니다. 다만 차이의 크기는 모형마다 다릅니다.

- **무엇을 바꿨나**:
  1. 문단 첫머리에 무엇을 보여 줄 문단인지 알리는 문장을 두었습니다.
  2. 끝에 따로 떨어져 있던 '몬테카를로 표준오차는 … 구했습니다'를 그 숫자가 처음 나오는 자리의 괄호로 옮겼습니다.
  3. '이렇게 구한'이 어느 설정의 결과인지 밝혔습니다. 또 '두 배쯤 → 난수 때문일 수 있음 → 그래서 작다고 읽음 → 다만 모형마다 다름'으로 근거와 결론을 '그래서', '다만'으로 이어, 짧게 끊긴 네 문장이 한 줄기 추론으로 읽히게 했습니다.
