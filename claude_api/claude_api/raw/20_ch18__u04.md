### 4. 문단 다시 쓰기

- **위치**: c.대조군이 있는 중단시계열 · 2. 예제 자료에서 따라가기 · 비교 지역의 변화를 빼면 왜 참값에 가까워지나? ('비교 계열을 빼면 신뢰구간도 좁아집니다'부터 Durbin–Watson 항목까지)

- **원문 첫 문장**: 비교 계열을 빼면 신뢰구간도 좁아집니다.

- **다시 쓴 문단**:

  비교 지역의 값을 빼면 신뢰구간도 좁아집니다. 수준 변화의 표준오차가 시범 지역의 계열에서는 1.12였는데, 차이의 계열에서는 0.40입니다. 두 계열이 서로 무관하게 오르내린다면, 빼는 계산은 오히려 우연한 변동을 키웁니다. 차이 계열의 잔차는 그 달 시범 지역의 잔차에서 비교 지역의 잔차를 뺀 값이고, 무관한 두 값을 뺀 값의 분산은 두 분산의 합이기 때문입니다(0장 e 절). 이 예의 잔차 표준편차(시범 지역 1.52, 비교 지역 1.37)로 계산하면 √(1.52² + 1.37²) = 2.05입니다. 그런데 두 지역은 계절 변동이나 전국적인 사건을 같은 달에 함께 겪어서, 시범 지역이 직선보다 높은 달에는 비교 지역도 높기 쉽습니다. 두 지역 잔차의 상관계수는 0.83입니다. 이렇게 함께 움직인 부분은 빼는 순간 지워집니다. 그래서 차이 계열의 잔차 표준편차는 2.05는 물론 시범 지역 계열의 1.52보다도 작은 0.84이고, 직선에서 벗어나는 우연한 변동이 작아진 만큼 수준 변화의 표준오차도 작아집니다. 이웃한 달을 닮게 만들던 계절 무늬도 함께 지워져, Durbin–Watson 통계량은 0.95에서 1.76으로 2에 가까워졌습니다.

- **무엇을 바꿨나**:
  - '이유를 단계로 나눠 봅니다'와 다섯 개 항목으로 끊겨 있던 설명을 한 문단으로 이었습니다. 그래서 "무관하면 커진다 → 그런데 함께 움직인다 → 그래서 줄어든다"는 반전이 문장의 흐름으로 드러납니다.
  - 짧은 문장(상관계수 0.83, "빼는 순간 지워집니다")과 긴 설명 문장을 섞어 리듬을 살렸습니다.
  - "0.84로 줄었습니다"가 무엇보다 작은지(2.05와 1.52)를 밝혔습니다. 숫자와 조건, 참조는 모두 그대로 두었습니다.
