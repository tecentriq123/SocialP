### 4. 문단 다시 쓰기

- **위치**: d. 다중회귀분석 · 결과 읽기 · 함께 나온 다른 변수의 계수는 어떻게 읽나? (둘째 문단)
- **원문 첫 문장**: 나이의 계수는 보정 전 +0.22, 보정 후 −0.81 mmHg/10세였습니다.
- **다시 쓴 문단**:

  나이의 계수는 보정 전 +0.22, 보정 후 −0.81 mmHg/10세였고, 보정 후 값은 두 가지 점에서 나이 자체의 관련과 다릅니다. 첫째, 나이가 많은 환자는 기저 SBP가 조금 높았고(10세당 평균 2.7 mmHg) 기저 SBP가 높으면 6개월 SBP도 높은데, 보정 모형은 기저 SBP가 같은 환자끼리 비교합니다. 그래서 나이의 보정 계수에는 '나이 → 기저 SBP → 6개월 SBP'로 이어지는 부분이 빠져 있습니다. 둘째, 모형의 변수는 계열 수의 교란변수로 고른 것이라, 나이와 혈압의 관련을 공정하게 비교하는 데 필요한 변수가 다 들어 있다는 보장이 없습니다. **따라서 −0.81을 "나이가 많을수록 6개월 혈압이 낮다"는 나이의 효과로 읽으면 안 됩니다.**

- **무엇을 바꿨나**:
  - 원문은 숫자를 보인 뒤 짧은 문장 여섯 개가 '높았고 → 높습니다 → 그런데 → 그래서 → 또 → 그래서'로 이어집니다. 그래서 독자는 끝까지 읽고 나서야 이 문단이 '두 가지 이유'를 말한다는 것을 알게 됩니다.
  - 첫 문장에 '두 가지 점'을 예고하고 첫째·둘째로 나란히 세웠습니다. 첫째 이유의 인과 사슬은 한 문장으로 묶어 긴 문장과 짧은 문장이 섞이게 했습니다.
  - 마지막 굵은 문장의 '그래서'는 '따라서'로 바꿔 '그래서'가 두 번 나오지 않게 했습니다. 숫자, 조건, 단정의 강도는 그대로 두었습니다.
