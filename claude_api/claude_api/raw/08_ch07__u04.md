  **중도절단 표시(+ 또는 \|).** 곡선 위의 작은 세로 눈금 하나가 중도절단된 환자 한 명입니다. 이 그림에서는 눈금이 24개월 이후에 몰려 있는데, 이는 자료 마감일 때문입니다. 이 코호트는 2016–2020년에 환자를 등록하고 2022년 말에 자료를 마감했습니다. 그래서 마감일까지 살아 있던 환자는 늦게 등록했을수록 일찍, 일찍 등록했을수록 늦게 중도절단됩니다. 그 시점은 24개월(2020년 말 등록)에서 84개월(2016년 초 등록) 사이에 놓입니다. 오른쪽 끝의 눈금이 일찍 등록해 오래 추적된 생존자인 것도 이 때문입니다. 눈금이 이렇게 뒤로 몰리는 것은 정상적인 모습입니다. 눈여겨볼 곳은 자료 마감으로는 중도절단이 생길 수 없는 24개월 전입니다. 이 초반에 눈금이 촘촘하다면 추적 소실이 많다는 뜻이므로 a 절의 비정보적 중도절단 가정을 떠올립니다.
