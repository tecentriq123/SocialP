### 4. 문단 다시 쓰기

- **위치**: b. 중단시계열분석 · 5. 논문에 쓰기 · 예문 해설 ④ 계절의 처리
- **원문 첫 문장**: 이 장은 계수 읽기 연습을 위해 계절 항이 없는 모형을 기본으로 두었으므로 계절 항 모형을 민감도 분석으로 썼습니다.
- **다시 쓴 문단**:

  ④ **계절의 처리.** 이 예문은 계절 항을 넣은 모형을 민감도 분석으로 두었습니다. 이 장이 계수 읽기 연습을 위해 계절 항이 없는 모형을 기본으로 삼았기 때문입니다. 두 지역이 함께 겪는 계절 변동은 c 절의 차이 계열에서 상당 부분 지워지기도 합니다. 내 연구에서 계절 무늬가 뚜렷한 단일 계열로 효과를 추정한다면, 계절 항을 넣은 모형을 주 분석으로 삼고 Methods에 그렇게 밝힙니다.

- **무엇을 바꿨나**:
  - 원문은 교재 사정(계수 읽기 연습), c 절의 사실, 일반 원칙이 이어지는 말 없이 연달아 나옵니다. 그래서 b 절 '흔한 함정'의 '실제 연구에서는 계절 항 모형을 주 분석으로 삼는다'와 어긋나 보였습니다. 이를 '예문이 한 일 → 그 이유 → 덧붙는 사실 → 내 연구에서 할 일' 순서로 놓아, 앞의 둘은 이 예문의 사정이고 마지막이 독자가 따를 원칙임을 드러냈습니다.
  - 긴 첫 문장을 두 문장으로 나눴습니다. '주 분석'이 계열과 모형을 번갈아 가리키던 마지막 문장은 '단일 계열로 효과를 추정한다면'으로 풀었습니다.
  - c 절 문장은 원문처럼 이유가 아닌 덧붙는 사실('~기도 합니다')로 두어 인과를 새로 만들지 않았습니다.
