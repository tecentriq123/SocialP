### 4. 문단 다시 쓰기

- **위치**
  c 절 · 6. 논문에 쓰기 · 정리 바로 앞, 세 절의 예문을 잇는 안내 문단

- **원문 첫 문장 (그대로 옮김)**
  **세 절의 예문을 이으면 경제성 평가 논문의 Methods 첫머리와 Discussion의 앞부분이 됩니다.**

- **다시 쓴 문단**
  **세 절의 예문을 이으면 경제성 평가 논문의 Methods 첫머리와 Discussion의 앞부분이 됩니다.** Methods는 a 절 예문으로 시작합니다. 그 뒤로 20–24장의 Methods 예문이 분석의 틀, 모형 구조, 비용과 효용, 불확실성 분석의 순서로 이어지고, Results 문장이 그다음에 옵니다. Discussion의 앞부분은 세 문단입니다. b 절 예문이 첫 문단이고, b 절 'Discussion과 재원은 어떻게 읽나?'에서 읽은 한계 문단이 둘째 문단, 이 절의 예문이 셋째 문단입니다. 재원과 이해상충은 논문 끝에 적습니다. 아래는 이 가운데 세 절의 예문만 표식 없이 이어 붙인 것이어서, 20–24장의 예문과 한계 문단은 빠져 있습니다.

- **무엇을 바꿨나**
  원문은 Methods 순서와 Discussion 순서를 각각 긴 문장 하나에 넣고, 문단 위치를 "(첫 문단)", "(둘째 문단)" 같은 괄호로 달았습니다. 이를 "~이 첫 문단입니다"처럼 서술어로 풀어, 짧은 문장과 중간 길이 문장이 번갈아 나오게 했습니다. 끝 문장에서는 아래 상자에 무엇이 빠졌는지 밝혔습니다. 그래서 독자가 상자의 둘째 문단에서 한계 문단을 찾다가 앞으로 돌아가지 않습니다.
