### 3. 문장 수정표

| 위치(절·소제목) | 원문 | 문제 | 수정안 | 의미 변경 |
|---|---|---|---|---|
| c 절 · 5% 약속은 무엇에 대한 것인가? | b 절에서 본 1종 오류, 즉 효과가 없는 약을 효과가 있다고 잘못 결론 내릴 확률이 검정 한 번마다 5%라는 약속입니다. | '1종 오류'와 그 풀이가 주어 앞에 길게 쌓여 있습니다. 그래서 '약속입니다'에 닿아야 문장 구조가 잡힙니다. | 검정 한 번마다 1종 오류, 곧 효과가 없는 약을 효과가 있다고 잘못 결론 내릴 확률을 5%로 묶는 약속입니다(b 절). | 없음 |
| c 절 · 5% 약속은 무엇에 대한 것인가? | 그런데 이 약속은 검정 한 번에 대한 것이라, 한 연구에서 검정을 여러 번 하면 연구 전체로는 지켜지지 않습니다. 효과가 없는 결과마다 검정이 5%씩 우연에 속을 수 있으므로, 여러 검정 가운데 어느 하나에서라도 속을 확률은 5%보다 커지기 때문입니다. | 바로 위 굵은 요약 문장을 거의 그대로 되풀이합니다. 결론을 말한 뒤 이유를 대며 한 번 더 돌아서, 세 문장 연속 '검정 한 번'이 나옵니다. | 그런데 효과가 없는 결과마다 5%씩 우연에 속을 수 있으므로, 한 연구에서 검정을 여러 번 하면 연구 전체로는 이 약속이 지켜지지 않습니다. | '하나라도 속을 확률은 5%보다 커진다'는 내용은 절 첫머리 굵은 문장에 그대로 남습니다. |
| c 절 · 접힌 상자 '왜 하필 5%인가?' | 분야에 따라 기준이 다르기도 해서, 유전체 연관분석은 5 × 10⁻⁸을 쓰고, 재현성 문제를 이유로 새로운 발견의 기준을 0.005로 낮추자는 제안도 있습니다[10]. | '~해서'로 묶었지만 0.005 제안은 분야 차이에서 나온 결과가 아닙니다. 쉼표 셋으로 이어져 다시 읽게 됩니다. | 기준은 분야에 따라 다르기도 해서, 유전체 연관분석은 5 × 10⁻⁸을 씁니다. 재현성 문제를 이유로 새로운 발견의 기준을 0.005로 낮추자는 제안도 있습니다[10]. | 없음 |
| c 절 · 검정을 여러 번 하면 무엇이 문제인가? | 복권을 20장 사면 한 장만 살 때보다 당첨 확률이 올라가는 것과 같습니다. | 무엇이 복권과 같은지 주어가 없습니다. 소제목 질문 바로 뒤라 독자가 '무엇이 같다는 건지'에서 멈춥니다. | 검정을 여러 번 하는 것은 복권을 여러 장 사는 것과 같습니다. 20장을 사면 한 장만 살 때보다 당첨 확률이 올라갑니다. | 없음 |
| c 절 · 검정을 여러 번 하면 무엇이 문제인가? | 신약에 효과가 전혀 없어도 20 × 0.05 = 1이므로 평균 1개는 우연히 '유의'하게 나옵니다. | 왜 20에 0.05를 곱하는지(결과변수마다 5%)가 빠져 있고, 식이 문장 가운데에 끼어 있습니다. | 신약에 효과가 전혀 없어도 결과변수마다 5%씩 우연히 '유의'할 수 있으므로, 20개 가운데 평균 1개(20 × 0.05)는 '유의'하게 나옵니다. | 없음 |
| c 절 · 검정을 여러 번 하면 무엇이 문제인가? | 이런 우연한 '유의'를 걸러 내려고 검정 하나하나의 기준을 엄격하게 조정하는 방법이 **다중비교 보정**(adjustment for multiple comparisons)입니다. | 새 용어 앞에 꾸밈말이 길게 쌓여 용어가 문장 끝에서야 나옵니다. | 이런 우연한 '유의'를 걸러 내려면 검정 하나하나의 기준을 더 엄격하게 조정합니다. 이것을 **다중비교 보정**(adjustment for multiple comparisons)이라고 합니다. | 없음 |
| c 절 · 논문에서는 언제 검정을 여러 번 하나? | 연구가 답하려고 미리 하나로 정한 1차 결과변수(primary outcome) 말고, 함께 보는 2차 결과변수(secondary outcomes)가 여러 개인 경우 | b 절에서 정의한 1차 결과변수를 목록 한 줄 안에서 다시 풀어, 항목이 길고 무거워졌습니다. | 1차 결과변수(primary outcome) 말고 함께 보는 2차 결과변수(secondary outcomes)가 여러 개인 경우 | 1차 결과변수의 풀이를 뺐습니다. 풀이는 b 절 '논문에 쓰기' 1번에 남아 있습니다. |
| c 절 · 접힌 상자 '내 연구에서 '여러 번'은 무엇을 세나?' | 다중성을 따질 때는 '그 가운데 하나라도 유의하면 효과가 있다고 말할' 검정들을 한 묶음으로 셉니다. | '다중성'은 '4. 논문에서 읽기'에서야 정의되는데 여기서 먼저 쓰입니다. 또 '그 가운데'가 가리킬 대상이 앞에 없습니다. | 다중성, 곧 검정을 여러 번 한 데서 오는 문제를 따질 때는, 하나라도 유의하면 효과가 있다고 말할 검정들을 한 묶음으로 셉니다. | 없음 |
| c 절 · 접힌 상자 '내 연구에서 '여러 번'은 무엇을 세나?' | 민감도 분석 가운데 하나라도 유의하면 효과가 있다고 말하는 것이 아니므로, 시도를 늘릴수록 우연한 '유의'가 늘어나는 문제가 생기지 않습니다. | 부정이 '아니므로'에 와서야 드러나, 처음에는 '하나라도 유의하면 효과가 있다'는 긍정으로 읽힙니다. | 민감도 분석은 그 가운데 하나만 유의해도 효과가 있다고 말하는 분석이 아닙니다. 그래서 시도를 늘려도 우연한 '유의'가 늘어나는 문제가 생기지 않습니다. | 없음 |
| c 절 · 접힌 상자 '내 연구에서 '여러 번'은 무엇을 세나?' | 묶음의 범위는 프로그램이 알 수 없으므로 분석 계획서에 미리 적습니다. | 상자 전체를 맺는 문장인데 Table 1 기저특성 이야기 끝에 붙어 있습니다. 화제가 갑자기 바뀌고 앞 문장의 일부처럼 읽힙니다. | (따로 한 문단으로 떼어) 어떤 검정을 한 묶음으로 셀지는 프로그램이 알 수 없으므로, 분석 계획서에 미리 적습니다. | 없음 |
| c 절 · 검정을 열 번 하면 우연한 '유의'는 얼마나 늘어나나? | 효과가 없는 약으로 검정을 10번 하고, 검정들이 서로 독립, 즉 한 검정의 결과가 다른 검정의 결과에 영향을 주지 않는다고 합시다. | 장면 설정과 '독립'의 풀이가 한 문장에 겹쳐, '즉…' 삽입구를 지나야 '합시다'에 닿습니다. | 효과가 없는 약으로 검정을 10번 한다고 합시다. 검정들은 서로 독립, 곧 한 검정의 결과가 다른 검정의 결과에 영향을 주지 않는다고 봅니다. | 없음 |
| c 절 · 검정을 열 번 하면 우연한 '유의'는 얼마나 늘어나나? | 그래서 검정 10개면 우연한 '유의'가 하나라도 나올 확률이 5%가 아니라 40%입니다. 검정들이 서로 독립이라는 같은 가정에서 '검정을 여러 번 하면 무엇이 문제인가?'의 혈압 시험처럼 결과변수 20개를 검정하면 64%로 커집니다. | 첫 문장은 바로 위 단계와 굵은 요약에 나온 40%를 다시 말합니다. 둘째 문장은 긴 소제목 인용이 가운데 끼어 '64%'까지 멉니다. | 같은 가정에서 검정 수를 늘리면 이 확률은 더 커져, 앞의 혈압 시험처럼 결과변수 20개를 검정하면 64%가 됩니다. | 40%를 되풀이한 문장을 지웠습니다. 40%는 '적어도 하나가 유의할 확률' 단계와 '2. 숫자로 따라가기'의 굵은 문장에 남아 있습니다. |
| c 절 · 보정은 어떤 생각으로 하나? | 어느 임상시험이 미리 정한 2차 결과변수 5개에서 얻은 원래 p값에 대표적인 보정 세 가지를 적용하면 다음과 같습니다. | '어느 임상시험이 미리 정한 2차 결과변수 5개에서 얻은'이 'p값' 앞에 쌓여 있습니다. 새 예를 꺼내는 장면과 표 안내가 한 문장에 겹칩니다. | 어느 임상시험이 2차 결과변수 5개를 미리 정해 두고 원래 p값 다섯 개를 얻었다고 합시다. 이 p값에 대표적인 보정 세 가지를 적용하면 다음과 같습니다. | 없음 |
| c 절 · Bonferroni 보정은 무엇인가? | 검정의 수를 k로 적으면 기준을 α/k로 낮추는 방법입니다. | 주어가 없어 무엇이 '방법'인지 다시 찾게 됩니다. 앞 문장을 일반식으로 바꿔 말한다는 연결도 없습니다. | 일반적으로 검정이 k개이면 기준을 α/k로 낮춥니다. | 없음 |
| c 절 · Bonferroni 보정은 무엇인가? | 그래서 다섯 결과 가운데 입원 하나만 유의합니다. | 바로 앞 '그래서 가족단위 오류율이…'에 '그래서'가 거듭됩니다. 또 이 결과는 가족단위 오류율이 아니라 표의 곱한 값에서 나옵니다. | 이 기준으로 보면 다섯 결과 가운데 입원 하나만 유의합니다. | 없음 |
| c 절 · Holm과 Benjamini-Hochberg는 Bonferroni와 무엇이 다른가? | 유의하다고 고른 결과 20개에 가짜가 1개쯤 섞이는 것은 받아들이는 대신, 진짜 효과를 덜 놓치는 방식입니다. | 주어가 빠져 있어 바로 앞 문장의 '거짓발견율'이 주어처럼 읽힙니다. | BH는 유의하다고 고른 결과 20개에 가짜가 1개쯤 섞이는 것을 받아들이는 대신, 진짜 효과를 덜 놓칩니다. | 없음 |
| c 절 · 접힌 상자 '프로그램으로 보정할 때 무엇을 지정하나?' | 그래서 Methods에 쓴 방법과 프로그램의 `method`가 같은지 확인합니다. | '그래서'가 '값이 조금 작게 나온다'에 이어져 연결이 어긋납니다. 확인해야 하는 이유는 기본값이 Holm이 아니라는 점입니다. | 기본값이 Holm이 아니므로, Methods에 쓴 방법과 프로그램의 `method`가 같은지 확인합니다. | 없음 |
| c 절 · 여러 결과 가운데 하나만 유의했다면? | '검정을 여러 번 하면 무엇이 문제인가?'의 결과변수 20개처럼 검정이 많으면 효과가 없어도 하나쯤은 유의하게 나오기 때문입니다. | 긴 소제목 인용이 문장 머리를 차지해, 이유의 핵심이 뒤로 밀립니다. | 앞의 결과변수 20개 예처럼, 검정이 많으면 효과가 없어도 하나쯤은 유의하게 나오기 때문입니다. | 없음 |
| c 절 · 보정 방법은 무엇으로 고르나? | 효과를 입증하려는 **확증적 분석**(confirmatory analysis)에서는 효과가 없는 비교를 하나라도 유의하다고 잘못 판단할 확률(가족단위 오류율)을 5% 이하로 묶습니다. | 이미 여러 번 나온 가족단위 오류율을 긴 꾸밈말로 다시 풀어, '5% 이하로 묶는다'가 멀어졌습니다. | 효과를 입증하려는 **확증적 분석**(confirmatory analysis)에서는 가족단위 오류율을 5% 이하로 묶습니다. | 괄호 속 풀이를 뺐습니다. 정의는 '숫자로 따라가기'와 바로 앞 BH 설명에 남아 있습니다. |
| c 절 · 보정 방법은 무엇으로 고르나? | 수백 개의 약물–이상반응 쌍을 훑어 따로 확인할 후보를 고르는 **탐색적 분석**(exploratory analysis)에서는 가짜가 조금 섞여도 뒤에 다시 확인하면 되므로, 거짓발견율을 통제하는 BH를 씁니다. | 새 용어 앞에 꾸밈말이 길고, 정의·이유·결론이 한 문장에 몰려 있습니다. | **탐색적 분석**(exploratory analysis)은 수백 개의 약물–이상반응 쌍을 훑어 따로 확인할 후보를 고릅니다. 가짜가 조금 섞여도 뒤에 다시 확인하면 되므로, 이때는 거짓발견율을 통제하는 BH를 씁니다. | 없음 |
| c 절 · 접힌 상자 '보정은 항상 해야 하나?' | Rothman은 탐색적 역학연구에서 보정은 1종 오류를 줄이는 대신 2종 오류를 키워 실제 연관을 놓치게 만들고, 검정 결과의 해석이 '몇 개를 함께 검정했는가'라는 임의적인 요소에 좌우된다고 지적했습니다[14]. | 주어 'Rothman은'과 서술어 '지적했습니다' 사이에 주장 두 개가 들어 있어, 끝까지 읽은 뒤 다시 나눠 읽게 됩니다. | Rothman은 두 가지를 지적했습니다[14]. 탐색적 역학연구에서 보정은 1종 오류를 줄이는 대신 2종 오류를 키워 실제 연관을 놓치게 만듭니다. 또 검정 결과의 해석이 '몇 개를 함께 검정했는가'라는 임의적인 요소에 좌우됩니다. | 없음 |

### 4. 문단 다시 쓰기

- **위치:** c 절 · 2. 숫자로 따라가기 › Holm과 Benjamini-Hochberg는 Bonferroni와 무엇이 다른가? (첫 문단)
- **원문 첫 문장:** **Holm 보정**은 p값을 작은 순서로 세운 뒤 곱하는 수를 하나씩 줄여 갑니다.
- **다시 쓴 문단:**

  **Holm 보정**은 p값을 작은 순서로 세운 뒤, 곱하는 수를 하나씩 줄여 갑니다. 표에서 가장 작은 입원의 p에는 Bonferroni처럼 5를 곱합니다. 곱한 값이 기준을 통과하면 입원은 효과가 있다고 보고 빼 둡니다. 그러면 아직 '효과 없음'일 수 있는 결과는 많아야 남은 4개입니다. 그러니 두 번째인 응급실 방문의 p에는 4만 곱해도, 남은 결과 가운데 하나라도 우연히 속을 확률이 5%를 넘지 않습니다. 이렇게 앞의 검정이 통과할 때마다 남은 검정의 수만큼만 기준을 엄격하게 적용합니다. 이 설명은 첫 결과가 진짜 효과인 경우만 따진 것입니다. 하지만 첫 결과가 우연히 통과한 경우까지 합쳐 따져도 5%를 넘지 않는다는 것이 Holm의 증명입니다. 그래서 가족단위 오류율은 Bonferroni와 똑같이 5%로 묶으면서도, 유의하다고 찾아내는 결과는 늘 Bonferroni와 같거나 많습니다[12].

- **무엇을 바꿨나:**
  - 절차 설명을 바로 위 표의 행(입원, 응급실 방문)에 붙여, '이 결과', '두 번째 p'가 무엇인지 표를 보며 따라가게 했습니다.
  - 원문은 절차 설명 가운데에 단서 두 문장이 끼어 있어, 그 뒤 '이렇게'가 무엇을 가리키는지 흐려졌습니다. 그래서 절차를 먼저 맺고, 단서는 결론 바로 앞에서 '하지만'으로 이어 덧붙였습니다.
  - '4만 곱해도 하나라도'처럼 조사가 겹친 대목을 '남은 결과 가운데 하나라도'로 풀었습니다.
