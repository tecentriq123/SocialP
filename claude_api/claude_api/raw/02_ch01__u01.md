### 4. 문단 다시 쓰기

- **위치**: a. 자료의 분류 · 2. 예로 따라가기 › ③ 종류마다 무엇으로 요약하고 분석하나?
- **원문 첫 문장**: 치우친 연속형 줄에서 분석 칸이 둘로 나뉜 것은 요약과 검정이 서로 다른 것을 다루기 때문입니다.
- **다시 쓴 문단**:

  치우친 연속형 줄에서 분석 칸이 둘로 나뉜 것은 요약과 검정이 서로 다른 것을 다루기 때문입니다. 요약은 환자 한 명 한 명의 값이 어떻게 흩어졌는지 보여 주므로 자료의 모양에 맞춰 고릅니다. 검정은 사정이 다릅니다. 검정이 비교하는 것은 두 군의 평균처럼 군 전체를 나타내는 값 하나입니다. 그래서 t 검정이 p값을 계산할 때 쓰는 것도 환자 값의 모양이 아니라, 같은 연구를 되풀이할 때 평균이 흩어지는 모양입니다(0장 d 절). 그리고 치우침에 비해 표본이 충분히 크면, 자료가 치우쳐도 평균은 종 모양에 가깝게 흩어집니다(f 절). 그러니 자료가 치우쳤다는 것만으로 비교 방법이 정해지지는 않고, 무엇을 비교할지는 질문이 정합니다. '평균 비용이 다른가'를 묻는다면 평균을, '한쪽 값이 더 큰 경향인가'를 묻는다면 순위를 비교합니다(g 절). 질문에 따라 방법을 고르는 표는 h 절의 '정규분포가 아니면 무엇을 고르나?'에 모았습니다.

- **무엇을 바꿨나**:
  - 따로 놓여 있던 '검정' 문장들을 "검정은 사정이 다릅니다"로 요약과 대비시킨 뒤 한 흐름으로 묶었습니다.
  - 원문의 '그래서'는 '평균이 종 모양으로 흩어진다'에서 곧바로 '순위로 비교한다'까지 건너뛰었습니다. 그 사이에 '치우침만으로는 정해지지 않고 질문이 정한다'는 한 단계를 넣었습니다. 이 단계는 바로 뒤 굵은 요약 문장에 이미 있는 내용입니다.
  - '치우침에 비해 표본이 충분히 크면'이라는 조건과 참조 위치는 그대로 두었습니다. 마지막 안내는 그 자리에 무엇이 있는지 알 수 있게 '방법을 고르는 표'로 바꿨습니다.
