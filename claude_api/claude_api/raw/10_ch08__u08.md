### 4. 문단 다시 쓰기

- **위치**
  g. 가변수의 설정 · 나이 같은 연속형 교란변수를 범주로 넣으면 무엇이 남나? (둘째 문단)

- **원문 첫 문장 (그대로 옮김)**
  이 코호트의 의료급여 수급자는 평균 68.0세로, 비수급자 평균 78.0세보다 10세 젊습니다(이 차이가 단변수 분석에 미치는 영향은 h 절).

- **다시 쓴 문단**
  출발점은 의료급여 수급자가 더 젊다는 사실입니다. 이 코호트에서 수급자는 평균 68.0세로 비수급자 78.0세보다 10세 젊고(이 차이가 단변수 분석에 미치는 영향은 h 절), 이 차이는 같은 나이 범주 안에서도 보입니다. 65–74세 범주에서 수급자는 평균 67.1세, 비수급자는 70.8세로 3.7세 차이가 납니다. 그런데 나이를 범주로 넣으면 모형은 같은 범주 안의 환자를 모두 같은 나이로 보므로, 이 3.7세 차이는 보정되지 않은 채 남습니다. 나이가 많을수록 재입원이 많으니(10세당 OR 1.82), 같은 범주 안에서 더 젊은 수급자는 그만큼 재입원 위험이 낮습니다. 보정되지 못한 이 낮은 위험이 의료급여의 높은 위험을 일부 가리고, 그래서 의료급여의 OR이 2.66에서 2.14로, 곧 1 쪽으로 갑니다.

- **무엇을 바꿨나**
  - 첫 문장에서 이 문단이 무엇에서 출발하는지 먼저 알렸습니다. '같은 범주 안에서도'로 앞뒤 숫자를 이어, 10세 차이가 왜 범주 안의 3.7세 이야기로 넘어가는지 짚었습니다.
  - 원문은 '~봅니다. 그래서 ~보정되지 않습니다.'처럼 짧게 끊긴 인과 사슬이었습니다. 이를 '~보므로', '~많으니'로 이어 한 흐름으로 읽히게 했고, 두 번 나오던 '보정되지 않는다'는 한 번으로 줄였습니다.
  - 끝에서 앞 문단의 2.66 → 2.14를 다시 불러, '1 쪽으로 간다'는 결론이 무슨 숫자를 가리키는지 앞으로 돌아가지 않아도 알게 했습니다.
